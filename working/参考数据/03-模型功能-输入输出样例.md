# 03 — 四个模型功能：输入 / 输出样例

> 四个功能：**匹配 Match**、**推荐 Recommendation**、**优化 Optimization**、**对比 Compare**。
> 所有响应均为统一包装 `{code, message, data}`，本节样例中的 `data` 即业务对象。
> `generated_by` / `agent_status` / `fallback_reason` / `error_code` 枚举值见文末附录。

---

## 1. 岗位匹配 Match

### 1.1 请求

```
POST /api/jobs/101/match
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "resume_id": 1,
  "generation_tier": "fast"
}
```

- `job_id` 在路径中；`resume_id` / `generation_tier` 在 body（body 可为空，`generation_tier` 默认 `fast`）。

## 3. 简历优化 Optimization（V2）

### 3.1 请求

```
POST /api/resumes/1/optimization
Authorization: Bearer <token>
```

```json
{
  "optimization_mode": "target_job",
  "job_id": 101,
  "generation_tier": "fast"
}
```

- `optimization_mode` ∈ `general`（默认）/ `target_direction` / `target_job`。
- `target_direction` 模式需传 `target_direction`；`target_job` 模式需传 `job_id`。

## 4. 版本对比 Compare（V2）

### 4.1 请求

```
POST /api/resumes/compare
Authorization: Bearer <token>
```

```json
{
  "from_resume_id": 1,
  "to_resume_id": 2,
  "comparison_mode": "general",
  "generation_tier": "fast"
}
```

- `comparison_mode` ∈ `general`（默认）/ `target_direction` / `target_job`。
- `target_direction` 模式需传 `target_direction`；`target_job` 模式需传 `job_id`。

## 附录：统一枚举值（迁移契约，必须一致）

| 字段 | 取值 |
|---|---|
| `generation_tier` | `fast` / `quality`（`deep` 归一化为 `quality`） |
| `generated_by` | `llm_agent` / `mock_agent` / `deep_fallback_agent` / `mock_quality`（旧） |
| `agent_status` | `success` / `repaired` / `fallback` / `mock_success` / `error` |
| `fallback_reason` | `none` / `llm_disabled` / `llm_error` / `llm_timeout` / `json_parse_failed` / `json_repair_failed` / `schema_invalid` / `pipeline_error` / `llm_api_key_missing` / `llm_auth_failed` / `deep_cascade_failed` / `quality_exhausted` / ... |
| `error_code` | `none` / `LLM_DISABLED` / `LLM_TIMEOUT` / `JSON_PARSE_FAILED` / `SCHEMA_INVALID` / `PIPELINE_ERROR` / `MOCK_FALLBACK_USED` / ... |
| `screening_result`（Match） | `pass` / `weak_match` / `mismatch` / `downgrade` |
| `match_level` / `optimization_level` / `compare_level` | `A` / `B` / `C` / `D` |
| `apply_readiness` | `ready` / `prepare_first` / `cautious_try` / `not_recommended` |
| `optimization_mode` | `general` / `target_direction` / `target_job` |
| `comparison_mode` | `general` / `target_direction` / `target_job` |

> 完整枚举常量见旧代码 `model/agent_response.go`、`model/generation_tier.go`、`model/resume_profile.go`，迁移时以本附录 + 源码为准。
