## 4. 关键字段映射提示（旧 `model` → 新系统）

- `Job` 的 JSON 字段（`ResponsibilitiesJSON` / `MustHaveJSON` / `SkillsJSON` 等）在旧系统里以 `[]byte` 存 DB，API 返回时反序列化为数组；GoFrame 迁移建议用 `gjson` / 结构体切片直存。
- `Resume` 的 7 个子表（`educations`/`projects`/`internships`/`language_exams`/`certificates`/`awards`/`works`）在 `ResumeRelationalRequest` 里是内嵌数组，创建/更新时整体提交。
- 岗位与简历的关联：匹配/推荐/优化均以 `resume_id` + `job_id`（或 `job_id` 可选）为输入，见 `03-模型功能-输入输出样例.md`。
