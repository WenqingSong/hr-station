# 01 — 现有接口清单

> 来源：`server/internal/http/router.go` + `resume_handler.go` 的 dispatcher + `dispatchJobWildcard`。
> 统计口径：唯一 URL 路径 **28 个**；URL + Method 组合 **33 个**。
> 未计入非业务入口：`/swagger/doc.json`、`/swagger/`、`/`（前端反代）。

统一响应包装（所有接口一致）：

```json
{ "code": 0, "message": "ok", "data": { } }
```

- 成功：`code = 0`，`message = "ok"`
- 失败：`code = 业务码`（400xx 通用 / 410xx Auth / 420xx Resume / 430xx Job），`message = 错误文案`

## 2. 认证 Auth

| Method | Path | 鉴权 | 请求 | 响应 data |
|---|---|---|---|---|
| POST | `/api/auth/register` | 公开 | `{phone, password}` | `{token, user}` |
| POST | `/api/auth/login` | 公开 | `{phone, password}` | `{token, user}` |
| GET | `/api/auth/me` | ✅ | — | `user` |
| POST | `/api/auth/logout` | ✅ | — | 登出结果 |

- 登录/注册返回 `AuthTokenResponse{token, user}`。
- 会话顶替：换设备登录 → 旧 token 返回 401「账号已在其他设备登录」。

## 8. 匹配 Match

| Method | Path | 鉴权 | 说明 |
|---|---|---|---|
| POST | `/api/jobs/{id}/match` | ✅（内联） | 生成匹配分析（body `MatchRequest`） |

> ⚠️ `/api/jobs/{id}/match` 系列**不走 `AuthMiddleware`**，而是在 `dispatchJobWildcard` 内**内联手动解析 token**。GoFrame 重构时应统一为路由组中间件鉴权。
