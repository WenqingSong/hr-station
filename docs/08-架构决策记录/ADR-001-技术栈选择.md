# ADR-001 技术栈选择

## 当前状态

已决策

## 决策

### 前端

- **React 18 + Vite + TypeScript**：项目已有 Figma Make 生成的 React 代码，沿用现有技术栈
- **TailwindCSS**：与 shadcn/ui 配合良好
- **react-router v7**：已安装，后续接入实现真实路由

### 后端

- **Go + Gin**：性能好、部署简单、适合 API 服务
- **GORM**：Go 主流 ORM，与 MySQL 配合成熟

### 数据库

- **MySQL 8.0**：关系型数据，适合简历和岗位的结构化存储
- **Redis 7**：缓存和 Session 存储

### AI

- **先 Mock 后接模型**：前期用硬编码/规则引擎，后续接入 LLM

## 原因

1. 前端已有 React 代码基础，切换框架成本高
2. Go 性能好、编译快、部署简单
3. MySQL 生态成熟，适合结构化数据
4. 先 Mock 保证产品闭环，降低不确定性
