# ADR-004 不自动生成简历

## 当前状态

已决策

## 决策

系统不提供自动生成或重写优化版简历的功能。系统只给出匹配分析与优化建议，用户根据建议手动修改简历后添加新版本。

## 原因

1. **保证求职真实性**：AI 生成的简历可能虚构或夸大经历，违反求职诚信原则
2. **避免 AI 虚构经历**：AI 可能生成看似合理但实际不存在的经历描述，误导招聘方
3. **培养用户能力**：让用户理解如何优化表达，而非依赖 AI 代写
4. **降低法律风险**：AI 代写简历可能涉及虚假陈述的法律风险

## 系统行为边界

| 行为 | 是否允许 |
|------|---------|
| 指出简历中模糊/空洞的描述 | ✅ 允许 |
| 建议如何更具体地描述经历 | ✅ 允许 |
| 提供表达优化方向 | ✅ 允许 |
| 直接生成优化版简历文本 | ❌ 不允许 |
| 替用户编造或润色不存在的经历 | ❌ 不允许 |

## 实现影响

- 匹配分析结果中只给建议，不给出改写后的文本
- 优化建议需要具体到原文位置，便于用户定位和修改
- 版本对比需展示用户手动修改的内容，而非 AI 生成的内容
