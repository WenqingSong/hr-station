# ADR-003 先 Mock 后接模型

## 当前状态

已决策

## 决策

AI Agent 能力采用"先 Mock 后接模型"策略：

1. **阶段 1（当前）**：使用 Mock Agent，基于硬编码数据和规则引擎返回结果
2. **阶段 2**：接入真实 LLM，替换 Mock 实现
3. **阶段 3**：Prompt 调优和性能优化

## 原因

1. **降低不确定性**：先跑通完整产品闭环，确认产品逻辑正确，再接入模型
2. **保证 Demo 可演示**：Mock Agent 返回结果稳定可控，演示不会因模型输出不稳定而出问题
3. **解耦开发**：前后端和 Agent 可以并行开发，不被模型接入阻塞
4. **成本控制**：前期不需要消耗 LLM API 费用

## Mock Agent 实现方式

| Agent | Mock 策略 |
|-------|----------|
| 简历提取 Agent | 基于关键词匹配提取技能标签，预定义表达风险模式 |
| 岗位推荐 Agent | 基于技能关键词匹配岗位，固定推荐等级 |
| 岗位匹配 Agent | 基于关键词匹配生成伪评分和证据链，固定优化建议 |
| 版本对比 Agent | 基于字段值差异对比，预定义改进评价 |

## 接入真实模型的前提

1. 产品闭环已跑通
2. API 接口稳定
3. Mock 数据结构经过验证
4. 有明确的 Prompt 模板
