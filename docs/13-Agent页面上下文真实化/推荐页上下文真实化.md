# 推荐页上下文真实化

## 一、本阶段目标

`JobRecommendationPage` 上下文从 mock 切到真实 resume versions 和真实 `resume_version_no`。

## 二、修改范围

| 文件 | 修改内容 |
|------|------|
| `web/src/app/pages/JobRecommendationPage.tsx` | 全面重写：移除 mock import、真实 options、versionNo 传递 |

## 三、原问题

| 问题 | 详情 |
|------|------|
| mock import | `import { mockCurrentResume, mockResumeVersions } from "../../mocks"` |
| 硬编码映射 | `resolveResumeVersionNo()` 默认为 2 |
| 展示上下文 | `mockResumeVersions.find()` + `mockCurrentResume.name` |
| 请求参数 | 从 `resumeId` 硬编码解析 `versionNo` |
| fallback 文案 | "已展示演示数据" |

## 四、修正后数据流

```
loadResumeOptionViewModelsFromApi()
  → getResumeVersions()
  → response.versions[]
  → ResumeOptionViewModel[]
  → selectedOption (URL param match or first)
  → Number(selectedOption.id)

loadRecommendationViewModel({ resume_version_no: versionNo })
  → runRecommendation({ resume_version_no: versionNo })
  → POST /jobs/recommend
```

## 五、URL 参数策略

| 参数 | 优先级 | 说明 |
|------|:--:|------|
| `resumeVersionNo` | 1 | 纯数字版本号 |
| `resumeId` (纯数字) | 2 | 兼容旧参数 |
| `resumeId=resume-vN` | 3 | Legacy regex 解析，不允许硬编码映射 |
| 无参数 | — | 默认选 `options[0]`（最新版本） |

## 六、展示上下文

| 展示项 | 来源 |
|------|------|
| 简历名称 | `selectedOption.name` |
| 版本号 | `selectedOption.id`（即 version_no） |
| 状态标签 | `selectedOption.statusLabel` + `selectedOption.directionLabel` |
| 请求 version_no | `Number(selectedOption.id)` |

## 七、空态

- **无 options**：显示"你还没有可用于推荐的简历…去添加简历"
- **options 为空**：不调用推荐 Agent
- **推荐失败**：产品化错误文案

## 八、agents.ts 默认值

`runRecommendation` 默认 `resume_version_no: 2` 未修改，但 `JobRecommendationPage` 已显式传入 `versionNo`，不再依赖默认值。
