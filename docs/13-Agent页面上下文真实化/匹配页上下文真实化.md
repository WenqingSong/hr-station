# 匹配页上下文真实化

## 一、本阶段目标

`JobMatchAnalysisPage` 上下文从 mock 切到真实 job detail + resume options。

## 二、修改范围

| 文件 | 修改内容 |
|------|------|
| `web/src/app/pages/JobMatchAnalysisPage.tsx` | 全面重写：移除 4 类 mock import，接入真实 job + resume |

## 三、原问题

| 问题 | 详情 |
|------|------|
| mock import | `mockSelectedJob` / `mockJobDetails` / `mockCurrentResume` / `mockResumeVersions` |
| 硬编码映射 | `resolveResumeVersionNo()` 默认为 2 |
| 目标岗位 | `mockJobDetails[jobId] ?? mockSelectedJob` |
| 当前简历 | `mockResumeVersions.find()` + `mockCurrentResume` |
| 请求参数 | 从 `resumeId` 硬编码解析 `versionNo` |
| fallback | "已展示演示数据" |

## 四、修正后数据流

### 10-3 初始版本

```
URL jobId → getJobDetail(jobId) → JobDetail → 子组件展示

loadResumeOptionViewModelsFromApi() + getCurrentResume()
  → resumeOptions + currentResume
  → selectedOption (URL param match or first)
  → Number(selectedOption.id)

loadMatchAnalysisViewModel(jobId, { resume_version_no: versionNo })
  → 页面展示 match result
```

### 10-3-R 修正版本（当前）

```
URL jobId
→ getJobDetail(jobId)
→ selectedJob

loadResumeOptionViewModelsFromApi()
→ resumeOptions
→ selectedResumeOption
→ versionNo = Number(selectedResumeOption.id)

versionNo
→ loadResumeVersionDetail(versionNo)         (新增)
→ selectedResumeDetail
→ Header / SidebarRight 展示

jobId + versionNo
→ loadMatchAnalysisViewModel(jobId, { resume_version_no: versionNo })
→ match result

四链路一致：
selectedResumeOption.versionNo
=== loadResumeVersionDetail(versionNo)
=== Match Agent resume_version_no
=== 页面展示 Resume 详情来源
```

## 五、目标岗位真实化

| 展示项 | 来源 |
|------|------|
| 岗位对象 | `getJobDetail(jobId)` → `JobDetail` |
| 传给子组件 | `MatchAnalysisHeader` / `MatchAnalysisSidebarLeft` 接收 `JobDetail` |

## 六、当前简历真实化

### 10-3 初始版本

| 展示项 | 来源 |
|------|------|
| 简历对象 | `getCurrentResume()` → `Resume`（传给子组件） |
| 版本号 | `selectedOption.id`（即 version_no） |
| 状态标签 | `selectedOption.statusLabel` + `selectedOption.directionLabel` |
| 请求 version_no | `Number(selectedOption.id)` |

> ⚠️ 10-3 partial_pass：`getCurrentResume()` 返回 latest，但 Match Agent 使用 `selectedOption.id`（可能是历史版本），存在一致性风险。

### 10-3-R 修正版本（当前）

| 展示项 | 来源 |
|------|------|
| 简历对象 | `loadResumeVersionDetail(versionNo)` → `selectedResumeDetail` |
| 版本号 | `selectedOption.id`（即 version_no） |
| 状态标签 | `selectedOption.statusLabel` + `selectedOption.directionLabel` |
| 请求 version_no | `Number(selectedOption.id)` |

> ✅ 10-3-R pass：四链路一致，`selectedResumeDetail` 来自指定版本而非 current/latest。

## 七、URL 参数策略

| 参数 | 优先级 | 说明 |
|------|:--:|------|
| `jobId` | 必须 | 岗位 ID |
| `resumeVersionNo` | 1 | 纯数字版本号 |
| `resumeId` (纯数字) | 2 | 兼容旧参数 |
| `resumeId=resume-vN` | 3 | Legacy regex 解析 |
