## 一、本阶段目标

`ResumeOptimizationPage` 上下文从 mock 切到真实 job detail + resume version detail。

## 二、修改范围

| 文件 | 修改内容 |
|------|------|
| `web/src/app/pages/ResumeOptimizationPage.tsx` | 全面重写：移除 mock import，接入真实 job + resume version detail |

## 三、原问题

| 问题 | 详情 |
|------|------|
| mock import | `mockSelectedJob` / `mockJobDetails` / `mockCurrentResume` / `mockResumeVersions` |
| 目标岗位 | `mockJobDetails[jobId] ?? mockSelectedJob` |
| 当前简历 | `mockResumeVersions.find(id)` + `mockCurrentResume` |
| resume_text | 由 mock resume 拼接（name、direction_label、skills、self_evaluation） |
| target_job | 由 mock job 拼接（gotJob.description, gotJob.requirements） |
| fallback | "已展示演示数据" |

## 四、修正后数据流

```
URL jobId
→ getJobDetail(jobId)
→ selectedJob
→ buildTargetJob(job) → target_job

loadResumeOptionViewModelsFromApi()
→ resumeOptions
→ selectedResumeOption
→ versionNo = Number(selectedResumeOption.id)

versionNo
→ loadResumeVersionDetail(versionNo)
→ selectedResumeDetail
→ buildResumeText(resume) → resume_text

selectedResumeDetail + selectedJob
→ loadResumeOptimizationViewModel({ resume_text, target_job, target_section })
→ 页面展示优化结果
```

## 五、resume_text 组装

`buildResumeText(resume: Resume)` 从真实版本详情组装：

```text
姓名、求职方向、期望城市
教育经历（学校 专业 学位 时间）
工作/实习经历（公司 角色 时间 描述）
项目经历（名称 描述 技术栈）
技能
自我评价
```

空字段自动跳过，不使用 mock 数据。

## 六、target_job 组装

`buildTargetJob(job: JobDetail)` 从真实岗位详情组装：

```ts
{
  title: job.title,
  jd_text: [banner_summary/short_description, responsibilities, requirements, bonus_points]
}
```

## 七、URL 参数策略

| 参数 | 优先级 | 说明 |
|------|:--:|------|
| `jobId` | 必须 | 岗位 ID |
| `resumeVersionNo` | 1 | 纯数字版本号 |
| `resumeId` (纯数字) | 2 | 兼容旧参数 |
| `resumeId=resume-vN` | 3 | Legacy regex 解析 |
