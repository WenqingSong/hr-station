# 功能范围

## 1. 本期目标

跑通"添加简历 → 岗位推荐 → 匹配分析 → 版本迭代"核心闭环，实现可演示的 Demo。

## 2. 页面范围

| 页面 | 路由 | 说明 | 状态 |
|------|------|------|------|
| 登录页 | /login | 登录/注册表单 | 页面已存在 |
| 首页 / 工作台 | / | 功能入口 + 最近分析记录 | 页面已存在 |
| 我的简历页 | /resume | 简历状态总览 + 操作入口 | 页面已存在 |
| 添加简历页 | /resume/add | 结构化表单（所有字段可选填） | 页面已存在 |
| 简历详情页 | /resume/detail | 简历内容 + AI 信息提取 + 表达风险 | 页面已存在 |
| 简历版本迭代页 | /resume/versions | 版本列表 + 版本对比 + 变化原因 | 页面已存在 |
| 岗位列表页 | /jobs | 岗位搜索 + 列表 + 详情抽屉 | 页面已存在 |
| 岗位推荐页 | /jobs/recommend | 推荐依据 + 推荐等级 + 推荐卡片 | 页面已存在 |
| 岗位匹配分析页 | /jobs/match/:jobId | 匹配总览 + 证据链 + 风险 + 建议 | 页面已存在 |

> 页面组件均已由 Figma Make 生成，当前为 Demo 预览模式（useState 切换），需接入真实路由。

## 3. 后端功能范围

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 用户注册 / 登录 | 邮箱或用户名注册，JWT 认证 | P0 |
| JWT 认证中间件 | 统一 Token 校验 | P0 |
| 添加简历版本 | 创建新版本，历史版本只读 | P0 |
| 查看当前简历 | 获取最新版本简历 | P0 |
| 查看简历详情 | 含 AI 提取结果和表达风险 | P0 |
| 查看简历版本列表 | 版本时间线 | P0 |
| 岗位列表 | 搜索和浏览岗位 | P0 |
| 岗位详情 | 单个岗位完整 JD | P0 |
| 岗位推荐（Mock） | 基于简历返回推荐列表 | P0 |
| 岗位匹配分析（Mock） | 返回匹配度 + 证据链 + 建议 | P0 |
| 版本对比（Mock） | 返回两版本差异和改进评价 | P0 |
| 保存最近一次分析结果 | 缓存匹配分析结果 | P1 |

## 4. 数据库范围

| 表 | 说明 |
|----|------|
| users | 用户表 |
| resumes | 简历主表（每用户一条） |
| resume_versions | 简历版本表（V1、V2、V3...） |
| education_experiences | 教育经历（关联版本） |
| work_experiences | 工作经历（关联版本） |
| project_experiences | 项目经历（关联版本） |
| jobs | 岗位表（预置数据） |
| match_analyses | 匹配分析结果缓存 |

## 5. Agent 范围

| Agent | 功能 | 阶段 3（Mock） | 阶段 4（真实模型） |
|-------|------|---------------|------------------|
| 简历信息提取 Agent | 提取技能标签、求职方向、表达风险 | 规则引擎 + 关键词匹配 | LLM 提取 |
| 岗位推荐 Agent | 基于简历推荐匹配岗位 | 预置推荐结果 | LLM 推荐 |
| 岗位匹配分析 Agent | 生成匹配度 + 证据链 + 优化建议 | 预置分析结果 | LLM 分析 |
| 版本对比 Agent | 对比两版本差异 + 改进评价 | 字段差异对比 | LLM 对比 |

**关键决策**：阶段 3 先 Mock，阶段 4 再接真实模型（参见 ADR-003）。

## 6. 前端接入范围

| 工作 | 说明 |
|------|------|
| 接入 react-router | 替换 useState 页面切换为真实 URL 路由 |
| 创建 API 对接层 | axios 封装 + 环境变量 + API Client |
| 替换 Mock 数据 | 各页面从硬编码改为调用后端接口 |
| 添加加载/错误状态 | 接口请求期间的 UI 反馈 |
| 清理冗余依赖 | 移除 MUI，整理 shadcn 组件 |

## 7. Demo 验收范围

| 场景 | 验收标准 |
|------|---------|
| 注册登录 | 注册后可登录，登录后跳转工作台 |
| 添加简历 | 填写表单后保存成功，可查看详情和 AI 提取结果 |
| 岗位推荐 | 基于简历生成推荐列表，有推荐等级 |
| 岗位搜索 | 可搜索岗位，查看详情 |
| 匹配分析 | 选择岗位后生成匹配度、证据链、优化建议 |
| 版本迭代 | 修改简历后添加新版本，可对比差异 |
| 全流程跑通 | Docker 一键启动，前后端联调成功 |
