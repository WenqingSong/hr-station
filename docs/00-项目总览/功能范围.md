# 功能范围

## 当前状态

已明确核心功能

## 已规划功能

### 简历管理

| 功能 | 说明 | 页面 |
|------|------|------|
| 简历录入 | 结构化表单录入简历信息 | /resume/add |
| 简历详情 | 查看简历内容 + AI 信息提取 + 表达风险 | /resume/detail |
| 简历版本 | 版本列表 + 版本对比 + 变化原因 | /resume/versions |
| 简历总览 | 简历状态 + 操作入口 | /resume |

### 岗位探索

| 功能 | 说明 | 页面 |
|------|------|------|
| 岗位搜索 | 关键词搜索 + 列表浏览 | /jobs |
| 岗位推荐 | 基于简历的智能推荐 | /jobs/recommend |
| 岗位匹配 | 简历与岗位的深度匹配分析 | /jobs/match/:jobId |

### 用户系统

| 功能 | 说明 | 页面 |
|------|------|------|
| 登录/注册 | 账号登录与注册 | /login |
| 工作台 | 功能入口 + 最近分析记录 | /dashboard |

### AI 能力

| 功能 | 说明 |
|------|------|
| 简历信息提取 | 从结构化简历中提取关键信息 |
| 表达风险检测 | 检测简历中的模糊表达、空洞描述 |
| 岗位推荐 | 基于简历内容推荐匹配岗位 |
| 匹配分析 | 分析简历与岗位的匹配度，生成证据链 |
| 优化建议 | 基于匹配结果给出简历优化建议 |
| 版本对比 | 对比两个版本的差异和改进点 |
