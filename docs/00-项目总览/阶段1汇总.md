## 4. 当前运行能力

| 能力 | 说明 |
|------|------|
| 环境检查 | `make doctor` 可检查开发环境 |
| 环境初始化 | `make init` 可恢复 `.env` |
| MySQL 可启动 | `make up` 启动 MySQL 容器，数据持久化 |
| 后端可启动 | `make dev-server` 启动 HTTP Server |
| 健康检查 | `/healthz` 返回 `{"status":"ok","service":"offer-catcher-server"}` |
| 前端可启动 | `make dev-web` 启动 Vite 开发服务（需安装依赖） |
| CNB 恢复 | 6 步恢复流程：doctor → init → up → status → dev-web → dev-server |
