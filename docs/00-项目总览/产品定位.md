# 产品定位

## 1. 产品名称

Offer捕手

## 2. 产品一句话定位

面向大学生求职场景的 AI 岗位推荐与简历匹配分析 Demo。

## 3. 目标用户

- 正在准备校招的应届毕业生
- 有简历但不知道投什么岗位的求职者
- 已有目标岗位但不确定匹配度的求职者
- 想要通过迭代优化简历提升匹配度的求职者

## 4. 核心场景

1. **不知道投什么**：用户有简历但不知道适合哪些岗位 → 系统基于简历推荐岗位
2. **已有目标岗位**：用户想知道自己与目标岗位的匹配情况 → 系统生成 JD-简历证据链
3. **简历需要优化**：用户发现匹配度不够 → 系统给出 P0/P1 优化建议，用户迭代版本后再次匹配

## 5. 用户核心痛点

| 痛点 | 说明 |
|------|------|
| 海投无反馈 | 不知道哪些岗位真正适合自己，盲目投递效率低 |
| 匹配度不明 | 无法量化评估自己与岗位的匹配程度 |
| 简历不会改 | 不知道简历哪里有问题、怎么改才能提升匹配度 |
| 迭代无追踪 | 修改简历后无法对比改进效果 |

## 6. 产品解决方案

| 解决方案 | 对应痛点 |
|---------|---------|
| 基于简历的岗位推荐 | 海投无反馈 → 精准推荐匹配岗位 |
| JD-简历证据链分析 | 匹配度不明 → 逐条对照岗位要求与简历经历 |
| P0/P1 优化建议 + 表达风险检测 | 简历不会改 → 指出具体问题及改进方向 |
| 版本迭代 + 版本对比 | 迭代无追踪 → V1→V2→V3 追踪改进效果 |

## 7. 核心差异点

1. **JD-简历证据链**：不是简单的匹配度评分，而是逐条展示岗位要求与简历内容的对应关系
2. **初筛风险提示**：识别简历中可能导致初筛被淘汰的表达风险
3. **简历版本迭代**：不是一次性分析，而是支持"分析→修改→再分析"的迭代闭环
4. **不代写**：不替用户生成优化版简历，只给诊断和建议，保护真实性

## 8. Demo 阶段定位

本项目**不是**：

- ❌ 招聘官网或正式投递系统
- ❌ 完整商业产品
- ❌ AI 聊天机器人
- ❌ 简历生成器

本项目**是**：

- ✅ 比赛/作业 Demo
- ✅ AI 岗位推荐与简历匹配分析工具
- ✅ 核心亮点是"JD-简历证据链 + 初筛风险 + 简历版本迭代"

Demo 重点：

1. 主流程清晰
2. AI 分析结果结构化
3. 页面信息克制
4. 功能边界明确
5. 可通过 Docker 和后端接口跑通演示链路

## 9. 当前边界

| 边界 | 说明 |
|------|------|
| 单主简历 | 用户只有一份主简历，通过版本迭代管理优化过程 |
| 所有字段可选填 | 降低填写压力，允许用部分信息快速体验 |
| 不上传 PDF/DOC | 只支持结构化表单录入 |
| 不自动生成简历 | 只给分析和建议，用户手动修改 |
| 先 Mock 后接模型 | 前期 Mock Agent 跑通闭环，后续接入真实 LLM |
