## 4. 已确认接口

| 优先级 | 接口用途 | 接口 URL | Method | 状态 | 用途 |
|--------|---------|---------|--------|------|------|
| P0 | 岗位列表 | `https://join.qq.com/api/v1/position/searchPosition` | POST | ✅ 已确认 | 获取岗位池（postId + 基础信息） |
| P0 | 岗位详情 | `https://join.qq.com/api/v1/jobDetails/getJobDetailsByPostId` | GET | ✅ 已确认 | 获取完整 JD（desc + request + 加分项） |
| P1 | 字典 | `https://join.qq.com/api/v1/dictionary/` | GET | ✅ 已确认 | code→name 映射（可选增强） |

明确：

- 岗位列表接口和岗位详情接口是 P0（必须接入）
- 字典接口是 P1 可选增强
- 不接登录、投递、收藏、用户中心、应聘进度接口

## 6. 已新增脚本

`scripts/dev/tencent_jobs.sh`，支持以下命令：

| 命令 | 说明 |
|------|------|
| help | 查看帮助 |
| check | 检查配置项、URL、输出目录、依赖工具 |
| fetch-list | 拉取岗位列表原始 JSON |
| fetch-details | 基于 positions.json 中的 postId 拉取岗位详情原始 JSON |
| fetch-dictionary | 拉取字典原始 JSON |
| fetch-all | 依次执行 fetch-list、fetch-details、fetch-dictionary |
| sample | 打印本地岗位样本摘要 |
| status | 查看本地原始数据文件状态 |
| clean | 清理 data/tencent-jobs/raw 下生成的 JSON 文件 |

别名支持：fetch-detail = fetch-details，source-check = check

## 8. 原始数据输出结构

| 文件 | 说明 |
|------|------|
| data/tencent-jobs/raw/positions.json | 岗位列表原始数据（source、fetched_at、total、count、items） |
| data/tencent-jobs/raw/details.json | 岗位详情原始数据（source、fetched_at、count、items，每条含 postId、ok、response） |
| data/tencent-jobs/raw/dictionary.json | 字典原始数据（source、fetched_at、ok、response） |
| data/tencent-jobs/raw/metadata.json | 元数据（source、fetched_at、config、summary） |

明确：

- `data/tencent-jobs/raw/*.json` 已被 `.gitignore` 忽略
- 这些文件是本地原始缓存
- 不作为源码提交
- 不直接写入数据库
- 后续 4-1.3 才进行字段清洗和入库
