# 阶段3汇总

> 最后更新：2026-05-29（阶段 3-9 阶段 3 汇总）

## 1. 阶段目标

阶段 3 的核心目标是：**在不接真实模型 API 的前提下，先用后端 Mock 数据跑通 Offerr鹅的核心业务闭环。**

阶段 3 完成后，后端应支持以下主链路：

```
用户注册 / 登录
→ 获取 token
→ 添加简历版本
→ 查看当前简历
→ 查看简历版本列表
→ 查看岗位列表
→ 查看岗位详情
→ 获取岗位推荐 Mock
→ 执行岗位匹配分析 Mock
→ 新增简历版本
→ 执行简历版本对比 Mock
```

## 4. 已实现业务闭环

阶段 3 完成后，后端已跑通以下业务闭环：

```
1. POST /api/auth/register        → 注册用户
2. POST /api/auth/login            → 登录获取 JWT
3. GET  /api/auth/me               → 获取当前用户
4. POST /api/resumes               → 添加简历 V1
5. GET  /api/resumes/current       → 查看当前简历
6. GET  /api/resumes/versions       → 查看简历版本列表
7. GET  /api/jobs                   → 查看岗位列表
8. GET  /api/jobs/{id}              → 查看岗位详情
9. POST /api/jobs/recommend         → 获取岗位推荐 Mock
10. POST /api/jobs/{id}/match       → 岗位匹配分析 Mock
11. POST /api/resumes               → 添加简历 V2
12. GET  /api/resumes/versions/compare?from=1&to=2 → 版本对比 Mock
```

## 8. Mock Agent 能力

| Agent | 输入 | 输出 | 实现方式 | 文件 |
|-------|------|------|---------|------|
| RecommendationMockAgent | 简历版本 + 岗位列表 | 推荐岗位列表 + 推荐理由 + 匹配亮点 + 风险点 + 优先级 | 规则打分（城市/方向/技能） | `agent/recommendation_mock.go` |
| MatchMockAgent | 简历版本 + 目标岗位 JD | 匹配分数 + 初筛判断 + JD-简历证据链 + 风险点 + P0/P1 优化建议 + 下一步建议 + 真实性提示 | 规则打分 + 证据链生成 | `agent/match_mock.go` |
| VersionCompareMockAgent | 旧版本简历 + 新版本简历 | 分数变化 + 字段变化 + 风险变化 + 建议完成情况 + 关键改进 + 剩余风险 + 总结 + 真实性提示 | 规则打分 + 字段差异对比 | `agent/version_compare_mock.go` |

关键约束：
- 不调用真实 LLM
- 不读取 LLM_API_KEY
- 不使用真实 Prompt
- 结果为结构化 JSON
- 阶段 4 或后续再接真实 Agent / LLM

## 9. 当前运行验证方式

```bash
# 1. 启动 MySQL
make up

# 2. 启动后端
make dev-server

# 3. 登录获取 token
TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"arthur@example.com","password":"123456"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['data']['token'])")

# 4. 验证简历接口
curl -s http://localhost:8080/api/resumes/current -H "Authorization: Bearer $TOKEN"

# 5. 验证岗位接口
curl -s http://localhost:8080/api/jobs -H "Authorization: Bearer $TOKEN"

# 6. 验证推荐接口
curl -s -X POST http://localhost:8080/api/jobs/recommend \
  -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" -d '{}'

# 7. 验证匹配接口
curl -s -X POST http://localhost:8080/api/jobs/1/match \
  -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" -d '{}'

# 8. 验证版本对比接口
curl -s "http://localhost:8080/api/resumes/versions/compare?from=1&to=2" \
  -H "Authorization: Bearer $TOKEN"
```

种子用户默认密码均为 `123456`，Demo 密码不应在生产环境使用。
