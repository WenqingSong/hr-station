# 用户路径

## 当前状态

已明确核心路径

## 主路径

```
注册/登录 → 工作台 → 添加简历 → 查看简历详情 → 搜索岗位 → 查看推荐 → 匹配分析 → 根据建议修改 → 添加新版本 → 再次匹配
```

## 详细路径

### 1. 首次使用

1. 用户访问首页，点击登录
2. 登录/注册
3. 进入工作台，看到"添加简历"引导
4. 填写结构化简历表单
5. 保存后查看简历详情，看到 AI 信息提取结果

### 2. 岗位探索

1. 从工作台进入岗位列表
2. 搜索/浏览岗位
3. 查看岗位推荐
4. 选择岗位进行匹配分析

### 3. 匹配分析与优化

1. 查看匹配总览（匹配度评分）
2. 查看 JD-简历证据链
3. 查看表达风险和优化建议
4. 根据建议手动修改简历
5. 添加新版本
6. 查看版本对比
7. 再次匹配验证改进效果
