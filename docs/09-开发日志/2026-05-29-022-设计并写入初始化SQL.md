## 6. 关键决策

| 决策 | 说明 |
|------|------|
| 使用 DROP TABLE IF EXISTS + CREATE TABLE | 支持可重复执行，方便 Demo 频繁重建 |
| 删除顺序按外键依赖反向 | version_compare_results → match_analyses → recommendation_results → resume_versions → jobs → users |
| 使用 SET FOREIGN_KEY_CHECKS = 0/1 | 避免建表时外键顺序问题 |
| 不设计 resumes 多简历表 | 用户只有一份主简历，通过 resume_versions version_no 管理 |
| 经历用 JSON 字段存储 | 不建独立子表，Demo 阶段简化 |
| 密码哈希使用 Demo 占位值 | 3-3 实现 bcrypt 后可更新种子密码 |
| result_json 用 JSON 类型 | 灵活存储推荐/匹配/对比结构化结果，阶段 4 可能扩展 |
