## 4. 脚本联动方式

Makefile 作为统一入口，只做命令编排，不写复杂逻辑。所有具体执行逻辑仍在 `scripts/dev/tencent_jobs.sh`。

命令映射关系：
- `make jobs-fetch-detail` → `tencent_jobs.sh fetch-details`（注意：Makefile 用单数，脚本用复数）
- `make jobs-source-check` → `tencent_jobs.sh check`（别名避免命名不统一）
- 脚本内部也支持 `fetch-detail` 和 `source-check` 别名
