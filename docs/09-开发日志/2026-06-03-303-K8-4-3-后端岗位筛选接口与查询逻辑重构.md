# K8-4-3 + K8-4-3-R：后端岗位筛选接口修复

## K8-4-3-R 追加修复

### 根因

**Go MySQL driver 中文 charset 问题**：`SELECT WHERE jobs.city IN ('深圳总部')` 在 MySQL CLI 返回 44，在 Go 返回 0。ASCII 参数正常（CSIG=37, Go=6）。

尝试的修复方案（均未解决中文匹配）：
- `collation=utf8mb4_unicode_ci` in DSN
- `interpolateParams=true`
- `SET NAMES utf8mb4` per connection
- `esc()` 内联中文值到 SQL
