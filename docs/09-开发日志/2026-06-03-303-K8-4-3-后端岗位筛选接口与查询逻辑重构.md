# K8-4-3：后端岗位筛选接口与查询逻辑重构

- **日期**：2026-06-03
- **阶段**：K8-4-3（backend, pass with known limitation）
- **性质**：后端 facets 接口升级 + 筛选维表查询 + 多选筛选支持

## 1. 背景

K8-4-2 已完成 SQL seed 和筛选维表（6 分组、1131 选项、1962 关联）。本次将后端 facets API 从"聚合业务表"升级为"读取筛选维表"，并让 `/api/jobs` 支持新筛选参数。

## 2. 实现方案

### 2.1 `/api/jobs/facets` 升级

- **新增 `groups[]` 字段**：从 `job_filter_groups` + `job_filter_options` + `job_filter_option_relations` 读取
- **保留旧字段**：`directions`/`cities`/`categories`/`skills` 等全部保留
- **父子层级**：`job_category` 组按 `parent_option_id` 构建父子树（5 大类：技术/产品/设计/市场/职能 → 46 细类）
- **数量统计**：从 `job_filter_option_relations` 表实时统计

响应结构：
```json
{"groups": [{"code":"job_category","name":"岗位类别","options":[
  {"label":"技术","count":26,"children":[
    {"label":"后台开发","count":1}, ...]},
  {"label":"产品","count":7,"children":[...]}, ...]}],
 "directions": [...], "cities": [...]}
```

### 2.2 `/api/jobs` 查询参数

| 参数 | 类型 | 示例 |
|------|------|------|
| `business_group` | string/逗号多选 | `?business_group=CSIG,IEG` |
| `city` | string/逗号多选 | `?city=深圳总部,北京` |
| `skill` | string/逗号多选 | `?skill=Go,Python` |
| `job_category` | string/逗号多选 | `?job_category=技术`（自动包含子类） |
| 旧参数 | 全部保留 | `direction`/`category`/`keyword`/`page`/`page_size` |

### 2.3 筛选规则

- 同组多选：OR（逗号分隔）
- 不同分组：AND
- 岗位类别父级：自动包含所有子类岗位
