# 2026-05-30-086-推荐接口联调与fallback验收

## 1. 本次任务

阶段 4-3.5：推荐接口联调与 fallback 验收。验证推荐接口在 LLM Pipeline 优先 + Mock fallback 模式下的稳定性和可用性。

## 2. 验收范围

- 推荐接口 `POST /api/jobs/recommend` 全链路
- 8 个验收场景：LLM success / repaired / fallback_required / LLM_ENABLE=false / 配置异常 / 候选集外岗位 / 空推荐列表 / 请求参数异常
- 安全边界验证
- 排序与结果可用性验证
- 接口返回结构验证

## 3. 当前推荐链路

```
POST /api/jobs/recommend
  → RecommendationHandler.Recommend()
    → RecommendationService.Recommend(ctx, userID, req)
      → getResume() → JobRepository.ListRecommendCandidates()
      → [LLM路径] recommendWithLLM()
        → RecommendationAgent.Recommend()
          → PipelineRunner.Run()
          → mapParsedToRecommendedJobs() + job_id白名单
          → 设置 GeneratedBy/AgentStatus/RepairApplied
        → on RecFallbackError → recommendWithMock()
      → [Mock路径] recommendWithMock()
        → RecommendationMockAgent.Recommend()
```

## 4. 验收场景

8 个验收场景 + 排序/结构/安全验证，共 19 个 service 层测试 + 12 个 agent 层测试。

## 5. LLM success 验收

✅ 通过。Agent 正确返回推荐结果，GeneratedBy=llm_agent, AgentStatus=success, RepairApplied=false。推荐档位映射正确（priority_apply→strong_recommend）。

## 6. LLM repaired 验收

✅ 通过。AgentStatus=repaired, RepairApplied=true, GeneratedBy=llm_agent（不是 json_repair_agent）。

## 7. fallback_required 验收

✅ 通过。Agent 返回 RecFallbackError（FallbackReason/ErrorCode 有值），Service 回退 Mock Agent。

## 8. LLM_ENABLE=false 验收

✅ 通过。Service 直接走 recommendWithMock()，generated_by=mock_agent, agent_status=mock。

## 9. 配置异常验收

✅ 通过。Pipeline 返回 fallback_required 时，Service 回退 Mock。不泄露 API Key，不返回 500。

## 10. 候选集外岗位验收

✅ 通过。job_id 不在候选集时被过滤，全部过滤后触发 RecFallbackError → Mock fallback。title/department/city 强制从候选岗位取值。

## 11. 空推荐列表验收

✅ 通过。LLM 返回空 recommendations 数组时，Agent 返回 RecFallbackError（field_mapping_failed），Service 回退 Mock。

## 12. 请求参数异常验收

✅ 通过。简历缺失返回 "resume not found"，候选岗位为空返回 "no jobs available"，limit 超出截断为 5。

## 13. 排序与结果可用性验收

✅ 通过。Mock 结果按 score 降序排列，推荐档位合法（strong_recommend/recommend/try），推荐理由/行动建议不为空。

## 14. 接口返回结构验收

✅ 通过。原有核心字段完整，新增字段 omitempty 不破坏旧结构。LLM 成功时 fallback_reason/error_code 为空。
