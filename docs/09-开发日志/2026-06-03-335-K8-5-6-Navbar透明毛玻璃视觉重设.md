# K8-5-6：Navbar 透明毛玻璃视觉重设

## 一、当前问题

K8-5-4 的 Navbar 使用了双态（顶部更透明 / 滚动后更不透明）的玻璃效果，整体偏"液态金属/蓝色玻璃"质感，压在 Banner 上显得重、廉价。不符合用户期望的高级透明毛玻璃风格。

## 二、设计定型

最终采用：

- **透明白色毛玻璃**（`bg-white/68 backdrop-blur-2xl backdrop-saturate-150`）
- **轻边框**（`border-b border-white/30`）
- **极轻阴影**（`shadow-[0_8px_30px_rgba(15,23,42,0.06)]`）
- **深色文字**（`text-slate-950 / text-slate-700`）
- **统一外观**（不区分顶部/滚动双态，保持稳定一致的毛玻璃质感）

## 三、Navbar class 修改

| 项目 | 旧值 | 新值 |
|------|------|------|
| 背景 | `bg-white/75` / `bg-white/40`（双态） | `bg-white/68 backdrop-blur-2xl backdrop-saturate-150`（统一） |
| 边框 | `border-white/20` / `border-white/10` | `border-white/30` |
| 阴影 | `shadow-[0_1px_3px_rgba(0,0,0,0.05)]` | `shadow-[0_8px_30px_rgba(15,23,42,0.06)]` |
| 高度 | `h-16` | `h-16 md:h-[68px]` |
| 动画 | `transition-all duration-300 ease-out` | `transition-transform duration-300 ease-[cubic-bezier(0.22,1,0.36,1)]` |
| 隐藏偏移 | `-translate-y-full` | `-translate-y-[110%]` |
| 品牌文字颜色 | `text-slate-900` | `text-slate-950` |
| 右侧链接 hover | `hover:text-[#0052D9]`（蓝） | `hover:text-slate-950`（深灰） |
| 登录按钮 | 普通文字链接 | 轻边框胶囊 `rounded-full border border-slate-200/70 bg-white/45 px-4 py-2` |
| 双态变量 | `scrolled` state | 已移除 |

## 四、滚动隐藏逻辑

**保留** K8-5-4 的 `requestAnimationFrame` 节流 + `lastScrollY` 滚动方向检测：

- 下滑且 scrollY > 80：隐藏（`-translate-y-[110%]`）
- 上滑：显示（`translate-y-0`）
- scrollY ≤ 20：强制显示
