## 5. CORS 配置化实现

### 修改前（硬编码）

```go
var allowedOrigins = map[string]bool{
    "http://localhost:5173": true,
    "http://127.0.0.1:5173": true,
}
const allowedMethods = "GET, POST, PUT, PATCH, DELETE, OPTIONS"
const allowedHeaders = "Content-Type, Authorization, X-Requested-With"
```

### 修改后（环境变量配置化）

1. `config.go` 新增 `CORSConfig`：
```go
type CORSConfig struct {
    AllowedOrigins   []string
    AllowedMethods   string
    AllowedHeaders   string
    AllowCredentials bool
}
```

2. `cors.go` 改为 `InitCORS(cfg)` 初始化

3. `.env.example` 新增：
```env
CORS_ALLOWED_ORIGINS=http://localhost,http://localhost:5173,http://127.0.0.1,http://127.0.0.1:5173
CORS_ALLOWED_METHODS=GET, POST, PUT, PATCH, DELETE, OPTIONS
CORS_ALLOWED_HEADERS=Content-Type, Authorization, X-Requested-With
CORS_ALLOW_CREDENTIALS=false
```

4. `main.go` 启动时调用 `middleware.InitCORS(cfg.CORS)`

### 关键改进

- `http://localhost` 和 `http://127.0.0.1` 已加入默认 allowlist（Nginx 同源代理场景）
- `CORS_ALLOW_CREDENTIALS` 默认 `false`（当前用 JWT 不用 Cookie）
- 保留 `localhost:` / `127.0.0.1:` 任意端口自动允许的开发便利性
- 不允许的 Origin 不返回 `Access-Control-Allow-Origin` 头

## 6. OPTIONS 预检验证

### Nginx 同源代理 OPTIONS 预检

```bash
curl -s -X OPTIONS http://localhost/api/auth/login \
  -H "Origin: http://localhost" \
  -H "Access-Control-Request-Method: POST" \
  -H "Access-Control-Request-Headers: Content-Type,Authorization" \
  -D - -o /dev/null
```

结果：`204 No Content` + `Access-Control-Allow-Origin: http://localhost` ✅

### 后端直连 OPTIONS 预检

```bash
curl -s -X OPTIONS http://localhost:8080/api/auth/login \
  -H "Origin: http://localhost:5173" \
  -H "Access-Control-Request-Method: POST" \
  -H "Access-Control-Request-Headers: Content-Type,Authorization" \
  -D - -o /dev/null
```

结果：`204 No Content` + `Access-Control-Allow-Origin: http://localhost:5173` ✅

## 7. Origin 安全验证

```bash
curl -s -X OPTIONS http://localhost:8080/api/auth/login \
  -H "Origin: http://evil.example.com" \
  -H "Access-Control-Request-Method: POST" \
  -D - -o /dev/null
```

结果：`405 Method Not Allowed`，无 `Access-Control-Allow-Origin` 头 ✅
