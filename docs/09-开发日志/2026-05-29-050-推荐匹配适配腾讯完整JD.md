## 3. 推荐接口变更

### 候选池
- 从 `jobRepo.List(Limit: 50)` 改为 `jobRepo.ListRecommendCandidates(50)`
- 候选池包含 local_mock + tencent_join 所有岗位
- 优先排序：is_featured DESC → data_quality 优先级 → id ASC

### 评分规则
- 基础分：60
- 城市匹配：+5
- 方向匹配：+10/+5
- skill_keywords 交集：+5/项（最大 25）
- 高技能重叠：+5（交集 > 4）
- JD keyword matching（description/requirements）：+5/项（最大 20）
- data_quality=full_jd：+5
- is_featured=1：+5
- summary_only：-10
- 最高 95，最低 0

### 新增响应字段
- external_source / external_id / data_quality / source_url / is_featured
- 不返回 raw_json

## 4. 匹配接口变更

### JD 输入
- 当 skill_keywords_json 非空时，使用 skill_keywords 匹配
- 当 skill_keywords_json 为空时，从 description/requirements 提取关键词匹配
- 使用 extractKeywordsFromJD 从 JD 文本中提取常见技术关键词

### data_quality 处理
- full_jd：正常完整分析，+5 匹配分
- manual_enriched：正常完整分析
- summary_only：-10 匹配分，authenticity_notice 增加降级提示，risk_points 增加信息不足警告

### 新增响应字段
- MatchAnalysisResult：external_source / external_id / data_quality / source_url / is_featured
- MatchResponse：analysis_basis（job_description_used / job_requirements_used / data_quality）
- 不返回 raw_json

## 5. Agent 边界

- 不实现 LLM Client 抽象
- 不写 Prompt 模板最终版
- 推荐和匹配服务仍只读取本地 jobs 表
