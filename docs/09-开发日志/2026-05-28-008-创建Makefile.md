## 6. 关键决策

1. **Makefile 命令全部幂等**：重复执行不破坏环境
2. **`make doctor` 严格只读**：不修改任何文件，只输出检查结果
3. **`make init` 不自动安装依赖**：只提示安装命令，避免不可控操作
4. **`make init` 兼容 `.env.example` 不存在**：输出提示但不报错
5. **`make reset` 不自动执行**：只输出危险提示和手动命令，避免误删数据
6. **`make up` 兼容空 docker-compose.yml**：输出提示但不报错
7. **`make dev-server` 兼容 server 未初始化**：输出提示待阶段 1-5
8. **前端命令使用 `web/` 目录**：根据实际 package.json 位置
