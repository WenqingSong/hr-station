## 生产部署架构

```
用户浏览器
  ↓
web 容器 Nginx :80（对外暴露）
  ├─ 静态资源 /assets/（30天缓存）
  ├─ SPA fallback: try_files $uri /index.html
  └─ /api/* → server:8080（内网）
        ↓
      server 容器 Go 二进制
        ↓
      mysql 容器（不暴露端口）
      redis 容器（不暴露端口）
```

## 安全设计

- MySQL 3306 / Redis 6379 在生产 compose 中不暴露公网端口
- 后端 server 不在 compose 中暴露端口（仅内网访问）
- 仅 web 容器暴露 80 端口
- `.env` 不打入镜像（通过 `.env.prod` 注入）
- `.env.prod.example` 仅含占位符，无真实密钥
- `.dockerignore` 排除 `.env`、`.git`、`node_modules`
