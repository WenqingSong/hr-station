## 5. 新增 AgentResponseMeta / AgentResponseEnvelope

新增 `server/internal/model/agent_response.go`，包含：

1. **AgentResponseMeta**：统一元数据结构体
   - `agent_name`：枚举 match_analysis / recommendation / resume_optimization
   - `generated_by`：枚举 llm_agent / mock_agent
   - `agent_status`：枚举 success / repaired / fallback / mock_success / error
   - `fallback_reason`：枚举 none / llm_disabled / llm_error / ... / unknown
   - `error_code`：枚举 none / LLM_DISABLED / LLM_ERROR / ... / UNKNOWN_ERROR
   - `repair_applied`：bool
   - `schema_valid`：bool
   - `request_id`：string（暂填空字符串）

2. **NewAgentResponseMeta**：构造函数，默认 mock_success

3. **DeriveMetaFromResult**：从业务 result 旧 meta 字段推导统一 meta
   - 处理 `"mock"` → `"mock_success"` 标准化
   - 处理空字符串 → `"none"` 标准化

4. **WithFallback / WithRepaired**：链式设置方法

5. **常量定义**：agent_name / generated_by / agent_status / fallback_reason / error_code 枚举常量

## 6. 三类接口返回结构改造

### MatchAnalysis
- `MatchResponse` 新增 `Meta model.AgentResponseMeta` 字段
- LLM success 路径：通过 `DeriveMetaFromResult` 从 result 推导 meta
- Mock direct 路径：通过 `NewAgentResponseMeta` 创建默认 meta
- Fallback 路径：通过 `DeriveMetaFromResult` 从 fallback error 推导 meta
- 旧字段 `GeneratedBy` 保留（deprecated）

### Recommendation
- `RecommendationResponse` 新增 `Meta` 和 `Result` 字段
- 新增 `RecommendationBusinessResult` 结构体，包含 `recommended_jobs`
- LLM success 路径：从第一个推荐 job 的 meta 推导统一 meta
- Mock direct 路径：默认 meta
- Fallback 路径：从 fallback error 推导 meta
- 旧字段 `RecommendedJobs` 保留（deprecated）

### ResumeOptimization
- `ResumeOptimizationResponse` 新增 `Meta` 字段
- LLM success 路径：通过 `DeriveMetaFromResult` 从 result 推导 meta
- Mock direct 路径：默认 meta
- Fallback 路径：从 fallback error 推导 meta
- 旧字段 `GeneratedBy` 保留（deprecated）

## 7. Recommendation 兼容策略

- 新增 `data.result.recommended_jobs` 作为前端新入口
- 保留 `data.recommended_jobs`（deprecated），短期兼容
- 两者数据一致（指向同一个 job 切片）
- 文档明确前端应读取 `data.result.recommended_jobs`

## 8. meta 字段填充规则

| 字段 | 填充方式 |
|------|---------|
| agent_name | 三类接口分别固定为 match_analysis / recommendation / resume_optimization |
| generated_by | LLM 路径从 result 透传，Mock 路径为 "mock_agent" |
| agent_status | LLM 路径从 result 透传，Mock direct 统一为 "mock_success"，Fallback 为 "fallback" |
| fallback_reason | Fallback 路径从 error 透传，其他为 "none" |
| error_code | Fallback 路径从 error 透传，其他为 "none" |
| repair_applied | LLM repaired 时为 true，其他为 false |
| schema_valid | 默认 true（暂不实现校验逻辑） |
| request_id | 默认空字符串（暂不实现生成逻辑） |
