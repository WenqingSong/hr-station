# K8-5-42-B：P0 修复 Resume Adapter project/projects 字段兼容

> 日期：2026-06-05 | 性质：前端修复 | 只改 `resumeAdapter.ts`

---

## 一、本阶段目标

修复 API 返回 `project`(singular) 但 adapter 读 `projects`(plural) 导致项目经历数据丢失的问题。

---

## 二、K8-5-42-A 审计结论

API `project` 字段有数据（list of 3 projects），但 `projects` 为 null。adapter 三处读 `projects`，无一读 `project`。

---

## 三、project/projects 不一致问题

```text
API response:
  "project": [{name: "...", ...}, ...]     ← 有 3 条数据
  "projects": null                          ← null

Adapter (修复前):
  toResumeSummaryViewModel:     resume.projects?.length ?? 0            → 0
  toResumeManagementViewModel:  Array.isArray(resume.projects) ? ... : [] → []
  parseV2Projects:              resume.projects                         → null → undefined

结果：项目经历完全丢失
```

---

## 四、修复

### 新增 helper

```ts
function getProjectsSafe(resume: Resume): ResumeProject[] | unknown[] {
  const raw = resume as Record<string, unknown>;
  if (Array.isArray(raw.projects) && raw.projects.length > 0) return raw.projects;
  if (Array.isArray(raw.project) && raw.project.length > 0) return raw.project;
  return [];
}
```

### 更新 3 处调用

| 位置 | 修改前 | 修改后 |
|------|--------|--------|
| `toResumeSummaryViewModel` projectCount | `resume.projects?.length ?? 0` | `getProjectsSafe(resume).length` |
| `toResumeManagementViewModel` projects | `Array.isArray(resume.projects) ? ... : []` | `getProjectsSafe(resume)` |
| `parseV2Projects` | `const proj = resume.projects` | `const proj = getProjectsSafe(resume)` |
