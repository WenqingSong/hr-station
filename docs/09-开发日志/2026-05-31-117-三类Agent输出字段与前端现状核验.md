## 4. Agent 输出字段核验

### 4.1 Schema 校验

- `match_analysis_schema.json`：VALID
- `recommendation_schema.json`：VALID
- `resume_optimization_schema.json`：VALID

### 4.2 关键发现

MatchAnalysisAgent 和 RecommendationAgent 的 Go Model 与 Schema 基本对齐（新字段用 omitempty 标记）。

**ResumeOptimizationAgent Go Model 与 Schema 差距显著**：
- Go Model（`ResumeOptimizationResult`）仅有：summary/top_fix_items/long_term_improvement/jd_evidence_chain/verification_notice
- Schema 定义了丰富的字段：optimization_summary/offer_go_summary/apply_readiness/optimization_stop_signal/top_fix_items/screening_focus/priority_suggestions/keyword_alignment/project_optimization/skill_section_optimization/summary_optimization/missing_evidence_plan/rewrite_examples/next_actions/authenticity_notice/analysis_basis
- 原因：Go Model 是 Mock Agent 输出结构，LLM Agent 输出需要后续映射改造

### 4.3 三类 Agent 共有战略字段

- apply_readiness：三类 Schema 均有，枚举一致
- optimization_stop_signal：三类 Schema 均有，枚举一致
- top_fix_items：三类 Schema 均有，结构一致（Match/Recommendation 共享 TopFixItem，ResumeOptimization 独立 ResumeOptimizationFixItem 多了 learn_more_query）
- generated_by / agent_status：三类 Go Model 均有
