## 三、新增 TwoColumnPageShell 的职责

**职责**：左侧主内容 + 右侧 aside 的响应式两栏布局。

**Props**：
```tsx
interface TwoColumnPageShellProps {
  children: ReactNode       // 左侧主内容
  aside?: ReactNode         // 右侧辅助栏（可选）
  className?: string        // 外层 wrapper 附加 className
  contentClassName?: string // 主内容区附加 className
  asideClassName?: string   // 右侧栏附加 className
}
```

**响应式规则**：
| 断点 | 布局 | 右侧栏宽度 |
|------|------|-----------|
| `< lg` | 单列，aside 在 children 下方 | 100% |
| `lg` (1024+) | 两列 grid | 320px |
| `xl` (1280+) | 两列 grid | 340px |

**关键 Tailwind 处理**：
- `min-w-0`：防止 grid 子元素溢出
- `minmax(0, 1fr)`：主内容自适应但可缩小
- `items-start`：两栏顶部对齐
- `gap-6 lg:gap-8`：间距

---

## 四、新增 AISidebarShell 的职责

**职责**：右侧 AI 辅助栏的 sticky 行为、宽度安全、最大高度、响应式降级。

**Props**：
```tsx
interface AISidebarShellProps {
  children: ReactNode              // 右侧 AI 模块内容
  className?: string               // 附加 className
  stickyTopClassName?: string      // desktop sticky top 偏移（默认 lg:top-24）
}
```

**响应式规则**：
| 桌面端（lg+） | 移动端（<lg） |
|-------------|-------------|
| `position: sticky` | `position: static` |
| `top: 96px` (top-24) | 正常流 |
| `max-height: calc(100vh - 7rem)` | `max-height: none` |
| `overflow-y: auto` | `overflow: visible` |

**安全性约定**：
- 不使用 `fixed`
- 不使用 `absolute`
- 不脱离布局流
- 不遮挡主内容
- 不造成横向滚动
- 不在此组件内渲染 Header / Navbar
