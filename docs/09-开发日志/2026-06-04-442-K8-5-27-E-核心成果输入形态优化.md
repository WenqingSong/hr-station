# K8-5-27-E：核心成果输入形态优化

## 本阶段目标

将项目经历和实习经历的"核心成果"从 textarea 改为动态成果列表。不改后端。

## UI 修改结果

| 模块 | 修改前 | 修改后 |
|------|--------|--------|
| 项目·核心成果 | `<Textarea>` 多行文本 | 动态列表（每条一行 Input + 删除按钮 + 添加按钮） |
| 实习·核心成果 | `<Textarea>` 多行文本 | 动态列表（同上） |

## state / payload 结果

| 字段 | 修改前 | 修改后 |
|------|--------|--------|
| `Project.achievements` | `string` | `string[]` |
| `Internship.achievements` | `string` | `string[]` |
| 默认值 | `""` | `[""]`（至少一条） |
| 移除时只剩一条 | — | 清空为 `[""]`（不删除到 0 条） |
| payload 构造 | `splitLines(achievements)` | `achievements.filter(Boolean)` |
| payload 输出 | `string[]` | `string[]`（不变） |

## 回填兼容结果

| 数据形态 | 回填结果 | helper |
|---------|---------|--------|
| `string[]`（新 V2） | 直接使用 | — |
| `string` 文本（V1/旧 V2） | `splitLines()` 拆分 | `toAchievementList()` |
| `undefined/null`（空数据） | `[""]` | `toAchievementList()` |

## 新增 helper

| 函数 | 用途 |
|------|------|
| `toAchievementList(value)` | 回填兼容：string→string[], 空→[""] |
| `addProjectAchievement(idx)` | 项目添加成果 |
| `updateProjectAchievement(idx, aIdx, val)` | 项目更新成果 |
| `removeProjectAchievement(idx, aIdx)` | 项目删除成果（至少保留 1 条） |
| `addInternshipAchievement(idx)` | 实习添加成果 |
| `updateInternshipAchievement(idx, aIdx, val)` | 实习更新成果 |
| `removeInternshipAchievement(idx, aIdx)` | 实习删除成果 |
