# K8-5-24-A — 简历编辑页底部保存模块左侧对齐修复

## 性质
UI bugfix（纯样式/布局修复，不改业务逻辑）。

## 问题现象

简历编辑页（MyResumesPage / ResumeEditorShell）底部「保存简历」模块的左边缘没有和左侧表单卡片严格对齐，视觉上脱离了左侧主内容流。

## 页面归属确认

实际页面是 **简历编辑页**（`/resumes/edit` 或 `/resumes/new`），不是岗位详情页。用户口头提到"岗位详情页面"属于误判。

## 问题原因

| 问题 | 原因 |
|------|------|
| 保存模块左边缘未对齐左侧表单 | `ResumeEditorShell` 将 `saveCard` 渲染在 `flex` 容器**外部**（Line 54），导致它独立占据 `max-w-[1280px]` 全宽 |
| 保存模块横跨右侧 sidebar 区域 | 同上——saveCard 不在 left column 的 `flex-1 min-w-0` 约束内 |

### 旧布局结构 (ResumeEditorShell.tsx)

```
<ContentPageShell max-w-[1280px]>
  <flex container>              ← flex: left + right
    <main flex-1>                ← 左侧表单卡片 (宽度 = 1280 - 280 - gap)
      <ResumeBasicsSection />
      <BasicInfoSection />
      ...
      <PortfolioExtraSection />
    </main>
    <aside w-[280px]>             ← 右侧状态栏
  </flex container>
  <div mt-8>{saveCard}</div>     ← 保存模块在 flex 外部！全宽
</ContentPageShell>
```

## 修改方案

| 文件 | 修改内容 |
|------|---------|
| `web/src/app/components/resume-editor/ResumeEditorShell.tsx` | 将 `{saveCard}` 从 flex 容器外部移入 main column 内部 |

### 新布局结构

```
<ContentPageShell max-w-[1280px]>
  <flex container>
    <main flex-1>
      <ResumeBasicsSection />
      ...
      <PortfolioExtraSection />
      <ResumeEditorSaveCard />    ← 现在在 main column 内，与表单卡片同宽
    </main>
    <aside w-[280px]>
  </flex container>
</ContentPageShell>
```

## 对齐结果

| 检查项 | 结果 |
|--------|:---:|
| 保存模块与左侧表单卡片同宽 | ✅ `flex-1 min-w-0` |
| 左边缘与左侧表单卡片对齐 | ✅ 同一父容器 |
| 右边缘与左侧表单卡片对齐 | ✅ 不上溢到 sidebar |
