# K8-5-29-B：证书与获奖模块外语考试动态列表实现

## 本阶段性质

前端简历编辑页功能增强。只改 `MyResumesPage.tsx`，不改后端/SQL/Agent。

## 修改清单

| 文件 | 修改 |
|------|------|
| `web/src/app/pages/MyResumesPage.tsx` | 新增 `LanguageExamDraft` 接口；`SkillsDraft` 删除 languageExamType/Score；新增 `languageExamDrafts` state + add/update/remove helper；回填改用 filter（全部 language_exam）；payload 改为多条 map；UI 改为动态列表 |

无后端修改。

## UI 实现结果

| 检查项 | 结果 |
|--------|:---:|
| 外语考试支持动态添加 | ✅ 按钮 + 自由填写 Input |
| 外语考试支持删除 | ✅ 每条有 🗑 按钮 |
| 考试类型从 Select 改为自由 Input | ✅ placeholder "如：CET-4、IELTS、日语 N2" |
| 空列表显示空状态提示 | ✅ "暂无外语考试" + "可以添加 CET-4…" |
| 多条可同时展示 | ✅ `languageExamDrafts.map` |
| 证书不受影响 | ✅ 独立 `certificateDrafts` |
| 获奖不受影响 | ✅ 独立 `awardDrafts` |

## state 修改结果

| 修改前 | 修改后 |
|--------|--------|
| `skillsDraft.languageExamType: string` | ❌ 删除 |
| `skillsDraft.languageExamScore: string` | ❌ 删除 |
| — | ✅ `languageExamDrafts: LanguageExamDraft[]`（动态列表） |
| `SkillsDraft` 含 4 字段 | `SkillsDraft` 含 2 字段（developmentLanguages + aiApplication） |

## payload 修改结果

| 修改前 | 修改后 |
|--------|--------|
| 单条 `{name, type:"language_exam", ...}` 从 skillsDraft 生成 | 多条 `languageExamDrafts.filter().map()` |
| `certificates[0]` 固定为 language_exam | certificates 含全部语言考试 + 普通证书 |

## 回填修改结果

| 修改前 | 修改后 |
|--------|--------|
| `certs.find(c.type === "language_exam")` → 取第一条回填 skillsDraft | `certs.filter(c.type === "language_exam")` → 全部回填 languageExamDrafts |
| 多条 language_exam 会丢失 | 全部恢复 |
| 旧 skills.language_exam 仍兼容 | ✅ 旧数据回填到 languageExamDrafts[0] |

## 兼容性确认

| 场景 | 结果 |
|------|:---:|
| 旧数据有 1 条 language_exam | ✅ 回填到 languageExamDrafts[0] |
| 旧数据有 3 条 language_exam | ✅ 全部回填 |
| 旧数据无 language_exam | ✅ languageExamDrafts 为空 |
| 普通证书（非 language_exam） | ✅ 不受影响 |
| 获奖 | ✅ 不受影响 |
| 旧 skills.language_exam 兼容 | ✅ V1 回填仍然生效 |
