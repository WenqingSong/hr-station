## 6. 关键决策

1. **Mock Agent 使用规则打分**：不调用真实 LLM，基于 target_city / target_role / skills_json 做简单规则打分
2. **优先级三级**：strong_recommend（≥50）/ recommend（30-49）/ try（<30）
3. **推荐结果保存快照**：每次调用推荐接口后，将结果保存到 recommendation_results 表
4. **limit 默认 5 最大 5**：推荐岗位数量有限，不做过多推荐
5. **resume_version_no 可选**：不传则使用最新简历版本
6. **推荐理由动态生成**：根据实际匹配项拼接理由，不使用固定文案
7. **路由路径**：`/api/jobs/recommend` 必须在 `/api/jobs/` 之前注册（Go ServeMux 匹配优先级）
8. **不引入新依赖**：使用已有的 database/sql + encoding/json

## 8. 当前风险

- `/api/jobs/recommend` 和 `/api/jobs/` 路由优先级：Go ServeMux 中具体路径优先于通配路径，已在代码中确保 recommend 在 jobs/ 之前注册
- Mock 推荐打分规则较简单，可能对某些简历-岗位组合的评分不够准确（Demo 阶段可接受）

## 9. 如何验证

```bash
# 启动服务
cd server && SERVER_PORT=18087 go run ./cmd/server

# 登录获取 token
TOKEN=$(curl -s -X POST http://localhost:18087/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"arthur@example.com","password":"123456"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['data']['token'])")

# 默认推荐
curl -s -X POST http://localhost:18087/api/jobs/recommend \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{}'

# 指定简历版本
curl -s -X POST http://localhost:18087/api/jobs/recommend \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"resume_version_no":1,"limit":3}'

# 非法版本
curl -s -X POST http://localhost:18087/api/jobs/recommend \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"resume_version_no":999}'

# 未登录访问（预期 40100）
curl -s -X POST http://localhost:18087/api/jobs/recommend \
  -H "Content-Type: application/json" \
  -d '{}'

# 验证推荐结果写入数据库
docker exec offer-catcher-mysql mysql -uroot -ppassword offer_catcher \
  -e "SELECT COUNT(*) FROM recommendation_results;"
```
