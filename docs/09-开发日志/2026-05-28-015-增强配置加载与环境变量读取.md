## 5. 删除内容

- 无（旧字段保留为兼容字段）

## 6. 关键决策

1. **保留兼容字段**：在 Config 顶层保留 ServerPort/AppEnv/LogLevel，使 main.go 无需修改即可编译
2. **不引入 godotenv**：配置通过进程环境变量加载，不在代码中自动读取 .env 文件
3. **JWT/LLM/Database 仅读取不使用**：JWT 配置阶段 3 才使用，LLM 配置阶段 4 才使用，Database 配置阶段 2-5 才连接
4. **ExpireHours 为 int 类型**：使用 `getEnvAsInt` 读取，默认 168
5. **EnableMockAgent 为 bool 类型**：使用 `getEnvAsBool` 读取，默认 true
6. **辅助函数不 panic**：解析失败时使用默认值
