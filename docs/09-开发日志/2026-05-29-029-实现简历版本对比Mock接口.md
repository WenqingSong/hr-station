## 6. 关键决策

1. **路由精确匹配**：Go 标准库 `http.ServeMux` 支持精确匹配优先，注册 `/api/resumes/versions/compare` 不会与 `/api/resumes/versions/` 冲突。精确路径优先于前缀匹配。
2. **from/to 参数通过 query 传递**：版本对比使用 GET 方法，from 和 to 作为 query 参数（而非请求体）
3. **分数计算基于简历完整度**：Mock 打分规则基于简历字段的填充度和详细程度，不是基于匹配度
4. **风险变化趋势**：使用 reduced / unchanged / stable 三种趋势表示风险变化方向
5. **建议完成情况**：跟踪三种典型建议（后端技能、量化指标、缓存/并发）的完成状态
6. **真实性提示**：每条对比结果都包含 authenticity_notice，明确告知用户不要虚构经历
