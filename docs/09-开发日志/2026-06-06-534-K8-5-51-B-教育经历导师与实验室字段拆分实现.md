# K8-5-51-B：教育经历导师与实验室字段拆分实现

## 背景（K8-5-51-A 盘点结论）

当前教育经历只有 `lab` 字段，前端显示为"导师 / 实验室"合并标签。需要拆分为 `advisor`（导师）+ `lab`（实验室）两个独立字段。

## 字段命名决策

- **导师**: `advisor` — 比 `tutor` 更专业，比 `supervisor` 更通用，快照 V2 已使用此名
- **实验室**: `lab` — 保留现有字段名，减少迁移成本

## DB 修改

| 操作 | 结果 |
| -- | -- |
| `ALTER TABLE ADD COLUMN advisor` | ✅ `varchar(100) NOT NULL DEFAULT '' COMMENT '导师'` |
| `MODIFY lab COMMENT '实验室'` | ✅ |
| `init.sql` 同步 | ✅ |

## 前端编辑页拆分

修改前：
```tsx
<label>导师 / 实验室</label>
<Input value={edu.lab} onChange={...} placeholder="如：XX实验室" />
```

修改后：
```tsx
<label>导师</label>
<Input value={edu.advisor} onChange={...} placeholder="如：张教授" />

<label>实验室</label>
<Input value={edu.lab} onChange={...} placeholder="如：智能信息处理实验室" />
```

## 详情页拆分

```tsx
{edu.advisor && <InfoItem label="导师" value={edu.advisor} />}
{edu.lab && <InfoItem label="实验室" value={edu.lab} />}
```
