# K8-5-11-2：首页三栏响应式适配

## 一、当前问题

- `JobFilterSidebar` 固定 `w-[260px] shrink-0`，小屏下宽度无法自适应
- `JobList` 有 `max-w-[820px]`，大屏 grid 中间列被额外限制

## 二、响应式布局方案

| 屏幕 | 布局 |
|------|------|
| ≥1280px | 三栏（筛选260px + 列表 1fr + AI 300px），AI sticky |
| <1280px | 单列（筛选→列表，AI hidden） |
| 所有屏幕 | `overflow-x-hidden`，筛选栏 w-full |

## 三、修改清单

| 文件 | 修改 | 原因 |
|------|------|------|
| `JobFilterSidebar.tsx` | `w-[260px] shrink-0` → `w-full xl:w-[260px]` | 小屏全宽 |
| `JobList.tsx` | `flex-1 max-w-[820px]` → `min-w-0 w-full` | 跟随 grid 列宽 |

JobListPage 已有正确的三栏 grid + `hidden xl:block`，无需改动。
