## 6. restart / reset / reset-up 语义

| 命令 | 行为 | 清 volume | 需 CONFIRM |
|------|------|----------|-----------|
| `make restart` | 软重启 = stop + up | ❌ | ❌ |
| `make restart-soft` | 同 restart | ❌ | ❌ |
| `make reset` | 停止 + 清 volume | ✅ | ✅ |
| `make reset-up` | 清 volume + 重启 | ✅ | ✅ |

主推荐：restart 不清 volume，reset/reset-up 清 volume 需 CONFIRM=yes。

## 7. 专业输出设计

统一使用 `[Offer Catcher]` 前缀和 `[OK]` / `[WARN]` / `[ERROR]` / `[INFO]` 标记。

`make up` 输出：
- 步骤编号 `[1/7]` ~ `[7/7]`
- Access 段：Frontend / Backend / Health / MySQL / Nginx(pending)
- Useful commands 段：status / logs / restart-soft / reset-up / down

`make status` 输出：
- 基础设施 / 后端 / 前端 / Nginx 四段
- 访问地址段

`make nginx-logs` 输出：
- `[WARN] nginx is not configured yet. This will be enabled in 4-3.7.B.3/B.4.`
