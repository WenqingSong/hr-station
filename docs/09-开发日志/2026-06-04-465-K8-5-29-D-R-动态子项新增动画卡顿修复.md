# K8-5-29-D-R：简历编辑页动态子项新增动画卡顿修复

## 本阶段性质

前端动画优化。只改 CSS + 2 处 JSX 逻辑，不改 state/payload/回填/后端。

## 卡顿原因判断

| 可能原因 | 是否存在 | 处理 |
|----------|:---:|------|
| 使用 `translateY` 而非 `translate3d` | ✅ | 改为 `translate3d` 触发 GPU 合成层 |
| 缺少 `will-change` | ✅ | 添加 `will-change: opacity, transform` |
| 缺少 `animation-fill-mode: both` | ✅ | 添加 `both` 避免初始帧闪烁 |
| 动画 180ms 偏长 | ⚠️ | 缩短至 140ms |
| easing 不够自然 | ⚠️ | 改为 `cubic-bezier(0.16, 1, 0.3, 1)` |
| 回填时所有已有项重复动画 | ✅ | 新增 `recentlyAdded` 状态，只给刚添加的项动画 |
| `translateY` 从 0.5rem 太突兀 | ⚠️ | 缩减为 4px |

## 修改清单

| 文件 | 修改 |
|------|------|
| `web/src/styles/tailwind.css` | translateY→translate3d；180ms→140ms；ease-out→cubic-bezier；+will-change；+animation-fill-mode:both |
| `web/src/app/pages/MyResumesPage.tsx` | 新增 `recentlyAdded` state + type；7 add helpers 加 `setRecentlyAdded`；7 卡片容器改为条件渲染 `resume-item-enter` |

## 动画优化结果

| 项 | 修改前 | 修改后 |
|----|--------|--------|
| transform | `translateY(0.5rem)` | `translate3d(0, 4px, 0)` |
| 时长 | 180ms | 140ms |
| easing | `ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` |
| fill-mode | 无 | `both` |
| will-change | 无 | `opacity, transform` |
| 动画范围 | 所有 map 项都动画 | 只有 `recentlyAdded` 项动画 |
| prefers-reduced-motion | ✅ 保留 | ✅ `will-change: auto` |

## 动画应用范围

| 子项 | 是否有动画 | 触发条件 |
|------|:---:|------|
| 教育经历 | ✅ | `recentlyAdded.type==="education"` |
| 项目经历 | ✅ | `recentlyAdded.type==="project"` |
| 实习经历 | ✅ | `recentlyAdded.type==="internship"` |
| 证书 | ✅ | `recentlyAdded.type==="certificate"` |
| 获奖 | ✅ | `recentlyAdded.type==="award"` |
| 外语考试 | ✅ | `recentlyAdded.type==="languageExam"` |
| 作品链接 | ✅ | `recentlyAdded.type==="work"` |
| 项目/实习核心成果 | ❌ | 行级不加 |
| 回填已有项 | ❌ | `recentlyAdded` 为 null 时不动画 |
