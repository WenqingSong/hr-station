# K8-5-48-C：前端简历模块按关系型 DTO 重构

## 一、本阶段目标

前端简历模块彻底从旧 JSON / versionNo 结构切换为关系型嵌套 DTO。

## 二、K8-5-48-B 后端关系型结构摘要

```text
resumes 主表：id, user_id, name, is_current, real_name, phone, email, city,
  professional_skills, ai_application, homepage, additional_info, raw_text

7 张子表：
  resume_educations, resume_projects, resume_internships,
  resume_language_exams, resume_certificates, resume_awards, resume_works
```

后端 API 路径：
```text
GET    /api/resumes
GET    /api/resumes/current
GET    /api/resumes/{id}
POST   /api/resumes
PUT    /api/resumes/{id}
DELETE /api/resumes/{id}
POST   /api/resumes/{id}/set-current
GET    /api/resumes/compare?from_id=X&to_id=Y
```

## 三、修改文件

| 文件 | 修改 |
| -- | -- |

| `web/src/utils/redirect.ts` | versionNo→id：normalizeResumeEditRedirect 用 id 参数；isValidResumeId 替代 isValidVersionNo（保留 deprecated wrapper） |
