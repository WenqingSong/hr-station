## 4. 新增接口

- **路径**：`POST /api/resumes/optimize`
- **认证**：需要 Bearer Token
- **请求体**：`resume_text`（必填）+ `target_job`（必填，title 或 jd_text 至少一个）+ `target_section`（可选）+ `user_intention`（可选）
- **响应体**：包含 `apply_readiness` / `optimization_stop_signal` / `top_fix_items` / `long_term_improvement` / `jd_evidence_chain` / `verification_notice`

## 5. Mock Agent 设计

- 不调用 LLM / Prompt / Schema / Pipeline
- 根据简历文本和 JD 关键词重叠度判断 `apply_readiness`
- 简历过短返回 `insufficient_information`
- `top_fix_items` 最多 3 项
- 使用"示例参考"而非"建议改为"
- 不编造具体指标（QPS、DAU、百分比）
- 每条 fix_item 包含 `self_check_question` / `learn_more_query`
- `long_term_improvement` 每项包含"不建议延后当前投递"提醒
- `jd_evidence_chain` 包含 `evidence_strength` / `match_judgement` / `screening_risk`
- `verification_notice` 提醒用户核实后使用

## 6. Service / Controller / Route 设计

- Service：校验参数 → 调用 Mock Agent → 组装响应 → 保存快照（best effort）
- Handler：POST → 解析 JSON → 调用 Service → 返回统一响应
- Route：`/api/resumes/optimize`，需要 Auth 中间件
- 参数校验：resume_text 必填、target_job 必填、title/jd_text 至少一个

## 7. Model 设计

- `ResumeOptimizationSnapshot`：DB 持久化模型
- `ResumeOptimizationTargetJob`：请求中的目标岗位
- `ResumeOptimizationUserIntention`：请求中的用户意向
- `ResumeOptimizationFixItem`：快速优化项（含 issue / why_it_matters / action / example_reference / self_check_question / learn_more_query / estimated_effort）
- `ResumeOptimizationLongTermItem`：长期提升项（含 direction / note）
- `ResumeOptimizationJDEvidenceItem`：JD 证据链项（含 jd_requirement / resume_evidence / evidence_strength / match_judgement / gap_analysis / screening_risk）
- `ResumeOptimizationResult`：完整结果（含 agent_status / generated_by / fallback_required / repair_applied / apply_readiness / optimization_stop_signal / summary / top_fix_items / long_term_improvement / jd_evidence_chain / verification_notice）
