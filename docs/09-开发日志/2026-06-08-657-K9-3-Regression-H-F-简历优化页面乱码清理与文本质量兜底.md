# K9-3-Regression-H-F — 简历优化页面乱码清理与文本质量兜底

日期：2026-06-08
性质：P0 修复。2 文件修改（后端 1 + 前端 1）。

## 根因定位

**问题**：快速优化模式下 `delivery_focus` 字段出现乱码 `��`。

**根因**：`server/internal/agent/resume_optimization_mock_v2.go:153`

```go
// 修复前：byte-slice 截断中文多字节字符
if len(focus) > 80 { focus = focus[:80] + "..." }

// 修复后：rune-safe slice
if len(focus) > 80 { focus = string([]rune(focus)[:80]) + "..." }
```

中文 UTF-8 字符占 3 bytes，`focus[:80]` 按字节截断可能在多字节字符中间切断，产生 U+FFFD 替换字符。
