## 5. 关键决策

1. **Docker 第一版只稳定 MySQL**：前端和后端用本地命令开发，便于热更新
2. **Makefile 以 CNB 重启恢复为核心**：doctor → init → up → dev-web/dev-server 链路
3. **所有命令幂等**：重复执行不破坏环境
4. **make reset 标记为危险命令**：执行前需确认
5. **Go 后端阶段 1 只实现 /healthz**：业务接口留给阶段 3
6. **DB_HOST 本地运行用 127.0.0.1**：Docker Compose 内用 mysql 服务名
7. **Redis 阶段 7 才引入**：当前不需要
