## 3. 当前数据链路图

```
前端页面 MyResumesPage (state: resumeName, jobDirection, personalName, degree,...)
  ↓ handleSave → 构造 payload
web/src/api/resumes.ts: createResume() / updateResume()
  ↓ POST /api/resumes (body: {name, phone, email, location, target_city,
  ↓   target_role, education, experience, project, skills, self_evaluation})
server/internal/http/resume_handler.go → middleware → Create(req)
  ↓
server/internal/service/resume_service.go → CreateVersion()
  ↓ GetNextVersionNo() → 新 version_no
  ↓ repository.CreateVersion()
server/internal/repository/resume_repository.go → INSERT INTO resume_versions
  ↓
database: resume_versions (id, user_id, version_no, name, phone, email, location,
         target_city, target_role, education_json, experience_json,
         project_json, skills_json, self_evaluation, raw_text, created_at)
  ↓
response → ResumeVersionResponse → client.ts → adapter
  ↓
adapter/resumeAdapter.ts: toResumeManagementViewModel() → ResumeManagementViewModel
  ↓
ResumeManagementPage / MyResumesPage (edit mode) / SelectResumeModal / AI pages
  ↓
Agent: RecommendationRequest/MatchAnalysisRequest { resume_version_no }
       → backend → agent → ResumeSnapshot → Prompt → LLM
```

## 7. Agent / Prompt / Schema 链路分析

| 能力 | 当前输入 | 方式 | 缺失 |
|------|---------|------|------|
| **岗位推荐** | `resume_version_no` → 后端查版本 → `ResumeSnapshot` | 版本号 | GPA/排名/证书/奖项/AI技能 |
| **岗位匹配** | `resume_version_no` + `jobId` | 版本号 | 同上 |
| **简历优化** | `resume_text` + `target_job` (旧模式) 或 `resume_version_no` | 结构化 vs 文本 | 缺少 field-level 优化 |
| **简历对比** | `from_version_no` + `to_version_no` → LLM | 两版本对比 | 仅基准字段，缺新字段 |

**ResumeSnapshot 结构推测**：基于 `ResumeVersion` model，包含 name/phone/email/location/target_city/target_role/education/experience/project/skills/self_evaluation。

## 10. 问题分级

| 级别 | 问题 | 影响 | 建议阶段 |
|:---:|------|------|:---:|
| **P0** | 无 | — | — |
| **P1** | education/experience/project 以 JSON 存，非结构化 | 新增字段需要 JSON schema 兼容，不易查询 |
| **P1** | ResumeSnapshot 结构仅覆盖旧字段 | Agent 无法感知新字段 |
| **P1** | MyResumesPage 保存 payload 与后端 CreateResumeRequest 字段映射复杂 | 新增字段需要同步多处 |
| **P2** | 学位字段仅在 education JSON 内，不在顶层 | 推荐/匹配时应作为顶层筛选维度 |
| **P2** | 前端 adapter 大量手动映射 | 新增字段维护成本高 |
| **P2** | 无 GPA、证书、奖项、AI 技能等字段 | AI 匹配/优化缺少学生画像关键信息 |
