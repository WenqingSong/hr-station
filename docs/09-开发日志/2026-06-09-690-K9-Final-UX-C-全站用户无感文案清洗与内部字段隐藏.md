## 禁用词检查结果

| 命中 | 文件 | 类型 | 是否用户可见 | 是否阻断 |
|---|---|---|---|---|
| 标签（JobDetailBanner/JobHeroBanner 等） | components/jobs/ | UI 组件标签胶囊 | ✅ 但非报告型 | ❌ |
| 能力标签（SkillsSection） | components/resume-editor/ | 用户可见描述 | ✅ | ❌ 超出范围 |
| 基础画像（MyResumesPage） | pages/ | 用户可见文案 | ✅ | ❌ 超出范围 |
| mock_agent / mock_quality | 页面代码 | 内部变量值 | ❌ | ❌ |
| profileDominantProfile | adapter / API | 内部变量名 | ❌ | ❌ |
| backend_engineering 等枚举 | 后端代码 | 内部判断值 | ❌ | ❌ |

### 超出范围说明

- `SkillsSection.tsx` 中的"能力标签"：属于简历编辑器，不在本阶段允许修改的4页面范围内
- `MyResumesPage.tsx` 中的"基础画像"：不在本阶段允许修改的4页面范围内
- `JobDetailBanner/JobHeroBanner` 中的"标签"：属于岗位详情展示组件的 UI 标签胶囊，非报告型列表
