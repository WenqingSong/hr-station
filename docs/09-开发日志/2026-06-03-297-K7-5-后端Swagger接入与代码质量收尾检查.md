## 2. Swagger 接入方案

### 方案

- **静态 OpenAPI 3.0 JSON**：`server/docs/swagger.json`，手写规范，覆盖 15 个路径
- **Swagger UI**：CDN 自托管 HTML，位于 `/swagger/index.html`
- **无新增依赖**：纯 `net/http` 内置能力 + CDN 前端资源

### 访问地址

| 地址 | 内容 |
|------|------|
| `http://localhost:8080/swagger/doc.json` | OpenAPI 3.0 JSON |
| `http://localhost:8080/swagger/index.html` | Swagger UI 页面 |

### 覆盖接口

| 分组 | 接口 |
|------|------|
| Health | GET /healthz |
| Auth | POST /register, POST /login, GET /me |
| Jobs | GET /jobs, GET /jobs/facets, GET /jobs/{id} |
| Resumes | POST /resumes, GET /current, GET /versions, GET /versions/{v} |
| Recommendation | POST /jobs/recommend（含 generation_tier） |
| Match Analysis | POST /jobs/{id}/match（含 generation_tier） |
| Resume Optimization | POST /resumes/optimize（含 mode=core + generation_tier） |
| Version Compare | GET /resumes/versions/compare（含 generation_tier） |

### 关键参数覆盖

- ✅ `generation_tier`（enum: fast/quality, default fast）
- ✅ `mode`（enum: core）
- ✅ `agent_status` / `generated_by` / `fallback_reason`
- ✅ 错误响应（40001, 40100, 50000）
