# K8-5-7：Navbar 顶部透明毛玻璃精修

## 一、当前问题

K8-5-6 的 Navbar 统一使用 `bg-white/68` 浅色毛玻璃，在 Banner 上方显得像一条浅蓝色实体横条，不能透出 Banner 图片。用户要求 Navbar 像覆盖在 Banner 上的透明玻璃层，而不是独立的一条浅色背景条。

## 二、修复方案

### 双态透明玻璃

| 状态 | 判定条件 | 视觉方案 |
|------|---------|---------|
| 顶部（覆盖 Banner） | `scrollY ≤ 80` | `bg-slate-950/18 backdrop-blur-md` + 白字 + 透明白边框 |
| 滚动后（白底内容区） | `scrollY > 80` | `bg-white/58 backdrop-blur-xl` + 深字 + 浅色边框 |

### 顶部状态参数

| 参数 | 值 |
|------|-----|
| 背景 | `bg-slate-950/18` |
| 模糊 | `backdrop-blur-md backdrop-saturate-150` |
| 边框 | `border-white/10` |
| 阴影 | `shadow-none` |
| 品牌文字 | `text-white`（+ `textShadow: 0 1px 12px rgba(0,0,0,0.18)`） |
| 链接文字 | `text-white/88 hover:text-white` |
| 登录按钮 | `border-white/25 bg-white/8 rounded-full` |

### 滚动后状态参数

| 参数 | 值 |
|------|-----|
| 背景 | `bg-white/58` |
| 模糊 | `backdrop-blur-xl backdrop-saturate-150` |
| 边框 | `border-slate-200/40` |
| 阴影 | `shadow-[0_8px_24px_rgba(15,23,42,0.06)]` |
| 品牌文字 | `text-slate-950` |
| 链接文字 | `text-slate-700 hover:text-slate-950` |

## 三、下滑隐藏 / 上滑显示

**保留** K8-5-4 逻辑：
- 下滑且 scrollY > 80：隐藏（`-translate-y-[110%]`）
- 上滑：显示（`translate-y-0`）
- scrollY ≤ 20：强制显示

动画扩展为多属性过渡：`transition-[transform,background-color,border-color,box-shadow,color] duration-300 ease-[cubic-bezier(0.22,1,0.36,1)]`

## 四、修改文件清单

| 文件 | 修改内容 | 原因 |
|------|---------|------|
| `web/src/app/components/Navbar.tsx` | 新增 `isTop` 状态 + 双态透明玻璃（顶部深色透明 / 滚动后浅色）+ 文字/按钮颜色随态切换 | 核心修改 |
