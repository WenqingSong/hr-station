## 3. Navbar 入口现状

| 登录状态 | 当前入口 | 触发方式 | 后续建议 |
|---------|---------|---------|---------|
| 未登录 | "登录" 胶囊按钮 | `Link to="/login"` → 页面跳转 | 改为 `onClick={setDialogOpen(true)}` 弹窗 |
| 已登录 | "我的简历" + "退出" | Link / button | 保持不变 |

关键发现：
- 无注册入口在 Navbar（注册只在 LoginPage 底部有 Link）
- Navbar `isLoggedIn` 通过 `location` 变化触发 `getAuthToken()` 重新检测
- 弹窗登录成功后需通知 Navbar 刷新状态：可通过 `navigate` 触发 or `window.dispatchEvent` 自定义事件

## 4. 路由与 fallback 分析

| 项目 | 当前状态 | 建议 |
|------|---------|------|
| `/login` | routes.tsx 注册为独立路由 | ✅ **保留** fallback（URL 直达时也可打开弹窗，或渲染 AuthDialog） |
| `/register` | 同上 | ✅ 保留 |
| 保护路由 | 无 | 暂不处理 |

推荐方案：
- **保留 `/login` `/register` 路由**，URL 直达时渲染 AuthDialog 而非整页
- 新增 `AuthDialog` 组件，封装 LoginPage/RegisterPage 逻辑（或直接复用表单 JSX）
- 放置位置：`components/AuthDialog.tsx`，state 提升到 `App.tsx` 或 `RootLayout`

## 5. Auth API 与状态同步分析

| 模块 | 当前实现 | 风险 | 后续建议 |
|------|---------|------|---------|
| 登录 API | `login(LoginRequest)` → `AuthTokenResponse` | 无 | 复用 |
| 注册 API | `register(RegisterRequest)` → `AuthTokenResponse` | 无 | 复用 |
| token 存储 | localStorage `offer_catcher_auth_token` | 无 | 复用 |
| Navbar 感知 | `useEffect → getAuthToken()` on `location` change | 弹窗内 navigate 后 location 变 → 自动刷新 ✅ | 无需额外处理 |
| 全局 auth context | **无** | 无需引入 | 保持当前 simple token check |

关键发现：弹窗登录成功后 `navigate("/")` 会触发 location 变化 → Navbar `useEffect` 重新 `getAuthToken()` → `isLoggedIn` 自动变为 true。**不需要额外 auth event。**

## 6. Dialog / 玻璃模糊能力分析

| 能力 | 当前是否支持 | 建议 |
|------|-----------|------|
| Dialog 组件 | ✅ `@radix-ui/react-dialog` + shadcn wrapper | 充分，支持 open/onOpenChange/Portal |
| 参考实现 | ✅ `SelectResumeModal` | 已有 modal pattern，可参考 |
| DialogOverlay | ✅ 当前 `bg-black/50` | 可传 className 注入 `backdrop-blur-xl` |
| DialogContent | ✅ 支持 className 覆盖 | 可定制白色半透明玻璃 |
| backdrop-blur | ✅ Tailwind 原生支持 | `backdrop-blur-xl backdrop-saturate-150` |
| 动画 | ✅ radix built-in: `scale-95→100` + `opacity-0→100` | 已有，无需新增 |

**玻璃模糊推荐方案**（不全局改 Dialog，局部在 AuthDialog 内定制）：

```tsx
// AuthDialog Overlay: 深色玻璃模糊
<DialogOverlay className="bg-black/30 backdrop-blur-xl backdrop-saturate-150" />

// AuthDialog Content: 白色半透明玻璃
<DialogContent className="bg-white/80 backdrop-blur-2xl ring-1 ring-gray-200/40 rounded-3xl ..." />
```

这样不影响 `SelectResumeModal` 等其他 Dialog。
