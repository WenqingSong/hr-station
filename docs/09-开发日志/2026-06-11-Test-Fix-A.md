## 背景

Dev-Reboot 系列完成后，`go test ./server/...` 有 10 个测试失败。

## 失败分布

| 包 | 失败数 | 原因 |
|---|---|---|
| agent | 5 | Mock 数据缺字段（evidence_chain、apply_readiness 等） |
| llm | 1 | DefaultConfig TimeoutSeconds 期望值过期 |
| prompt | 1 | List 期望 6 个 prompt，实际 14 个（新增 8 个 Deep Agent prompt） |

## 修复内容

### 配置测试
- `config_test.go`：TimeoutSeconds 期望值 30→120（匹配 DefaultConfig 当前值）

### Loader 测试
- `prompt/loader_test.go`：List 期望 6→14，新增 8 个 Deep Agent PromptName
- `schema/loader_test.go`：List 期望 5→13，新增 8 个 Deep Agent SchemaName；清除残留代码
- 8 个 schema JSON 文件添加 `title` 字段（4 个通过 sed 插入，4 个通过 python json dump）

### Mock 数据补齐
- `match_mock.go` `AnalyzeFast()`：
  - 补齐 `EvidenceChain`（2 条：整体评估 + skills 模块）
  - 补齐 `ApplyReadiness`
  - 补齐 `OptimizationStopSignal`
  - 补齐 `TopFixItems`
  - 补齐 `AuthenticityNotice`
  - 修正 `ScreeningResult` 从 `matchLevel()` 改为 `"possible"`（通过枚举校验）

### 未改动
- 不回滚 ENABLE_MOCK_AGENT/LLM_FALLBACK_ENABLE
- 不回滚 Hy3 默认配置
- 不修改前端
