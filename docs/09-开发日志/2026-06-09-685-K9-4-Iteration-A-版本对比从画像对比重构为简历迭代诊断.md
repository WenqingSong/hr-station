## 6. 新 Agent 输出标准

| 字段/模块 | 标准 |
| -- | -- |
| `iteration_summary` | 一句话说明迭代本质（从 X 到 Y 的变化），不出现 profile label |
| `improved_items` (to_strengths 重定义) | ≥3 条：新版相比旧版具体增强在哪 + 为什么对初筛有帮助 |
| `remaining_gaps` (to_risks 重定义) | ≥3 条：新版缺什么证据 + 会造成什么筛选风险 + 怎么补 |
| `keep_from_items` | ≥2 条：保留什么 + 为什么 + 放下一版哪里；如无值得保留的 → 明确说明 |
| `merge_plan` (merge_suggestions 重定义) | ≥3 条：动作词(保留/删除/压缩/合并/改写/补充) + 具体模块 + 原因 |
| `rewrite_examples` | ≥2 条：原写法 / 当前写法 / 下一版建议 / 为什么 |
| `screening_impact` (delivery_advice 重定义) | 对初筛的影响，不夸大；有岗位→"更适合该岗位"；无岗位→"岗位信号更集中" |
