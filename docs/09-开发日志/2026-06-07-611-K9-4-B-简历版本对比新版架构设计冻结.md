## 4. 设计要点摘要

### 输入模型
- `from_resume_id` + `to_resume_id`（必填，不能相同）
- `comparison_mode`: general / target_direction / target_job
- `generation_tier`: fast / quality
- `target_direction` / `job_id`（按模式可选）

### API
- `POST /api/resumes/compare` — 生成
- `GET /api/resumes/compare/latest` — 读取（三维联合过滤）
- 旧 `GET /versions/compare` 废弃为 deprecated adapter

### 数据库
- 开发库 ALTER 11 列 + 3 索引（不修改 init.sql）
- Metadata 三件套: generation_tier / generated_by / status
- Profile 元数据: from/to profile_type / dominant_profile
- Append-Only 模式

### 前端状态机
```
loading_latest → has_result? → fast_done/deep_done
                             → no → fast_loading → fast_done → (click Deep) → deep_loading → deep_done
```
- DisplayMode token: fast_compact / deep_full
- ActiveResult 回退: Deep 失败 → fallback Fast

### Fast / Deep 差异化
- Fast: 3句话结论 + 简略差异 + 简要建议
- Deep: 完整差异 + keep/merge + rewrite_examples（最核心差异化）+ next_version

### 复用
- ResumeProfile（方向判断）
- K9-3 optimization（改写参考）
- AgentStepLoadingOverlay（Deep 进度）
