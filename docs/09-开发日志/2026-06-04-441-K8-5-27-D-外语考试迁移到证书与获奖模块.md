# K8-5-27-D：外语考试迁移到证书与获奖模块

## 本阶段目标

将外语考试/等级从 SkillsSection 迁移到 CertificatesSection。不改后端/SQL/Agent。

## UI 迁移结果

| 项 | 修改前位置 | 修改后位置 |
|----|---------|---------|
| 外语考试 / 等级 | SkillsSection（技能信息模块） | CertificatesSection（证书与获奖模块最前面） |
| 考试类型 Select | SkillsSection | CertificatesSection ✅ |
| 分数 / 等级 Input | SkillsSection | CertificatesSection ✅ |
| languageExamType/languageExamScore 变量 | 保留在 SkillsDraft | 保留（UI 迁移至新位置） |

## payload 迁移结果

| 字段 | 修改前 | 修改后 |
|------|--------|--------|
| `skills.language_exam` | `{type, score}` | **不存在** ✅ |
| `skills.development_languages` | 存在 | **不变** ✅ |
| `skills.ai_application` | 存在 | **不变** ✅ |
| `certificates[0]` | 普通证书 | **language_exam 项前置** ✅ |
| `certificates.type` | 普通证书类型 | **`"language_exam"` 标识外语** ✅ |

最终 skills payload：
```json
{ "development_languages": [...], "ai_application": "..." }
```

最终 certificates payload：
```json
[
  { "name": "CET-4", "type": "language_exam", "level": "CET-4", "score": "503" },
  { "name": "阿里云 ACP", "type": "云计算认证", "level": "中级" }
]
```
