# K8-5-14-J-R：简历编辑页保存操作区改为底部普通模块

## 1. 本阶段目标

用户反馈：保存区不应 fixed 在视口底部，而应和"技能关键词""自我评价"一样，是页面内容流中的最后一个卡片模块。

**目标**：将 fixed 底部保存栏改为页面内容流末尾的普通卡片模块。

## 2. 为什么取消 fixed 保存栏

K8-5-14-J 将 `sticky` 改为 `fixed`，但用户认为 fixed 悬浮栏不像正式产品的编辑器操作栏，更希望保存区回归为普通内容模块，跟随页面滚动，自然出现在自我评价模块之后。

## 3. 修改方案

| 区域 | 修改内容 | 原因 |
|------|---------|------|
| 保存容器 | `fixed inset-x-0 bottom-0 z-40 bg-white/90 backdrop-blur-xl shadow-[...]` → 普通 `<section className="rounded-2xl bg-white ring-1 ring-gray-100 p-6">` | 改为页面流末尾卡牌模块 |
| 保存栏位置 | 独立于主内容流之外 | 放入主表单 `space-y-5` 末尾，成为最后一个模块 |
| 页面底部留白 | `pb-32 md:pb-36`（为 fixed 栏预留） | 删除额外 padding，依赖 ContentPageShell 的 `pb-12` |
| 内部布局 | 横排按钮栏 | `flex-col gap-4 md:flex-row md:items-start md:justify-between`（左文案右按钮） |
| 保存标题 | 无标题 | 新增标题 `mode==="add" ? "创建简历" : "保存简历"` |
| 按钮 spinner | 无 | 新增 `<Loader2 animate-spin>` |
| 成功/失败提示 | 单独在表单流中 | 移入保存模块卡片内部（`mt-4`） |
| 错误图标 | 无 | 新增 `<AlertCircle>` |
| 导入 | — | 新增 `Loader2`、`AlertCircle` 导入 |
