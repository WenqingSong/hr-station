# K8-5-14-J：简历编辑页删除右侧状态栏与固定底部保存栏重设计

## 1. 本阶段目标

用户反馈：
1. 右侧"简历状态"卡片占用空间但信息价值不够高。
2. 主表单被压窄（双栏 `xl:grid-cols-[minmax(0,1fr)_320px]`），右侧显得拥挤。
3. 底部保存栏为 `sticky`，视觉上像内容流的一部分，不像正式编辑器的操作栏。

**目标**：删除右侧栏 → 单主栏布局 → 底部保存栏 fixed 到视口底部。

## 2. 修改方案

| 区域 | 修改内容 | 原因 |
|------|---------|------|
| 右侧状态栏 | **删除** `ResumeStatusSidebar`（完成度/AI可用性/缺失项/最近保存/版本对比） | 占用空间，信息价值不高 |
| 布局 | `grid xl:grid-cols-[minmax(0,1fr)_320px]` → 单栏 `space-y-5` | 释放表单宽度 |
| 页面宽度 | `max-w-[1280px]` → `ContentPageShell maxWidthClassName="max-w-[1040px]"` | 单栏表单适合 1040px |
| 底部保存栏 | `sticky bottom-0` → `fixed inset-x-0 bottom-0 z-40` | 固定在视口底部，不再随内容滚动 |
| 保存栏视觉 | 新增 `backdrop-blur-xl` + `shadow-[0_-12px_30px_rgba(15,23,42,0.06)]` | 毛玻璃 + 上阴影，专业编辑器风格 |
| 底部留白 | `pb-24` → `pb-32 md:pb-36` | 防止固定栏遮挡最后的 self-evaluation textarea |
| 内部 wrapper | 去掉冗余 `mx-auto max-w-[1280px] px-4`（ContentPageShell 已提供） | 简化 |
| 保存文案 | "基于当前简历" → "基于最新保存版本" | 语义更精准 |
| ResumeSkeleton | 删除右侧栏骨架，改单栏 `max-w-[1040px]` | 与主页面一致 |
