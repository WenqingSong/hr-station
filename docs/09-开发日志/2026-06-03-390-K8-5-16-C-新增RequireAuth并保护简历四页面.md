# K8-5-16-C — 新增 RequireAuth 并保护简历四页面

> 日期：2026-06-03 | 性质：implementation | 新增路由守卫

---

## 1. 本阶段目标

基于 K8-5-16-B 冻结方案，新增 `RequireAuth` 组件并保护简历四页面（`/resumes` `/resumes/new` `/resumes/edit` `/resumes/compare`）。

---

## 2. 修改方案

| 区域 | 修改内容 | 原因 |
|------|---------|------|
| `components/auth/RequireAuth.tsx` | **新建**：路由级登录鉴权守卫 | 之前不存在任何 route guard |
| `routes.tsx` | 简历四页面 `Component:` → `element: <RequireAuth><Page /></RequireAuth>` | P0 路由保护 |
| `LoginPage.tsx` | 新增 `useLocation` + `getSafeRedirect()`，登录/已登录导向 redirect | 支持从 RequireAuth 跳回原页面 |
| `RegisterPage.tsx` | 同上 | 注册后也支持 redirect |

---

## 3. 新增组件

| 文件 | 组件 | 行为 |
|------|------|------|
| `web/src/app/components/auth/RequireAuth.tsx` | `RequireAuth` | `getAuthToken()` → 无 token 跳 `/login?redirect=<当前路径>` → 有 token 渲染 children |
