## 4. 逐岗位解释生成逻辑

| 模块 | 说明 |
|------|------|
| `detectJobDomain` | 16 种岗位细分识别（算法-多模态/NLP/数据科学/CV/图形学/AI应用 等） |
| `precisionBonus` | 根据候选 domain tags 与岗位 domain 精准度给分（0-8） |
| `buildWhyRankedHereV3` | 基于 rank 对比上一名生成差异化排名解释 |
| `buildResumeEvidenceV3` | 从项目名/实习岗位/研究方向提取具体证据 |
| `buildJobSpecificReasonV3` | 针对 16 种 domain 逐岗位生成推荐理由 |
| `buildJobSpecificRisksV3` | 针对 16 种 domain 生成差异化风险 |
| `buildSuggestedImprovementV3` | 针对 16 种 domain 生成可执行补强建议 |
| `calibrateLabels` | 后处理：strong ≤2、rank>3 降级、precision<5 降级、risks≥2 降级 |
