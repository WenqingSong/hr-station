## 4. 根因判断

| 问题 | 根因 |
|------|------|
| 全站页面贴近 Navbar | `RootLayout` `<main className="flex-1">` 无 `pt-*` |
| Navbar 脱离文档流 | `fixed` 定位，高度 64~68px |
| 各页自行补间距 | 无统一 `PageShell` 组件 |
| Hero 页例外 | Hero 组件内部自行 `pt-*` 处理 |

**核心结论**：`RootLayout` 的 `<main>` 缺少 `pt-20`（≈80px，留出 Navbar 64px + 16px 呼吸空间）。
