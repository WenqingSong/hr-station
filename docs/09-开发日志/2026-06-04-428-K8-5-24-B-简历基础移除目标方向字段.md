# K8-5-24-B — 简历基础模块移除目标方向字段并修正推荐场景设计

## 性质
product-design correction（产品设计修正，不改后端/SQL/Agent）。

## 问题背景

Offer捕手 的四核心功能之一"岗位智能推荐"主要服务于"不知道自己适合投什么岗位"的学生。但当前的"简历基础"模块强制或突出填写"目标方向"，与推荐功能的产品价值冲突——让用户误以为必须先知道目标岗位才能使用推荐。

## 当前字段链路盘点

| 字段 | 修改前用途 | 修改后处理 |
|------|---------|---------|
| `jobDirection` (state) | 简历基础 UI "目标方向" 输入 | **已删除** |
| `resumeDesc` (state) | 简历基础 UI "简历说明" 输入 | **已删除** |
| `direction` (state) | 求职意向模块 "目标岗位方向" | **保留**（求职意向，可选） |
| `target_direction` (payload) | 来自 `jobDirection \|\| direction` | 来自 `direction` only |
| `target_role` (V1 compat) | 来自 `direction \|\| jobDirection` | 来自 `direction` only |
| `description` (payload) | 来自 `resumeDesc` | 传 `undefined` |
| `job_intention.target_roles` | 来自 `splitList(direction)` | **不变** |

## 修改方案

| 文件 | 修改内容 | 原因 |
|------|---------|------|
| `ResumeBasicsSection.tsx` | description 文案改为"给这份简历起一个便于区分的名称" | 产品设计修正 |
| `JobIntentionSection.tsx` | description 文案改为可选引导："暂时不确定也可以留空" | 降低心理门槛 |
| `MyResumesPage.tsx` | 删除 `jobDirection`/`resumeDesc` state | 不再需要 |
| `MyResumesPage.tsx` | 删除 V1/V2 回填中对 jobDirection 的赋值 | 不再需要 |
| `MyResumesPage.tsx` | handleSave: `target_direction` → `direction`; `description` → `undefined` | 不再依赖 jobDirection |
| `MyResumesPage.tsx` | 删除"目标方向"和"简历说明" UI | 不再需要 |
| `MyResumesPage.tsx` | 更新底部提示文案：告诉用户不确定方向也可以留空 | 降低心理门槛 |
