# K9-1-E：岗位推荐Agent排序逻辑与Deep全量替换机制重构

## 用户问题

算法研究生简历(算法/推荐系统/CTR/NLP)Top1竟是"后台开发"，排序不合理。

## 后端排序重写

- **画像提取**: CandidateProfile from relational fields(educations/projects/internships/skills), JobProfile from title/category/description
- **方向识别**: algorithm/backend/product/business 自动分类
- **评分规则**: 基础45 + 方向匹配(+30/+25) + 技能重叠(每项+3) + 学历boost + 方向惩罚
- **分数**: 50-95区间，强匹配85-95，良好匹配78-84
- **Quality模式**: RecommendQuality()使用同一引擎增强模式，generated_by="mock_quality"

## 前端Deep全量替换

- 全局毛玻璃加载层(fixed+backdrop-blur)
- Deep成功后左侧Top5、详情、来源全部替换
- 默认选中Deep Top1
