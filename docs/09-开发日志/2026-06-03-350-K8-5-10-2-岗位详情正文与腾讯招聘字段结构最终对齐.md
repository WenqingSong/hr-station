## 二、字段来源

| 字段 | 来源 | 当前用途 |
|------|------|---------|
| responsibilities | API responsibilities[] | 岗位描述 |
| mustHave / niceToHave | API must_have[] / nice_to_have[] | 岗位要求 → 必须具备/有一定了解 |
| bonusPoints | API bonus_points[] | 加分项或注意事项 |
| interviewLocations | API interview_locations[] | 参加面试的城市 |
| skills | API skills[] | 技能关键词（弱化） |
| deliveryNotes | API delivery_notes | 投递说明（弱化） |
| organizations | API organizations[{code,name}] | 招聘部门（第二白卡） |
| locations | API locations[] | 工作地点（第二白卡） |
