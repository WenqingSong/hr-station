# 2026-05-29-047-Makefile接入腾讯岗位入库命令

## 1. 本次任务

将腾讯岗位清洗与入库脚本 `scripts/dev/tencent_jobs_import.sh` 接入 Makefile，形成统一命令入口，支持 `make jobs-import-*` 系列命令。

## 2. 修改范围

| 文件 | 操作 |
|------|------|
| `Makefile` | 修改：新增 8 个 jobs-import-* target |
| `scripts/dev/tencent_jobs_import.sh` | 轻量修改：新增 3 个命令别名、更新 help 文案 |

## 3. 新增 Makefile 命令

| 命令 | 说明 | 是否请求外部接口 | 是否入库 |
|------|------|-----------------|---------|
| `make jobs-import-help` | 查看腾讯岗位入库命令帮助 | 否 | 否 |
| `make jobs-import-check` | 检查 raw JSON、MySQL、输出目录 | 否 | 否 |
| `make jobs-import-preview` | 预览将导入的腾讯岗位 | 否 | 否 |
| `make jobs-import-sql` | 生成腾讯岗位导入 SQL | 否 | 否 |
| `make jobs-import` | 执行腾讯岗位导入 MySQL | 否 | 是 |
| `make jobs-import-status` | 查看腾讯岗位导入状态 | 否 | 否 |
| `make jobs-db-status` | 同 jobs-import-status | 否 | 否 |
| `make jobs-import-clean` | 清理 generated 目录中的预览和 SQL | 否 | 否 |

## 4. 脚本联动方式

Makefile target 仅做命令转发，具体执行逻辑仍在 `scripts/dev/tencent_jobs_import.sh`：

```makefile
jobs-import-check:
    @scripts/dev/tencent_jobs_import.sh check

jobs-import:
    @scripts/dev/tencent_jobs_import.sh import
```

新增的脚本别名：

| 别名 | 对应命令 |
|------|---------|
| `generate` | `generate-sql` |
| `db-status` | `status` |
| `clean` | `clean-generated` |
