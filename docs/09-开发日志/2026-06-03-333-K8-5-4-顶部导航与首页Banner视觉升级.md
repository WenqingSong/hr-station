# K8-5-4：顶部导航与首页 Banner 视觉升级

## 一、本阶段目标

将 `/jobs` 岗位列表页顶部区域从"普通后台管理页面"升级为"招聘官网首屏视觉"：

1. Banner 改为全宽横向大视觉区，不再是居中小卡片
2. Navbar 改为 Liquid Glass 质感，悬浮覆盖顶部
3. Navbar 在用户下滑时优雅隐藏，上滑时优雅出现
4. Navbar 高度加大，视觉更高级
5. Navbar 左侧只保留品牌文字，右侧只保留「我的简历 / 登录」
6. 品牌文字使用开源字体栈设计，提升质感

## 二、Navbar 修改方案

- **定位**：`sticky` → `fixed top-0 left-0 right-0 z-50`
- **高度**：`h-14` → `h-16`
- **背景**：Liquid Glass 双态
  - 顶部（scrollY ≤ 10）：`bg-white/40 backdrop-blur-md border-white/10`
  - 滚动后：`bg-white/75 backdrop-blur-xl border-white/20 shadow-sm`
- **滚动动效**：
  - `requestAnimationFrame` 节流，避免频繁 setState
  - 下滑且 scrollY > 80：`translateY(-100%)` 隐藏
  - 上滑：`translateY(0)` 显示
  - scrollY ≤ 20：强制显示
- **内容精简**：
  - 左侧：仅保留「Offer 捕手」品牌文字（`font-extrabold`，开源字体栈，`-0.02em` 字距）
  - 右侧：未登录显示「登录」，已登录显示「我的简历」+「退出」
  - 移除：「推荐岗位」链接、品牌小图标、过长副标题

## 三、Banner 修改方案

- **宽度**：从 `max-w-[1440px]` 容器内的圆角卡片 → 全宽 `w-full`，贴近左右边缘
- **高度**：`min-h-[240px] md:min-h-[320px] lg:min-h-[340px]`
- **圆角/间距**：移除 `rounded-2xl mb-6`
- **背景**：深蓝到亮蓝渐变 `from-[#0039a6] via-[#0052D9] to-[#001a4d]`
- **装饰**：纯 CSS 光斑、圆环、网格纹理、底部微光边缘
- **文案**：
  - 主标题放大至 `text-[36px] md:text-[44px] lg:text-[52px]`
  - 使用品牌字体栈 + `font-extrabold`
  - 副标题与辅助说明保持蓝色系层次
- **右侧抽象图形**：桌面端显示模拟岗位卡片悬浮效果，纯 CSS 实现
- **非 clickable**：无跳转、无外部图片

## 四、JobListPage 布局调整

- Banner 移出 `max-w-[1440px]` 容器，作为页面最顶层全宽元素
- 主体内容继续使用 `<main className="mx-auto max-w-[1440px] px-6 md:px-8 py-6">`
- 保持 K8-5-3 响应式三栏布局：`grid-cols-1 xl:grid-cols-[260px_minmax(0,1fr)_300px]`
- 不出现横向滚动：`overflow-x-hidden`
