## 2. P0 根因（5 层联动失效）

### A. CandidateProfile 错判

`directionLabel()` 返回 **"mixed"**（不是 "algorithm"）。

**证据**: Judge 输出 `pass:true`（说明没有触发 "top-1 is backend despite algorithm profile" 检查），recommendation_reason 显示 "通用技术方向"。

**原因**: `beKeywords` 匹配了大量工程关键词（go/c++/redis/mysql/docker/linux/git），后台得分(≈10)接近算法得分(≈15)，差距不足触发 +2 阈值。

### B. 所有岗位同分起步

因 cd="mixed"，scoreJob 中所有岗位统一 +14 方向加分。算法岗位应得的 +28 未能激活。

### C. 后端工程关键词重叠度 = 算法关键词重叠度

简历有 go/redis/mysql/docker/linux，岗位描述也包含这些词。短英文 token 匹配效率 = 长中文术语匹配效率，导致后台岗位关键词得分与算法岗位相当甚至更高。

### D. Judge 完全失效

Judge 检查 `cd=="algorithm" && top1=="backend"` 但 cd="mixed"，不触发。

### E. Label 纯分数驱动

`recommendationLabel(score)` ≥90 → "强匹配，优先投递"。不检查方向匹配。
