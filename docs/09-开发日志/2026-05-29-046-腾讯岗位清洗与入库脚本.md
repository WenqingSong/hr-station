## 3. 新增脚本

`scripts/dev/tencent_jobs_import.sh`，支持 7 个命令：

| 命令 | 说明 | 是否需要 MySQL |
|------|------|---------------|
| help | 查看帮助 | ❌ |
| check | 检查 raw JSON、MySQL、输出目录、依赖工具 | 部分 |
| preview | 预览将导入的岗位数量和字段映射 | ❌ |
| generate-sql | 根据 raw JSON 生成导入 SQL | ❌ |
| import | 执行 generate-sql + MySQL 导入 | ✅ |
| status | 查看数据库中岗位数量和质量分布 | ✅ |
| clean-generated | 清理生成的 SQL 和 preview JSON | ❌ |

## 4. 字段清洗规则

| jobs 字段 | 来源 | 映射规则 |
|-----------|------|---------|
| title | detail.title 优先，list.positionTitle 兜底 | 字符串 |
| department | detail.intentionBGDList[0].showTitle 优先，list.bgs 兜底 | 字符串 |
| city | detail.workCityList 优先，list.workCities 兜底 | 多城市逗号拼接 |
| category | detail.tidName 优先 | 字符串 |
| job_type | list.projectName | 字符串 |
| description | detail.desc 优先，list.positionTitle 兜底 | 文本 |
| requirements | detail.request 优先 | 文本 |
| skill_keywords_json | 从 title/category/desc/request 提取预置关键词 | JSON 数组 |
| external_source | 固定 tencent_join | 字符串 |
| external_id | postId | 字符串 |
| external_inner_id | list.id | 字符串 |
| source_url | https://join.qq.com/post_detail.html?postid={postId} | 字符串 |
| raw_json | list_item + detail_item + dictionary_snapshot + imported_at | JSON |
| data_quality | full_jd（有详情）或 summary_only（无详情） | 字符串 |
| is_featured | 固定 0 | 数字 |
| synced_at | 当前时间 | 时间戳 |

## 5. SQL 生成策略

- 使用 `INSERT INTO jobs (...) VALUES (...) ON DUPLICATE KEY UPDATE ...`
- 以 `external_source + external_id` 为唯一业务键实现幂等
- 不删除 local_mock 岗位
- 不 truncate / delete jobs 表
- ON DUPLICATE KEY UPDATE 更新所有可变字段 + updated_at

## 6. 导入策略

1. 检查 positions.json 是否存在
2. 检查 MySQL 是否可用
3. 读取 positions.json 的 items 数组
4. 读取 details.json，建立 postId → detail 映射
5. 遍历每个列表项，执行字段映射
6. 有详情 → data_quality=full_jd，无详情 → data_quality=summary_only
7. 生成 SQL 文件
8. 导入 MySQL
9. 验证导入结果（数量、质量分布、raw_json 有效性）
