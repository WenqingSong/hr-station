## 四、P0 发现：项目经历 adapter 字段名不兼容

### 问题

```text
API response:
  "project": [{...}, {...}, {...}]    ← singular, has data
  "projects": null                     ← plural, null

Adapter (toResumeManagementViewModel):
  parseV2Projects(resume) → reads resume.projects → null → undefined
  projects: Array.isArray(resume.projects) ? resume.projects : [] → []
```

**`project` (singular) 的数据有 3 条，但 adapter 读 `projects` (plural) 得到 null。**

这与 `experience` (singular) 的处理方式不一致——adapter 对 `experience` 做了 singular/plural 兼容（line 271-273），但对 `projects` 没有做同样的兼容。

### 影响

编辑已有简历时，项目经历数据完全丢失。用户看到的项目经历始终为空列表。
