## 7. 真实 LLM Smoke 规则

4-5.2 默认不调用真实 LLM。只有用户明确确认后，才允许执行 `RUN_REAL_LLM_SMOKE=1 make llm-smoke`。

规则：
1. 不读取或输出 `.env`
2. 不输出 API Key
3. 不大规模调用
4. 只做最小 smoke
5. 优先只调用 LLM Client health / 最小 MatchAnalysis
6. 调用结果只记录成功 / 失败 / 错误类型，不记录敏感响应
7. 若未配置 Key，4-5.2 可记录为 skipped，不阻塞进入前端 Mock 演示，但要标记"真实 LLM 未现场验证"
