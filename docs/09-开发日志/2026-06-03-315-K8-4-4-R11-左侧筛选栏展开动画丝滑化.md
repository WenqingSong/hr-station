## 二、当前问题确认

### 问题位置

`web/src/app/components/JobFilterSidebar.tsx`

### 具体问题

1. **一级分组展开/收起是条件渲染**：`{expanded && (...)}` 导致内容瞬间出现/消失，无过渡动画
2. **二级子项展开/收起也是条件渲染**：`{isChildExpanded && hasChildren && (...)}` 同样无动画
3. **箭头/加减号无旋转动画**：只是文字切换，无过渡
4. **`height: auto` 无法直接 transition**：需要用 grid rows 技巧

---

## 三、采用的动画方案

### 方案：CSS Grid Rows 动画

使用 `grid-template-rows: 0fr → 1fr` 实现 `height: auto` 平滑过渡。

**原理**：
- 外层 `display: grid; grid-template-rows: 0fr` → 内层 `overflow-hidden` → 内容高度为 0
- 切换到 `grid-template-rows: 1fr` → 内层高度自动撑开
- CSS Grid 支持 `transition: grid-template-rows` 平滑过渡

**优点**：
- 不需要测量 DOM 高度
- 比 `max-height: 999px` 更自然（不会有多余延迟）
- 适合 React + Tailwind 项目
- 不需要新增依赖

## 四、一级分组动画

### 实现方式

新增 `CollapsibleSection` 组件，包裹一级分组的内容区域：

```tsx
<CollapsibleSection open={expanded} duration={220}>
  <div className="pb-3 space-y-0">
    {/* 筛选项 */}
  </div>
</CollapsibleSection>
```

### 动画参数

- `duration`: 220ms
- `easing`: `ease-out`
- 透明度：`opacity-0 → opacity-100`
- 位移：`-translate-y-1 → translate-y-0`

---

## 五、二级子项动画

### 实现方式

同样使用 `CollapsibleSection`，包裹二级子项：

```tsx
<CollapsibleSection open={isChildExpanded} duration={180}>
  <div className="space-y-0">
    {children.map((child) => (
      <OptionRow ... />
    ))}
  </div>
</CollapsibleSection>
```

### 动画参数

- `duration`: 180ms（比一级稍快）
- `easing`: `ease-out`

## 六、箭头同步动画

### 一级分组箭头

使用 `transition-transform duration-200` 实现旋转：

```tsx
<span className={`transition-transform duration-200 ${expanded ? 'rotate-0' : ''}`}>
  {expanded ? '−' : '+'}
</span>
```

### 二级子项箭头

同样使用 `transition-transform duration-200`：

```tsx
<span className={`transition-transform duration-200 ${isChildExpanded ? 'rotate-0' : ''}`}>
  {isChildExpanded ? '−' : '+'}
</span>
```
