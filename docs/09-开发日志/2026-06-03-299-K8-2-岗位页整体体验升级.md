## 3. 前端改造内容

### 3.1 岗位卡片（JobCard.tsx）重设计

参照腾讯招聘岗位卡片风格，全新信息层级：

| 维度 | 旧版 | 新版 |
|------|------|------|
| 标题 | text-lg bold, 第一行 | text-[17px] bold, hover 蓝色 |
| 副标题行 | `department | type | 📍city | status` 挤在一行 | `方向 | 类型 | 部门` → 事业群标签行 → `📍城市` 独立行 |
| 状态标签 | 挤在行内 | 右上角独立 badge，蓝色背景+圆点 |
| 描述 | line-clamp-2 | line-clamp-2, leading-relaxed |
| 技能标签 | Badge 组件 | 简洁 span，gray-50 背景 |
| 操作按钮 | "查看详情" | "查看详情 →" 带箭头 |
| 卡片整体 | rounded-lg, border-gray-200 | rounded-xl, border-gray-100, hover:shadow-md+border-[#0052D9]/30 |
| 间距 | p-5 | p-6, 各区间距增大 |

### 3.2 列表顶部状态栏（JobList.tsx）

新增：
- "共 **X** 个岗位" 计数（加粗显示总数）
- 已选筛选条件以蓝色可关闭标签展示
- "清除全部" 按钮

### 3.3 右侧 AI 模块收敛（AIDecisionWorkspace.tsx）

| 维度 | 旧版 | 新版 |
|------|------|------|
| 宽度 | 340px | 300px |
| 标题 | h2 text-xl bold | h3 text-base semibold |
| 副标题 | text-sm | text-[12px] text-gray-400 |
| 卡片圆角 | rounded-lg | rounded-xl |
| 边框色 | border-gray-200 | border-gray-100 |
| 整体视觉 | 突出 | 收敛、不抢主内容 |

### 3.4 数据适配层（jobAdapter.ts）扩展

`JobCardViewModel` 新增字段：
- `direction`：岗位方向
- `businessGroups`：事业群名称列表（从 organizations_json 解析）
- `locationsList`：工作城市列表（从 locations_json 解析）
- `applicationType`：应聘类型

新增安全解析函数 `parseStringArray()` 和 `parseOrgNames()`。

## 4. 后端/数据库改动

### 4.1 种子数据丰富（server/sql/init.sql）

为 8 个种子岗位新增字段：

| 新增字段 | 示例值 | 目的 |
|---------|--------|------|
| `application_type` | `"应届实习"` | 匹配腾讯招聘展示 |
| `locations_json` | `["深圳","北京"]` | 支持多城市展示 |
| `organizations_json` | `[{"code":"CDG","name":"CDG 企业发展事业群"}]` | 支持事业群标签展示 |

每个岗位分配了合理的事业群映射：
- Go 后端 → CDG + CSIG
- 云计算 → CSIG + TEG
- AI 应用 → IEG
- 数据开发 → TEG
- 测试开发 → TEG + WXG
- 产品经理 → PCG
- 前端开发 → WXG + PCG
- 算法 → IEG + TEG

### 4.2 后端代码

后端 `toJobResponse()` 已经正确映射 `locations_json` 和 `organizations_json`，无需改动。
