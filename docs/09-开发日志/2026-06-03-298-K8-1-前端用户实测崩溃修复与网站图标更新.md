## 1. 问题 1：JobFilterSidebar 崩溃修复

### 用户报错

```
TypeError: Cannot read properties of null (reading 'length')
at JobFilterSidebar (JobFilterSidebar.tsx:224:23)
```

### 根因

`JobFilterSidebar.tsx` 中 `facets.directions`、`facets.cities`、`facets.categories` 三个字段未被 null 守卫保护。

API 返回 `GET /api/jobs/facets` 中，这三个字段可能为 `null`（与其他可选字段相同），但代码直接访问 `.length`：

```tsx
// ❌ 崩溃
{facets.cities.length > 0 && ...}

// ✅ 修复后
{facets.cities && facets.cities.length > 0 && ...}
```

### 修复

| 位置 | 修改 |
|------|------|
| lines 124-148 | directions/cities/categories 均添加 `&& facets.xxx` 守卫 |
| line 164 | 空态检查中 `facets.directions.length` → `(facets.directions\|\|[]).length` |

### 同类风险检查

- `FilterGroup` 组件 `items.map()` — items 类型为数组且渲染前有 `.length > 0` 守卫 ✅
- 其他 `.map/.filter/.length` 调用 — 均为可选字段且已有守卫 ✅
