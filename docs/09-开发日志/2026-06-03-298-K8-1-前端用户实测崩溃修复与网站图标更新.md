## 2. 问题 1：JobFilterSidebar 崩溃修复

### 用户报错

```
TypeError: Cannot read properties of null (reading 'length')
at JobFilterSidebar (JobFilterSidebar.tsx:224:23)
```

### 根因

`facets` 中所有字段（包括接口定义的必选字段如 `directions`、`cities`、`categories`）在 API 实际返回中可能为 `null`。代码在多处直接调用 `.length`、`.map()` 未做空值守卫。

关键风险点：
- `facets.*.length > 0` — 字段可能为 null
- `skills.slice(0, 20)` — skills 可能为 null
- `items.map()` 在 FilterGroup 内 — items 未做 Array.isArray 检查
- `filters` 的 Object.entries 遍历 — val 可能为 undefined/null

### 修复方案（全面 null-safe）

引入 `safeItems<T>()` 工具函数：

```ts
function safeItems<T>(v: T[] | null | undefined): T[] {
  return Array.isArray(v) ? v : [];
}
```

所有 facet 数组通过此函数预处理，确保后续 `.length`、`.map()`、`.filter()` 调用永不崩溃。

具体修改点：
| 位置 | 修改 |
|------|------|
| 新增 `safeItems()` | 全组件统一空值守卫函数 |
| 所有 facet 字段 | 通过 `safeItems(facets?.xxx)` 安全获取 |
| FilterGroup `items.map()` | 内部 `safeList = safeItems(items)` 二次守卫 |
| `Object.entries(filters).map` | 增加 `typeof val === "string"` 类型判断 |
| 空态检查 | `hasAnyFacets` 统一判断，去除冗长链式 `||[]` |

## 3. 问题 2：左侧筛选栏重设计

### 参考风格

腾讯校园招聘左侧筛选栏：卡片式白底容器、大圆角、精致搜索框、分组可展开收起、checkbox 干净、层级感明确。

### 设计改动

| 维度 | 旧版 | 新版 |
|------|------|------|
| 卡片容器 | `rounded-lg` + `border-gray-200` | `rounded-2xl` (16px) + `border-gray-100` + `shadow-sm` |
| 搜索框 | h-10, `rounded-md`, 普通边框 | h-12 (48px), `rounded-xl` (12px), `bg-gray-50` 背景, focus `ring-2` |
| 筛选分组 | 固定标题（无展开/收起） | 可展开/收起，`+` / `−` 符号, 选中值在收起态显示 |
| 选项交互 | 选中态蓝色背景高亮 | checkbox 样式（蓝色填充边框 + 白色勾）, 选项独立圆角 `rounded-lg` |
| 间距 | 紧凑 | 更舒展：标题 py-3, 选项 px-3 py-2 |
| 字号 | 混杂 | 统一：标题 13px, 选项 14px, 数量 12px |
| 页面背景 | 白色（与卡片无对比） | `bg-gray-50`（来源 JobListPage 外层容器） |
| 宽度 | 260px | 280px |

### 组件结构

```
<aside>
  <div className="bg-white rounded-2xl shadow-sm">
    ├── 搜索框（h-12, rounded-xl, 左侧搜索图标）
    ├── 已选筛选标签区（蓝色标签 + 清空按钮）
    └── 筛选分组区
         ├── CollapsibleFilterGroup（可展开/收起）
         │    ├── 标题栏（13px bold + chevron 图标）
         │    └── 选项列表（checkbox 样式 + 数量）
         └── ...
  </div>
</aside>
```

## 5. 问题 4：网站图标更新

### 旧图标

旧 favicon.svg：深色背景 + 金色靶心圆圈 + 灰色 O 字母（与 navbar 风格不一致）。

### 新图标

navbar 项目图标为：
```tsx
<span className="flex h-5 w-5 items-center justify-center rounded bg-[#0052D9] text-white">
  O
</span>
```

新 favicon.svg 匹配此风格：
```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64">
  <rect width="64" height="64" rx="12" fill="#0052D9"/>
  <text x="32" y="43" text-anchor="middle" font-family="Arial, Helvetica, sans-serif"
        font-weight="700" font-size="34" fill="#ffffff">O</text>
</svg>
```

- 蓝色圆角方块（#0052D9, rx=12 ≈ 19% 圆角）
- 白色粗体 O 字母居中
- 与 navbar 图标高度一致

`index.html` 引用：
```html
<link rel="icon" type="image/svg+xml" href="/favicon.svg" />
```
