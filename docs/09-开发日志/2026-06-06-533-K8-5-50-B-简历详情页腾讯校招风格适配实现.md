# K8-5-50-B：简历详情页腾讯校招风格适配实现

## 背景（K8-5-50-A 盘点结论）

- 项目没有简历详情页，路由 `resumes/:id` / `resumes/detail` 均不存在
- `MyResumesPage` 是编辑页，非详情页
- API `getResumeById(id)` 已有，DTO 字段完整
- 不需要新增后端接口或修改数据库

## 新增文件

### `web/src/app/pages/ResumeDetailPage.tsx`（~280 行）

纯只读展示页，结构如下：

| 区域 | 内容 |
| -- | -- |
| 顶部栏 | "简历详情"标题 + "返回我的简历"按钮 + "编辑简历"按钮 |
| 摘要行 | 更新时间 + 完善度进度条 + 当前标签 |
| Hero 卡片 | 蓝色渐变卡片：简历名称 + 姓名/城市/手机号/邮箱/个人主页（5 字段） |
| 能力摘要 | professional_skills（拆分标签）+ ai_application + additional_info |
| 教育经历 | 学校/学历/专业/院系 + GPA/排名/课程/研究方向/论文 |
| 项目经历 | 项目名称 + 角色 + 时间 + 描述 |
| 实习经历 | 公司 + 职位 + 时间 + 描述 |
| 证书与获奖 | 外语考试 + 证书 + 获奖，三项条件渲染 |
| 作品链接 | 作品名 + URL（可点击）+ 密码 + 个人主页 |
| AI 提示 | 去岗位推荐 / 岗位广场 / 简历优化 快捷入口 |

### 辅助组件（文件内置）

- `InfoItem`：label + value 静态字段展示
- `DetailSection`：卡片容器（带图标标题 + 空状态支持）
- `TagList`：技能标签列表
- `formatDate` / `dateRange`：时间格式化

### 完善度计算

纯前端 10 维度：简历名称 / 姓名 / 城市 / 教育经历 / 项目经历 / 技能信息 / 实习经历 / 证书与获奖 / 作品链接 / 补充信息，每项有有效值记 10%。

## 腾讯校招风格适配

| 参考元素 | 采用方式 |
| -- | -- |
| 灰色页面背景 | `bg-[#F5F7FA]`（全局背景，由 RootLayout 提供） |
| 大圆角白色卡片 | `bg-white rounded-2xl border border-slate-100` |
| 蓝色个人信息主色块 | `bg-gradient-to-r from-[#0052D9] to-[#2979FF] rounded-3xl` |
| 最近更新时间 | `Clock` 图标 + `formatDate()` |
| 完善度进度条 | 自定义 `<div>` 进度条 + 百分比文字 |
| 模块化卡片 | `DetailSection` 组件 |
| 只读静态展示 | 全部使用 `label + value` 而非 input |
| 头像区 | ❌ 不采用（无上传能力） |
| 身份证/紧急联系人 | ❌ 不采用（隐私字段） |
| 应聘信息 | ❌ 不采用（非投递系统） |
