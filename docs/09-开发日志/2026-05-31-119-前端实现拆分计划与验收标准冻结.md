## 7. 验收标准

### 不合格

- 只展示一段 AI 文本
- 只 stringify JSON
- 没有 apply_readiness / optimization_stop_signal / top_fix_items
- 没有 loading / error 态

### 合格

- 三类 Agent 都有明确页面
- 共享字段统一展示
- 关键字段拆成卡片/表格/任务/看板/核实清单
- 推荐可分组，匹配有证据链，优化有 Top Fix 和核实
- loading / error / fallback 清晰
- Mock 数据与真实接口结构一致

## 8. 不可混做事项

1. 不在 API client 阶段改页面
2. 不在路由阶段接 LLM
3. 不在 Recommendation 页面做 ResumeOptimization
4. 不在共享组件阶段改后端
5. 不在前端实现阶段改 Prompt / Schema
6. 不把 P2 塞进 P0
7. 不为好看牺牲数据真实性
8. 不把 AI 输出退化成一段文本
