# K8-4-4-R4：岗位列表加载状态专业化重设计

- **日期**：2026-06-03
- **阶段**：K8-4-4-R4（frontend, pass）
- **性质**：岗位列表加载状态专业化重设计

## 1. 用户反馈

当前加载状态非常不专业：
- 首次加载显示纯文字 "正在加载岗位列表…"
- loading 文案和旧卡片同时渲染，出现 "loading + 卡片" 割裂
- total 数量在 loading 时显示旧值
- 无骨架屏，无状态区分

## 2. 当前问题确认

| 问题 | 根因 |
|------|------|
| loading 文案 + 旧卡片共存 | `{loading && <p>…</p>}` 与 `{jobCards.map(…)}` 并行渲染，无互斥 |
| 无首次加载/刷新区分 | 单一 `loading` bool |
| total 在 loading 时显示旧值或 0 | 无条件渲染 `{total}` |
| 无骨架屏 | 纯文字 loading |

## 3. 修复方案

### 状态模型

| 状态 | 条件 | 渲染策略 |
|------|------|----------|
| `isInitialLoading` | `loading && jobCards.length === 0` | 5 个卡片骨架屏，隐藏 total 数字、分页 |
| `isRefetching` | `loading && jobCards.length > 0` | 保留旧列表 + 半透明遮罩 + 顶部刷新图标 + total 保持不变 |
| `isEmpty` | `!loading && !error && jobCards.length === 0` | 专业空状态卡片（图标 + 文案 + 清除按钮） |
| `isError` | `Boolean(error)` | 错误状态卡片（图标 + 文案 + 重新加载按钮） |

### 新增组件

- **`JobCardSkeleton.tsx`**：单个卡片骨架屏（含标题/元信息/标签/位置/描述/技能/按钮占位）
- **`JobListSkeleton`**：5 个骨架屏的列表

### JobList 渲染改动

- total 区域：初始加载时显示 `"..."`，刷新时追加旋转图标的 "更新中"
- 卡片区域：初始加载 → Skeleton，错误 → Error card，空 → Empty card，正常/刷新 → JobCards（刷新时 opacity-50）
- 分页：初始加载和错误时隐藏
