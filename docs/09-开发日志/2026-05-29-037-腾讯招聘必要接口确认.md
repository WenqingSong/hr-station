## 3. 执行命令

### 3.1 获取样本岗位

```bash
curl -s -X POST "https://join.qq.com/api/v1/position/searchPosition" \
  -H "Content-Type: application/json" \
  -H "User-Agent: Mozilla/5.0" \
  -H "Referer: https://join.qq.com/post.html?query=p_2" \
  -H "Origin: https://join.qq.com" \
  -d '{"bgList":[],"keyword":"","pageIndex":1,"pageSize":3,...}'
```

获取 3 条样本：id=21417/21415/21418，postId=1200791473415778304/1199423750186201088/1200889496565214208。

### 3.2 分析前端详情页 HTML

```bash
curl -s "https://join.qq.com/detail.html?postId=1200791473415778304" \
  -H "User-Agent: Mozilla/5.0"
```

发现 HTML 中加载了以下关键 JS：
- `V2Dynamic_zh-cn.js`（CDN 403，需 Referer，实际是语言包）
- `p_zh-cn_detail.build.js`（728KB，**包含完整 API 路径**）

### 3.3 下载并分析 JS bundle

```bash
curl -s "https://cdn.multilingualres.hr.tencent.com/joinqq/static2/js/p_zh-cn_detail.build.js" \
  -H "Referer: https://join.qq.com/" \
  -H "User-Agent: Mozilla/5.0" > /tmp/detail_build.js
grep -oP 'api/v[0-9]+/[a-zA-Z/]+' /tmp/detail_build.js | sort -u
```

**关键发现**：JS 中包含完整的 API 路径列表，其中包括：
- `api/v1/jobDetails/getJobDetailsByPostId` ✅
- `api/v1/jobDetails/getJobDetailsByPidAndId` ✅

### 3.4 详情接口验证

```bash
curl -s "https://join.qq.com/api/v1/jobDetails/getJobDetailsByPostId?postId=1200791473415778304" \
  -H "User-Agent: Mozilla/5.0" \
  -H "Referer: https://join.qq.com/detail.html"
```

返回 HTTP 200，JSON status=0，data 包含完整 JD。

### 3.5 字典接口验证

```bash
curl -s "https://join.qq.com/api/v1/dictionary/?types=RecruitType,BusinessGroup,RecruitProjectPostList,RecruitCity"
```

返回 HTTP 200，4 类字典数据完整。
