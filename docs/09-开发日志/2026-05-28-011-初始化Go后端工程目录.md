## 6. 关键决策

1. **使用 Go 标准库 net/http**：不引入 Gin / Echo / Fiber 等 Web 框架，保持最小依赖
2. **模块名 offer-catcher/server**：使用项目名 + server 作为模块路径
3. **Go 1.24**：根据当前环境 Go 版本（go1.24.1）设置
4. **internal/http/ 包名 httpserver**：避免与标准库 net/http 包名冲突
5. **单 SQL 初始化文件**：`server/sql/init.sql` 集中维护表结构和种子数据，不引入复杂迁移工具
6. **预留分层目录**：middleware / model / repository / service / agent / llm 目录已创建，用 .gitkeep 保持
7. **配置使用 os.Getenv**：不引入配置库，支持默认值
8. **/healthz 响应包含 service 字段**：便于识别服务实例
