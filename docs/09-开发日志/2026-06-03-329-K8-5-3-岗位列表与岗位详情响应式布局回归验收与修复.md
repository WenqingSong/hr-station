# K8-5-3：岗位列表与岗位详情响应式布局回归验收与修复

**日期：** 2026-06-03
**性质：** responsive layout fix
**范围：** 3 文件修改（JobListPage + AISidebarShell + TwoColumnPageShell）
**上游依赖：** K8-5-2 结构治理已冻结

---

## 1. 本阶段目标

只针对 `/jobs` 和 `/jobs/:id` 做响应式布局修复：
- 大屏（≥1280px）三栏/两栏稳定显示
- 中屏（1024-1279px）不横向滚动、不挤爆
- 小屏（<1024px）单列、不 sticky、不崩
- 右侧 AI sticky 对齐大屏断点

---

## 2. 执行前响应式问题分析

| 页面 | 问题 |
|------|------|
| `/jobs` | `flex` 三栏无响应式断点，1024-1279px 时 260+内容+300 挤压严重 |
| `/jobs` | 无 `overflow-x-hidden`，可能横向滚动 |
| `/jobs` | 无 `min-w-0`/`minmax` 防护 |
| `/jobs/:id` | `TwoColumnPageShell` 用 `lg` 断点，1024px 就两栏 |
| `/jobs/:id` | `AISidebarShell` 用 `lg:sticky`，中屏单列时仍 sticky |
| 共享 | AI sticky 断点与页面布局断点不一致 |

---

## 3. 修复方案

### `/jobs`（JobListPage.tsx）

| 修改项 | 旧值 | 新值 |
|--------|------|------|
| 外层容器 | `min-h-screen bg-gray-50` | `min-h-screen bg-gray-50 overflow-x-hidden` |
| 三栏布局 | `flex gap-6 items-start` | `grid grid-cols-1 xl:grid-cols-[260px_minmax(0,1fr)_300px] gap-6 items-start` |
| 右侧 AI | 直接渲染 `AISidebarShell` | 包裹 `hidden xl:block` div，仅 ≥1280px 显示 |

**响应式效果：**
- ≥1280px：筛选栏 260px | 列表 `minmax(0,1fr)` | AI 300px，三栏稳定
- <1280px：单列，筛选栏在上 → 列表在下，AI 隐藏

### `/jobs/:id`（TwoColumnPageShell.tsx）

| 修改项 | 旧值 | 新值 |
|--------|------|------|
| 容器 overflow | 无 | `overflow-x-hidden` |
| 两栏断点 | `lg:grid-cols-[minmax(0,1fr)_320px] xl:grid-cols-[minmax(0,1fr)_340px]` | `xl:grid-cols-[minmax(0,1fr)_340px]` |

**响应式效果：**
- ≥1280px：主内容 `minmax(0,1fr)` | AI 340px，两栏
- <1280px：单列，主内容在上 → AI 在下

### AISidebarShell.tsx

| 修改项 | 旧值 | 新值 |
|--------|------|------|
| sticky 断点 | `lg:sticky` | `xl:sticky` |
| top 断点 | `lg:top-24` | `xl:top-24` |
| max-h 断点 | `lg:max-h-[...]` | `xl:max-h-[...]` |
| overflow-y 断点 | `lg:overflow-y-auto` | `xl:overflow-y-auto` |
| 默认 top | `"lg:top-24"` | `"xl:top-24"` |

**效果：** 仅在 ≥1280px 时 sticky，<1280px 时 static 正常流。与 TwoColumnPageShell 两栏断点一致。
