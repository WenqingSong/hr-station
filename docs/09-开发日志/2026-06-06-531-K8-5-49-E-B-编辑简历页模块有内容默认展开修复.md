# K8-5-49-E-B：编辑简历页模块有内容才默认展开修复

## 根因（K8-5-49-E-A 盘点结论）

K8-5-49-C 将 EducationSection / ProjectSection / SkillsSection 的 `defaultOpen` 改为 `!isCreateMode`。编辑模式下 `isCreateMode=false`，表达式恒为 `true`，导致这三个模块无论有无内容都展开。

对比已正确实现的实习经历使用 `isEditingExistingResume && hasInternshipContent`。

## 修复内容

### 新增三个"有内容"判断变量

```ts
const hasEducationContent = educations.some((edu) =>
  edu.school || edu.major || edu.degree !== "本科" || edu.department || edu.startDate || edu.endDate || edu.gpa || edu.gpaScale || edu.rank || edu.coreCourses || edu.researchDirection || edu.lab || edu.paperSummary
);
const hasProjectContent = projects.some((proj) =>
  proj.name || proj.role || proj.desc || proj.startDate || proj.endDate
);
const hasSkillsContent = !!(skillsDraft.developmentLanguages.trim() || skillsDraft.aiApplication.trim());
```

### 修改 defaultOpen

| 模块 | 修改前 | 修改后 |
| -- | -- | -- |
| EducationSection | `{!isCreateMode}` | `{isEditingExistingResume && hasEducationContent}` |
| ProjectSection | `{!isCreateMode}` | `{isEditingExistingResume && hasProjectContent}` |
| SkillsSection | `{!isCreateMode}` | `{isEditingExistingResume && hasSkillsContent}` |

### 行为变化

- **新增模式**：三模块仍默认折叠（`isEditingExistingResume` 为 false）
- **编辑模式无内容**：三模块折叠（`hasXxxContent` 为 false）
- **编辑模式有内容**：三模块展开（两个条件均为 true）
