# 2026-05-29-049-岗位接口适配腾讯岗位

## 1. 本次任务

适配 Go 后端岗位列表和岗位详情接口，使其支持腾讯岗位新增字段，支持 external_source 筛选，确保 local_mock 与 tencent_join 双来源岗位都能正确返回。

## 2. 修改范围

| 文件 | 修改内容 |
|------|---------|
| server/internal/model/job.go | 新增 7 个字段（ExternalSource/ExternalID/ExternalInnerID/SourceURL/RawJSON/DataQuality/IsFeatured/SyncedAt） |
| server/internal/repository/job_repository.go | 更新 SELECT 字段、Scan 逻辑、新增 ExternalSource 过滤、排序调整、新增辅助函数 |
| server/internal/service/job_service.go | 更新 Request/Response DTO、新增 external_source 校验、更新 toJobResponse |
| server/internal/http/job_handler.go | 读取 external_source 参数、传递到 service、处理校验错误 |

## 3. 模型变更

Job 模型新增字段：

| 字段 | Go 类型 | 说明 |
|------|---------|------|
| ExternalSource | string | 数据来源标识 |
| ExternalID | *string | 外部岗位 ID |
| ExternalInnerID | *string | 外部系统内部 ID |
| SourceURL | *string | 公开详情页 URL |
| RawJSON | []byte | 原始 JSON（不暴露给 API） |
| DataQuality | string | 数据质量标记 |
| IsFeatured | bool | 是否精选岗位 |
| SyncedAt | *time.Time | 同步时间 |

## 4. Repository 变更

- SELECT 字段从 11 个扩展到 18 个（不含 raw_json 在列表查询中不读取，但 FindByID 也跳过）
- 实际实现：SELECT 包含 external_source ~ synced_at 共 7 个新字段，但不包含 raw_json
- 新增 ExternalSource 到 JobQuery
- buildWhereClause 新增 external_source = ? 过滤
- 排序改为 ORDER BY is_featured DESC, id ASC
- 新增 fromNullString / fromNullTime 辅助函数

## 5. Service 变更

- JobListRequest 新增 ExternalSource 字段
- JobResponse 新增 7 个字段（ExternalSource/ExternalID/ExternalInnerID/SourceURL/DataQuality/IsFeatured/SyncedAt）
- 新增 ValidExternalSources 校验 map（local_mock / tencent_join）
- List 方法增加 external_source 校验
- toJobResponse 映射所有新字段，raw_json 不暴露

## 6. Handler 变更

- 读取 external_source query 参数
- 传递到 service.JobListRequest
- invalid external_source 返回 40001 错误
