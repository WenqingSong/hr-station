## 4. 配置项说明

### 开关类

- `TENCENT_JOBS_ENABLE`：总开关，控制是否启用腾讯招聘公开岗位数据源
- `TENCENT_JOBS_FETCH_DETAIL`：控制是否基于列表 postId 继续拉取岗位详情
- `TENCENT_JOBS_FETCH_DICTIONARY`：控制是否额外拉取字典数据

### URL 类

- `TENCENT_JOBS_LIST_URL`：岗位列表接口，来自 4-1.2.0.2 必要接口确认报告
- `TENCENT_JOBS_DETAIL_URL`：岗位详情接口，来自 4-1.2.0.2 必要接口确认报告
- `TENCENT_JOBS_DICTIONARY_URL`：字典接口，来自 4-1.2.0.2 必要接口确认报告

### 分页类

- `TENCENT_JOBS_PROJECT_MAPPING_IDS`：控制招聘项目范围，2=应届实习（岗位最多）
- `TENCENT_JOBS_PAGE_SIZE`：单页岗位数量
- `TENCENT_JOBS_MAX_PAGES`：最多拉取页数，Demo 阶段控制请求量

### 请求安全类

- `TENCENT_JOBS_REQUEST_INTERVAL_MS`：低频请求控制
- `TENCENT_JOBS_TIMEOUT_SECONDS`：避免请求长时间阻塞
- `TENCENT_JOBS_USER_AGENT`/`TENCENT_JOBS_REFERER`/`TENCENT_JOBS_ORIGIN`：模拟公开网页正常请求上下文

### 输出目录类

- `TENCENT_JOBS_OUTPUT_DIR`：后续 4-1.2.3 脚本会把原始数据写入该目录

## 7. 安全边界

1. 腾讯招聘公开岗位接口不需要 API Key
2. 不需要 Cookie
3. 不需要 Token
4. 不接登录态接口
5. 不请求投递、收藏、用户中心接口
6. 低频请求（默认间隔 500ms）
7. Demo 阶段限制最大页数（默认 3 页）
8. 后续脚本通过这些配置低频同步公开岗位数据
9. 当前业务接口不会实时请求 join.qq.com
