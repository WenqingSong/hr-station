## 3. 新增脚本

`scripts/dev/tencent_jobs.sh`，使用 Bash 编写，可 source `scripts/dev/common.sh`，使用 `set -euo pipefail`。

核心特点：
- 从 `.env` / `.env.example` 读取配置，环境变量最高优先
- 使用 `curl` 发送 HTTP 请求
- 使用 `python3` 标准库解析和合并 JSON
- 通过临时文件传递大量数据，避免命令行过长
- 低频请求控制（默认 500ms 间隔）
- 出现 403/429 立即停止

## 4. 脚本命令

| 命令 | 说明 |
|------|------|
| help | 查看帮助 |
| check | 检查配置项、URL、输出目录、依赖工具 |
| fetch-list | 拉取岗位列表原始 JSON（POST searchPosition，分页合并） |
| fetch-details | 基于 positions.json 中的 postId 拉取岗位详情原始 JSON（GET getJobDetailsByPostId） |
| fetch-dictionary | 拉取字典原始 JSON（GET dictionary，P1 可选） |
| fetch-all | 依次执行 fetch-list → fetch-details → fetch-dictionary → update_metadata |
| sample | 打印本地岗位样本摘要（最多 10 条） |
| status | 查看本地原始数据文件状态 |
| clean | 清理 data/tencent-jobs/raw 下生成的 JSON 文件 |

## 5. 输出文件

| 文件 | 说明 |
|------|------|
| data/tencent-jobs/raw/positions.json | 岗位列表（含 source、fetched_at、project_mapping_ids、page_size、max_pages、total、count、items） |
| data/tencent-jobs/raw/details.json | 岗位详情（含 source、fetched_at、count、items，每条含 postId、ok、response） |
| data/tencent-jobs/raw/dictionary.json | 字典数据（含 source、fetched_at、ok、response） |
| data/tencent-jobs/raw/metadata.json | 元数据（含 source、fetched_at、config、files、summary） |
