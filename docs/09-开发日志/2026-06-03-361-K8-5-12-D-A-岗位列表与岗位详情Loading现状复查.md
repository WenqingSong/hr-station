### 核心问题：重复请求

```
JobDetailBanner: loadSelectedJobDetailViewModel(jobId)  ← 请求 1
JobDetailJD:     loadSelectedJobDetailViewModel(jobId)  ← 请求 2（重复！）
JobDetailAIDecision: loadJobDetailViewModel(jobId)      ← 请求 3
```
**同一个详情接口被 3 个组件独立请求，其中 Banner 和 JD 完全相同。**

| 组件 | 是否请求数据 | 请求什么 | 应保留？ |
|------|-----------|---------|---------|
| JobListPage | 否（只传参） | — | ✅ |
| JobList | ✅ 是 | `getJobs` | ✅（唯一请求点） |
| JobDetailPage | 否 | — | ✅ |
| JobDetailBanner | ✅ 是 | `loadSelectedJobDetailViewModel` | ⚠️ 与 JD 重复 |
| JobDetailJD | ✅ 是 | `loadSelectedJobDetailViewModel` | ⚠️ 与 Banner 重复 |
| JobDetailAIDecision | ✅ 是 | `loadJobDetailViewModel` + resume | ⚠️ 独立请求（第3次） |

## 五、问题分级

| 级别 | 问题 | 影响 |
|------|------|------|
| **P0** | 详情页接口失败无 UI（catch 空） | 用户白屏/局部缺失无提示 |
| **P1** | Banner+JD 重复请求同一接口 | 浪费带宽，各自独立加载可能跳动 |
| **P1** | 详情页无 DetailSkeleton | 内联文本 loading 不专业 |
| **P1** | 详情页无 PageError/retry | 失败无法恢复 |
| **P2** | 列表分页/筛选切换无过渡 | 卡片瞬间变化 |
| **P2** | 列表未接入 PageLoading/PageEmpty | 内联实现 vs 统一组件 |
