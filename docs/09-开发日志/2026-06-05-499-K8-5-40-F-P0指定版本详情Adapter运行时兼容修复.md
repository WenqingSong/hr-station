# K8-5-40-F：P0 指定版本详情 Adapter 运行时兼容修复

> 日期：2026-06-05 | 性质：前端修复 | 改 `resumeAdapter.ts` + `MyResumesPage.tsx`

---

## 一、本阶段目标

修复指定版本详情回填失败的真实根因：adapter 对 `/api/resumes/versions/{N}` 返回的特定字段类型不兼容。

---

## 二、K8-5-40-E 结论回顾

```
1. /resumes/edit?versionNo=1 能正确读取并调用 getResumeDetail(1)
2. 后端接口 200 + 完整 JSON
3. 失败进入 MyResumesPage:269 的 "other error" catch
4. 不是 API 路径/后端/401/404 问题
5. → 怀疑 toResumeManagementViewModel 抛异常
```

---

## 三、真实根因定位

### API 字段类型差异

| 字段 | `/api/resumes/current` | `/api/resumes/versions/1` |
|------|:--:|:--:|
| `expected_cities` | `string[]` 或 `undefined` | **`string`（`"\"\""`）** |
| `projects` | `array` | **`null`** |

### Crash 调用链

```
toResumeManagementViewModel(resume)
  → displayLocation fallback (line 284-286)
  → getV2ExpectedCities(resume) → checks resume.expected_cities?.length
  → expected_cities is "\"\"" → String.length is truthy → returns "\"\""
  → getV2ExpectedCities returns empty array (fixed case)
  
  → BUT: getV2ExpectedCities returns [] due to string not matching Array expectation
  → [].length === 0 → not truthy → fallback path:
  → resume.expected_cities?.length → "\"\""?.length → truthy!
  → resume.expected_cities.join(' / ') → STRING.join() → TypeError!
```

**String 没有 `.join()` 方法。TypeError 是普通 Error，不是 ApiClientError，导致所有分类检查失败，最终显示通用错误文案。**

## 四、修改文件

| 文件 | 修改 | 说明 |
|------|------|------|
| `resumeAdapter.ts` | `getV2ExpectedCities` + `displayLocation` | `Array.isArray()` 先判断，再访问 `.length` |
| `MyResumesPage.tsx` | 拆分 API/adapter catch | `.then()` 内 try/catch adapter；`.catch()` 只处理 API 错误 |

### resumeAdapter.ts

**getV2ExpectedCities**（line 161-164）：
```ts
// 修改前
if (resume.expected_cities?.length) return resume.expected_cities;

// 修改后
const cities = resume.expected_cities;
if (Array.isArray(cities) && cities.length > 0) return cities;
```

**displayLocation fallback**（line 284-286）：
```ts
// 修改前
: (resume.expected_cities?.length
  ? resume.expected_cities.join(' / ')
  : '暂未填写');

// 修改后
: (Array.isArray(resume.expected_cities) && resume.expected_cities.length > 0
  ? resume.expected_cities.join(' / ')
  : '暂未填写');
```

### MyResumesPage.tsx

**API/adapter 分层**：
```ts
getResumeDetail(editingVersionNo)
  .then((resume) => {
    // K8-5-40-F: adapter try/catch —— 与 API .catch() 分开
    let vm;
    try {
      vm = toResumeManagementViewModel(resume);
    } catch (adapterError) {
      console.error("[resume-edit] adapter failed for resume version", {
        versionNo: editingVersionNo,
        error: adapterError,
        resumeKeys: resume ? Object.keys(resume) : null,
      });
      setResumeError("简历数据解析失败，请稍后重试或检查该版本数据结构是否完整。");
      return;
    }
    setFormVm(vm);
    setLoading(false);
  })
  .catch((err: unknown) => {
    // K8-5-40-D: API 错误分类
    ...
  });
```

## 五、Adapter 兼容结果

| 字段结构 | 兼容方式 |
|------|------|
| `expected_cities: string` | `Array.isArray()` 先判，不是数组则返回 `[]` |
| `expected_cities: string[]` | `Array.isArray() && length > 0` → 正常返回 |
| `projects: null` | `resume.projects?.length ?? 0` → 容忍 null |
| `education: array` | `Array.isArray()` → 正常处理 |
| `experience: array` | `Array.isArray(raw.experience)` → 兼容 singular 字段名 |
