# K8-5-20-B — 首页右侧登录/注册按钮接入 AuthDialog

> 日期：2026-06-03 | 性质：implementation | 仅 AIDecisionWorkspace.tsx

---

## 1. 本阶段目标

将首页右侧 AIDecisionWorkspace 的「登录」「注册新账号」按钮从旧 `navigate("/login")` / `navigate("/register")` 改为 AuthDialog 弹窗。

---

## 2. 修改方案

| 区域 | 修改 | 原因 |
|------|------|------|
| import | 新增 `AuthDialog` | 接入弹窗 |
| state | 新增 `isLoggedIn` state（原为 computed） | 登录成功后刷新状态 |
| state | 新增 `authDialogOpen` + `authDialogMode` | 控制弹窗 |
| 登录按钮 | `navigate("/login")` → `setMode("login"); setOpen(true)` | 弹窗代替跳转 |
| 注册按钮 | `navigate("/register")` → `setMode("register"); setOpen(true)` | 弹窗代替跳转 |
| JSX | 底部新增 `<AuthDialog>` | 弹窗渲染 |
