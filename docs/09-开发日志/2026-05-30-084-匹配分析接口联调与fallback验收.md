# 2026-05-30-084-匹配分析接口联调与fallback验收

> 日期：2026-05-30
> 阶段：4-3.3
> 任务：匹配分析接口联调与 fallback 验收

## 1. 本次任务

对匹配分析接口进行联调与 fallback 验收，验证在以下场景下接口均稳定：

1. LLM success
2. JSON repair 成功（repaired）
3. fallback_required
4. LLM_ENABLE=false
5. LLM 配置异常
6. Pipeline / Agent 异常

## 2. 验收范围

- 匹配分析接口 `POST /api/jobs/{id}/match`
- MatchAnalysisAgent（LLM Pipeline 路径）
- MatchMockAgent（Mock fallback 路径）
- MatchService（LLM 优先 + Mock 回退）
- 字段映射（LLM Schema → model.MatchAnalysisResult）
- generated_by / agent_status / repair_applied / fallback_reason / error_code
- 安全边界（不泄露 API Key、不输出完整 raw output）

## 3. 当前匹配分析链路

```
POST /api/jobs/{id}/match
  → MatchHandler.Analyze
    → MatchService.Analyze
      → if llmEnabled && pipelineRunner != nil:
        → analyzeWithLLM → MatchAnalysisAgent.Analyze → Pipeline.Run
          → success/repaired: mapParsedToMatchResult + save snapshot
          → fallback_required: return MatchFallbackError → analyzeWithMock
      → else: analyzeWithMock
        → mockAgent.Analyze + save snapshot
```

## 4. 验收场景

### 4.1 LLM success

- Pipeline 返回 AgentStatus=success
- generated_by=llm_agent, agent_status=success, repair_applied=false
- 不调用 match_mock
- ✅ 通过

### 4.2 LLM repaired

- Pipeline 返回 AgentStatus=repaired
- generated_by=llm_agent, agent_status=repaired, repair_applied=true
- ✅ 通过

### 4.3 fallback_required

- Pipeline 返回 AgentStatus=fallback_required
- 返回 MatchFallbackError → Service 回退 Mock Agent
- mock 结果 generated_by=mock_agent, agent_status=fallback
- fallback_reason / error_code 有值
- ✅ 通过

### 4.4 LLM_ENABLE=false

- Service 直接走 Mock Agent
- generated_by=mock_agent, agent_status=mock
- 不调用 Hunyuan
- ✅ 通过

### 4.5 LLM 配置异常

- Pipeline 返回 fallback_required（llm_config_missing / json_parse_failed）
- Service 回退 Mock Agent
- 不泄露 API Key
- ✅ 通过

### 4.6 请求参数异常

- handler 层校验 job_id / resume_version_no
- 参数错误不被 fallback 掩盖
- ✅ 通过
