## 关键发现

- JSON 字段（education/experience/project/skills）后端使用 `json.RawMessage`，响应中已作为内联 JSON 数组，**不需要二次 JSON.parse**
- 空简历用户（新注册）返回 `data: null`，seed 用户 `arthur@example.com` 有 V1/V2 两个版本
- compare 接口当前是普通后端业务逻辑（`generated_by: "mock_agent"`），非真实 LLM 调用
