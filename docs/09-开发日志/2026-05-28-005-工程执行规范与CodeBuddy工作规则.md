## 6. 关键决策

1. **任务颗粒度**：一个 Prompt 只做一个明确工程任务，不跨阶段、不顺手修、不自行新增
2. **执行前必读文档**：每次执行前必须阅读说明书、项目状态、下一步任务、变更记录、最近日志
3. **执行后必更新文档**：每次执行后必须更新项目状态、下一步任务、变更记录、开发日志
4. **中文命名仅限 docs**：docs 目录 Markdown 使用中文命名，代码文件不使用中文
5. **越权绝对禁止**：15 项绝对禁止事项，包括不自动生成简历、不新增多简历管理等
6. **不确定先记录**：遇到不确定事项先记录风险或提问，不擅自决定
7. **8 阶段划分**：阶段 0-7 从文档到交付的完整阶段线
8. **Demo 验收标准**：10 个验收维度，含明确的不通过条件
