# K9-Final-UX-A：全站列表圆点对齐与用户无感文案只读巡检

> 日期：2026-06-09 | 编号：688 | 阶段：K9-Final-UX | 类型：只读巡检

## 一、巡检目标

1. 确认全站圆点列表与文字基线不齐的问题
2. 定位 Unicode 圆点（●/•）和散写 `<span className="rounded-full" />` 的使用情况
3. 评估统一 BulletList 组件的必要性

## 二、巡检范围

| 页面 | 文件 | 列表类型 |
|------|------|----------|
| ResumeComparisonPage | `web/src/app/pages/ResumeComparisonPage.tsx` | ● + flex items-start gap-2 |
| JobRecommendationPage | `web/src/app/pages/JobRecommendationPage.tsx` | Badge 标签 |
| JobMatchAnalysisPage | `web/src/app/pages/JobMatchAnalysisPage.tsx` | <ul><li> 结构 |
| ResumeOptimizationPage | `web/src/app/pages/ResumeOptimizationPage.tsx` | ● + <ul><li> |

## 三、巡检发现

### 3.1 Unicode 圆点问题

- `ResumeComparisonPage.tsx`：使用 `●` + `flex items-start gap-2`
- `ResumeOptimizationPage.tsx`：右侧栏使用 `<span className="text-amber-500 shrink-0">●</span>`

### 3.2 列表样式不统一

- 页面间圆点大小、间距、对齐方式不一致
- 部分使用 `items-center`（多行文本时圆点不跟第一行对齐）
- 缺少统一的语义色系统

### 3.3 推荐方案

- **方案 B**：封装 `BulletList` / `BulletItem` 通用组件
- 支持 tone 色彩（blue/green/amber/red/purple/slate）
- 支持 size（xs/sm/md）
- 使用 `items-start` 保证多行对齐
- 使用 `mt-[0.42em]` 微调圆点垂直位置
- 不使用 Unicode ●/•

## 四、高风险页面

1. `ResumeComparisonPage.tsx` — 6+ 列表区域
2. `JobRecommendationPage.tsx` — 2 列表区域
3. `JobMatchAnalysisPage.tsx` — 2 列表区域
4. `ResumeOptimizationPage.tsx` — 5+ 列表区域

## 五、结论

- 需要创建统一 BulletList 组件
- 需要替换 4 个页面中的所有 Unicode 圆点和散写列表
- 不处理画像/标签/backend_engineering 文案问题（留给 K9-Final-UX-C）
