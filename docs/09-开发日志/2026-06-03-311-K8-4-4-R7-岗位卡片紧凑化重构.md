# K8-4-4-R7：岗位卡片紧凑化重构，删除"招聘中"和"查看详情"

- **日期**：2026-06-03
- **阶段**：K8-4-4-R7（frontend-only）
- **性质**：JobCard 从"详情型卡片"改为"招聘列表型卡片"

## 1. 用户反馈

上一轮 R5/R6 虽然调整了视觉风格和文字结构，但卡片仍然不像腾讯招聘：

- 卡片太大，像详情卡片而非列表项
- 右上角"招聘中"badge 在腾讯招聘卡片中不存在
- 右下角"查看详情 →"按钮在腾讯招聘卡片中不存在
- 描述大段文字使卡片高度明显变大
- 目标不是"弱化"，而是直接**删除**这些元素

## 2. 为什么上一版卡片仍然太大

R5/R6 保留了以下非列表项元素，导致卡片臃肿：

| 元素 | 位置 | 高度消耗 |
|------|------|---------|
| 状态 badge "招聘中" | 右上角 | 标题行高度被 badge 撑大 |
| 岗位描述 2 行 | 工作地点下方 | ~40px |
| "查看详情 →" + 分割线 | 底部 | ~36px（含分割线） |
| 内部 padding `p-6` | 四周 | 48px 内部空白 |

上述元素合计使卡片高度偏大约 60-70px。

## 3. 本次删除的元素

| 删除项 | 原因 |
|--------|------|
| 右上角"招聘中"状态 badge | 腾讯招聘列表卡片无此元素 |
| 左下角岗位描述大段文字 | 腾讯招聘列表卡片无描述 |
| 底部"查看详情 →"按钮 + 分割线 | 腾讯招聘卡片整卡可点击，无独立按钮 |
| `p-6` → `py-4 px-6` | 减少内部空白，紧凑化 |

## 4. 本次保留的信息结构

```
软件开发-后台开发方向

技术  |  应届实习  |  CDG CSIG IEG PCG TEG WXG S1 S2

工作地点：深圳总部 北京 上海 广州 成都 武汉 杭州
```

仅三行核心信息：标题、元信息行、工作地点。

## 5. 整卡点击方案

由于删除了"查看详情"，整卡点击成为唯一导航方式：

- 卡片 `<div>` 绑定 `onClick={() => navigate(`/jobs/${id}`)}`
- 添加 `role="link"` + `tabIndex={0}` 支持键盘可访问性
- 添加 `onKeyDown` 支持 Enter 键导航
- hover 时边框微蓝 + 阴影增强（`group` + CSS 类）
- 鼠标指针 `cursor-pointer`
