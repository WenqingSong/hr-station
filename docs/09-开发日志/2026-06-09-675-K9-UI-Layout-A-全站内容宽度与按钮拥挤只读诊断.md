## 三、简历管理页拥挤根因

| 问题 | 根因 | 建议 |
| -- | -- | -- |
| 操作按钮拥挤 | `max-w-[1040px]` + `flex-[2]` 主列表 ≈ 697px → 扣减日期(88px)+操作列(180px)+gap+padding → 名称仅 365px → 操作列 180px 中 "查看详情"（4字+icon≈66px）、"编辑"（2字+icon≈46px）、"删除"（2字+icon≈46px）+ gap-3×2 = 182px → **正好到极限，无余量** | 方案 B：页宽扩至 1200px + 操作列 220px + nowrap |
| 页面整体偏窄 | `max-w-[1040px]` 是全站唯一窄页面，其他最少 1280px | 提升至 1200px |
| 按钮无 nowrap | `ActionBtn` 组件无 `whitespace-nowrap` | 添加 |

### 空间计算

| -- | -- | -- |

| 名称列可用宽 | ~365 | ~468 |

| 按钮余量 | ~0（182px 用满 180px） | ~38px |

## 五、操作按钮诊断

| 项 | 当前实现 | 问题 | 建议 |
| -- | -- | -- | -- |
| 按钮 nowrap | ❌ 无 | 文字换行风险 | 加 `whitespace-nowrap` |
| icon+文字间距 | `gap-1`（4px） | ✅ 合理 | 保持 |
| 按钮类型 | text button（icon+文字） | ✅ | 保持 |
| 「查看详情」长度 | 4 汉字 + icon ≈ 66px | 在 180px 中偏紧 | 操作列扩至 220px |
| 最小修复 | — | — | 操作列 220px + nowrap |

### 按钮方案对比

| 方案 | 是否推荐 | 理由 |
| -- | -- | -- |
| 操作列恢复 220px | ✅ **推荐** | 最小风险 |
| 按钮加 nowrap | ✅ **推荐** | 配合 220px 使用 |
| 「查看详情」→「详情」 | ❌ | 语义模糊 |
| 删除进更多菜单 | ❌ | 删除是高频操作 |
| 只显示 icon | ❌ | 可发现性差 |

## 七、修复方案判断

| 方案 | 内容 | 是否推荐 |
| -- | -- | -- |
| 方案 A | 仅修按钮（220px + nowrap），不改页面宽度 | ⚠️ 仍然不够大气 |
