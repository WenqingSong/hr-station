## 6. 关键决策

1. **使用 database/sql + MySQL Driver**：阶段 2 只需连接和 Ping，不引入 GORM/sqlx，降低复杂度
2. **单 SQL 文件策略**：不引入复杂迁移工具，表结构统一写入 server/sql/init.sql
3. **统一响应格式**：`{"code":0,"message":"ok","data":{}}`，阶段 2-3 确立
4. **基础错误码**：0/40000/40001/40100/40300/40400/50000/50300，阶段 2 只定义基础码
5. **中间件执行顺序**：Recover（最外层）→ CORS → RequestLogger（最内层）
6. **健康检查策略**：开发阶段数据库不可用返回 200+degraded，不返回 503
7. **CORS 策略**：local 环境允许 localhost:5173，较宽松策略
8. **2-2 只读取配置不使用**：JWT/LLM/DB 配置在 2-2 只读取，JWT 使用留阶段 3，LLM 留阶段 4，DB 连接留 2-5
