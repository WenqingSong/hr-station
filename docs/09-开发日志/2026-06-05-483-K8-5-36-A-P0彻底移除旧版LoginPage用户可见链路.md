# K8-5-36-A：P0 彻底移除旧版 LoginPage 用户可见链路并统一登录体验

## 一、本阶段目标

彻底移除旧版独立 LoginPage / RegisterPage 用户可见入口，统一为 Navbar + AuthDialog 这一套登录体验。

实现：

1. `/login?redirect=%2Fresumes` 不再渲染旧 LoginPage 独立页面
2. `/register` 不再渲染旧 RegisterPage 独立页面
3. 未登录访问受保护页面时，不再跳到旧 LoginPage
4. 统一使用 Navbar/AuthDialog 这一套登录体验
5. "评委一键体验"保留，并且仍可登录 demo 账号
6. redirect 逻辑保留：未登录访问 /resumes，登录成功后回到 /resumes
7. LoginPage / RegisterPage 改为纯 redirect wrapper，不再显示旧表单

## 二、用户复现路径

用户再次复现：

```text
http://localhost:8080/login?redirect=%2Fresumes
```

页面仍然进入独立登录页：

```text
登录 Offerr鹅 / 手机号 / 密码 / 登录 / 评委一键体验 / 还没有账号？注册
```

虽然 K8-5-33-B 已经给 LoginPage 补了"评委一键体验"，但这不是根治。

## 三、根因

保留了 `/login` 和 `/register` 两套登录 UI：

1. Navbar/AuthDialog 一套（弹窗式）
2. /login 独立页面一套（全页面式）

RequireAuth 无 token 时重定向到 `/login?redirect=...`，API 401 时也重定向到 `/login?redirect=...`，导致用户反复看到旧 LoginPage。

## 五、/login 新行为

```text
/login                      → /?auth=login                        （立即重定向，不渲染任何 UI）
/login?redirect=%2Fresumes  → /?auth=login&redirect=%2Fresumes    （保留 redirect）
```

- LoginPage 改为 `AuthRedirectPage`：useEffect 中读取 redirect 参数 → `navigate(target, { replace: true })` → `return null`
- 不再显示"登录 Offerr鹅"、"手机号"、"密码"、"还没有账号？注册"等旧表单

## 六、/register 新行为

```text
/register                      → /?auth=login                      （重定向到统一弹窗，注册入口在 AuthDialog 内 tab 切换）
/register?redirect=%2Fresumes  → /?auth=login&redirect=%2Fresumes
```

- RegisterPage 改为纯 redirect wrapper，return null
- 注册入口在 AuthDialog 内通过 tab 切换提供

## 七、RequireAuth 新行为

```text
修改前：<Navigate to="/login?redirect=<当前路径>" replace />
修改后：<Navigate to="/?auth=login&redirect=<当前路径>" replace />
```

- 不再跳转到旧 LoginPage 独立页面
- 跳转到首页并携带 `auth=login` 参数，由 Navbar 检测后自动打开 AuthDialog

## 八、AuthDialog URL 自动打开逻辑

Navbar 新增：

```typescript
const [searchParams, setSearchParams] = useSearchParams();
const redirectAfterLoginRef = useRef<string | null>(null);

useEffect(() => {
  const auth = searchParams.get("auth");
  if (auth === "login" || auth === "register") {
    redirectAfterLoginRef.current = searchParams.get("redirect");
    setAuthDialogMode(auth === "register" ? "register" : "login");
    setAuthDialogOpen(true);
    setSearchParams({}, { replace: true });  // 清理 URL，避免刷新反复弹窗
  }
}, []);
```

`handleAuthSuccess` 增强：

```typescript
const handleAuthSuccess = () => {
  setIsLoggedIn(Boolean(getAuthToken()));
  if (redirectAfterLoginRef.current) {
    const target = redirectAfterLoginRef.current;
    redirectAfterLoginRef.current = null;
    navigate(target);
  }
};
```

## 九、redirect 保留结果

| 场景 | redirect 链路 |
|------|--------------|
| 未登录访问 `/resumes` | RequireAuth → `/?auth=login&redirect=%2Fresumes` → AuthDialog → 登录成功 → `/resumes` |
| API 401（token 过期） | `getAuthRedirectIf401()` → `/?auth=login&redirect=%2Fresumes` → AuthDialog → 登录成功 → redirect |
| 直接访问 `/login?redirect=%2Fresumes` | LoginPage → `/?auth=login&redirect=%2Fresumes` → AuthDialog → 登录成功 → `/resumes` |
| 直接访问 `/register` | RegisterPage → `/?auth=login` → AuthDialog 打开，无 redirect → 登录成功后停留在首页 |
| Navbar 手动点击"登录" | AuthDialog 打开 → 登录成功 → 保留当前页面（无 redirect） |
