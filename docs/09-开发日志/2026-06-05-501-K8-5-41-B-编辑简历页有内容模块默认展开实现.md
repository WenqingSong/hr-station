# K8-5-41-B：编辑简历页有内容模块默认展开实现

> 日期：2026-06-05 | 性质：前端修复 | 改 `ResumeEditorSectionCard.tsx` + `MyResumesPage.tsx`

---

## 一、本阶段目标

编辑已有简历时，有内容的 3 个问题模块（实习经历/证书与获奖/作品链接）默认展开；无内容保持折叠；新增简历保持原体验。

## 二、修改文件

| 文件 | 修改 |
|------|------|
| `ResumeEditorSectionCard.tsx` | 新增 `autoOpenKey` prop + `touched` 状态 + `useEffect` 自动展开 |
| `MyResumesPage.tsx` | 新增内容判断 helper + 4 个模块传动态 `defaultOpen` + `autoOpenKey` |

---

## 三、内容判断逻辑

```tsx
const isEditingExistingResume = Boolean(editingVersionNo);
const hasInternshipContent = internships.length > 0;
const hasCertificateAwardContent = languageExamDrafts.length > 0 || certificateDrafts.length > 0 || awardDrafts.length > 0;
const hasPortfolioExtraContent = portfolioDraft.works.some(w => w.name.trim() || w.link.trim())
  || !!portfolioDraft.homepage.trim() || !!summary.trim() || !!extraInfoDraft.additionalInfo.trim();
const sectionAutoOpenKey = editingVersionNo ?? "_new";
```

---

## 四、动态 defaultOpen

| 模块 | defaultOpen |
|------|------|
| InternshipSection | `isEditingExistingResume && hasInternshipContent` |
| CertificatesSection | `isEditingExistingResume && hasCertificateAwardContent` |
| PortfolioExtraSection × 2 | `isEditingExistingResume && hasPortfolioExtraContent` |

每个模块同时传 `autoOpenKey={sectionAutoOpenKey}`。

---

## 五、异步回填 defaultOpen 处理（ResumeEditorSectionCard）

```tsx
const [touched, setTouched] = useState(false);
const prevKeyRef = useRef(autoOpenKey);

// autoOpenKey 变化（切换简历版本 → 回填完成）→ 重置展开状态
useEffect(() => {
  if (autoOpenKey !== undefined && autoOpenKey !== prevKeyRef.current) {
    prevKeyRef.current = autoOpenKey;
    setOpen(defaultOpen);
    setTouched(false);
  }
}, [autoOpenKey, defaultOpen]);

// 手动 toggle → 标记 touched
const handleToggle = () => {
  if (!collapsible) return;
  setTouched(true);
  setOpen(!open);
};
```

---

## 六、用户手动折叠保护

- `autoOpenKey` 变化（切换版本/重新加载）→ `touched=false` → 重新读取 `defaultOpen`
- 用户点击折叠 → `touched=true` → 同一 `autoOpenKey` 下不受后续 `defaultOpen` 变化影响
- 切换不同简历版本 → `autoOpenKey` 从 `versionNo` 变化 → 重置
