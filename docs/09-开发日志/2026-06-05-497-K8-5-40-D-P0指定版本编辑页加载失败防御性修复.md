# K8-5-40-D：P0 指定版本编辑页加载失败防御性修复

> 日期：2026-06-05 | 性质：前端修复 | 只改 `MyResumesPage.tsx`

---

## 一、本阶段目标

对 `MyResumesPage` 的指定版本加载失败做防御性修复：分类 401/404/other，401 跳统一登录保留 redirect，404 给明确文案，other 加 console.error。

---

## 二、修改文件

| 文件 | 修改 |
|------|------|
| `web/src/app/pages/MyResumesPage.tsx` | 新增 `isApiClientError` 导入；两个 `.catch()` 加入错误分类 |

---

## 三、错误分类逻辑

### getResumeDetail 分支（指定版本加载）

```
try { getResumeDetail(N) → toResumeManagementViewModel → setFormVm }
catch (err):
  ├── isApiClientError && status === 401
  │   → console.error("[resume-edit] unauthorized while loading version")
  │   → navigate("/?auth=login&redirect=/resumes/edit?versionNo=N", { replace })
  │
  ├── isApiClientError && status === 404
  │   → console.error("[resume-edit] resume version not found")
  │   → setResumeError("该简历版本不存在或已被删除。")
  │
  └── 其他
      → console.error("[resume-edit] failed to load resume version")
      → setResumeError("指定简历版本加载失败，请稍后重试。")
```

### loadResumeManagementPageViewModel 分支（current 加载）

```
catch (err):
  → setLoading(false)
  → getAuthRedirectIf401 → if auth, navigate redirect
  → console.error("[resume-edit] failed to load current resume")
  → setResumeError("简历加载失败，请稍后重试。")
```

## 四、401 跳转统一登录逻辑

```tsx
const loginRedirect = `/?auth=login&redirect=${encodeURIComponent(`/resumes/edit?versionNo=${editingVersionNo}`)}`;
navigate(loginRedirect, { replace: true });
```

- 使用项目统一的 `/?auth=login&redirect=...` 格式
- `redirect` 参数编码为 `/resumes/edit?versionNo=N`
- 用户登录后自动回到当前编辑页
