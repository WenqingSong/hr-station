## 前端 adapter / viewModel 传递盘点

### 数据流水线

```
GET /api/resumes/current  →  `Resume` type (has V2 fields ✅)
   ↓
toResumeManagementViewModel()  →  `ResumeManagementViewModel` (DROPS V2 raw fields ❌)
   ↓
MyResumesPage formVm  →  useFormVm state
   ↓
edit mode backfill useEffect  →  只回填 V1 字段 ❌
```

### 各层级 V2 支持

| 层级 | 是否识别 V2 | 是否传给页面 | 结论 |
|------|:---:|:---:|------|
| `types/resume.ts` `Resume` type | ✅ 有 `profile_json`/`job_intention`/`internships`/`certificates`/`awards`/`portfolio_links`/`extra_info` | — | 类型已完整 |
| `api/client.ts` request/post | ✅ 自动 Bearer token | ✅ | 认证链路正常 |
| `api/viewModels.ts` `loadResumeManagementPageViewModel` | ❌ 调用 `toResumeManagementViewModel` → **丢弃 V2 字段** | ❌ | **断点 1** |
| `adapters/resumeAdapter.ts` `toResumeManagementViewModel` | ❌ 只输出 V1 兼容字段 | ❌ | **断点 2** |
| `ResumeManagementViewModel` type | ❌ 只有 `schemaVersion`，无 V2 raw | ❌ | **缺 V2 raw 字段** |
| `MyResumesPage` backfill useEffect | ❌ 只回填 V1 字段 | ❌ | **断点 3** |

**断点分析：**
1. **断点 1+2**：`toResumeManagementViewModel` 把 API response 中的 V2 raw JSON（`profile`/`job_intention`/`internships`/`certificates`/`awards`/`portfolio_links`/`extra_info`）全部丢弃，只取了 V1 兼容字段。
2. **断点 3**：即使补上 ViewModel 的 V2 raw 字段，`MyResumesPage` 的回填代码也需要逐个映射到 V2 draft state。

## 后续阶段建议

### K8-5-23-B：V2 编辑回填修复

**目标**：让 MyResumesPage 在 edit 模式下回填所有 10 模块 V2 draft state。

**修改范围（建议）**：
1. `ResumeManagementViewModel`：新增 V2 raw 字段（或在 MyResumesPage 直接调 `getCurrentResume` 拿 `Resume` 类型）。
2. `MyResumesPage` backfill useEffect：从 V2 JSON 字段回填到 draft state。
3. 逐项映射：
   - `resume.job_intention` → `acceptOtherCities`/`earliestStartDate`/`internshipDuration`/`weeklyAvailableDays`/`targetIndustries`/`targetCompanies`

   - `resume.education` (V2 format) → `Education[].department`/`gpa`/`gpaScale`/`rank`/`coreCourses`/`researchDirection`/`lab`/`paperSummary`
   - `resume.projects` (V2 format) → `Project[].projectType`/`startDate`/`endDate`/`responsibilities`/`achievements`/`link`
   - `resume.skills` (V2 format) → `skillsDraft` 10 分类
   - `resume.certificates` → `certificateDrafts`
   - `resume.awards` → `awardDrafts`
   - `resume.portfolio_links` → `portfolioDraft`
   - `resume.extra_info` → `extraInfoDraft`
4. 不改 SQL/Agent/Prompt/Schema/Mock。
