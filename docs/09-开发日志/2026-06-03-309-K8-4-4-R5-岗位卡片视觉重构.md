# K8-4-4-R5：岗位卡片视觉重构，对齐腾讯招聘岗位列表风格

- **日期**：2026-06-03
- **阶段**：K8-4-4-R5（frontend, pass）
- **性质**：JobCard 视觉彻底重构，对齐腾讯招聘岗位列表

## 1. 用户反馈

当前岗位卡片像后台管理系统 / demo，不像成熟招聘官网：
- tag 大量堆叠（事业群 tag + 技能 tag + 底部 tag）
- 英文 "open" 状态，不符合中文站
- 标题蓝色悬停过强
- 卡片高度偏大，信息密度不自然

## 2. 腾讯招聘卡片参考特征

| 特征 | 描述 |
|------|------|
| 信息层级 | 标题 → 元信息（`|` 分隔）→ 事业群缩写 → 工作地点 → 简述 |
| 卡片风格 | 白底、大圆角、轻边框、无重阴影 |
| 标签策略 | 无 tag 堆叠，事业群用空格分隔 codes |
| 状态 | 弱化右上角中文 badge |
| 跳转 | 自然 "查看详情 →" |

## 3. 重构方案

### 卡片结构

```
┌──────────────────────────────────────────┐
│ 岗位标题                          招聘中  │
│ 技术 | 软件开发 | 校园招聘               │
│ 事业群：CDG CSIG IEG PCG                     │
│ 📍 工作地点：深圳总部 北京 上海...     │
│ 岗位简述（最多2行，灰色小字）              │
│                             查看详情 →  │
└──────────────────────────────────────────┘
```

### 主要改动

| 改动 | 旧 | 新 |
|------|----|----|
| 标题 | `text-[17px] font-bold` 蓝 hover | `text-[18px] font-semibold` 深色 |
| 元信息行 | `direction / type / department` 三项 | `jobTypeLabel | direction | typeLabel` 三项 + `|` 分隔 |
| 事业群 | 一堆浅灰 tag badge | 空格分隔缩写 codes + "事业部："前缀 |
| 工作地点 | MapPin + `·` 分隔 | MapPin + `工作地点：` 空格分隔 |
| 技能标签 | 底部 5+ 个 tag + 边框 | **完全移除** |
| 状态 | `open` + 蓝点 | 右上角 "招聘中" 中文 badge |
| 描述 | `text-[14px] text-gray-500` | `text-[13px] text-gray-400 line-clamp-2` |
| 底部操作 | 技能标签 + 查看详情按钮 | 仅 `查看详情 →`（右对齐+箭头动效） |
| 圆角 | `rounded-xl` | `rounded-2xl` |
| hover | `shadow-md` + 蓝边框 | `hover:border-[#0052D9]/25` + `hover:shadow-sm` |

### Props 重构

移除：`type`、`department`、`businessGroups`、`skills`、`location`

新增：`jobTypeLabel`、`organizationCodes`

保留：`id`、`title`、`direction`、`typeLabel`、`locations`、`description`、`statusLabel`

### Adapter 新增字段

- `JobCardViewModel.organizationCodes: string[]` — 从 API `organizations[].code` 提取
- `JobCardViewModel.jobTypeLabel: string` — 从 API `job_type` 读取
