# K8-5-34-B：修复我的简历页前端数据链路不显示示范简历

## 一、本阶段目标

修复 `/resumes` 页面，使 demo 用户在登录后不再显示"你还没有创建简历"的空状态，而是显示 9 份示范简历版本列表 + 当前简历详情。

## 二、P0 根因

K8-5-34-A 确认：

1. `/api/resumes/current` 对 demo user_id=2 返回完整有效数据
2. `/api/resumes/versions` 返回 9 份 versions
3. 但 `ResumeManagementPage` 只调用 `getCurrentResume()`，不调用 `getResumeVersions()`
4. 前端 `Resume` type 与后端 `ResumeVersionResponse` 存在多处字段名不匹配（`version_no` vs `version`、`experience` vs `experiences`、`created_at` vs `updated_at`）
5. `loadResumeManagementPageViewModel` 只能返回 null 或当前简历 VM，没有任何 versions 数据
6. 当 `toResumeManagementViewModel` 出现运行时异常时（如 null access），catch 返回 null → EmptyState

## 四、API 返回和前端链路差异修复

| 后端字段 | 前端旧类型 | 修复 |
|---------|----------|------|
| `version_no` (int) | `version` (string) | `toResumeSummaryViewModel` 同时读取 raw `version_no`，显示为 "V{version_no}" |
| `experience` (singular) | `experiences` (plural) | `toResumeManagementViewModel` fallback `raw.experience` |
| `created_at` | `updated_at` | `toResumeSummaryViewModel` fallback `raw.created_at` |
| 缺 `status`/`direction`/`completeness` | 必填字段 | 改为可选，提供默认值（"历史版本" / "" / 0） |

## 五、ResumeManagementPage EmptyState 修复

```
旧逻辑：if (!vm || !vm.hasResume) → EmptyState
新逻辑：if (!vm || !vm.hasAnyResume) → EmptyState
  — hasAnyResume = versions.length > 0 || current !== null
  — 只有真正无任何简历时才显示空状态
```

## 六、versions 列表展示实现

在页面标题下方新增"全部简历版本"卡片网格：
- 2 列 grid 布局（sm 断点）
- 每卡片显示：简历名称、方向标签、城市标签、更新时间、编辑按钮
- 编辑按钮跳转 `/resumes/edit`
- 数据来自 `toResumeOptionViewModelsFromVersions()`
