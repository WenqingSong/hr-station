# K8-4-4-R3：移除左侧已选筛选区域，统一使用列表顶部筛选标签

- **日期**：2026-06-03
- **阶段**：K8-4-4-R3（frontend, pass）
- **性质**：移除左侧重复已选筛选 UI，统一由中间顶部展示

## 1. 用户反馈

左侧筛选栏顶部出现重复的已选筛选区域（"已选 X 项 / 清空筛选 / 标签 chip"），与中间岗位列表顶部的筛选标签完全重复，占用空间且不符合成熟招聘网站体验。

## 2. 问题确认

| 位置 | 内容 | 问题 |
|------|------|------|
| `JobFilterSidebar` L86-103 | "已选 X 项 / 清空筛选 / chip" 区域 | 与 JobList 顶部标签重复 |
| `JobFilterSidebar` L105 | 分隔线 | 仅分隔已选区域与筛选组，冗余 |
| `JobFilterSidebar` L51, L53-68 | `activeCount` + `selectedLabels` useMemo | 变死代码 |
| `JobFilterSidebar` L1-2 | `useMemo`, `X` 导入 | 变无用导入 |
| `JobList` L42-72 | 中间顶部筛选标签 | 保留，继续承担展示职责 |

## 3. 修复方案

| 操作 | 说明 |
|------|------|
| 删除左侧 chips 区域 | 移除 "已选 X 项 / 清空筛选 / chip" 整块 UI |
| 删除分隔线 | 移除 `<div className="border-t">` |
| 清理死代码 | 移除 `activeCount`、`selectedLabels`、`useMemo`/`X` 导入 |
| 保留中间顶部标签 | `JobList` L42-72 不动，所有筛选条件在此展示 |
| 保留搜索框 | 左侧搜索框不变 |

左侧筛选栏结构变为：搜索框 → 筛选分组（不再有已选区域）。
