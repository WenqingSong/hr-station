## 二、用户截图仍为空的真实根因

**Vite dev server 未运行**。K8-5-34-B 修改了源码，但没有任何服务在端口 5173 上提供前端页面。Nginx 和 Go server 的 `newFrontendProxy` 都将非 API 请求代理到 `host.docker.internal:5173`（Vite），但 Vite 进程已停止。`npm run build` 输出到 `dist/`，但架构不从此处提供服务。

**修复**：Kill 旧 Vite 进程 → 重新启动 `npx vite --port 5173 --host 0.0.0.0`。
