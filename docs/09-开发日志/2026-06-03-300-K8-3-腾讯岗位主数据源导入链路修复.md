## 2. 修复方案

### 2.1 数据导入执行

```bash
cd server && go run ./cmd/import_jobs \
  --file ../resources/jobs/tencent-campus-jobs.json \
  --replace
```

结果：
- 删除旧 8 条 `local_mock`
- 导入 46 条 `manual_curated` 岗位
- 写入 180 条 `job_locations`
- 写入 194 条 `job_business_groups`
- 写入 1402 条 `job_skills`
- 0 条 orphan 记录

### 2.2 make up 自动导入 (scripts/dev/up.sh)

新增 Step 6b：**自动导入腾讯岗位主数据源**

幂等逻辑：
1. 如果 `manual_curated/demo_curated` 岗位已存在 → 跳过
2. 如果仅 1-10 条 `local_mock` 兜底岗位 → 自动替换为腾讯岗位
3. 如果已有其他来源大量岗位 → 跳过，提示手动执行

- **旧匹配分析/推荐结果已清理**：`--replace` 会删除 `match_analyses`、`recommendation_results` 中关联旧 job_id 的记录。用户若需要，需重新执行匹配分析和岗位推荐

- **后端已重启**：导入后后端无需重启（直接操作数据库，API 实时生效）
