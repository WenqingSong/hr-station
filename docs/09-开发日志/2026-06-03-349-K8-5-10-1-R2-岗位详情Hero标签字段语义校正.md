# K8-5-10-1-R2：岗位详情 Hero 标签字段语义校正

## 一、当前问题

K8-5-10-1-R 后 Hero 标签展示 `category="后台开发"` + `applicationType="应届实习"` + `direction="软件开发"`。但 `category="后台开发"` 是细粒度方向，不是用户目标 Hero 中的 `技术`（岗位大类）。

## 二、字段语义分析

| 字段 | API 值 | 语义 | 是否用于 Hero |
|------|--------|------|-------------|
| `job_type` | `技术` | 岗位大类 | ✅ **核心**（映射为 `jobTypeLabel`） |
| `category` | `后台开发` | 细粒度方向 | ❌ 移除 |
| `direction` | `软件开发` | 标题子方向 | ❌ 移除（标题已含） |
| `application_type` | `应届实习` | 招聘项目 | ✅ 核心（映射为 `applicationType`） |
| `typeLabel` | `应届实习` | application_type 显示值 | ❌ 与 applicationType 同义 |

## 三、修正方案

Hero 只展示 2 个核心标签（去重）：
```ts
const heroTags = Array.from(
  new Set([jobVm.jobTypeLabel, jobVm.applicationType].filter(Boolean))
);
```

- `jobVm.jobTypeLabel` = `job.job_type` = "技术"（已在 adapter 中映射）
- `jobVm.applicationType` = `job.application_type` = "应届实习"

## 四、修改清单

| 文件 | 修改内容 | 原因 |
|------|---------|------|
| `JobDetailBanner.tsx` | `category+applicationType+direction` → `jobTypeLabel+applicationType` + `Array.from(new Set(...))` 去重 + 移除 direction | 岗位大类语义校正 |

无需修改 adapter — `jobTypeLabel` 已存在于 ViewModel（L118）。
