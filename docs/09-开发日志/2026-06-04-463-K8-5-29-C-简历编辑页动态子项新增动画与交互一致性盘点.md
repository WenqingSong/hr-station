## 动画设计建议

### 推荐方案

**只用 Tailwind + CSS @keyframes，不引入新依赖。**

推荐统一 class：

```css
/* 加到 global CSS 或在组件中用 style injection */
@keyframes resume-fade-in {
  from { opacity: 0; transform: translateY(0.5rem); }
  to   { opacity: 1; transform: translateY(0); }
}
.resume-item-enter {
  animation: resume-fade-in 180ms ease-out;
}
```

或直接用 Tailwind CSS utility（v4 原生支持 `animate` 搭配自定义 keyframes）：

```css
@theme {
  --animate-item-enter: item-enter 180ms ease-out;
}
@keyframes item-enter {
  from { opacity: 0; transform: translateY(0.5rem); }
  to   { opacity: 1; transform: translateY(0); }
}
```

使用方式：

```tsx
<div className="rounded-2xl bg-gray-50/70 ring-1 ring-gray-100 p-5 animate-item-enter">
```

### 设计原则

1. **只加进入动画，不加删除动画**（删除涉及 DOM unmount，需要 transition-group 复杂方案）
2. 时长 **180ms**，不超过 200ms
3. opacity 0→1 + translateY 8px→0
4. 不引入 framer-motion / GSAP / react-spring 等依赖
5. 不影响 layout shift
6. 不影响保存逻辑
7. 回填时已有列表不加动画（初始渲染无 animation）
