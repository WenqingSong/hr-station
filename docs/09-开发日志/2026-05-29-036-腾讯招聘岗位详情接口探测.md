## 3. 执行命令

### 3.1 获取样本岗位

```bash
curl -s -X POST "https://join.qq.com/api/v1/position/searchPosition" \
  -H "Content-Type: application/json" \
  -H "User-Agent: Mozilla/5.0" \
  -H "Referer: https://join.qq.com/post.html?query=p_2" \
  -H "Origin: https://join.qq.com" \
  -d '{"bgList":[],"keyword":"","pageIndex":1,"pageSize":3,...}'
```

获取 3 条样本：id=21417、id=21415、id=21418。

### 3.2 详情接口探测

```bash
# 候选路径 1-5
curl -s GET "https://join.qq.com/api/v1/position/detail?id=21417"
curl -s GET "https://join.qq.com/api/v1/position/detail?postId=1200791473415778304"
curl -s GET "https://join.qq.com/api/v1/position/getPositionDetail?id=21417"
curl -s POST "https://join.qq.com/api/v1/position/queryPositionDetail" -d '{"id":21417,...}'
curl -s GET "https://join.qq.com/api/v1/position/getPositionDetail?postId=1200791473415778304"
```

### 3.3 前端详情页检查


## 5. 是否发现详情接口

**❌ 未发现稳定公开岗位详情接口。**

- 5 个候选 API 路径全部返回 404
- 列表接口中 `positionUrl` 为 null
- 前端详情页是 SPA 空壳，API 路径未在 JS bundle 中找到
- 继续探测 ROI 不高，不再扩大范围

## 6. 对 Demo 的影响

| 影响项 | 说明 | 应对 |
|--------|------|------|
| 岗位描述（description） | 无法获取完整 JD | 方案 A：用 positionTitle 推断；方案 B：保留 Mock 岗位数据；方案 C：LLM 生成模拟 JD |
| 岗位要求（requirements） | 无法获取完整任职要求 | 同上 |
| 匹配分析质量 | 证据链缺乏 JD 正文支撑 | 可基于 positionTitle + 事业群 + 城市做基础匹配 |
| 推荐理由 | 深度受限但仍可工作 | 基于 positionTitle 和城市仍可生成推荐理由 |

**结论**：列表摘要字段（positionTitle、bgs、workCities、projectName、positionFamily）足以支撑 Demo 演示。
