## 4. Agent 边界

- Agent 采用 Stateless 单次请求模式
- 不做 MCP 记忆，不做多轮 Agent，不让 Agent 自主调用工具
- 后续模型调用链：简历 + 岗位 JD + Schema → Prompt → LLM → JSON → 校验 → 成功/回退

## 5. 输入上下文

- 简历上下文：target_role, target_city, skills, projects, education, experience, self_evaluation
- 岗位上下文：title, department, city, category, description, requirements, data_quality, source_url
- 业务约束：不编造经历、只输出 JSON、分数 0-100、证据链必须引用 JD 和简历

## 6. 输出 JSON 原则

- 所有 LLM 输出必须是严格 JSON
- 不允许 Markdown 包裹、解释性前后缀、代码块
- 必填字段必须存在，枚举值固定，分数 0-100
- JSON parse 失败则回退 Mock Agent

## 7. 离线测试方式

- 输入：1 份学生简历 + 3 个腾讯岗位（强匹配/中匹配/弱匹配）+ Prompt + Schema
- 测试指标：合法 JSON、证据链、真实缺口、P0/P1/P2 建议、避免幻觉
- 允许手动 curl 调用 Hunyuan，不写 Go Client

## 8. 失败兜底策略

- 9 种失败场景：超时、非 JSON、字段缺失、类型错误、分数超范围、输出过长、幻觉、不可用、未开启
- 处理策略：优先校验 JSON → 尝试一次 JSON repair → 失败回退 Mock Agent
- generated_by 标记：mock_agent / llm_agent / llm_agent_fallback
