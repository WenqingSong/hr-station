## 四、四核心入口实现

| 功能 | 跳转 | 参数 |
|------|------|------|
| 岗位匹配分析 | `/match?jobId=X&resumeVersionNo=N` | 01→10003, 02→10001, 03→10016 |
| 岗位智能推荐 | `/recommend?resumeVersionNo=N` | 04/05→version_no |
| 简历版本对比 | `/resumes/compare?from=6&to=7` | 06/07→from/to |
| 简历优化建议 | `/resume-optimization?jobId=10001&resumeVersionNo=N` | 08/09→10001 |

## 五、分组规则

| 分组 | 规则（version_no 前缀） | 分组函数 |
|------|----------------------|---------|
| 岗位匹配分析 | 1-3 | `getScenario(v)` → versionNo≤3 |
| 岗位智能推荐 | 4-5 | versionNo≤5 |
| 简历版本对比 | 6-7 | versionNo≤7 |
| 简历优化建议 | 8-9 | versionNo≤9 |

分组完全由 `version_no` 数值驱动，不依赖简历名称内容。
