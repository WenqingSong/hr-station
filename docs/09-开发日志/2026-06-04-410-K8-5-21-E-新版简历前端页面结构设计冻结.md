## 4. 核心设计结论

| 决策 | 冻结 |
|------|------|
| **页面结构** | 方案 B：单页 + 模块卡片 + 推荐/可选模块折叠 |
| **默认展开** | 6 个核心模块（简历基础/基础信息/求职意向/教育经历/项目经历/技能信息） |
| **默认折叠** | 4 个可选模块（实习经历/证书与语言/获奖与竞赛/作品链接与补充） |
| **右侧状态栏** | 新增 280px sticky 右侧栏（完成度/AI可用性/四功能状态/缺失提示） |
| **响应式** | ≥1280px 双栏，768-1279px 单栏+顶部状态条，<768px 紧凑单栏 |
| **技能模块** | 从扁平 tag 改为 9 个分类区域（AI 技能区蓝色高亮） |
| **保存区** | 保持当前底部模块卡片模式（非 fixed） |
| **不做** | 照片/PDF/附件/身份证/联系人/证明人/内推/隐私/正式投递/年龄字段 |

## 5. 3 种方案比较
