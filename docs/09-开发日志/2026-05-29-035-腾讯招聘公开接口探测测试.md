# 2026-05-29-035-腾讯招聘公开接口探测测试

## 1. 本次任务

阶段 4-1.2.0：腾讯招聘公开接口探测测试。验证腾讯招聘官网公开岗位接口是否可用、分页是否稳定、字段结构是否清晰、是否适合后续作为公开岗位数据源接入。

本次只做低频公开接口探测和文档记录，不做正式接入。

## 2. 测试范围

| 接口 | 类型 | 用途 |
|------|------|------|
| `POST /api/v1/position/searchPosition` | 岗位搜索 | 验证基础可用性、分页、项目类型、keyword、城市筛选 |
| `GET /api/v1/dictionary/` | 字典查询 | 验证招聘类型、事业群、城市等字典映射 |

总请求次数约 14 次，每次间隔 ≥ 1 秒。

## 3. 执行命令

### 3.1 基础可用性测试

```bash
curl -s -X POST "https://join.qq.com/api/v1/position/searchPosition" \
  -H "Content-Type: application/json" \
  -H "User-Agent: Mozilla/5.0" \
  -H "Referer: https://join.qq.com/post.html?query=p_2" \
  -H "Origin: https://join.qq.com" \
  -d '{"bgList":[],"keyword":"","pageIndex":1,"pageSize":10,"positionFidList":[],"projectIdList":[],"projectMappingIdList":[2],"recruitCityList":[],"workCityList":[],"workCountryType":0}'
```

### 3.2 字典接口测试

```bash
curl -s "https://join.qq.com/api/v1/dictionary/?types=RecruitType,BusinessGroup,RecruitProjectPostList,RecruitCity" \
  -H "User-Agent: Mozilla/5.0" \
  -H "Referer: https://join.qq.com/post.html?query=p_2"
```

### 3.3 其他测试

- 分页测试：pageIndex=2, pageSize=10 / pageIndex=1, pageSize=100 / pageIndex=1, pageSize=200
- 项目类型测试：projectMappingIdList=[1] / [12] / [14]

## 5. 字段观察

### 5.1 岗位列表接口字段

| 字段 | 类型 | 示例值 | 含义 |
|------|------|--------|------|
| id | int | 21417 | 岗位数字 ID |
| position | int | 101 | 岗位子分类 code |
| positionTitle | string | "软件开发-后台开发方向" | 岗位名称 |
| positionFamily | int | 2 | 岗位族 code |
| projectId | int | 2 | 项目 ID |
| bgs | string | "CDG CSIG IEG PCG TEG WXG S1 S2 " | 事业群列表（空格分隔） |
| workCities | string | "深圳总部 北京 上海 广州 成都 武汉 杭州 " | 工作城市（空格分隔） |
| positionUrl | null | — | 岗位链接（列表为 null） |
| positionSource | string | "oa" | 数据来源 |
| projectName | string | "应届实习" | 招聘项目名称 |
| recruitLabelName | string | "应届实习" | 招聘标签 |
| groupTag | null | — | 分组标签 |
| postId | string | "1200791473415778304" | 岗位帖子 ID |

### 5.2 关键发现

1. 列表接口不返回 JD 正文（description/requirements）
2. 城市和事业群是空格分隔的字符串
3. 存在两种 ID：id（数字）和 postId（长字符串）

## 6. 映射初判

| 腾讯字段 | jobs 字段 | 映射可行性 | 备注 |
|---------|----------|-----------|------|
| positionTitle | title | ✅ 直接映射 | |
| bgs | department | ⚠️ 需转换 | 需字典映射 |
| workCities | city | ⚠️ 需转换 | 多城市需处理 |
| positionFamily | category | ⚠️ 需映射 | 需字典 |
| projectName | job_type | ✅ 可映射 | |
| — | description | ❌ 缺失 | 列表接口无此字段 |
| — | requirements | ❌ 缺失 | 列表接口无此字段 |
| — | skill_keywords_json | ❌ 缺失 | 需从标题提取或留空 |

当前 jobs 表需考虑新增：`external_id`（存储原始 postId）、`raw_json`（存储原始数据）。

3. **接口可能增加鉴权**：需 Mock 数据兜底
4. **字段结构可能变化**：需 raw_json 保存原始数据
