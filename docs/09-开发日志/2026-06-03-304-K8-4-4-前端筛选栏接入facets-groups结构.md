# K8-4-4：前端筛选栏与岗位列表接入新 facets groups[] 结构

- **日期**：2026-06-03
- **阶段**：K8-4-4（frontend, pass）
- **性质**：前端筛选栏消费产品化 facets groups[]

## 1. 实现方案

### facets 类型（api/jobs.ts）

新增 `JobFacetGroup`（含 `options`/`children` 层级）+ `JobFacetOption` 类型。`JobFacets` 新增 `groups?` 字段，保留旧兼容字段。

### JobFilterSidebar.tsx 改造

| 改动 | 说明 |
|------|------|
| 数据源 | `groups[]` 优先，缺失时 fallback 旧字段 |
| 多选 | city/business_group/skill 组使用逗号分隔多选 toggle |
| 展开/收起 | 按后端 `default_expanded` + 前端 `max_visible_options` |
| 岗位类别 | 递归渲染父子树（`CategoryTree` 组件，深度缩进） |
| 技能关键词 | 默认收起 + max_visible_options 截断 + "展开更多"按钮 |
| 已选标签 | 从 groups 中提取 `label` 显示（含多选逗号拆分） |
| 空值安全 | `safeArr()` 守卫全部数组访问 |

### JobListPage.tsx

- `JobFilters` 新增 `job_category?: string`
- URL query 构建统一循环处理 9 个 filter key
- `filtersToDisplay` 支持逗号多选拆分

### JobList.tsx

- useEffect 依赖新增 `params.job_category`
