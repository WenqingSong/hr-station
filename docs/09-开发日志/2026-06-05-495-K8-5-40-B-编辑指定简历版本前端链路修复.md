## 一、本阶段目标

- 编辑按钮携带 `versionNo`
- 编辑页读取 `versionNo` 并加载指定版本

## 三、编辑入口传 versionNo（ResumeManagementPage.tsx）

**修改前**：
```tsx
<Link to="/resumes/edit">编辑</Link>
```

**修改后**：
```tsx
<Link to={`/resumes/edit?versionNo=${row.versionNo}`}>编辑</Link>
```

- "添加简历"按钮保持 `/resumes/edit` 不变
- `versionNo` 来自 API 返回的 `version_no` 字段

## 四、编辑页读取 versionNo（MyResumesPage.tsx）

### 新增导入

```tsx
import { useSearchParams } from "react-router";
import { getResumeDetail } from "../../api/resumes";
import { toResumeManagementViewModel } from "../../adapters";
```

### 新增逻辑

```tsx
const [searchParams] = useSearchParams();
const versionNoParam = searchParams.get("versionNo");
const editingVersionNo = versionNoParam && /^\d+$/.test(versionNoParam) ? Number(versionNoParam) : null;
```

### 加载分支

```
- editingVersionNo 有效 → getResumeDetail(N) → toResumeManagementViewModel()
- editingVersionNo 无效 → 原逻辑（loadResumeManagementPageViewModel = getCurrentResume）
```

- 复用现有 V1+V2 回填 useEffect（line 318+）
- 错误处理与原有一致（401 → redirect；其他 → error 提示）
