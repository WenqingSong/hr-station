## 4. 当前 UI 结构诊断

| 区域 | 现状 | 问题 |
|------|------|------|
| 遮罩层 | `bg-black/35` 全覆盖 | **过重**：与 Offerr鹅 蓝白轻风格不一致 |
| Modal 主体 | 700px 宽，无圆角 | **无 rounded-2xl**：与其他白卡片不统一 |
| Header | 标题 + X 关闭按钮 | 正常 |
| Context Strip | 灰色条，显示当前操作+目标岗位 | 设计偏旧，可融入 header |
| Resume List | 图文卡片列表，支持选中态 | **卡片信息偏多**：6 种 badge 同时出现，阅读负担重 |
| Footer | 取消 + 确认按钮，左侧管理简历入口 | 正常 |

### 4.1 具体设计问题

| 问题 | 证据 | 建议 |
|------|------|------|
| 遮罩过重 | `bg-black/35` | 改为 `bg-black/20` 或纯色半透明 |
| 无圆角 | 缺少 `rounded-2xl` | 统一 rounded-2xl |
| 卡片 badge 过多 | 同时显示"推荐使用""当前使用""可用于AI分析""历史版本""方向不匹配" | 最多保留 2 个关键标签 |
| 蓝色选中态不一致 | `bg-[#EEF4FF]` 而非 `bg-blue-50` | 统一蓝色系选中态 |

## 5. 数据来源诊断

| 数据 | 来源 | 问题 |
|------|------|------|
| 弹窗简历列表 | `loadResumeOptionViewModelsFromApi()` | ✅ API 可用 |
| 默认选中 | `opts[0].id` | ⚠️ 未优先选"当前使用"简历 |
| 简历名称 | `resume.name` | ✅ |
| 方向标签 | `resume.directionLabel` | ✅ (K9-2-Regression 修复) |
| 技能标签 | `resume.tags` | ✅ (K9-2-Regression 修复) |
| 项目数量 | `resume.projectCount` | ✅ (K9-2-Regression 修复) |
| 更新时间 | `resume.updatedAt` | ✅ |
| mismatchReason | `resume.mismatchReason` | ⚠️ 始终为空（需要场景上下文计算） |
| isRecommended | `resume.isRecommended` | ⚠️ 始终为 `isCurrent` 的值 |
| isDefault | `resume.isDefault` | ✅ |
| 右侧栏简历摘要 | `ResumeSummaryViewModel` | ❌ 缺少 `directionLabel`/`skillTags`/`projectCount` |

### 5.1 ResumeSummaryViewModel 字段缺失

`JobDetailAIDecision.tsx` 访问 `resumeVm?.directionLabel`、`resumeVm?.skillTags`、`resumeVm?.projectCount`，但 `ResumeSummaryViewModel` 只有 `id/name/isCurrent/updatedAt` 四个字段。Optional chaining 防止了崩溃，但数据为空。

## 6. 交互链路诊断

| 场景 | 当前行为 | 问题 |
|------|---------|------|
| 未选简历点确认 | `selected` 初始化为 `"1"`（硬编码），按钮永远可点击 | **P1**: 应初始 `null`，未选时 disabled |
| "切换简历"按钮 | 无 onClick 处理 | **P1**: 死按钮 |
| loading | 显示"正在加载简历列表…" | 基本可用 |
| empty | 显示"暂无可选择的简历版本" | 缺少"去添加简历"引导 |
| error | catch 中只处理 401，否则静默失败 | **P1**: 无用户可见错误状态 |
| 确认后 | `handleConfirm → navigate(/match)` | ✅ |
| 关闭弹窗 | 状态未重置（`selected` 保持上次值） | P2 |
| 重复点击确认 | 无防重复保护 | P2 |
| ESC 关闭 | 不支持 | P2 |
| 弹窗后状态 | `onClose` 将 `modalAction` 设为 null，SelectResumeModal 不重置 state | P2 |

## 8. 视觉设计问题

| 问题 | 证据 | 建议 |
|------|------|------|
| 遮罩过重 | `bg-black/35` | `bg-black/20` |
| 无圆角 | 缺少 `rounded-2xl` | 统一 rounded-2xl |
| Modal 宽度固定 | `max-w-[700px]` | 建议 560px 更紧凑 |
| 阴影不统一 | `shadow-xl` 而非 `shadow-sm` | 统一为 `shadow-sm` |
| 按钮样式偏离规范 | Footer 按钮非 Button 组件 | 改用 `Button` 组件 |

---

## 9. 产品体验问题

| 问题 | 影响 | 建议 |
|------|------|------|
| 默认选中硬编码 `"1"` | 首次打开可能不选当前使用的简历 | 优先选 `isCurrent` 简历 |
| "切换简历"无功能 | 用户困惑 | 实现或移除 |
| 无搜索 | 简历多时选不到 | 添加搜索框 |
| 无方向匹配提示 | 用户不知道哪份简历最适合 | 基于岗位 direction 增加匹配提示 |
| mismatch 静态无数据 | 浪费 UI 空间 | 后端计算或移除 |
| 确认按钮无 disabled | 可点击空白状态 | 未选时禁用 |

---

## 10. 与当前产品设计规范差距

| 规范 | 当前 | 差距 |
|------|------|------|
| 蓝白灰轻风格 | 黑色重遮罩 bg-black/35 | **大**: 遮罩破坏整体氛围 |
| 白卡片圆角 | 无圆角 | **大**: 与其他页面不统一 |
| 影子克制 | shadow-xl | **中**: 其他卡片用 shadow-sm |
| Button 组件 | 原生 button | **中**: 应使用项目 Button 组件 |
| 简洁信息 | 6 种 badge 同时出现 | **中**: 标签泛滥 |

## 11. 建议目标方案

| 模块 | 设计建议 |
|------|---------|
| 遮罩 | `bg-black/20`，轻量半透明 |
| Modal 主体 | `rounded-2xl shadow-sm`，560px 宽 |
| Header | 标题 + 副标题 + X 关闭（合并 Context Strip） |
| Toolbar | 搜索框 + 筛选（当前使用/全部） |
| Resume Card | 仅显示：简历名 + 状态(当前使用/历史版本) + 方向 + 更新时间。去掉 mismatch/推荐等无效标签 |
| Footer | 取消(Button variant=outline) + 确认(Button variant=primary)，未选时 disabled |
| 默认选中 | 优先 `isCurrent` 简历，无则选第一个 |
