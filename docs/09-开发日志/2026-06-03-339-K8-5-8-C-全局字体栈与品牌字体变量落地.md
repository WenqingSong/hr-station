# K8-5-8-C：全局字体栈与品牌字体变量落地

## 一、当前状态确认

项目当前仍是零字体依赖状态。本次基于 K8-5-8-B 冻结的方案，在 `theme.css` 中落地 CSS 字体变量，使全局正文和品牌字各使用独立的字体栈。

## 二、修改方案

### 新增 CSS 变量（theme.css `:root`）

| 变量名 | 字体栈 | 用途 |
|--------|--------|------|
| `--font-sans` | HarmonyOS Sans SC → Source Han Sans SC → Noto Sans SC → PingFang SC → Microsoft YaHei → Inter → system-ui → sans-serif | **全局正文**（body / jobs 卡片 / 详情 / AI / 按钮） |
| `--font-brand` | Alimama ShuHeiTi → MiSans → HarmonyOS Sans SC → Source Han Sans SC → Noto Sans SC → Inter → system-ui → sans-serif | **品牌文字**（Navbar `Offer 捕手`） |
| `--font-mono` | JetBrains Mono → SFMono-Regular → Consolas → Liberation Mono → Menlo → monospace | **等宽/代码数字** |

### Tailwind v4 注册（`@theme inline`）

```css
--font-sans: var(--font-sans);
--font-brand: var(--font-brand);
--font-mono: var(--font-mono);
```

注册后可在 JSX 中使用 `font-sans`、`font-brand`、`font-mono` utility class。

### body 全局应用

```css
body {
  @apply bg-background text-foreground;
  font-family: var(--font-sans);
}
```

### Navbar 品牌字接入

- 移除 `brandFontStyle`（inline fontFamily + letterSpacing）
- 改用 `font-brand` utility class + `tracking-[-0.03em]`
- 保留 `brandTextShadow` inline style（仅顶部透明态 `textShadow`）

## 三、修改文件清单
