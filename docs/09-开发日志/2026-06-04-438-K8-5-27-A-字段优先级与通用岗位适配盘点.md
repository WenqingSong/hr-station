## 核心成果输入形态分析

### 当前状态

| 模块 | 字段 | 输入形态 | 行号 |
|------|------|---------|:---:|
| 项目·核心成果 | `achievements` | **Textarea** `min-h-[72px] resize-none` | L1173 |
| 实习·核心成果 | `achievements` | 同上 | — |
| 实习·量化指标 | `metrics` | **Input** | — |

### 三种方案对比

| 方案 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| A: 自定义滚动条 | 给 textarea 加 `overflow-y:auto` + 自定义滚动条样式 | 改动最小 | 信息密度仍低 |
| B: autoHeight | textarea `onInput` 自动调整高度 | 体验自然 | 长内容导致卡片过长 |
| C: **动态成果列表** | 每条成果一行 Input + 添加/删除按钮 | 结构化、可单独编辑、AI 可精准分析 | 改动较大，需改 payload |

### 推荐方案

**方案 C（动态成果列表）+ 方案 B（autoHeight fallback）**

- 核心成果改为 `achievements: string[]`，payload 已是 `string[]`（`splitLines` 输出）
- 实习 `metrics` 保留为 Input（单一数字/指标）
- 短期可用 B 快速改善体验

### payload 影响

`achievements` 在 payload 中已是 `string[]`（splitLines 拆分），**不需要改后端**。

## YearMonthPicker 影响范围

### 涉及字段

| 模块 | 字段 | 当前实现 | 行号 |
|------|------|---------|:---:|
| 教育 | startDate | **普通 Input**（text 字符串） | L1088/1100 |
| 教育 | endDate | 同上 | L1088/1100 |
| 项目 | startDate | **普通 Input** | — |
| 项目 | endDate | **普通 Input** | — |
| 实习 | startDate | **普通 Input** | — |
| 实习 | endDate | **普通 Input** | — |
| 证书 | issuedAt | **`type="month"`** 原生控件 | L1346 |
| 获奖 | awardedAt | **`type="month"`** 原生控件 | L1364 |

### 分析

| 项 | 说明 |
|----|------|
| 原生 `type="month"` | 浏览器表现不一致（Chrome/Safari/Firefox 样式迥异），与 Tailwind UI 割裂 |
| 普通 Input | 无格式约束，用户输入 "2024" 或 "2024年9月" 不统一 |
| 是否需要 YearMonthPicker | **需要** — 统一 8 处年月字段的 UI |
| 是否影响 payload | ❌ 不影响 — payload 已是 `string` 类型（"2024-09"） |
| 是否有现成组件 | `calendar.tsx` 使用 `react-day-picker`（日期级），不可复用为年月 |
