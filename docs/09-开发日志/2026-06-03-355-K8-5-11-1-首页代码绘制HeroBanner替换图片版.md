# K8-5-11-1：首页代码绘制 Hero Banner 替换图片版

## 一、当前问题

首页使用 `offer-catcher-banner.png` 图片 Banner，多屏适配时裁切不自然、文字烘焙在图片中不便维护。

## 二、新 Banner 设计方案

- **左侧**：胶囊标签 "AI 智能匹配 · 校园招聘" + 主标题 "Offerr鹅 2026 实习生招聘" + 副标题 + 描述 + CTA（查看岗位 / 我的简历）
- **右侧**：CSS 绘制抽象插画（简历卡片 + 匹配度徽章 92% + 浮动光斑），lg+ 显示
- **背景**：`radial-gradient` + `linear-gradient` 蓝色科技感
- **无图片引用**
