# K9-4-A-Blocker-Fix: 首页黑屏无限加载 P0 修复

Date: 2026-06-07 | Author: AI Agent | Phase: K9-4-A-Blocker-Fix

## 1. 问题现象

浏览器访问 `http://localhost:8080/` 黑屏/无限加载，无法进入系统。

## 2. Console / Network 诊断

| 页 | 现象 | 证据 |
|----|------|------|
| localhost:8080/ | HTML 返回 200 | `curl` 验证**
| localhost:8080/ | 前端资源 200 | `src/main.tsx` 200 1961B |
| localhost:8080/api/jobs | API 正常 | code=0 46 岗位 |
| localhost:8080/api/auth/me | 有效 token → code=0 | 正常 |

## 3. 根因分析

| 问题 | 根因 | 证据 |
|------|------|------|
| 首页卡住 | Go 后端进程僵死 | K9-3-F 16+ 次 API 调用后 healthz 返回空 |

K9-3-F 总验收期间执行了大量优化 API 调用（16 次 POST + 多次 GET latest），Go 服务器进程出现僵死。虽然 Vite dev server 正常运行，但 Go → Vite 反向代理转发时可能因 goroutine/resource 泄漏导致响应缓慢或超时。

## 4. 修复方案

**最小修复：重启后端服务。零代码修改。**

```bash
make stop && make up
```

| 修复点 | 说明 |
|--------|------|
| 停止旧进程 | `make stop` 清理僵死的 go run 进程 |
| 重启全部服务 | `make up` 重新启动 MySQL+Nginx+Backend+Frontend |
| 验证链路 | HTML/API/Vite proxy 全部恢复 |
