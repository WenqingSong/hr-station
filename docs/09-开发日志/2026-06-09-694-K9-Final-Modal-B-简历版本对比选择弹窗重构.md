## 二、compare 模式状态重构

| 项 | 修改前 | 修改后 |
| ---- | ---- | ---- |
| 内部选择状态 | `selectedIds: number[]`（通过 props 传入） | `baseId: number|null` + `currentId: number|null`（内部局部状态） |
| 激活槽位 | 无 | `activeSlot: "base" | "current"`（默认 "base"，选第一份后自动切 "current"） |
| 选择逻辑 | `toggleSelection(id)` — 点击即切换，满 2 个替换第一个 | `handleSlotSelect(id)` — 按 activeSlot 填入对应槽位，不能重复选 |
| 移除选择 | 再次点击取消 | `handleSlotRemove(slot)` — 槽位 X 按钮移除 |
| 交换顺序 | ❌ 不存在 | `handleSwap()` — 双向交换 baseId ↔ currentId |
| 同步父组件 | `onSelectionChange(ids)` 每次点击 | `notifyCompareSelection(baseId, currentId)` — 槽位变化时同步 |
| 确认 | `onConfirm(selectedIds)` | `handleConfirm()` → `onConfirm([baseId, currentId])` — 保持 `number[]` 接口 |

### 同步策略

- 弹窗打开时从 `selectedIds` 初始化 `baseId`/`currentId`
- 每次槽位变化通过 `notifyCompareSelection` 同步回父组件 `onSelectionChange`
- 确认时 `handleConfirm` 确保 baseId 对应 `fromResumeId`，currentId 对应 `toResumeId`
