## 6. PasswordInput 设计规范（冻结）

### 6.1 视觉规范

基于 Input + 右侧 Eye 按钮：

```text
position: relative 包裹
input: h-11 ... pr-11（给按钮留空间）
button: absolute right-3 top-1/2 -translate-y-1/2
        h-8 w-8 flex items-center justify-center
        text-slate-400 hover:text-slate-600
        hover:bg-slate-100 rounded-lg
        active:scale-95 transition
        tabIndex={-1}
        aria-label={show ? "隐藏密码" : "显示密码"}
icon: EyeOff（显示时）/ Eye（隐藏时）h-4 w-4
```

### 6.2 双眼睛修复规范（冻结）

```css
input[type="password"]::-ms-reveal,
input[type="password"]::-ms-clear {
  display: none;
}
```

此 CSS 应写入 `theme.css`（或 `password-input.tsx` 的内联 style 标签），**确保 Chrimium/Edge 内置 password reveal 被隐藏**。

### 6.3 API

```tsx
type PasswordInputProps = Omit<React.InputHTMLAttributes<HTMLInputElement>, "type"> & {
  error?: boolean;
};
```

### 6.4 行为

| 行为 | 规范 |
|------|------|
| 内部 `showPassword` state | `useState(false)` |
| `showPassword=false` | `type="password"` |
| `showPassword=true` | `type="text"` |
| `autoComplete` | 透传给 input |
| `disabled` | 透传给 input，按钮不可见或 disabled |
| `error` | 透传给 Input error 视觉 |

### 6.5 实现策略

| 项目 | 规范 |
|------|------|
| 文件 | `web/src/app/components/ui/password-input.tsx`（新建） |
| 依赖 | 基于 Input 组件，或直接复用 Input 的 className 常量 |
| 密码 reveal 隐藏 | 在组件内注入 `<style>` 或全局 `theme.css` 加规则 |
