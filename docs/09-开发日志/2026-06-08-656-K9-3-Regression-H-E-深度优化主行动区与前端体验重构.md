# K9-3-Regression-H-E — 深度优化主行动区与前端体验重构

日期：2026-06-08
性质：前端 UX 重构。1 文件修改（ResumeOptimizationPage.tsx）。

## 问题

H-D 收口后发现产品体验问题：
- 快速优化占据主视觉，深度优化入口不突出（仅在右侧小按钮）
- 用户不知道"深度优化"才是完整报告
- 右侧操作区太弱，像链接列表
- 冲奖 Demo 感不足

## 变更内容

### 1. Fast 状态重构

**主 CTA 卡片**：在快速优化结果上方增加醒目升级卡片
- 标题："生成深度优化报告"
- 副标题：列出深度优化能提供哪些价值（JD 证据链、改写示例、关键词补强、投递策略）
- 蓝色大按钮 `px-6 py-3 font-semibold`
- 支持 loading/error 状态

**FastView 标注**：添加"快速优化结果 · 初步预览"标签，弱化快速预览定位

### 2. Deep 状态重构

- 顶部新增绿色"深度优化报告已完成"提示栏
- 上下文栏 tier 显示"深度优化已完成"
- headerLabel 简化为"深度优化已完成"（不再暴露 genBy）

### 3. 右侧栏重构为"优化操作面板"

- 章节名改为"优化操作"（替代"操作"）
- 当前状态指示器（圆点 + "当前：快速优化" / "深度优化已完成"）
- 主按钮：蓝色 `bg-[#0052D9]` 全宽 `w-full`，文案"生成深度优化报告"
- 次级操作：查看匹配分析、返回岗位详情、重新选择

### 4. AgentStepLoadingOverlay 文案增强

- 标题："正在生成深度优化报告"
- 描述："系统正在结合目标岗位 JD、匹配分析结果和当前简历，生成更完整的修改建议。"
- 步骤：读取 JD → 对照证据 → 生成建议 → 汇总策略

### 5. deep_error 处理

- 保留 fast 结果不清空
- CTA 卡片和按钮文案变为"重新生成深度优化报告"
- 提示："深度优化生成失败，已保留当前快速优化结果。请稍后重试。"
