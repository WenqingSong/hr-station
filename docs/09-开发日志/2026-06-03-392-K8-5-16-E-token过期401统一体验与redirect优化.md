# K8-5-16-E — token 过期后的 401 统一体验与 redirect 优化

> 日期：2026-06-03 | 性质：implementation | 401 透传与 redirect

---

## 1. 本阶段目标

在 K8-5-16-C/D 路由级保护基础上，优化 token 过期 / API 401 后的统一体验。确保：

- 401 不再被 viewModel/page catch 吞成"无简历"
- token 过期时直接 redirect 到 `/login?redirect=当前路径`
- 非 401 错误保持不变

## 4. 401 处理结果

| 页面/模块 | 401 行为 |
|-----------|---------|
| `client.ts` | `clearAuthToken()` + throw `ApiClientError(status=401)` |
| `viewModels loadResumeManagementPageViewModel` | `isAuthError` → throw（透传） |
| `viewModels loadResumeVersionDetail` | `isAuthError` → throw（透传） |
| `ResumeManagementPage` | 401 → `navigate(/login?redirect=/resumes, replace)` |
| `MyResumesPage` (edit) | 401 → `navigate(/login?redirect=/resumes/edit, replace)` |
