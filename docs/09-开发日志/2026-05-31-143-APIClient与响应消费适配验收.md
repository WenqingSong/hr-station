## 5. 核心验收结果

### client 基础层
- 原生 fetch，无 axios ✅
- 默认 base URL = `/api`，支持 `VITE_API_BASE_URL` ✅
- requestRaw/request/get/post/put/patch 六方法完整 ✅
- 错误处理覆盖：HTTP 非 2xx / JSON 解析失败 / 缺 code 字段 / code!==0 ✅
- 统一抛出 ApiClientError（含 status/code/details） ✅

### Jobs / Resumes API
- Jobs：getJobs + getJobDetail + getSelectedJob = 3 函数 ✅
- Resumes：P0 5 函数 + P1 3 函数 = 8 函数 ✅
- 路径使用相对路径（`/jobs` 而非 `/api/jobs`） ✅
- 统一 withFallback helper ✅

### 三类 Agent API
- runRecommendation / runMatchAnalysis / runResumeOptimization = 3 函数 ✅
- 统一返回 AgentResponseEnvelope<TResult> ✅
- 请求体含 resume_id/resume_snapshot/job_id/job_snapshot ✅
- agent_status / fallback_reason / error_code / repair_applied / schema_valid / request_id 均已处理 ✅

### ViewModel Loader
- 9 个 Loader 函数（Jobs 3 + Resumes 4 + Agents 3） ✅
- 串联 API 调用 + Adapter 转换 ✅
- Agent Loader 从 response.result + response.meta 拆包 ✅

### 越界检查
- fetch 只在 client.ts ✅
- 无 axios ✅
- 无 /api/v1 ✅
- 无 selectors ✅
- 页面零 import api ✅
- 后端零修改 ✅
