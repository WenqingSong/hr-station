## 4. 左侧目录导航去留

| 方案 | 优点 | 缺点 | 推荐 |
|------|------|------|:--:|
| A. 保留旧左侧目录 | 导航快捷 | 后台系统感强，占用左侧空间 | ❌ |
| **B. 废弃，用右侧状态栏** | 视觉清爽，产品化 | 长表单无目录跳转 | ✅ |
| C. 顶部 sticky pill 导航 | 轻量 | 需额外开发 | 中期可选 |

**推荐方案 B**：废弃旧左侧后台式目录，改为右侧状态栏（包含完成度+缺失项），表单模块标题清晰即可定位。

## 5. 表单模块设计

| 模块 | 字段 | 视觉形态 | 折叠 | 优先级 |
|------|------|---------|:--:|:--:|
| 简历基础 | 名称、方向、说明 | 单列卡 | 否 | P0 |
| 基础信息 | 姓名/年龄/学历/毕业/学校/专业/手机/邮箱 | 两列 grid | 否 | P0 |
| 求职方向 | 方向/城市/类型 | 单列卡 | 否 | P0 |
| 教育经历 | 学校/专业/学历/时间/课程 | 多条目卡片 | 否 | P1 |
| 实习经历 | 公司/职位/时间/内容 | 多条目卡片 | 否 | P1 |
| 项目经历 | 名称/技术栈/描述/职责 | 多条目卡片 | 否 | P1 |
| 技能关键词 | input+tag | 单列 | 否 | P0 |
| 自我评价 | textarea | 单列 | 否 | P2 |

- 卡片统一 `rounded-2xl bg-white ring-1 ring-gray-100 p-6`
- 标题：`text-[16px] font-semibold text-slate-900`
- input：`rounded-xl border-slate-200`

## 6. 右侧状态栏设计

| 状态项 | 展示内容 | 数据来源 | 必须 |
|--------|---------|---------|:--:|
| 完成度 | 环形进度 0-100% | `completeness` | ✅ |
| 当前简历状态 | "当前简历" badge 或 "未设为当前" | `status` | ✅ |
| AI 可用性 | 岗位推荐 ✅/匹配分析 ✅/简历优化 ❌ | fields 完整性判断 | ✅ |
| 最近保存 | 时间戳 | `updated_at` | 可选 |
| 缺失项提示 | "建议补充项目经历和技能关键词" | fields 为空判断 | 推荐 |

## 7. 保存 CTA 语义

| 按钮 | 语义 | 当前问题 | 后续建议 |
|------|------|---------|---------|
| 保存草稿 | 只存表单，不改 current | **与"保存并设为当前"同一 handler** | 区分逻辑/传参 |
| 保存并设为当前 | 存表单 + 设为 current | `setCurrentResume` 抛异常 | P1：等待后端补 API |

短期前端策略：两个按钮调用不同的 handler，`保存并设为当前` 先保存后调用 `setCurrentResume`（失败时降级提示）。

## 8. Loading / Error / Pending 方案

| 场景 | 组件 | 文案 | 行为 |
|------|------|------|------|
| 编辑模式初次加载 | `ResumeSkeleton` | — | K8-5-12-C 已有骨架组件可用 |
| 加载失败 | `PageError` | "简历加载失败" | onRetry |
| 未登录 | `PageError` | "请先登录" | 引导登录弹窗 |
| 保存中 | 按钮 disabled + Loader2 | "保存中…" | 防重复 |
| 保存失败 | 卡片内 `bg-red-50` | 具体错误 | — |
| 保存成功 | 轻量绿色提示 | "简历已保存" | 3 秒淡出 |
| 空教育/实习/项目 | 空状态 placeholder | "暂无教育经历，点击添加" | 添加按钮 |

## 9. 数据层风险

| 风险 | 级别 | 建议 |
|------|:--:|------|
