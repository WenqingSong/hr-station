# K8-4-4-R2：岗位类别二级默认收起与筛选栏层级体验修复

- **日期**：2026-06-03
- **阶段**：K8-4-4-R2（frontend, pass）
- **性质**：修复岗位类别二级子项默认全部展开的体验问题

## 1. 用户反馈

用户实机体验后报告：
- 一级分组"岗位类别"展开后，所有二级子项默认全部渲染（技术→AI应用开发、PC客户端开发…），导致左侧筛选栏非常长。
- 用户明确要求：**二级默认关闭，而不是默认打开。**
- 正确效果：初始只显示 5 个父级大类（技术/产品/设计/市场/职能），点击父级右侧展开按钮后才显示子项。

## 2. 问题确认

| 问题 | 根因 |
|------|------|
| 一级分组默认关闭 | `FacetGroupBlock` 中 `expanded` 初始值为 `useState(false)` |
| 二级子项默认全部渲染 | `CategoryTree` 组件无条件递归渲染所有 children，无展开/收起状态控制 |
| 父级 checkbox 与展开共用整行 | `CategoryTree` 将父级渲染为整行 `OptionRow`（button onClick 同时触发筛选），无独立展开按钮 |

## 3. 修复方案

### 状态分层设计

| 状态 | 作用域 | 默认值 | 说明 |
|------|--------|--------|------|
| `expanded` (已有) | 一级分组 (group) | `true` | 控制应聘项目/岗位类别等分组头是否展开 |
| `expandedParentCodes` (新增) | 父级 option 的 children | `new Set()` (全关闭) | 控制技术/产品等父级下的子项列表是否展开 |

### 组件改造

1. **`FacetGroupBlock`** 新增 `expandedParentCodes` 状态 (`Set<string>`)
2. **新增 `JobCategoryParentRow`** 组件替换原 `CategoryTree`：
   - 渲染为 `flex` 布局，左侧 checkbox+label+count 按钮（触发筛选），右侧独立 Chevron 按钮（`e.stopPropagation()` 仅触发展开/收起）
   - 子项仅在 `isChildExpanded=true` 时渲染（`OptionRow depth=1`）
3. **`CategoryTree`** 组件保留但不再被引用
