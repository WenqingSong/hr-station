## 二、新增组件

### 1. AppBootLoading

**文件**：`web/src/app/components/common/AppBootLoading.tsx`

**设计**：
- 全屏居中（`fixed inset-0 z-[99999]`）
- 浅灰蓝背景 `#F5F7FB`
- 显示 "Offer捕手" 品牌标识（bold 28px 文字）
- 轻量 `Loader2` spinner（蓝色 `#0052D9`）
- 文案：正在准备 Offer捕手…
- 不夸张，不大渐变，不 emoji

**接入点**：`web/src/app/App.tsx` — `AuthBoot` 组件内，当 `isBootstrapping && !isAuthReady` 时渲染。

### 2. RouteProgressBar

**文件**：`web/src/app/components/common/RouteProgressBar.tsx`

**设计**：
- 监听 `useLocation()` 的 `pathname` + `search` 变化
- `fixed top-0 left-0 right-0 z-[9999]`，2px 高度
- 分两段过渡：0→70%（30ms）→100%（180ms）→隐藏（380ms）
- 蓝色主色 `#0052D9`
- 使用 CSS `transition` 控制宽度变化
- 零依赖，纯 React hooks + CSS

**接入点**：`web/src/app/routes.tsx` — `RootLayout` 根部的第一子元素。

### 3. AIThinkingLoading

**文件**：`web/src/app/components/common/AIThinkingLoading.tsx`

**Props**：
```ts
type AIThinkingLoadingProps = {
  title: string;
  description?: string;
  steps?: string[];  // 最多 3 条
};
```

**设计**：
- 白底卡片（`bg-white rounded-2xl ring-1 ring-blue-100 shadow-sm`）
- 顶部蓝色圆形 spinner 容器
- title（16px semibold）
- description（13px gray-400）
- steps 最多 3 条，小圆点 pulse 动画

## 三、authStore 改造

在原有 `AuthState` 基础上新增 `isBootstrapping` 字段：

- **初始值**：`false`
- **`SET_BOOTSTRAPPING`** action：`isBootstrapping = true`
- **`bootstrapAuth` 开始时**：dispatch `SET_BOOTSTRAPPING`
- **`SET_AUTH_READY` / `SET_AUTHENTICATED` / `CLEAR_AUTH`**：同时设置 `isBootstrapping = false`

改动最小化（新增 1 个 state 字段 + 1 个 action type + 各 reducer 分支 +1 行），不改变原有 auth 流程。
