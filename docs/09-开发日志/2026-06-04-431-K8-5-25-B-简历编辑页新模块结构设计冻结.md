# K8-5-25-B — 简历编辑页新模块结构设计冻结

## 性质
design-freeze（设计冻结，不修改源码）。

## 本阶段目标

冻结新版简历编辑页最终模块结构（9 模块）、字段结构、payload 结构和状态栏设计，为后续 C/D/E/F/G 阶段提供明确依据。

## 核心决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 模块数从 10 减至 9（删除求职意向） | 岗位推荐不需要预填求职意向 |
| 2 | 技能信息从 10 分类改为 3 字段 | 模仿腾讯招聘风格 |
| 3 | 作品从 7 平台字段改为 works+homepage | 模仿腾讯招聘风格 |
| 4 | 证书与获奖合并为 1 模块 | 尾部模块合并降低界面长度 |
| 5 | 自我评价独立为模块 9 | 原被埋在 PortfolioExtra 底部 |
| 6 | 基础信息删除 school/degree/major/gradYear/age | 迁移到教育经历 |
| 7 | 后端/SQL/Snapshot 不需要改 | json.RawMessage 接受任意 JSON |
| 8 | Agent 暂停至 K8-5-26-A | |

## 最终 9 模块

| 序号 | 模块 | 状态 | 分级 |
|:---:|------|------|:---:|
| 1 | 简历基础 | 展开·不可折叠 | 必填 |
| 2 | 基础信息 | 展开·折叠 | 必填 |
| 3 | 教育经历 | 展开·折叠 | 推荐 |
| 4 | 项目经历 | 展开·折叠 | 推荐 |
| 5 | 技能信息 | 展开·折叠 | 推荐 |
| 6 | 实习经历 | 折叠 | 推荐 |
| 7 | 证书与获奖 | 折叠 | 可选 |
| 8 | 作品或个人主页 | 折叠 | 可选 |
| 9 | 自我评价 | 折叠 | 可选 |

## 关键 payload 设计

- `job_intention`: 不传(undefined)
- `skills`: `{language_exam:{type,score}, development_languages:[], ai_application:""}`
- `portfolio_links`: `{works:[{name,link,password}], homepage:""}`
- `profile`: 保留旧字段但 UI 删除 school/degree/major/gradYear
