> 日期：2026-06-03 | 性质：implementation | 3 路由包裹

---

## 1. 本阶段目标

使用已有 `RequireAuth` 保护 AI 三页面（`/recommend` `/match` `/resume-optimization`）。

只改 `routes.tsx`，不改页面业务逻辑。

---

## 2. AI 三页面为什么需要登录保护

| 页面 | 路由 | 依赖 | 未登录时的表现（C 阶段前） |
|------|------|------|--------------------------|
| 岗位推荐 | `/recommend` | 简历版本列表 API | 空态「无简历」+ 引导创建，但创建也无法保存 |
| 岗位匹配 | `/match` | 简历版本 + 岗位详情 API | 同上 |
| 简历优化 | `/resume-optimization` | 简历版本 + 岗位详情 API | 同上 |

三者均依赖 `GET /api/resumes/versions`（需登录），未登录时 401 被静默为「无简历」，误导用户。

---

## 3. 修改方案

| 区域 | 修改内容 | 原因 |
|------|---------|------|
| `routes.tsx` | `/recommend` `Component:` → `element: <RequireAuth>` | 路由保护 |
| `routes.tsx` | `/match` `Component:` → `element: <RequireAuth>` | 路由保护 |
| `routes.tsx` | `/resume-optimization` `Component:` → `element: <RequireAuth>` | 路由保护 |
