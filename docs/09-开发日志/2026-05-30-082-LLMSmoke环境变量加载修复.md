# 2026-05-30-082-LLMSmoke环境变量加载修复

## 1. 本次任务

4-3.1.D：LLM Smoke 环境变量加载修复与验收。

修复 `scripts/dev/llm_smoke.sh` 中 `source .env` 导致含特殊字符的 `.env` 无法正确加载的问题，将修复结果登记到项目文档。

## 2. 问题现象

`make llm-check` 显示：

```text
.env 存在
但 LLM_ENABLE=false / LLM_BASE_URL 未配置 / LLM_API_KEY missing
```

用户已正确配置 `.env`，但脚本读取不到 LLM 配置。

## 3. 根因分析

`scripts/dev/llm_smoke.sh` 原先使用 `load_env_silent()` 函数加载 `.env`：

```bash
load_env_silent() {
  local env_file="${PROJECT_ROOT}/.env"
  if [[ -f "$env_file" ]]; then
    set -a
    source "$env_file" 2>/dev/null || true
    set +a
  fi
}
```

问题根因：`.env` 中第 37 行 `DB_DSN=root:password@tcp(127.0.0.1:3306)/offer_catcher?charset=utf8mb4&parseTime=True&loc=Local`，其中 `tcp(127.0.0.1:3306)` 的括号 `()` 被 bash 当作子 shell 语法解析，导致：

```text
syntax error near unexpected token '('
```

`source .env` 执行失败并中断，**后续所有变量（包括 LLM_ENABLE / LLM_BASE_URL / LLM_API_KEY / LLM_MODEL）均未加载**。

而 `2>/dev/null || true` 将错误静默吞掉，所以表现为变量全为空值。

## 4. 修复方案

1. 移除 `load_env_silent()` 函数（使用 `source .env` 的方式）
2. 复用 `scripts/dev/common.sh` 中已有的 `load_env()` 函数（逐行 `while read` 解析 + `export`）
3. `load_env()` 能正确处理含括号 `()`、`&`、`?` 等特殊字符的值

修复后 `llm_smoke.sh` 在 `do_check()` 和 `do_smoke()` 中调用 `load_env`（来自 `common.sh`）。

## 5. 修改范围

| 文件 | 修改内容 |
|------|---------|
| `scripts/dev/llm_smoke.sh` | 移除 `load_env_silent()` 函数，改用 `common.sh` 的 `load_env()` |

具体变更：
- 删除 `load_env_silent()` 函数定义
- 将 `do_check()` 和 `do_smoke()` 中的 `load_env_silent` 调用改为 `load_env`
- 在 `.env 加载` 注释区域标注修复原因
