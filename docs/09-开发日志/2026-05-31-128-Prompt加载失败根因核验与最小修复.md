# 2026-05-31-128-Prompt加载失败根因核验与最小修复

## 1. 本次任务

定位并修复三类 Agent 接口联调时 `fallback_reason=prompt_load_failed` 的根因。

## 2. 背景

4-5.3 三类 Agent 接口联调验收主体通过，但三类接口均返回 `fallback_reason=prompt_load_failed`，不是预期的 API Key 占位符导致的 fallback。需要定位根因并做最小修复。

## 3. 问题现象

三类 Agent 接口联调时，`data.meta.fallback_reason` 均为 `prompt_load_failed`，`data.meta.error_code` 均为 `PROMPT_LOAD_FAILED`。

## 4. 根因核验

### 4.1 Prompt 文件存在性

4 个 Prompt 文件 + 3 个 Schema 文件全部存在：

```
server/prompts/json_repair_v1.md
server/prompts/match_analysis_v1.md
server/prompts/recommendation_v1.md
server/prompts/resume_optimization_v1.md
server/prompts/schema/match_analysis_schema.json
server/prompts/schema/recommendation_schema.json
server/prompts/schema/resume_optimization_schema.json
```

### 4.2 配置默认路径

`config.go` 和 `.env.example` 设置：

- `PromptDir = "server/prompts"`
- `SchemaDir = "server/prompts/schema"`

这些路径是相对于项目根目录的。

### 4.3 启动脚本 cwd

`backend.sh` 第 47 行：`cd "${PROJECT_ROOT}/server"` 后运行 `go run ./cmd/server`。

**Server 的 cwd 是 `/workspace/server/`**。

### 4.4 路径解析失败

当 cwd 为 `/workspace/server/` 时：

- `"server/prompts"` 解析为 `/workspace/server/server/prompts` → 不存在
- `"prompts"` 解析为 `/workspace/server/prompts` → 存在

**根因确认：配置路径 `"server/prompts"` 与 cwd `/workspace/server/` 不匹配。**

## 5. 修改范围

| 文件 | 操作 |
|------|------|
| `server/internal/prompt/loader.go` | 添加 `resolveDir`，修改 `NewLoader` |
| `server/internal/schema/loader.go` | 添加 `resolveDir`，修改 `NewLoader` |
| `server/internal/prompt/loader_test.go` | 添加 4 个 `resolveDir` 测试 |
| `server/internal/schema/loader_test.go` | 添加 4 个 `resolveDir` 测试 |

## 6. 最小修复

在 `prompt.NewLoader` 和 `schema.NewLoader` 中添加 `resolveDir` 函数：

1. 优先使用 `baseDir` 原始值（从项目根目录启动时正确）
2. 如果原始值不存在且以 `"server/"` 开头，尝试去掉前缀（从 `server/` 目录启动时正确）
3. 两种场景均兼容，不破坏现有测试
