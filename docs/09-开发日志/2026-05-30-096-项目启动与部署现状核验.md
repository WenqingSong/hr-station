## 3. Makefile 核验结果

- Makefile 共 40+ 个命令，按 12 个功能分组

- `make restart` = stop + up，不清空 volume
- `make down` 保留 volume
- 破坏性命令（rebuild/db-reset/clean-volume）需 CONFIRM=yes
- `ensure-env` 已接入 up/restart/llm-check/llm-smoke

- 缺少 Nginx 相关命令（当前无 Nginx）

## 5. 后端启动 / CORS 核验结果

### 后端启动

- Go 标准库 net/http，默认端口 8080
- 后台进程管理（PID 文件 + 日志文件）
- 健康检查：GET /healthz
- 依赖 MySQL（启动时 Ping 验证）
- 不依赖 Redis

### CORS

- 文件：`server/internal/middleware/cors.go`
- allowedOrigins 硬编码：`http://localhost:5173` + `http://127.0.0.1:5173`
- isAllowedOrigin() 额外允许任何 localhost/127.0.0.1 端口（宽松）
- Allowed Methods: GET, POST, PUT, PATCH, DELETE, OPTIONS
- Allowed Headers: Content-Type, Authorization, X-Requested-With
- Allow Credentials: true
- OPTIONS 预检返回 204
- **风险：Origin 硬编码，生产部署需修改代码**
