## 三、腾讯招聘式分页器目标结构

目标分页器结构：

```
‹  1  2  3  4  5  6  ...  19  ›
```

### 视觉特征

1. 整个分页器是一个白色圆角容器
2. 左右翻页使用箭头（`ChevronLeft` / `ChevronRight`）
3. 当前页是蓝色实心方块（`bg-[#0052D9] text-white`）
4. 普通页码是黑色文字，无强边框
5. 省略号使用 `...`
6. 最后一页在页数较多时显示
7. 分页器整体靠右
8. 不显示"第 1/5 页"

---

## 四、页码算法

### 规则设计

1. **总页数较少时**（`totalPages <= 7`）：全部展示
   ```
   ‹  1  2  3  4  5  ›
   ```

2. **当前页靠前时**（例如 `totalPages = 19`，`currentPage = 1`）：
   ```
   ‹  1  2  3  4  5  6  ...  19  ›
   ```

3. **当前页在中间时**（例如 `totalPages = 19`，`currentPage = 9`）：
   ```
   ‹  1  ...  7  8  9  10  11  ...  19  ›
   ```

4. **当前页靠后时**（例如 `totalPages = 19`，`currentPage = 18`）：
   ```
   ‹  1  ...  14  15  16  17  18  19  ›
   ```

### 省略号规则

- 省略号显示为 `...`
- 省略号不可点击
- 不要重复省略号
- 不要出现 `1 ... ... 19`
- 不要页码重复

- 箭头颜色：`text-gray-600` → `text-gray-500`，更柔和
