# K8-5-17-A — 登录注册弹窗优雅动画设计与实现

> 日期：2026-06-03 | 性质：animation enhancement | AuthDialog only

---

## 1. 本阶段目标

优化 AuthDialog 弹出动画和登录/注册切换动画，实现「镜头聚焦」般的优雅体验。

- 不改登录注册业务逻辑
- 不引入第三方动画库
- 不污染全局 Dialog 样式

---

## 2. 动画设计方案

| 区域 | 动画 | 目的 |
|------|------|------|
| Overlay | 渐暗 + blur(0→12px)，220ms | 背景柔和变暗变模糊 |
| Content | opacity + scale(0.96→1) + translateY(-46%→-50%) + blur(6→0px)，260ms | "镜头聚焦"感 |
| 内容面板切换 | opacity + translateY(4→0px)，180ms | 登录↔注册不突兀 |
| 错误提示 | opacity + translateY(-4→0px)，160ms | 错误提示轻微弹入 |
| 关闭按钮 | hover:scale-105 active:scale-95 | 微交互反馈 |
