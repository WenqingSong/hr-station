## 4. 字段设计

### 4.1 jobs 表新增字段

| 字段 | 类型 | 用途 |
|------|------|------|
| external_source | VARCHAR(50) | 数据来源（local_mock / tencent_join） |
| external_id | VARCHAR(100) | 腾讯岗位 postId |
| external_inner_id | INT | 腾讯列表内部 id |
| source_url | VARCHAR(500) | 公开详情页 URL |
| raw_json | JSON | 原始列表+详情响应 |
| data_quality | VARCHAR(20) | 数据质量标记 |
| is_featured | TINYINT(1) | 是否 Demo 精选 |
| synced_at | DATETIME | 同步时间 |

### 4.2 核心映射

- desc → description（完整职责）
- request → requirements（完整要求）
- tidName → category（技术/产品等）
- intentionBGDList[0].showTitle → department
- workCityList → city（逗号拼接）
- projectName → job_type
- postId → external_id

## 5. 入库策略

- 唯一业务键：external_source + external_id
- 导入方式：INSERT ... ON DUPLICATE KEY UPDATE
- 腾讯详情正常：data_quality=full_jd
- 腾讯详情缺失：data_quality=summary_only
- 本地 Mock 岗位：data_quality=manual_enriched
- raw_json 存储 list_item + detail_item + dictionary_snapshot

## 6. 接口适配方向

- 岗位列表：返回腾讯岗位，新增 external_source / external_id / data_quality / source_url 字段
- 岗位详情：返回腾讯岗位完整 JD，可返回 source_url
- 推荐接口：候选池纳入腾讯岗位，full_jd 优先
- 匹配接口：使用腾讯岗位完整 JD，支持深度证据链
