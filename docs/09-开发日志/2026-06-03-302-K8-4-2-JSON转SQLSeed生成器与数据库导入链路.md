# K8-4-2：JSON 转 SQL seed 生成器与数据库导入链路

- **日期**：2026-06-03
- **阶段**：K8-4-2（implementation, pass）
- **性质**：JSON→SQL 生成器实现 + 筛选维表创建 + 导入链路升级

## 1. 背景

K8-4-1 已冻结设计。K8-3 的运行时 Go import 方式不稳定（依赖编译链、job_id 不固定）。本次将岗位主数据链路升级为 SQL seed 方案。

## 2. 实现方案

### 2.1 生成器：`server/cmd/generate_jobs_seed/main.go`

- 复用 `import_jobs` 的 JSON 类型定义
- 读取 `resources/jobs/tencent-campus-jobs.json`，校验 46 个岗位完整性
- 生成 `server/sql/seed/tencent_jobs.sql`（524KB）
- 使用事务（START TRANSACTION / COMMIT）
- 删除旧 `manual_curated` + `local_mock` 数据
- 写入固定 job_id（10001-10046）
- 写入 7 张表：jobs / locations / business_groups / skills / filter_groups / filter_options / filter_option_relations
- 写入 seed_versions 记录
- 确定性输出：相同 JSON → 相同 SQL（相同 checksum）

| 表 | 用途 |
|----|------|

### 2.4 导入链路升级

```
make up: up.sh Step 6 → init.sql → Step 6b → seed_versions 检查
  └─ 已存在 seed → 跳过
  └─ 不存在 → docker exec mysql < tencent_jobs.sql

make reset: 清 volume → init.sql（表结构）→ tencent_jobs.sql（完整岗位+维表）
```

### 2.5 K8-3 Go import_jobs 保留

保留 `make jobs-import` 为备用方案，定位为：
