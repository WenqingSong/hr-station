# K8-5-39-A：简历管理页产品定位纠偏，恢复真实招聘网站简历管理体验

> 日期：2026-06-05 | 性质：前端重构 | 只改 `ResumeManagementPage.tsx`

---

## 一、本阶段目标

将 `/resumes` 从 Demo 中控台（Agent 功能分组）重构为真实招聘网站风格的简历管理页。

**不改后端 / SQL / seed / Agent。**

---

## 二、用户反馈

```
当前 /resumes 被设计成 Demo 功能中控台：
1. 按"岗位匹配分析 / 岗位智能推荐 / 简历版本对比 / 简历优化建议"分组展示简历。
2. 每份简历右侧直接放 Agent 功能按钮。
3. 页面看起来像测试样例入口页。

这是简历管理页面，不是功能管理页面。
应该当成真实招聘网站的简历管理页，在此基础上加 Agent 能力。
```

---

## 三、原页面产品定位错误

| 错误 | 具体表现 |
|------|----------|
| Agent 成了信息架构 | 按 match/recommend/compare/optimize 分组简历 |
| Demo 映射硬编码 | `DEFAULT_JOB_MAP`：versionNo → jobId 5 条硬编码 |
| 示范简历被绑定 | `getScenario()` 按 versionNo 范围（1-3 match, 4-5 recommend…）分类 |
| 主按钮是 Agent 功能 | 每行按钮是"去匹配岗位/推荐岗位/优化简历" |

## 五、移除功能分组

删除：

- `DEFAULT_JOB_MAP`（5 条 versionNo→jobId 硬编码）
- `GROUPS`（4 组 Agent 功能定义）
- `Scenario` / `GroupDef` 类型
- `getScenario()` / `groupRows()` / `getMatchHref()` / `getRecHref()` / `getOptHref()`
- `AIFeatureCards` 组件（4 张顶部功能概览卡片）
- `GroupSection` 组件（每组分栏 + Agent 主按钮）

## 六、恢复简历管理页信息架构

### Header

- 标题："我的简历"
- 副标题："管理你的简历内容，用于岗位投递、匹配分析和简历优化。"（原："选择一份示范简历，体验…"）
- 右侧："+ 添加简历"按钮

### 两栏布局

| 区域 | 比例 | 内容 |
|------|------|------|
| 左侧 | flex-[2] | 简历列表（白卡 + 选中态 + 编辑按钮） |
| 右侧 | flex-1 (max-w-[320px]) | 智能求职助手面板 |

### 简历列表

- 不分组，所有简历一个平级列表
- 每行：简历名称 + "编辑"按钮
- 选中态：`bg-blue-50/60` + 左侧蓝色 `border-l-[3px] border-l-[#0052D9]`
- 不显示：学校、城市、技能、时间、versionNo、schema_version
- 排序：versionNo 倒序（最新在前）

### 空/加载/错误状态

| 状态 | 处理 |
|------|------|
| loading | `PageLoading("正在加载简历列表…")` |
| empty | `EmptyState`："你还没有创建简历…添加简历" |
| error | `PageError("简历列表加载失败，请稍后重试。")` + 创建链接 |

## 七、智能助手入口设计

右侧 `SmartAssistant` 组件，4 个入口：

| 入口 | 跳转 | 条件 |
|------|------|------|
| 推荐适合的岗位 | `/recommend?resumeVersionNo=N` | 有选中简历 |
| 去岗位广场做匹配 | `/jobs` | 有简历即可 |
| 优化当前简历 | `/resume-optimization?resumeVersionNo=N` | 有选中简历 |
| 查看版本对比 | `/resumes/compare` | 有简历即可 |

- 未选中简历时，推荐/优化入口 disabled（opacity-50, cursor-not-allowed）
- 入口为独立白色卡片：`rounded-2xl ring-1 ring-gray-100`
- hover 效果：`bg-blue-50/50`
