## 3. LLM Client 抽象设计

### Client 接口

```go
type Client interface {
    Chat(ctx context.Context, req ChatRequest) (*ChatResponse, error)
    Provider() Provider
}
```

核心约束：
- Chat 必须接收 context.Context
- ChatRequest 不绑定 Hunyuan 私有结构
- ChatResponse 不绑定 Hunyuan 私有结构
- 业务 Agent 后续只依赖该接口

### Provider

```go
type Provider string
const (
    ProviderHunyuan Provider = "hunyuan"
    ProviderNoop    Provider = "noop"
)
```

当前只定义 hunyuan 和 noop，不定义 OpenAI / Qwen 等无关 provider。

## 4. 核心类型

### Role / Message

```go
type Role string  // system / user / assistant
type Message struct {
    Role    Role   `json:"role"`
    Content string `json:"content"`
}
```

### ChatRequest

- Model：可为空，由具体 Client 使用默认配置补齐
- Messages：不能为空
- Temperature：控制输出稳定性
- MaxTokens：限制输出长度
- TimeoutSec：请求超时
- Metadata：记录 prompt_name / schema_name / agent_name 等非敏感信息，不允许放 API Key

### ChatResponse

- RawContent：模型原始文本，后续由 llmjson 工具处理
- RawOutputLength：用于日志
- 不放完整 Prompt / API Key

### Usage

- PromptTokens / CompletionTokens / TotalTokens
- provider 暂时不返回 usage 时保持 0

## 5. Config 设计

### Config 结构体

### DefaultConfig()

默认值与 .env.example 完全一致：
- Enable=false, Provider=hunyuan, Temperature=0.2
- MaxOutputTokens=8192, TimeoutSeconds=30
- RepairEnable=true, RepairMaxAttempts=1
- FallbackEnable=true, LogRawOutput=false
- PromptDir=server/prompts, SchemaDir=server/prompts/schema

### Config.Validate()

校验要求：
- Enable=false 时可以不要求 APIKey
- Enable=true 时 Provider/BaseURL/APIKey/Model 必须存在
- RepairMaxAttempts 必须为 1
- TimeoutSeconds 必须 > 0
- MaxOutputTokens 必须 > 0
- Temperature 必须在 [0, 2] 范围
- PromptDir / SchemaDir 不为空

## 6. ErrorCode 与 LLMError

### ErrorCode（9 个）

- LLM_DISABLED / LLM_CONFIG_MISSING / LLM_API_KEY_MISSING
- LLM_TIMEOUT / LLM_HTTP_ERROR / LLM_RATE_LIMIT
- LLM_EMPTY_RESPONSE / LLM_OUTPUT_TRUNCATED
- UNKNOWN_ERROR

### LLMError

- Code + Message + Cause
- Error() 实现标准错误输出
- Unwrap() 支持错误链检查
- 错误中不包含 API Key / 完整 Prompt / 完整简历 / 完整 JD

### IsDirectMockFallback()

- LLM_DISABLED / LLM_CONFIG_MISSING / LLM_API_KEY_MISSING / LLM_TIMEOUT / LLM_HTTP_ERROR / LLM_RATE_LIMIT / LLM_EMPTY_RESPONSE / UNKNOWN_ERROR → 直接 Mock
- LLM_OUTPUT_TRUNCATED → 尝试 repair
- 非 LLMError 类型的未知错误 → 直接 Mock

## 7. NoopClient / DisabledClient

NoopClient 实现：
- 不访问外部网络
- Provider() 返回 ProviderNoop
- Enable=false 时 Chat 返回 LLM_DISABLED
- Enable=true 时 Chat 返回固定 RawContent
- 不模拟真实模型质量
- 只用于测试 Client 接口与错误码
