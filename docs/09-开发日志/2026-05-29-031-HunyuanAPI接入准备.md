## 6. 关键决策

1. **阶段 4 调整为"Agent 与模型接入"**：原先阶段 4 为"前端接入后端 API"，现调整为"Agent 与模型接入"，前端接入后延至阶段 5
2. **Hunyuan 作为首选 LLM Provider**：国内稳定、有免费额度、OpenAI-compatible
3. **保留 Mock Agent 兜底**：LLM 失败时自动回退 Mock，不阻断用户操作
4. **Agent 改造顺序**：匹配分析 → 推荐 → 版本对比（风险从低到高）
5. **低温度（0.2）**：确保 LLM 输出稳定，减少随机性
6. **只输出 JSON**：Prompt 必须要求模型只输出 JSON，不做自由文本
7. **`generated_by` 区分来源**：`mock_agent` / `llm_agent` / `llm_agent_fallback`

## 7. 用户需要填写的信息

用户需要在本地 `.env` 中填写以下信息才能启用真实 LLM：

1. `LLM_API_KEY`：从腾讯云控制台获取的混元 API Key
2. `ENABLE_LLM_AGENT=true`：启用真实 LLM
3. 确认 `LLM_BASE_URL` 和 `LLM_MODEL` 与控制台一致

详见 `docs/05-Agent设计/Hunyuan接入准备.md`。
