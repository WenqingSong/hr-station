1. **用户必须创建 `.env` 文件**并配置真实 LLM 参数：
   ```env
   LLM_ENABLE=true
   LLM_PROVIDER=hunyuan
   LLM_BASE_URL=<真实 Hunyuan/TokenHub 地址>
   LLM_API_KEY=<真实 API Key>
   LLM_MODEL=<可用模型名称>
   ```

2. 执行 `make llm-check` 确认配置完整
3. 执行 `RUN_REAL_LLM_SMOKE=1 make llm-smoke` 验证连通性
4. 如果 smoke 通过，正式进入 4-3.2 MatchAnalysisAgent 接入 Pipeline
5. 如果 smoke 失败，先修复 LLM 配置或调用问题
