# K8-5-13-E：登录注册弹窗玻璃模糊视觉精修与响应式验收

## 1. 本阶段目标
K8-5-13-D 已接入 Navbar。本次精修 AuthDialog 的玻璃模糊视觉与响应式体验。

## 2. 当前 AuthDialog 视觉问题
- Content 通过 `DialogContent` 渲染，Overlay 无法定制 `backdrop-blur`
- 缺少移动端高度安全处理
- Header/body padding 未做响应式区分

## 3. 视觉精修方案

| 区域 | 修改前 | 修改后 |
|------|--------|--------|
| Overlay | `DialogContent` 内置黑半透明 | **自定义** `DialogOverlay`：`bg-slate-950/35 backdrop-blur-md` |
| Content | `DialogContent` 组件 | **自定义** `div`：`bg-white/88 backdrop-blur-xl rounded-3xl ring-1 ring-white/60` |
| 高度 | 无限高 | `max-h-[min(88vh,720px)] overflow-y-auto` |
| 关闭按钮 | radix 内置 X | 自定义右上角圆 X 按钮 |
| Mobile padding | `px-7` | `px-5` / `sm:px-7` |
| 错误 | `bg-red-50` | `bg-red-50/90 ring-1 ring-red-100 rounded-xl` |
| 输入框 | `border-gray-200` | `border-slate-200/80 focus:ring-2` |
| 按钮 | `py-3` | `h-11 shadow-sm` |
| 动画 | 保持 radix 原生 | 保持 |

## 4. 响应式策略

| 屏幕 | 策略 |
|------|------|
| ≥1024px | 420px 宽，`sm:px-7`，完整可见 |
| 768~1023px | `min(92vw,420px)`，居中 |
| <640px | `px-5`，max-h 防溢出，内部可滚动 |
