## 4. Docker Compose 调整

### 修改前

- 只有 MySQL 服务
- 头部注释说"第一版只稳定 MySQL"

### 修改后

- MySQL + Nginx 两个服务
- Nginx 使用 `nginx:alpine` 镜像
- Nginx 暴露 80:80 端口
- Nginx 挂载 `nginx/nginx.conf` 和 `nginx/conf.d/` 只读
- Nginx 配置 `extra_hosts: host.docker.internal:host-gateway`（Linux 支持）
- Nginx depends_on mysql (service_healthy)
- 头部注释更新为"混合式开发环境"

## 5. Nginx 代理调整

### 路由规则

```
/        → http://host.docker.internal:5173  (前端 Vite Dev Server)
/api/    → http://host.docker.internal:8080   (后端 API，不 strip /api)
/healthz → http://host.docker.internal:8080/healthz (健康检查)
```

### 关键配置

1. `/api/` 使用 `proxy_pass http://host.docker.internal:8080;` 不带尾部 `/`，保留 `/api` 前缀
2. `/` 代理配置了 WebSocket Upgrade 头，支持 Vite HMR
3. `/api/` 配置了 `proxy_buffering off` 和 `proxy_read_timeout 300s`，预留 SSE / 长连接
4. `/healthz` 配置了 `access_log off`，减少日志噪声

### host.docker.internal

- macOS / Windows：Docker Desktop 自动支持
- Linux：`extra_hosts: host.docker.internal:host-gateway`

## 7. 启动命令契约

| 命令 | 语义 | 说明 |
|------|------|------|
| `make up` | 启动完整混合式开发环境 | Docker(MySQL+Nginx) + 本机(Backend+Frontend) |
| `make down` | 关闭完整混合式开发环境，不清 volume | Docker down + 本机进程 stop |
| `make restart` / `restart-soft` | 软重启，不清 volume | stop + up |
| `make reset` | 清开发 volume，必须 CONFIRM=yes | |
| `make reset-up` | 清开发 volume 后重启，必须 CONFIRM=yes | |
| `make status` | 查看完整开发环境状态 | MySQL + Nginx + Backend + Frontend |
| `make nginx-logs` | 查看 Nginx 容器实时日志 | `docker compose logs -f nginx` |
