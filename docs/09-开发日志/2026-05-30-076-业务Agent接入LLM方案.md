## 4. MatchAnalysisAgent 接入方案

### 4.1 Pipeline 调用参数

```text
AgentName:        "MatchAnalysisAgent"
PromptName:       prompt.PromptMatchAnalysis
SchemaName:       schema.SchemaMatchAnalysis
TargetOutputType:  pipeline.TargetMatchAnalysis
PromptValues: {
    "RESUME_CONTEXT_JSON":  json.Marshal(resume)
    "JOB_CONTEXT_JSON":     json.Marshal(job)
    "BUSINESS_CONTEXT":     matchAnalysisBusinessContext
}
```

### 4.2 处理路径

```text
success → mapToMatchAnalysisResult(parsed, job, resume) → llm_agent
repaired → mapToMatchAnalysisResult(parsed, job, resume) → llm_agent
fallback_required → mockAgent.Analyze(resume, job) → mock_agent
映射失败 → mockAgent.Analyze(resume, job) → mock_agent
```

### 4.3 Service 改造方向

MatchService 新增 pipelineRunner 依赖，Analyze 方法中根据 Pipeline 结果决定使用 LLM 结果或 Mock fallback。

## 5. RecommendationAgent 接入方案

### 5.1 Pipeline 调用参数

```text
AgentName:        "RecommendationAgent"
PromptName:       prompt.PromptRecommendation
SchemaName:       schema.SchemaRecommendation
TargetOutputType:  pipeline.TargetRecommendation
PromptValues: {
    "RESUME_CONTEXT_JSON":  json.Marshal(resume)
    "JOB_CANDIDATES_JSON":  json.Marshal(jobs)
    "BUSINESS_CONTEXT":     recommendationBusinessContext
}
```

### 5.2 处理路径

```text
success → mapToRecommendedJobs(parsed, candidateJobMap) → llm_agent
repaired → mapToRecommendedJobs(parsed, candidateJobMap) → llm_agent
fallback_required → mockAgent.Recommend(resume, jobs) → mock_agent
映射失败 / job_id 全部无效 → mockAgent.Recommend(resume, jobs) → mock_agent
```

### 5.3 岗位完整性约束

- job_id / title / external_id 必须来自输入候选集
- LLM 不能编造不存在的岗位
- 推荐项的 job_id 必须与候选集匹配

## 7. Pipeline 调用位置

推荐结构：

```text
Service 层
→ 组装 PromptValues
→ pipelineRunner.Run(ctx, runReq)
→ switch runResult.AgentStatus:
   success / repaired → 映射 LLM 结果
   fallback_required → 调用 Mock Agent
```

禁止结构：

```text
❌ Controller → Pipeline
❌ Business Agent → HunyuanClient
```

业务 Agent 只依赖 Pipeline，不直接依赖 HunyuanClient。

## 8. fallback_required 处理策略

```text
Pipeline RunResult.AgentStatus = success
→ generated_by = "llm_agent", agent_status = "success", repair_applied = false

Pipeline RunResult.AgentStatus = repaired
→ generated_by = "llm_agent", agent_status = "repaired", repair_applied = true

Pipeline RunResult.AgentStatus = fallback_required
→ 调用 Mock Agent
→ generated_by = "mock_agent", agent_status = "fallback"
→ 记录 fallback_reason / error_code

LLM 结果映射失败
→ fallback 到 Mock Agent
→ generated_by = "mock_agent"
```

fallback_required 不是失败，是稳定性机制。
