# K8-4-4-R6：岗位卡片文字信息架构重构，对齐腾讯招聘列表卡片

- **日期**：2026-06-03
- **阶段**：K8-4-4-R6（frontend + adapter）
- **性质**：JobCard 文字信息结构彻底重构，对齐腾讯招聘

## 1. 用户反馈

当前 Offer 捕手岗位卡片文字信息设计与腾讯招聘差距很大：

- 第二行出现 `技术 | 软件开发 | 技术` 文字重复
- `事业群：` 前缀 label 风格不符合腾讯招聘
- 文字层级不符合参考图
- 卡片展示过多详情描述文字
- 英文 `open` 状态不符合中文招聘站

## 2. 腾讯招聘卡片文字结构参考

```
软件开发-后台开发方向

技术  |  应届实习  |  CDG CSIG IEG PCG TEG WXG S1 S2

工作地点：深圳总部 北京 上海 广州 成都 武汉 杭州
```

## 3. 当前卡片字段问题根因

### 3.1 `技术 | 软件开发 | 技术` 重复的根因

1. **后端 bug**：`job_service.go` 第 364 行 `RecruitType: j.JobType` — `recruit_type` 返回的是 `job_type`（"技术"），而非真实的招聘类型
2. **前端 adapter**：`typeLabel` 使用 `RECRUIT_TYPE_LABELS[job.recruit_type]`，但 `recruit_type` 实际是 "技术"，不匹配任何映射，fallback 返回原始值 "技术"
3. **JobCard metaParts 构建**：
   - `jobTypeLabel` = "技术"（来自 `job_type`）
   - `direction` = "软件开发"（来自 `direction`）
   - `typeLabel` = "技术"（来自有 bug 的 `recruit_type`）
   - 结果：`技术 | 软件开发 | 技术`

### 3.2 字段含义

| 字段 | 含义 | 来源 | 示例 |
|------|------|------|------|
| `job_type` | 岗位大类 | `jobs.job_type` | 技术/产品/设计 |
| `application_type` | 应聘类型 | `jobs.application_type` | 应届实习/日常实习/校园招聘 |
| `application_project` | 应聘项目 | `jobs.application_project` | 实习生/应届生 |
| `application_subtype` | 应聘子类型 | `jobs.application_subtype` | 应届实习 |
| `category` | 岗位子类 | `jobs.category` | 后台开发/前端开发 |
| `direction` | 技术方向 | `jobs.direction` | 软件开发 |
| `recruit_type` | API 中的错误字段 | 后端返回 `job_type` | 技术（bug） |

### 3.3 其他问题

- **事业群**：前端拿到 code（如 CDG CSIG），但用 `事业群：` 前缀 label 展示，不够自然
- **工作地点**：有全部 locations（7 个），但只展示 6 个 + `+1`
- **status=open**：后端默认值 `open`，前端 adapter 只映射 `active`→`招聘中`，`open` 未映射
- **描述行**：与腾讯招聘风格不一致，列表卡片不应承载大量说明文字

## 4. 修复方案

### 4.1 标题行

保持 R5 风格：18px、font-semibold、深色 gray-900、hover 微蓝。

### 4.2 元信息行重组

**目标格式**：`技术 | 应届实习 | CDG CSIG IEG PCG TEG WXG S1 S2`

**字段优先级**：`job_type | application_type | organization_codes`

**改动**：
- 移除 `direction`（已在标题中体现，无需在列表卡片重复）
- 使用 `application_type` 替代有 bug 的 `recruit_type`
- 将事业群 codes 合并入元信息行（无 `事业群：` 前缀）
- 移除独立的事业群行

### 4.3 工作地点行

- 移除 MapPin 图标
- 展示全部 7 个城市（从 6 个提升到 7 个）
- 保留 `+N` 机制但阈值提高

### 4.4 描述行

保留但保持弱化（R5 已做：`text-[13px] text-gray-400 line-clamp-2`）。

### 4.5 技能标签

卡片不展示技能标签（R5 已移除）。

### 4.6 状态 badge

已在 R5 改为右上角中文 "招聘中" badge。本次补充 `open` → `招聘中` 的映射。

### 4.7 查看详情

保持 R5 风格：底部右对齐 `查看详情 →`。

## 5. 是否修改后端 / adapter

### 修改 adapter（jobAdapter.ts）

| 改动 | 原因 |
|------|------|
| 新增 `APPLICATION_TYPE_DISPLAY` 映射表 | `application_type` 中文展示 |
| `typeLabel` 改用 `application_type` | 不再依赖有 bug 的 `recruit_type` |
| 删除 `RECRUIT_TYPE_LABELS` 映射 | `typeLabel` 不再使用 `recruit_type` |
| `STATUS_LABELS` 新增 `open: '招聘中'` | 补充 `open` 状态映射 |

### 未修改后端

后端 `RecruitType: j.JobType` bug 属于已有命名问题（`recruit_type` 字段名与 `job_type` 值混淆），前端已通过 adapter 绕过此 bug。修复需要统一重命名前端筛选参数和 facets 查询，超出 R6 范围。
