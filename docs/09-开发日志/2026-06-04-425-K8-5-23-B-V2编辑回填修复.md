# K8-5-23-B — V2 编辑回填修复

## 性质
implementation（前端 only：adapter + viewModel + MyResumesPage，不改后端/SQL/Agent）。

## 本阶段目标

修复 K8-5-23-A 识别的 3 个断点：让 MyResumesPage 在 edit 模式下能从 V2 raw 字段回填所有 10 模块 draft state。

## 修改方案

| 区域 | 修改内容 | 原因 |
|------|---------|------|
| `ResumeManagementViewModel` | 新增 `v2?` 可选字段（含 10 模块 V2 raw 类型） | 传递后端 V2 数据到页面 |
| `toResumeManagementViewModel` | 从 Resume 提取 V2 raw 模块 → v2 | adapter 不再丢弃 V2 字段 |
| `parseV2Educations` / `parseV2Projects` / `parseV2Skills` | 安全解析 V2 格式 education/projects/skills | 兼容 V1/V2 混合格式 |
| `MyResumesPage` edit useEffect | 新增 V2 回填（约 80 行），优先使用 formVm.v2 | 修复 38 个 V2 字段不回填 |
| `joinList` / `joinLines` helpers | 数组→字符串反向转换 | draft state 是字符串 |
