# 2026-05-29-045-扩展jobs表与初始化SQL

## 1. 本次任务

扩展 `server/sql/init.sql` 中的 `jobs` 表，新增 8 个字段以支持腾讯招聘公开岗位数据来源，同时更新本地 Mock 岗位种子数据以适配新字段。

## 2. 修改范围

| 文件 | 操作 |
|------|------|
| `server/sql/init.sql` | 修改：扩展 jobs 表结构 + 更新种子数据 |

## 3. 表结构变更

### 3.1 新增字段

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| external_source | VARCHAR(50) | 'local_mock' | 外部数据来源：local_mock / tencent_join |
| external_id | VARCHAR(100) | NULL | 外部岗位ID，腾讯岗位使用 postId |
| external_inner_id | VARCHAR(100) | NULL | 外部系统内部ID |
| source_url | VARCHAR(500) | NULL | 公开岗位来源页面URL |
| raw_json | JSON | NULL | 原始列表与详情响应JSON |
| data_quality | VARCHAR(50) | 'manual_enriched' | 数据质量：full_jd / summary_only / manual_enriched |
| is_featured | TINYINT(1) | 0 | 是否 Demo 精选岗位 |
| synced_at | TIMESTAMP | NULL | 外部岗位同步时间 |

### 3.2 索引变更

| 索引 | 类型 | 说明 |
|------|------|------|
| uk_jobs_external_source_id | UNIQUE | (external_source, external_id) 唯一业务键 |
| idx_jobs_external_source | KEY | external_source 辅助索引 |
| idx_jobs_data_quality | KEY | data_quality 辅助索引 |
| idx_jobs_is_featured | KEY | is_featured 辅助索引 |

## 4. 种子数据变更

8 条本地 Mock 岗位新增字段值：

| 字段 | 值 |
|------|-----|
| external_source | 'local_mock' |

| external_inner_id | NULL |
| source_url | NULL |
| raw_json | JSON_OBJECT('source', 'local_mock', 'note', 'seed demo job') |
| data_quality | 'manual_enriched' |
| is_featured | 1 |
| synced_at | NULL |
