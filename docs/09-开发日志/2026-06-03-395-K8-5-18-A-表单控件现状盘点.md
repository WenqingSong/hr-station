## 4. 密码双眼睛专项分析

### 4.1 当前 AuthDialog 密码框结构

```
<div className="relative">
  <label>密码</label>
  <input type={showPassword ? "text" : "password"} className="...pr-10" />
  <button>  ← 自定义 Eye / EyeOff 按钮，absolute right-3
    {showPassword ? <EyeOff /> : <Eye />}
  </button>
</div>
```

### 4.2 双眼睛根因

```text
浏览器内置 password reveal 按钮（Edge/Chrome 默认） + 自定义 Eye 图标 = 双眼睛
```

具体：
- Edge 浏览器在 `type="password"` 时自动在框内右侧渲染 👁 按钮
- 项目自定义的 `<button>`（Eye/EyeOff 图标）也定位在右侧
- 两者重叠或并排出现在同一输入框

### 4.3 无 CSS 抑制

```text
⚠️ 项目中不存在任何 ::-ms-reveal / ::-ms-clear 的 CSS 抑制规则
```

### 4.4 影响范围

| 页面 | password 数 | 受双眼睛影响 |
|------|:---:|:---:|
| AuthDialog | 3 | ✅ |
| LoginPage | 1 | ✅ |
| RegisterPage | 2 | ✅ |
| **合计** | **6** | 全部 |

## 6. 样式碎片化分析

### 6.1 Input 样式对比

| 位置 | rounded | height | border | focus ring | bg |
|------|---------|--------|--------|-----------|-----|
| AuthDialog | `rounded-xl` | `h-11`(44px) | `border-slate-200/80` | `ring-2 ring-blue/25` | `bg-white/80` |
| LoginPage/RegisterPage | `rounded-md` | `py-2`(~40px) | `border-gray-300` | `ring-1 ring-blue` | `bg-white` |
| MyResumesPage (inputCls) | `rounded` | `py-2`(~40px) | `border-gray-200` | `ring-1 ring-blue` | `bg-white` |
| MyResumesPage (内联) | `rounded-xl` | `h-11 / h-10` | `border-slate-200` | `ring-2 ring-blue/25` | `bg-white` |

### 6.2 Focus Ring 混乱

| 策略 | 使用位置 |
|------|---------|
| `focus:ring-1 focus:ring-[#0052D9]` | LoginPage, RegisterPage, inputCls |
| `focus:ring-2 focus:ring-[#0052D9]/25` | AuthDialog, MyResumesPage 内联 |
| `focus-visible:ring-[3px] focus-visible:ring-ring/50` | shadcn ui/input.tsx (未使用) |

### 6.3 高度不统一

| 高度 | 使用位置 |
|------|---------|
| `h-11` (44px) | AuthDialog, MyResumesPage 主表单 |
| `h-10` (40px) | MyResumesPage 教育经历子表单 |
| `py-2` (~40px) | LoginPage, RegisterPage, inputCls |
| `h-9` (36px) | shadcn ui/input.tsx 默认 |

## 7. 高风险问题分级

| 级别 | 问题 | 影响页面 | 风险 |
