## 2026-05-28 - 阶段 2-4 - 实现请求日志与 CORS 中间件

### 新增

- 新增 RequestLogger 中间件 `server/internal/middleware/logger.go`
  - 记录 method / path / status / duration / remote / user_agent
  - 自定义 responseWriter 包装器捕获 HTTP 状态码
  - 默认状态码 200
- 新增 CORS 中间件 `server/internal/middleware/cors.go`
  - 允许 `http://localhost:5173` 和 `http://127.0.0.1:5173`
  - 本地开发便利：允许所有 localhost/127.0.0.1 端口的 Origin
  - OPTIONS 预检返回 204 No Content
  - 允许 Content-Type / Authorization / X-Requested-With 头
  - Allow-Credentials: true
  - Max-Age: 86400
- 新增 Recover 中间件 `server/internal/middleware/recover.go`
  - 捕获 panic 返回统一错误 `{code:50000, message:"internal server error"}`
  - 使用 `log.Printf` 记录 panic 值和完整堆栈
  - 不暴露 panic 细节给前端
  - 复用 `apperror.ErrInternal` 和 `response.Error()`

- 修改 `server/internal/http/router.go`：在 NewRouter() 中组装中间件链（Recover → CORS → RequestLogger → mux）
