## 开发环境部署

### 首次启动

```bash
# 1. 检查环境
make doctor

# 2. 初始化开发环境
make init

# 3. 启动 MySQL
make up

# 4. 启动前端
make dev-web

# 5. 启动后端（新终端）
make dev-server
```

### CNB 云原生环境重启后恢复

```bash
# 1. 检查环境
make doctor

# 2. 初始化（幂等，已有则跳过）
make init

# 3. 启动 MySQL
make up

# 4. 启动开发服务
make dev-web
make dev-server
```

### 日常开发

```bash
make dev-web      # 前端开发
make dev-server   # 后端开发
make logs         # 查看服务日志
make status       # 查看容器状态
```

### 停止服务

```bash
make down         # 停止 Docker 服务（不删数据）
make reset        # ⚠️ 危险：停止并删除所有数据
```
