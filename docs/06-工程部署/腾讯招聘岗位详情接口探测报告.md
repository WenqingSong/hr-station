# 腾讯招聘岗位详情接口探测报告

> 探测时间：2026-05-29
> 探测目的：确认腾讯招聘公开站点是否存在岗位详情接口，判断能否拿到完整岗位职责和任职要求

## 1. 探测目标

基于 4-1.2.0 探测结果，岗位列表接口可用但**不返回 JD 正文**（description/requirements）。本次探测旨在确认：

- 是否存在公开的岗位详情 API 接口
- 详情接口是否返回完整岗位职责和任职要求
- 详情数据是否值得后续正式接入

## 2. 探测边界

| 边界 | 说明 |
|------|------|
| 总请求数 | ≤ 10 次 |
| 探测对象 | 仅岗位详情接口 |
| 不探测 | 登录/投递/收藏/用户中心接口 |
| 不做 | 接口爆破/全站扫描 |
| 收敛原则 | 未发现则直接结论，不继续扩大探测 |

## 3. 探测时间

2026-05-29，总请求约 10 次，每次间隔 ≥ 1 秒。

## 9. 是否拿到完整 JD

**❌ 未拿到完整 JD。**

- 5 个候选 API 路径全部返回 404
- 前端详情页是 SPA 空壳，数据通过 JS 动态加载
- 未能从 JS bundle 中提取出详情 API 路径
- 列表接口的 `positionUrl` 为 null，没有提供详情链接

## 14. 结论

> ⚠️ 本报告的原始结论已被 4-1.2.0.2 修正。详情接口已通过前端 JS 分析确认存在。

### 14.0 修正说明（2026-05-29，4-1.2.0.2 补充）

4-1.2.0.2 通过分析前端 JS bundle（`p_zh-cn_detail.build.js`，728KB）发现了真实的详情接口路径：

- ✅ `GET /api/v1/jobDetails/getJobDetailsByPostId?postId={postId}` — 已确认可用，返回完整 JD
- ✅ `GET /api/v1/jobDetails/getJobDetailsByPidAndId?pid={projectId}&id={position}` — 已确认可用

**4-1.2.0.1 探测失败原因**：
1. 候选路径都在 `/api/v1/position/` 下，而真实路径在 `/api/v1/jobDetails/` 下
2. 下载 JS bundle 时未带 Referer 头，导致 CDN 返回空文件
3. 未检查 detail.html 页面加载的完整 JS 文件列表

**修正后结论**：✅ **已确认稳定公开岗位详情接口。** 详见 `腾讯招聘必要接口确认报告.md`。
