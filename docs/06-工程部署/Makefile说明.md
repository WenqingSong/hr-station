## 规划命令

| 命令 | 说明 |
|------|------|
| `make dev` | 启动开发环境（docker-compose up） |
| `make dev-down` | 停止开发环境 |
| `make server` | 启动后端服务 |
| `make web` | 启动前端服务 |
| `make migrate` | 执行数据库迁移 |
| `make seed` | 加载种子数据 |
| `make build` | 构建前后端 |
| `make lint` | 代码检查 |
| `make test` | 运行测试 |
| `make clean` | 清理构建产物 |
