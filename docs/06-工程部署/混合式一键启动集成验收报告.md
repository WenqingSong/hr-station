## 10. CORS 验收

### Nginx 入口 OPTIONS

```text
curl -X OPTIONS http://localhost/api/auth/login \
  -H "Origin: http://localhost" \
  -H "Access-Control-Request-Method: POST" \
  -H "Access-Control-Request-Headers: Content-Type,Authorization"

→ 204 No Content
→ Access-Control-Allow-Origin: http://localhost
→ Access-Control-Allow-Methods: GET, POST, PUT, PATCH, DELETE, OPTIONS
→ Access-Control-Allow-Headers: Content-Type, Authorization, X-Requested-With
```

✅ 通过

### 后端直连 OPTIONS

```text
curl -X OPTIONS http://localhost:8080/api/auth/login \
  -H "Origin: http://localhost:5173" \
  -H "Access-Control-Request-Method: POST" \
  -H "Access-Control-Request-Headers: Content-Type,Authorization"

→ 204 No Content
→ Access-Control-Allow-Origin: http://localhost:5173
→ Access-Control-Allow-Headers: Content-Type, Authorization, X-Requested-With
```

✅ 通过

### 不允许 Origin

```text
curl -X OPTIONS http://localhost:8080/api/auth/login \
  -H "Origin: http://evil.example.com" \
  -H "Access-Control-Request-Method: POST"

→ 405 Method Not Allowed
→ 无 Access-Control-Allow-Origin 头
→ 无 Access-Control-Allow-Origin: *
```

✅ 通过

## 16. 风险与限制

- CORS 配置 Go 后端启动时一次性加载，不支持热更新
- `localhost:` / `127.0.0.1:` 任意端口自动允许仅限开发环境
- `CORS_ALLOW_CREDENTIALS=false` 意味着前端不能使用 `credentials: 'include'`
- LLM Agent 尚未配置（`ENABLE_LLM_AGENT` 未设置），不影响混合式启动
