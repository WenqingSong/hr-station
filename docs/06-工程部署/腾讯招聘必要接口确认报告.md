### Request URL

```
GET https://join.qq.com/api/v1/dictionary/?types=RecruitType,BusinessGroup,RecruitProjectPostList,RecruitCity
```

### Request Method

GET

### types 参数

| types 值 | 返回内容 | 数量 |
|----------|---------|------|
| RecruitType | 招聘类型 | 3（实习生/应届生/人才专项） |
| BusinessGroup | 事业群 | 10 |
| RecruitProjectPostList | 岗位类别 | 5（技术/产品/设计/市场/职能） |
| RecruitCity | 招聘城市 | 57 |

### Response 结构

```json
{
  "status": 0,
  "message": "",
  "data": {
    "RecruitType": [...],
    "BusinessGroup": [...],
    "RecruitProjectPostList": [...],
    "RecruitCity": [...]
  }
}
```

### 可提供的字典

- RecruitType：code → name（招聘类型）
- BusinessGroup：code → name（事业群名称）
- RecruitProjectPostList：code → name（岗位大类）
- RecruitCity：code → name（城市名称）

### 是否必须接入

⬜ **非必须，但建议接入。**

理由：
1. 详情接口已返回 `workCityList`（城市名称列表）和 `intentionBGDList`（事业群详情），大部分映射不需要字典
2. 字典接口主要用于列表接口的 bgs/positionFamily 等 code 字段映射
3. 如果只接详情接口，可以不接字典接口

### 是否建议接入

✅ **建议接入。** 作为本地缓存使用，避免 code 到 name 的硬编码映射。

## 10. Demo 最小接口决策

### 最少需要几个接口

**2 个**：岗位列表 + 岗位详情

### 必须接入的接口

1. **岗位列表接口**（P0）：`POST /api/v1/position/searchPosition`
   - 获取岗位列表和 postId，供详情接口使用
   - 支持分页、搜索、筛选

2. **岗位详情接口**（P0）：`GET /api/v1/jobDetails/getJobDetailsByPostId?postId={postId}`

   - 获取岗位子分类列表
   - 非必须

3. **项目映射接口**（P2）：`GET /api/v1/position/getProjectMapping`
   - 获取项目列表映射
   - 非必须

### 不接入的接口

- 所有需要登录态的接口
- 与 Demo 无关的接口（banner、公告、图片等）

## 14. 结论

### 14.1 接口确认汇总

| 接口 | 确认状态 | 说明 |
|------|---------|------|
| 岗位列表接口 | ✅ 已确认 | POST /api/v1/position/searchPosition，稳定可用 |
| 岗位详情接口 | ✅ 已确认 | GET /api/v1/jobDetails/getJobDetailsByPostId，返回完整 JD |
| 字典接口 | ✅ 已确认 | GET /api/v1/dictionary/，code→name 映射 |

### 14.2 关键发现

1. ✅ **岗位详情接口已确认**：通过分析前端 JS bundle（`p_zh-cn_detail.build.js`）发现 `getJobDetailsByPostId` 接口
2. ✅ **完整 JD 可获取**：`desc` 是完整岗位职责，`request` 是完整任职要求
3. ✅ **详情接口返回城市名称列表**：`workCityList` 不需要字典映射
4. ✅ **详情接口返回事业群详情**：`intentionBGDList` 含部门层级
5. ✅ **4-1.2.0.1 之前探测失败原因**：只尝试了 `/api/v1/position/detail` 等路径，而真实路径是 `/api/v1/jobDetails/getJobDetailsByPostId`
6. ⚠️ 详情接口参数是 `postId`（列表接口返回），不是列表接口的 `id` 字段

### 14.3 之前 4-1.2.0.1 探测失败原因分析

| 原因 | 说明 |
|------|------|
| 候选路径不在 `/api/v1/position/` 下 | 真实路径在 `/api/v1/jobDetails/`，不在 `/api/v1/position/` |
| 未下载正确的 JS bundle | 4-1.2.0.1 尝试下载 JS 时文件为 0 字节，可能是未带 Referer |
| 未检查前端 HTML 加载的 JS 列表 | 4-1.2.0.1 未分析 detail.html 页面引用的完整 JS 文件列表 |

### 14.4 对 4-1.2.1 的影响

| 影响项 | 结论 |
