# 中文命名规范

## 1. 适用范围

本规范适用于 `docs/` 目录下所有 Markdown 文档的命名。

代码文件不适用本规范，遵循技术生态惯例。

## 2. docs 文档命名规则

1. 所有 Markdown 文件必须使用中文命名
2. 文件名不含空格，使用纯中文字符
3. 允许使用连字符 `-` 连接前缀和中文
4. 允许使用中文标点中的短横线

## 3. docs 目录命名规则

1. 子目录名使用数字前缀 + 中文
2. 数字前缀格式：`00-`、`01-`、`02-`...
3. 目录名不含空格

## 4. 开发日志命名规则

格式：`YYYY-MM-DD-三位序号-中文任务名.md`

示例：

```
2026-05-28-002-创建docs中文文档体系.md
2026-05-28-003-编写产品范围文档.md
2026-05-28-004-前端工程化改造计划.md
2026-05-28-005-工程执行规范与CodeBuddy工作规则.md
```

规则：

- 日期使用 YYYY-MM-DD 格式
- 序号三位数字，从 001 递增
- 任务名使用中文
- 序号在同一天内递增

## 5. ADR 命名规则

格式：`ADR-序号-中文标题.md`

示例：

```
ADR-001-技术栈选择.md
ADR-002-单主简历设计.md
ADR-003-先Mock后接模型.md
ADR-004-不自动生成简历.md
```

规则：

- ADR 前缀固定
- 序号三位数字递增
- 标题使用中文

## 6. 不适用范围

以下文件不适用中文命名：

1. 代码文件（`.go`、`.tsx`、`.ts`、`.css` 等）
2. 配置文件（`package.json`、`tsconfig.json`、`docker-compose.yml` 等）
3. 环境文件（`.env`、`.env.example` 等）
4. 构建文件（`Makefile`、`Dockerfile` 等）
5. 锁文件（`package-lock.json`、`go.sum` 等）

## 7. 代码文件命名规则

### 后端 Go 文件

- 使用英文小写
- 使用下划线分隔
- 示例：`user_handler.go`、`resume_service.go`、`job_match_agent.go`

### 前端文件

- 按现有技术栈和项目规范执行
- 组件文件使用 PascalCase：`App.tsx`、`ResumePage.tsx`
- 工具文件使用 camelCase 或 kebab-case：`apiClient.ts`、`use-auth.ts`
