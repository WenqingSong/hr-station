# K9-1 岗位推荐双阶段页面交互设计

> 版本：v1.0 | 状态：设计冻结 | 日期：2026-06-06

## 1. 背景

K9-1-A 只读盘点确认当前岗位推荐页存在严重字段契约错位：

| 前端 adapter 读取 | 后端实际返回 | 结果 |
| -- | -- | -- |
| `job.job_title` | `job.title` | undefined |
| `job.recommendation_level` | `job.recommendation_score` (int) | undefined / 类型错 |
| `job.match_keywords` | `job.match_highlights` | undefined |
| `job.location` | `job.city` | undefined |
| `job.reason` | `job.recommendation_reason` | undefined |
| `job.risk_tags` | `job.risk_points` | undefined |
| `job.next_action` | `job.suggested_action` | undefined |

这导致页面左侧 Top 5 卡片几乎为空，中间详情区大量为空。

## 2. Fast / Deep 双阶段定义

### Fast 快速推荐

| 属性 | 值 |
| -- | -- |
| 触发方式 | 进入 `/recommend` 页面后自动触发 |
| 目标 | 尽快生成 Top 5 结果，页面不能空白 |
| 实现 | Mock Agent / Fast LLM / fallback |
| 内容要求 | 完整可读：标题、城市、类别、分数、理由、亮点、风险、建议 |
| 来源标签 | 见下方 §模拟/LLM/回退文案 |

### Deep 深度推荐

| 属性 | 值 |
| -- | -- |
| 触发方式 | 用户主动点击"生成深度推荐"按钮 |
| 目标 | 在 Fast 基础上生成更完整的高质量分析 |
| 实现 | Quality LLM Pipeline（同接口 `generation_tier: "quality"`） |
| 用户感知 | 必须明确告知等待中，不卡死 |
| 失败策略 | 保留 Fast 结果，显示温和错误提示 |

## 4. 推荐详情字段契约

```ts
interface RecommendationPageViewModel {
  recommendedJobs: RecommendedJobViewModel[];
  selectedJob?: RecommendedJobViewModel;
  
  summary: string;
  evidenceChain: RecommendationEvidenceRow[];
  riskItems: string[];
  nextActions: string[];
  
  deepStatus: "idle" | "loading" | "done" | "error";
  deepError?: string;
  
  meta?: {
    generatedBy: string;
    agentStatus: string;
    sourceLabel: string;
  };
}

interface RecommendationEvidenceRow {
  module: string;
  jobRequirement: string;
  resumeEvidence: string;
  strength: "strong" | "medium" | "weak";
}
```

**Fast 阶段**：`evidenceChain` 可为空，前端用 `matchHighlights` 生成简化证据行。
**Deep 阶段**：`evidenceChain` 应为 Agent 输出的完整证据。

interface RecommendationContextViewModel {

## 7. 状态流转

```
initial → fast_loading → fast_done → [user clicks deep] → deep_loading → deep_done
                         ↓                                     ↓
                      fast_error                           deep_error (keep fast_done)
```

| 状态 | 页面行为 |
| -- | -- |
| `fast_loading` | 骨架屏 / 加载卡片 |
| `fast_done` | Top 5 + 详情完整显示，显示"生成深度推荐"按钮 |
| `fast_error` | 错误提示 + 重试按钮 |
| `deep_loading` | Fast 结果保持可见，详情区显示"正在深度分析…"，按钮 spinner |
| `deep_done` | 详情区增强内容，按钮变"深度分析已完成" |
| `deep_error` | Fast 结果保持，温和提示"深度分析暂时失败，快速推荐结果仍可参考" |

**禁止**：`deep_loading` 时清空左侧列表；`deep_error` 时整页 error。

## 8. 模拟/LLM/回退文案

| 来源 | 右侧栏展示 | 详情区展示 |
| -- | -- | -- |
| `mock_agent` | 快速推荐 · 演示数据 | （正常显示） |
| `fast_llm` | 快速推荐 · AI 生成 | （正常显示） |
| `deep_llm` | 深度推荐 · AI 生成 | 深度分析标签 |
| `fallback` | 快速推荐 · 兜底结果 | "当前为兜底结果，深度分析可提供更准确推荐" |
| `unknown` | 推荐结果 | （正常显示） |

## 9. Deep Loading / 错误文案

**Deep loading**:
```
正在生成深度推荐分析…
系统正在结合你的简历内容、岗位要求和匹配证据进行更细致分析。
快速推荐结果仍可参考，请稍等。
```

**Deep error**:
```
深度分析暂时生成失败
快速推荐结果仍可参考。你可以稍后重试，或直接进入岗位匹配分析。
```
