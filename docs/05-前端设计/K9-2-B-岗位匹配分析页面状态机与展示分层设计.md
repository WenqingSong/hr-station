# K9-2-B：岗位匹配分析页面状态机与展示分层设计

> 状态：设计冻结 | 日期：2026-06-07 | 阶段：K9-2-B

## 1. K9-2-A 诊断结论

- P0: 无 Fast/Deep、无 latest、无 gen_tier
- P1: score=0，不消费 ResumeProfile

## 2. 页面进入状态机

```
loading_latest → GET /api/jobs/{jobId}/match/latest?resume_id=X
  → has_result=true + tier=fast → fast_done (Fast)
  → has_result=true + tier=quality → deep_done (Deep)
  → has_result=false → POST /match gen_tier=fast → fast_done
```

## 3. Fast 简化展示

| 区域 | 展示 |
|------|------|
| Header | 岗位名称 + 简历名称 |
| 左侧 | match_level + score + summary + 2 fit + 1 gap |
| 中间 | 匹配结论 + 核心优势 + 最大短板 + 快速建议 |
| 右侧 | 简历/岗位卡片 + "生成深度匹配分析"按钮 |

## 4. Deep 完整展示

| 区域 | 展示 |
|------|------|
| Header | 岗位名称 + 简历名称 |
| 左侧 | match_level + score + summary + fit + gap/risk |
| 中间 | 匹配结论 + 岗位要求 + 简历证据 + 优势 + 差距 + 风险 + 补强建议 + 面试点 + 投递策略 |
| 右侧 | 简历/岗位卡片 + "重新生成深度匹配分析" |

## 5. 顶部状态栏

| 场景 | 文案 |
|------|------|
| Fast | 快速匹配分析 · 规则推荐 |
| Deep (LLM disabled) | 深度匹配分析 · 规则兜底 |
| pending | 正在生成深度画像 |
| timeout | 深度画像生成较慢 · 已保留当前结果 |
| error | 深度匹配分析生成失败 · 已保留当前结果 |
