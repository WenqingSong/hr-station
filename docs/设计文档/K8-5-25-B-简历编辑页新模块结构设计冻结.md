# K8-5-25-B — 简历编辑页新模块结构设计冻结

## 性质
design freeze（设计冻结，不修改源码）。

## 设计原则

1. 模块数量不是目标，正确设计才是目标。
2. 腾讯招聘风格优先，不做"平台自创"模块。
3. 岗位推荐不需要用户在简历中预填求职意向。
4. 后端/SQL/Snapshot 暂不改，Agent 暂停至 K8-5-26-A。
5. 所有字段明确必填/推荐/可选，减少学生困惑。

---

## 最终模块结构（9 模块）

| 序号 | 模块 | 默认状态 | 主要字段 | 分级 |
|:---:|------|---------|---------|:---:|
| 1 | 简历基础 | 展开·不可折叠 | resumeName | 必填 |
| 2 | 基础信息 | 展开·折叠 | name, phone, email, currentCity | 必填 |
| 3 | 教育经历 | 展开·折叠 | school, degree, major, department, startDate, endDate, gpa, gpaScale, rank, coreCourses, researchDirection, lab, paperSummary | 推荐 |
| 4 | 项目经历 | 展开·折叠 | name, role, type, startDate, endDate, techStack, description, responsibilities, achievements, link | 推荐 |
| 5 | 技能信息 | 展开·折叠 | languageExam(type+score), developmentLanguages, aiApplication | 推荐 |
| 6 | 实习经历 | 折叠 | company, role, startDate, endDate, workContent, techStack, achievements, metrics | 推荐 |
| 7 | 证书与获奖 | 折叠 | certificates[], awards[] | 可选 |
| 8 | 作品或个人主页 | 折叠 | works[], homepage | 可选 |
| 9 | 自我评价 | 折叠 | selfEvaluation, additionalInfo | 可选 |

### 模块变更说明

| 旧模块 | 新模块 | 变更原因 |
|--------|--------|---------|
| 求职意向 | **已删除** | 岗位推荐不需要用户预填方向 |
| 技能信息(10分类) | 技能信息(3字段) | 模仿腾讯招聘 |
| 证书与语言能力 + 获奖与竞赛 | 证书与获奖(合并) | 两个尾部模块价值相近，合并降低界面长度 |
| 作品链接与补充信息 | 作品或个人主页 + 自我评价(拆分) | 作品与 self_evaluation 不应捆绑 |
| 基础信息(school/degree/major) | 基础信息(精简) | 学校/学历/专业迁移到教育 |

## 四个设计修正点冻结结论

### 1. 求职意向删除

| 项 | 冻结方案 |
|----|---------|
| UI | JobIntentionSection 组件移除; 9 个 state 删除 |
| payload | `job_intention` 不传(undefined → JSON.stringify 剔除) |
| target_direction | 传 `""` 空字符串(后端有 DEFAULT '') |
| target_role | 传 `""` 空字符串(V1 兼容) |
| backend | 后端 `req.JobIntention` 为空 → backfillV1FromV2 跳过 target_roles 分支 |
| adapter | `ResumeManagementViewModel.v2.jobIntention` 保留(后端仍返回空) |
| 回填 | V2 backfill 中 jobIntention.setDirection/setCities 代码删除 |
| Agent | ⏸️ 暂停，K8-5-26-A 再设计 |

### 2. 技能信息重构

| 项 | 冻结方案 |
|----|---------|
| UI | 删除 10 分类 Input; 改为 3 项: languageExam(type+score), languages, aiApplication |
| payload skills | `{ language_exam: {type,score}, development_languages: [], ai_application: "" }` |
| payload 兼容旧 skills | 旧 10 分类字段不进入新增保存; 编辑时从后端旧数据读取 → 映射到 3 新字段; 后端 skills_json 列接受任意 JSON |
| 外语考试来源 | 新建字段 languageExam，不与 certificates 冲突 |
| 回填(旧→新) | `old.skills.programming_languages` + `other_keywords` → `developmentLanguages`; `old.skills.ai_tools` + `ai_application_scenarios` → `aiApplication` |
| Agent | ⏸️ 暂停 |

### 3. 作品/个人主页重构

| 项 | 冻结方案 |
|----|---------|
| UI | 删除 github/gitee/cnb/blog/demoLinks/portfolioLinks 7 字段; 改为 works 列表 + homepage |
| works 字段 | `{ name: string, link: string, password?: string }` |
| payload portfolio_links | `{ works: [{name, link, password}], homepage: "" }` |
| 回填(旧→新) | `old.github` → works entry `{name:"GitHub",link:old.github}`; `old.blog` → homepage; `old.demo_links` → works entries(link only, no name); `old.portfolio_links` → works entries |
| 上传能力 | 禁止 FormData/type="file" |
| Agent | ⏸️ 暂停 |

### 4. 基础信息去重复

| 项 | 冻结方案 |
|----|---------|
| UI 删除 | school, degree, major, gradYear, age(共 5 字段) |
| UI 保留 | name, phone, email, currentCity(共 4 字段) |
| payload profile | 仍传完整字段(school/degree/major/gradYear → 后端仍写) |
| adapter displaySummary | `displaySchool` → `education[0].school`; `displayMajor` → `education[0].major`; `hasResume` 改从 `education[0].school` 判定 |
| 状态栏 hasResume | `!!(education[0]?.school \|\| name \|\| school)` |

## payload 设计冻结

### 完整 V2 payload

```json
{
  "schema_version": 2,
  "resume_name": "",
  "target_direction": "",
  "description": "",

  "profile": {
    "name": "", "phone": "", "email": "", "current_city": "",
    "school": "", "degree": "", "major": "", "graduation_year": ""
  },

  "job_intention": null,

  "educations": [{ "school":"","degree":"","major":"","department":"","start_date":"","end_date":"","gpa":"","gpa_scale":"","rank":"","core_courses":[],"research_direction":"","lab":"","paper_summary":"" }],

  "internships": [{ "company":"","role":"","start_date":"","end_date":"","work_content":"","tech_stack":[],"achievements":[],"metrics":"" }],

  "projects": [{ "name":"","role":"","type":"","start_date":"","end_date":"","tech_stack":[],"description":"","responsibilities":"","achievements":[],"link":"" }],

  "skills": {
    "language_exam": { "type": "", "score": "" },
    "development_languages": [],
    "ai_application": ""
  },

  "certificates": [{ "name":"","type":"","level":"","score":"","issued_at":"" }],
  "awards": [{ "name":"","type":"","level":"","awarded_at":"","description":"" }],

  "portfolio_links": {
    "works": [{ "name": "", "link": "", "password": "" }],
    "homepage": ""
  },

  "extra_info": { "self_evaluation": "", "additional_info": "" },

  "name": "", "phone": "", "email": "", "location": "",
  "target_city": "", "target_role": "",
  "education": [], "experience": [], "project": [],
  "skills": [], "self_evaluation": ""
}
```

### 关键字段策略

| 字段 | 策略 | 原因 |
|------|------|------|
| `job_intention` | 不传(undefined) | 后端仍可接收空 |
| `profile.school/degree/major/gradYear` | 保留(传空) | 后端 response 仍需这些摘要列 |
| `profile.school` | 前端 UI 不展示 | education[0].school 替代 |
| `target_direction` | `""` | K8-5-24-B 已有 |
| `target_role` | `""` | V1 兼容，无求取意向后为空 |
| `skills` | 新 3-key 结构 | 后端 `json.RawMessage` 接受 |
| `portfolio_links` | works+homepage | 同上 |
| `description` | `""` | 仍有后端列，不删除 |
| V1 兼容字段 | 全部保留 | 旧列表页/旧 adapter 依赖 |

## adapter / 回填策略

| 旧结构 | 新 UI | 回填策略 |
|--------|-------|---------|
| V2 `profile.school/degree/major/gradYear` | 基础信息已删除这些字段 | 不回填基础信息 → 转为 education[0] |
| V2 `job_intention.*` | 已删除求职意向模块 | 不回填任何字段 |
| V2 `skills.programming_languages + other_keywords` | developmentLanguages | `joinList([...pl, ...ok])` |
| V2 `skills.ai_tools + ai_application_scenarios` | aiApplication | `joinList([...at, ...aas])` |
| V2 `skills.backend_frameworks/frontend_technologies/databases/middleware/cloud_platforms/dev_tools` | (废弃) | 不回填 → 仅保留旧数据在 DB |
| old `portfolio.github` | works | → `{name:"GitHub", link:github}` |
| old `portfolio.gitee/cnb` | works | → `{name:"Gitee/CNB", link:...}` |
| old `portfolio.blog` | homepage | → homepage |
| old `portfolio.demo_links/portfolio_links` | works | → `[{name:"", link}]` (无名称) |
| V1 `skills[]` | developmentLanguages | → `joinList(skills)` |

## 状态栏设计冻结

| 状态项 | 新逻辑 |
|--------|-------|
| 完成度 % | 简历基础(必填) + 基础信息(4/4) + 教育(≥1 entry) + 项目(≥1 entry) + 技能(≥1 语言或 ≥1 工具) |
| 必填项 | 简历名称 + 姓名 + currentCity |
| 推荐项 | 教育≥1/项目≥1/技能≥1 语言 |
| `aiReady` | `!!(education.length>0 && (projects.length>0 \|\| internships.length>0) && skills.haveAny)` |
| 岗位推荐 available | `aiReady && hasResume` |
| 岗位匹配 available | `aiReady && 已选择岗位` |
| 简历优化 available | `aiReady && 已选择岗位` |
| 版本对比 available | `resume version≥2` |

## 是否需要改后端 / SQL / Snapshot / Agent

| 层 | 是否需要改 | 原因 |
|----|:---:|------|
| 后端 Go | ❌ 不改 | `CreateResumeRequest` 全部字段为 `json.RawMessage` — 接受任意 JSON 结构 |
| 后端 Response | ❌ 不改 | response 保留现有字段，前端从新字段读取 |
| SQL | ❌ 不改 | skills_json/portfolio_json/job_intention_json 等列均接受新内容 JSON |
| Snapshot | ❌ 不改 | `ResumeSnapshotSkills`/`ResumeSnapshotPortfolio` 保留旧结构; normalize 从 V1/V2 raw JSON 提取 — 新 payload 写旧列 → normalize 仍可读取 |
| Agent | ⏸️ 暂停 | 独立 K8-5-26-A |
| Adapter | ✅ 部分改 | displaySchool→education[0]; 回填映射函数 |
| Frontend | ✅ 全改 | 9 模块 UI + state + payload + backfill |
