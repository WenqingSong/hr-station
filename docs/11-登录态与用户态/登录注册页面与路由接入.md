## 八、为什么本阶段不保存 token

```
token storage 属于 8-3 范围。
8-2 只让用户能调用 login/register 接口并获得 token 响应。
登录成功后 navigate("/") 或 navigate("/login")，
刷新后不保持登录态（8-3 修复）。
```

---

## 九、为什么本阶段不做全局 token 注入

```
Authorization 自动注入属于 8-3 范围。
8-2 的 login/register 调用本身不需要 Authorization（后端公开接口）。
getMe 需要 token 作为参数，但本阶段不调用 me。
```

---

## 十、为什么本阶段不做 ProtectedRoute

```
路由鉴权需要全局登录态（token storage + 注入）和当前用户状态。
这些属于 8-3 + 8-4 范围。
当前所有页面仍然可通过 fallback 展示演示数据。
```
