## 5. 准入条件逐项评审

### 5.1 三类 Agent 接口可返回稳定结构

- MatchAnalysis：`POST /api/jobs/{id}/match` → `data.result` + `data.meta` ✅
- Recommendation：`POST /api/jobs/recommend` → `data.result.recommended_jobs` + `data.meta` ✅
- ResumeOptimization：`POST /api/resumes/optimize` → `data.result` + `data.meta` ✅

### 5.2 前端可统一读取 data.result

三类接口 `data.result` 均为业务结果容器，不含系统状态字段。前端统一从 `data.result` 读取业务数据。

### 5.3 前端可统一读取 data.meta

三类接口 `data.meta` 包含 8 个必填字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| agent_name | string | Agent 名称标识 |
| generated_by | string | llm_agent / mock_agent |
| agent_status | string | success / repaired / fallback / mock_success / error |
| fallback_reason | string | none / llm_error / json_repair_failed / schema_invalid / pipeline_error / llm_disabled |
| error_code | string | none / LLM_ERROR / JSON_REPAIR_FAILED / SCHEMA_INVALID / PIPELINE_ERROR 等 |
| repair_applied | bool | 是否经过 JSON repair |
| schema_valid | bool | 最终结果是否满足契约 |
| request_id | string | 请求追踪 ID |

### 5.4 Recommendation 可读取 data.result.recommended_jobs

新入口 `data.result.recommended_jobs` 已实现，旧入口 `data.recommended_jobs` 保留但 deprecated。

### 5.5 三类 Agent 共享字段已具备

| 字段 | MatchAnalysis | Recommendation | ResumeOptimization |
|------|:---:|:---:|:---:|
| apply_readiness | ✅ | ✅ | ✅ |
| optimization_stop_signal | ✅ | ✅ | ✅ |
| top_fix_items | ✅ | ✅ | ✅ |

### 5.6 fallback / mock / error 状态可被前端识别

前端展示规则：

| agent_status | generated_by | 前端展示 |
|-------------|-------------|---------|
| success | llm_agent | "AI 分析"（无特殊标记） |
| repaired | llm_agent | "AI 分析（已修复）" |
| fallback | mock_agent | "降级输出" + fallback_reason 友好文案 |
| mock_success | mock_agent | "规则分析"（降级提示） |
| error | — | 错误态，允许重试 |

### 5.7 Prompt 加载问题已修复

4-5.3-R 已在 `prompt.NewLoader` 和 `schema.NewLoader` 中添加 `resolveDir` 自动路径解析。三类接口不再出现 `prompt_load_failed`。
