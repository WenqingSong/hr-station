## 核心功能

### 1. 简历版本对比
学生上传多个版本简历后，系统自动分析各版本差异，展示技能、项目、实习等维度的版本演进。

### 2. 岗位智能推荐
基于学生简历语义画像，从岗位库中智能推荐最匹配的岗位。Fast 模式秒级判断，Deep 模式深度分析。

### 3. 岗位匹配分析 ⭐ 主推功能
**定位：初筛通过率诊断 + 简历命中率提升方案**

- **Fast**：秒级语义匹配，快速判断岗位是否适合投递
- **Deep**：5 个 Hy3 深度模块生成完整投递决策报告
  - A. 投递决策：分数 + 建议（可直接投递/修改后投递/备选/不建议投递/建议换方向）
  - B. 为什么可能过初筛：列出简历中的命中点，绑定真实证据
  - C. 为什么可能被筛掉：识别淘汰风险，说明影响和修复方向
  - D. 简历具体怎么改：before/after 改写示例，基于学生真实经历
  - E. 下一步投递策略：推荐更适合岗位方向，避免方向错位

### 4. 简历优化建议
AI 分析简历中的表达问题，给出具体的优化建议。

## 已知小问题

1. **nginx 502**：Docker nginx 与本地 Backend 网络不通，需通过 `docker compose -f docker-compose.prod.yml up -d` 方式部署，或将 Backend 也容器化。
2. 前端部分 chunk 较大（chunkSizeWarning），不影响功能。
3. 简历优化/岗位推荐 API 路径需确认（非核心演示功能）。
