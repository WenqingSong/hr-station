# 演示视频脚本（3分钟）

## 0:00-0:15 开场

大家好，我是 Offer 鹅。

我自己也是应届生，找工作的时候最头疼的就是：海投了几十个岗位，根本不知道哪个适合我，也不知道简历到底能不能过初筛。

所以我们做了 Offer 鹅——一个帮学生提高投递成功率的产品。

## 0:15-0:40 首页 + 我的简历

打开之后，先看到我的简历。我上传了不同版本的简历——从最早的基础版，到后来加了实习和项目经验的投递版。

Offer 鹅会自动帮我整理简历的语义画像，后面匹配岗位就是靠这个。

## 0:40-1:10 岗位推荐

然后看岗位推荐。系统会根据我的简历，从岗位库里找出最适合我的岗位。

这里每个岗位都有匹配分数，点进去就能看到详细分析。

## 1:10-2:10 ⭐ 岗位匹配 Deep（重点展示）

这是 Offer 鹅最核心的功能——岗位匹配。

我们看一个具体的例子。这是一份有后端实习和项目经验的简历，投的是腾讯的软件开发-后台开发岗位。

系统给出 78 分，结论是"修改后投递"——不是直接投，也不是不建议。

为什么这么说呢？往下看。它告诉我：
- 为什么能过初筛：因为我有后端实习、有项目经验、有 Java Spring MySQL 这些技术栈
- 为什么可能被筛：因为简历表达还不够工程化，没有把权限校验、缓存设计这些具体场景写清楚

最关键的是这个"简历怎么改"——它给我 before 和 after。比如我原来的项目写的是"负责后端接口开发、数据库表设计"，系统帮我改成了"基于 RESTful 规范设计接口、用 JWT 实现登录态管理、对敏感操作校验资源归属"——这就是 HR 初筛时想看到的关键词。

这不是我编的，全是基于我简历里真实的东西。

## 2:10-2:30 两个对比案例

同一个简历，如果投的是 NLP 算法岗位——分数直接掉到 33 分，建议换方向。系统帮你省时间，不会敷衍你说"可以考虑"。

再看一个基础版的简历投同样的岗位——42 分，不建议投。但不是你方向不对，是你还没有足够的项目证据。系统告诉你要先补一个什么项目。

## 2:30-2:50 Fast + 总结

回到岗位匹配页面，这是 Fast 模式——秒级判断，适合快速筛选岗位。Deep 模式就是刚才看到的完整分析。

总结一下：Offer 鹅帮学生做三件事——判断该不该投、简历怎么改、下一步投什么。不是打分工具，是投递决策引擎。
