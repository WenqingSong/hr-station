# Offer 鹅 — 方案说明

## 我们解决什么问题

校招投递是典型的"信息不对称"场景：学生拿着一份简历海投几十个岗位，HR用10秒筛掉一份简历。学生不知道简历能不能过初筛，不知道怎么写才能过，不知道哪些岗位值得投。

Offer 鹅的答案是：**把岗位JD和学生简历转化为可执行的投递决策**——该不该投、为什么会过、为什么会被筛、简历怎么改、下一步投什么。

## 四大功能闭环

**简历管理**：学生上传多版本简历，系统自动提取技能、项目、实习等维度的语义标签，形成个人能力画像。

**岗位推荐**：基于简历画像，从岗位库智能推荐最匹配的岗位。秒级Fast判断适合快速筛选，Deep深度分析适合重点岗位。

**岗位匹配分析（核心）**：点击任一岗位，系统给出5个维度的投递判断：
- A. 投递决策：分数+建议（修改后投递/备选/建议换方向），不是简单的"匹配度XX%"
- B. 初筛命中点：简历中哪些内容能让HR一眼看到匹配信号，每条绑定真实证据
- C. 初筛淘汰风险：为什么简历可能被筛掉，哪些关键技能缺失或表达不足
- D. 简历改写建议：具体的before/after示例，告诉学生"把A改成B"——不改经历，只改写表达
- E. 投递策略：如果不适合这个岗位，推荐更适合的方向

**简历优化**：AI分析简历表达问题，给出具体可操作的优化建议。

## 为什么岗位匹配是核心亮点

1. **不是打分工具**：传统岗位匹配只是"匹配度85%"，但不知道85%意味着什么。Offer 鹅明确告诉学生"你可以投，但要修改简历"——给出可执行的下一步。

2. **敢于说不**：当简历与岗位方向错位（如后端简历投NLP算法岗位），系统直接建议换方向，帮学生节省投递成本。

3. **有成长路径**：对于基础薄弱的学生，系统不直接打低分，而是告诉学生"先补一个什么类型的项目，再投递"。

4. **改写可执行**：每条简历改写都有before/after对照，学生可以直接把after放入简历。

5. **深度不是假深度**：Deep模式通过5个Hy3深度模块生成，投喂完整简历原文、岗位JD和语义画像，不是简单的规则拼接。
