## 阶段 3 执行约束

1. CodeBuddy 每次任务必须先读文档
2. 每次任务必须小颗粒度，一个 Prompt 只做一个任务
3. 每次任务必须更新项目状态、下一步任务、变更记录、开发日志
4. 阶段 3 只做核心业务后端 Mock
5. 阶段 3 可以修改 `server/` 和 `docs/`
6. 阶段 3 可以在明确授权时修改 `.env.example`、Makefile、docker-compose.yml
7. 阶段 3 可以写 SQL 表结构和种子数据
8. 阶段 3 可以写基础认证接口
9. 阶段 3 可以写简历、岗位、推荐、匹配、版本对比接口
10. 阶段 3 推荐 / 匹配 / 对比先返回 Mock JSON
11. 阶段 3 仍不接真实模型 API
12. 阶段 3 不修改前端页面业务逻辑
