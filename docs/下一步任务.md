## 阶段 4 执行约束

1. CodeBuddy 每次任务必须先读文档
2. 每次任务必须小颗粒度，一个 Prompt 只做一个任务
3. 每次任务必须更新项目状态、下一步任务、变更记录、开发日志
4. 阶段 4 可以修改 `server/` 和 `docs/`
5. 阶段 4 不改变已有 API 路径和响应主结构
6. 阶段 4 必须保留 Mock Agent 兜底
7. 阶段 4 不接真实模型（直到 4-2 实现 LLM Client）
8. 阶段 4 不改前端页面
9. 阶段 4 不自动生成优化版简历
10. 阶段 4 不修改用户简历内容
