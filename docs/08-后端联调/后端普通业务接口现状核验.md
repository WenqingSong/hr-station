# 后端普通业务接口现状核验

> 阶段：6-0 | 状态：已完成 | 日期：2026-05-31

## 1. 本阶段目标

摸清后端普通业务 API 的真实状态，为阶段 6 联调提供接口矩阵、差异清单和风险分级。

## 2. 核验范围

- 后端结构（Go 标准库 + net/http + MySQL）
- Jobs / Resumes 普通业务 API
- 响应结构契约
- 数据库 / SQL / Seed
- 鉴权 / 用户态
- 与前端契约的差异

## 3. 前端期望契约摘要

前端 API Client (`web/src/api/jobs.ts`, `resumes.ts`) 预期：

| API | 方法 | 路径 | 前端函数 |
|------|:--:|------|------|
| 岗位列表 | GET | `/api/jobs` | `fetchJobs()` |
| 岗位详情 | GET | `/api/jobs/{id}` | `fetchJobDetail(id)` |
| 当前简历 | GET | `/api/resumes/current` | `fetchCurrentResume()` |
| 简历版本列表 | GET | `/api/resumes/versions` | `fetchResumeVersions()` |
| 简历详情 | GET | `/api/resumes/detail` | `fetchResumeDetail()` |
| 新增简历 | POST | `/api/resumes` | `createResume()` |
| 版本对比 | GET | `/api/resumes/versions/compare` | `fetchVersionCompare()` |

前端响应契约：`{ code: number, message: string, data: any }`
