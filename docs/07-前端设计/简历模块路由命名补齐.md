# 简历模块路由命名补齐

> 阶段：5-3.2-R | 状态：已完成 | 日期：2026-05-31

## 1. 本阶段目标

将简历模块路由从 `/my-resumes*` 统一为 `/resumes*`，与 5-UX.0.1-A 冻结形态一致，并保留旧路径兼容。

## 2. 5-3.2 partial_pass 原因

5-3.2 完成了岗位路由统一（`/recommend` `/match` `/jobs/:id`），但简历模块路由仍为 `/my-resumes*`，未对齐冻结规范。

## 3. 修改前简历路由

```
/my-resumes          我的简历管理首页
/my-resumes/edit     修改简历
/my-resumes/compare  历史简历比较

（无 `/new` 路径，添加页复用编辑页组件）

```
/resumes             我的简历管理首页
/resumes/edit        修改简历
/resumes/new         添加简历（复用 MyResumesPage 组件）
/resumes/compare     历史简历比较页
