# 岗位匹配分析页接收上下文与演示态展示

> 阶段：5-4.3 | 状态：已完成 | 日期：2026-05-31

## 1. 本阶段目标

让岗位匹配分析页读取 URL 中的 `jobId`/`resumeId`，展示匹配上下文和来源。

## 2. 前置链路

- 5-4.1：`/match?jobId=xxx&resumeId=xxx`（详情页入口）
- 5-4.2：`/match?resumeId=xxx`（推荐页入口，缺 jobId）

## 3. `/match?jobId=xxx&resumeId=xxx` 读取方式

`JobMatchAnalysisPage` 使用 `useSearchParams()`：
```ts
const [searchParams] = useSearchParams();
const jobId = searchParams.get("jobId");
const resumeId = searchParams.get("resumeId");
```

## 4. jobId fallback 规则

| 场景 | 行为 | 来源标签 |
|------|------|------|
| 有 jobId，匹配到岗位 | 使用匹配岗位 | 已选择岗位 |
| 有 jobId，未匹配 | fallback `mockSelectedJob` | 默认岗位 |
| 无 jobId | fallback `mockSelectedJob` | 默认岗位 |

## 5. resumeId fallback 规则

| 场景 | 行为 | 来源标签 |
|------|------|------|
| 有 resumeId，匹配到简历 | 使用匹配简历 | 已选择简历 |
| 有 resumeId，未匹配 | fallback `mockCurrentResume` | 默认简历 |
| 无 resumeId | fallback `mockCurrentResume` | 默认简历 |
