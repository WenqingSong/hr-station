# 岗位推荐页接收上下文与演示态展示

> 阶段：5-4.2 | 状态：已完成 | 日期：2026-05-31

## 1. 本阶段目标

让岗位推荐页 URL 读取 `resumeId`，展示推荐上下文和来源，补齐 5-4.1 弹窗确认后的参数消费链路。

## 2. 5-4.1 已完成的入口链路

```
岗位列表 → SelectResumeModal → /recommend?resumeId=v2
```

## 3. `/recommend?resumeId=xxx` 读取方式

`JobRecommendationPage` 使用 `useSearchParams()`：
```ts
const [searchParams] = useSearchParams();
const resumeId = searchParams.get("resumeId");
```

## 4. 简历上下文 fallback 规则

| 场景 | 行为 |
|------|------|
| 有 `resumeId`，匹配到简历 | 使用匹配简历 + 来源「已选择简历」 |
| 有 `resumeId`，未匹配到 | fallback `mockCurrentResume` + 「默认简历」 |
| 无 `resumeId` | fallback `mockCurrentResume` + 「默认简历」 |

## 5. 页面展示内容

### RecommendationHeader
- 描述文案：「基于已选择简历」
- 新增「推荐来源」标签：`已选择简历` / `默认简历`

### RecommendationContext（右侧）
- 卡片标题：「当前用于推荐的简历」
- 新增来源标签

### RecommendationDetail
- 「进行岗位匹配分析」按钮带 `resumeId`：`/match?resumeId=xxx`

## 6. 修改清单

| 文件 | 修改 |
