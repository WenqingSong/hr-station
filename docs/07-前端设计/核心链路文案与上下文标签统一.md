# 核心链路文案与上下文标签统一

> 阶段：5-8.2 | 状态：已完成 | 日期：2026-05-31

## 1. 本阶段目标

统一推荐/匹配/优化三条核心链路的上下文标签和 AI 边界文案，移除暴露 Mock/静态数据的工程化表达。

## 2. 原问题

5-8.0 发现的 P1 问题：

| 编号 | 问题 |
|:--:|------|
| C-1/2 | 推荐页 "当前简历" vs "当前用于推荐的简历" 同一页不一致 |
| C-5/6 | 匹配页 "所选简历" 与推荐/优化页 "当前简历" 跨页不一致 |
| AI-5~11 | 7+ 个组件暴露 "Mock 演示状态/结果" 标签 |

## 3. 统一文案规则

| 维度 | 统一前（混乱） | 统一后 |
|------|------|------|
| 简历标签 | 当前简历/默认简历/已选择简历/所选简历/当前用于推荐的简历 | **当前简历** |
| 岗位标签 | 目标岗位/当前岗位/默认岗位/已选择岗位 | **目标岗位**（匹配/优化页） |
| 推荐来源 | 推荐来源：已选择简历/默认简历 | 推荐来源：当前简历（通过 props） |
| 分析来源 | 岗位来源 + 简历来源 双行 | **分析来源：基于目标岗位与当前简历** |
| 优化来源 | 岗位来源 + 简历来源 双行 | **优化来源：基于匹配分析结果** |
| Mock 标签 | Mock 演示状态/Mock 演示结果/兜底结果 | **演示数据** / **当前为演示数据** |

## 4. 修改范围

**仅修改核心链路（推荐/匹配/优化页面及其组件），不涉及简历管理模块。**
