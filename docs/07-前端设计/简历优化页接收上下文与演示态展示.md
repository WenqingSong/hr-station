# 简历优化页接收上下文与演示态展示

> 阶段：5-4.4 | 状态：已完成 | 日期：2026-05-31

## 1. 本阶段目标

让简历优化页读取 URL 中 jobId/resumeId，展示优化上下文，闭环匹配分析→优化带参链路。

## 2. 5-4.3 已完成的带参链路

```
/match?jobId=xxx&resumeId=xxx
→ "针对该岗位优化简历"
→ /resume-optimization?jobId=xxx&resumeId=xxx
```

## 3. 读取方式

`ResumeOptimizationPage` 使用 `useSearchParams()`：
```ts
const jobId = searchParams.get("jobId");
const resumeId = searchParams.get("resumeId");
```

## 4. fallback 规则

| 参数 | 有匹配→ | 缺/无效→ |
|------|------|------|
| jobId | 匹配岗位 +「来自岗位匹配分析」 | mockSelectedJob +「默认岗位」 |
| resumeId | 匹配简历 +「来自岗位匹配分析」 | mockCurrentResume +「默认简历」 |
