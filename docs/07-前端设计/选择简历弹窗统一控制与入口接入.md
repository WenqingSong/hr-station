# 选择简历弹窗统一控制与入口接入

> 阶段：5-4.1 | 状态：已完成 | 日期：2026-05-31

## 1. 本阶段目标

将 SelectResumeModal 接入岗位列表推荐按钮和岗位详情匹配按钮两个 P0 入口，替代直接裸跳。

## 2. 5-4.0 发现的 P0 断点

| 断点 | 入口 | 问题 |
|------|------|------|
| BP-1 | AIDecisionWorkspace | 推荐按钮直接 navigate("/recommend") |
| BP-2 | JobDetailAIDecision | 匹配按钮直接 navigate("/match") |
| BP-3 | — | 无 resumeId 传递 |
| BP-4 | — | 无 jobId 传递 |

## 3. 入口 1：岗位列表页推荐按钮

**文件**：`components/AIDecisionWorkspace.tsx`

改造：
```diff
- import React from "react";
+ import React, { useState } from "react";
+ import { SelectResumeModal } from "./SelectResumeModal";
+ const [isResumeModalOpen, setIsResumeModalOpen] = useState(false);
+ const handleConfirmRecommend = (resumeId: string) => {
+   navigate(`/recommend?resumeId=${encodeURIComponent(resumeId)}`);
+ };
- onClick={() => navigate("/recommend")}
+ onClick={() => setIsResumeModalOpen(true)}
```

弹窗：
```tsx
<SelectResumeModal
  isOpen={isResumeModalOpen}
  onClose={() => setIsResumeModalOpen(false)}
  onConfirm={handleConfirmRecommend}
  scene="recommendation"
/>
```

跳转 URL：`/recommend?resumeId=v2`

## 4. 入口 2：岗位详情页匹配按钮

**文件**：`components/JobDetailAIDecision.tsx`

改造：
```diff
- import React from "react";
+ import React, { useState } from "react";
+ import { useParams } from "react-router";
+ import { SelectResumeModal } from "./SelectResumeModal";
+ const { id: routeJobId } = useParams();
+ const jobId = routeJobId || mockSelectedJob.id;
+ const [isResumeModalOpen, setIsResumeModalOpen] = useState(false);
+ const handleConfirmMatch = (resumeId: string) => {
+   navigate(`/match?jobId=${encodeURIComponent(jobId)}&resumeId=${encodeURIComponent(resumeId)}`);
+ };
- onClick={() => navigate("/match")}
+ onClick={() => setIsResumeModalOpen(true)}
```

弹窗：
```tsx
<SelectResumeModal
  isOpen={isResumeModalOpen}
  onClose={() => setIsResumeModalOpen(false)}
  onConfirm={handleConfirmMatch}
  scene="match-analysis"
  jobTitle={jobVm.title}
/>
```

跳转 URL：`/match?jobId=xxx&resumeId=v2`

jobId 策略：优先 `useParams().id`，缺失时 fallback `mockSelectedJob.id`。

## 5. SelectResumeModal 复用方式

| 属性 | AIDecisionWorkspace | JobDetailAIDecision |
|------|:--:|:--:|
| `isOpen` | `isResumeModalOpen` state | `isResumeModalOpen` state |
| `onClose` | 关闭 state | 关闭 state |
| `onConfirm` | navigate + URL params | navigate + URL params |
| `scene` | `"recommendation"` | `"match-analysis"` |
| `jobTitle` | — | `jobVm.title` |

## 6. URL 参数规则

| 入口 | URL |
|------|------|
| 推荐入口 | `/recommend?resumeId=v2` |
| 匹配入口 | `/match?jobId=xxx&resumeId=v2` |

使用 `encodeURIComponent()` 编码。
