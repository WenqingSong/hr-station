## 4. 旧路径兼容策略

| 旧路径 | 策略 | 实现 |
|------|------|------|
| `/job/:id` | 复用同一组件 | `{ path: "job/:id", Component: JobDetailPage }` |
| `/recommendations` | 重定向 | `<Navigate to="/recommend" replace />` |
| `/match-analysis` | 重定向 | `<Navigate to="/match" replace />` |
| `/resume-comparison` | 重定向 | `<Navigate to="/my-resumes/compare" replace />`（已有） |

旧路径仅为兼容保留，不作为后续开发主路径。后续清理阶段可安全移除。

## 5. 页面入口关系整理

| 页面 | 入口方式 | 路径 |
|------|------|------|
| 岗位列表页 | Navbar 品牌 / index | `/` `/jobs` |
| 岗位详情页 | JobCard 点击 | `/jobs/:id` |
| 岗位推荐页 | AIDecisionWorkspace 按钮 | `/recommend` |
| 岗位匹配分析页 | JobDetailAIDecision 按钮 | `/match` |
| 简历优化页 | MatchAnalysisDetail 按钮 | `/resume-optimization` |
| 我的简历管理 | Navbar 右侧 | `/my-resumes` |
| 修改/添加简历 | 简历管理页按钮 | `/my-resumes/edit` |
| 历史简历比较 | 简历管理页按钮 | `/my-resumes/compare` |

## 6. Navbar 路由边界

- 左侧品牌 Link → `/jobs`
- 右侧"我的简历" Link → `/my-resumes`
- Navbar 不承载岗位推荐/匹配分析/简历优化入口
- 无禁止导航项
