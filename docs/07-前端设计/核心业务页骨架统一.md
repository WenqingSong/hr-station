# 核心业务页骨架统一

> 阶段：5-3.3 | 状态：已完成 | 日期：2026-05-31

## 1. 本阶段目标

统一 5 个核心业务页（岗位列表/详情/推荐/匹配分析/简历优化）的页面骨架，保证宽度、间距、结构一致。

## 2. 改造前问题

| 问题 | 页面 |
|------|------|
| 各自带 `min-h-screen` 外层（与 RootLayout 重复） | 全部 5 页 |
| 各自设 `bg-[#F3F4F6]` 背景（与 RootLayout `bg-[#F5F7FA]` 冲突） | 全部 5 页 |
| 各自设 `font-sans text-gray-900 selection:...`（RootLayout 已处理） | 全部 5 页 |
| 岗位详情页 `max-w-[1200px]`，其他 `max-w-[1440px]` | JobDetailPage |
| padding 不一致（`py-8` vs `py-6`） | JobListPage/JobDetailPage |
| 不必要的 `justify-center` | 3 页有 header 的页面 |

## 3. 改造后统一规则

```
容器：mx-auto max-w-[1440px] px-6 md:px-8 py-6
底部：pb-12（有 header 的页面）
背景：由 RootLayout 统一管理
字体：由 RootLayout 统一管理
```

## 5. 统一要点

| 规则 | 值 |
|------|------|
| 页面最大宽度 | `max-w-[1440px]` |
| 左右 padding | `px-6 md:px-8` |
| 上下间距 | `py-6` |
| 底部留白 | `pb-12`（header 页面） |
| 三栏间距 | `gap-6` |
| 对齐 | `items-start`（非 `justify-center`） |
| 背景 | 由 RootLayout 统一 |
| 字体 | 由 RootLayout 统一 |
