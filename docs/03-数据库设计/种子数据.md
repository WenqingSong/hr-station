## 当前状态

阶段 3 方案已创建，已明确种子数据范围。数据库已可连接（阶段 2-5 已完成）。阶段 3-2 将写入种子数据。本次 3-1 不写具体种子数据。

## 种子数据策略

Demo 阶段不单独创建复杂种子系统，后续岗位库种子数据也写入 `server/sql/init.sql`。

### 约定

1. 种子数据与表结构统一维护在 `server/sql/init.sql`
2. 不单独创建种子数据加载脚本
3. Demo 阶段优先稳定可重建
4. 阶段 3-2 才写具体种子数据

## 导入方式

清空 volume 后，通过 init.sql 重新导入：

```bash
docker compose down -v
make up
docker compose exec mysql mysql -uroot -ppassword offer_catcher < server/sql/init.sql
```
