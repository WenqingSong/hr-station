## 当前状态

已预留 `server/sql/init.sql`，当前不写真实岗位数据。阶段 2 只连接数据库，阶段 3 才写种子数据。

## 种子数据策略

Demo 阶段不单独创建复杂种子系统，后续岗位库种子数据也写入 `server/sql/init.sql`。

### 约定

1. 种子数据与表结构统一维护在 `server/sql/init.sql`
2. 不单独创建种子数据加载脚本
3. Demo 阶段优先稳定可重建
4. 当前阶段不写真实岗位数据
5. 阶段 2 不写种子数据，只连接数据库
6. 阶段 3 才写岗位库和示例用户等数据

## 种子数据范围

| 数据 | 说明 | 填写阶段 |
|------|------|---------|
| 示例用户 | 用于 Demo 演示的测试账号 | 阶段 3 |
| 示例简历 | 包含完整信息的示例简历 | 阶段 3 |
| 示例岗位 | 覆盖不同方向的技术岗位 | 阶段 3 |
| 示例匹配结果 | 展示匹配分析功能的样例数据 | 阶段 3 |

## 导入方式

清空 volume 后，通过 init.sql 重新导入：

```bash
docker compose down -v
make up
docker compose exec mysql mysql -uroot -ppassword offer_catcher < server/sql/init.sql
```
