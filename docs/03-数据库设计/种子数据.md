## 种子数据策略

Demo 阶段不单独创建复杂种子系统，种子数据与表结构统一维护在 `server/sql/init.sql`。

### 约定

1. 种子数据与表结构统一维护在 `server/sql/init.sql`
2. 不单独创建种子数据加载脚本
3. Demo 阶段优先稳定可重建
4. 使用 `INSERT` 语句直接插入，配合 `DROP TABLE` 可重复执行

| 数据来源 | external_source | data_quality | is_featured |

| 本地 Mock 岗位 | local_mock | manual_enriched | 1（精选） |

本地 Mock 岗位继续保留，用于稳定 Demo 和兜底；腾讯岗位提供真实岗位池。
