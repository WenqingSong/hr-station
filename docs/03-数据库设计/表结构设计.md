# 表结构设计

> 最后更新：2026-05-29（阶段 4-1.2.6 阶段 4-1.2 汇总）

## 1. 设计目标

阶段 3 数据库设计服务于核心业务 Mock 闭环：

- 用户注册 / 登录
- 单主简历版本管理
- 岗位列表与详情
- 推荐 / 匹配 / 版本对比结果存储

设计原则：先简后繁，Demo 阶段用 JSON 字段存储复杂结构，不做过度范式化。

## 9. 单主简历设计说明

**核心决策**：不设计 `resumes` 多简历表。

理由：
1. 用户只有一份主简历，每次添加简历就是新增一个版本
2. 版本号 `version_no` 从 1 递增，由业务层维护
3. 历史版本只读，不能编辑或删除
4. 符合"单主线迭代"产品理念（V1→V2→V3）
5. `uk_resume_user_version (user_id, version_no)` 保证同一用户版本号唯一

## 10. JSON 字段设计说明

| 表 | JSON 字段 | 存储内容 |
|----|-----------|---------|
| resume_versions | education_json | 教育经历数组 `[{school, major, degree, start_date, end_date}]` |
| resume_versions | experience_json | 工作经历数组 `[{company, position, start_date, end_date, description}]` |
| resume_versions | project_json | 项目经历数组 `[{name, role, start_date, end_date, description}]` |
| resume_versions | skills_json | 技能列表 `["Go", "MySQL", "Redis"]` |
| jobs | skill_keywords_json | 技能关键词 `["Go", "Kubernetes"]` |
| recommendation_results | result_json | 推荐结果（推荐岗位/理由/亮点/风险/优先级） |
| match_analyses | result_json | 匹配分析（分数/证据链/风险/优化建议/真实性提示） |
| version_compare_results | result_json | 版本对比（分数变化/字段变化/风险变化/建议完成/总结） |

所有 JSON 字段已通过 `JSON_VALID()` 验证。

## 13. 腾讯岗位数据后续适配方向

> 4-1.2.1 接入方案中明确的 jobs 表适配方向，具体表结构变更放到 4-1.3 执行。

### 13.1 建议新增字段

| 字段 | 类型 | 用途 | 优先级 |
|------|------|------|--------|
| external_source | VARCHAR(50) | 数据来源（tencent_join / local_mock） | P0 |
| external_id | VARCHAR(100) | 腾讯岗位 postId | P0 |
| external_inner_id | INT | 腾讯列表内部 id | P1 |
| source_url | VARCHAR(500) | 公开详情页 URL | P0 |
| raw_json | JSON | 原始列表 + 详情响应 | P0 |
| data_quality | VARCHAR(20) | 数据质量标记（full_jd / summary_only / manual_enriched） | P1 |
| is_featured | TINYINT(1) DEFAULT 0 | 是否 Demo 精选岗位 | P2 |
| synced_at | DATETIME | 同步时间 | P1 |

### 13.2 data_quality 含义

| 值 | 含义 | 数据来源 |
|----|------|---------|
| full_jd | 完整 JD（desc + request） | 岗位详情接口 |
| summary_only | 仅列表摘要 | 列表接口，详情未获取 |
| manual_enriched | 人工补充/本地 Mock | 种子数据 |

### 13.3 字段映射核心规则

| 腾讯详情字段 | jobs 字段 | 映射方式 |
|-------------|----------|---------|
| title | title | 直接映射 |
| desc | description | 直接映射 |
| request | requirements | 直接映射 |
| tidName | category | 直接映射 |
| intentionBGDList[0].showTitle | department | 取第一个 |
| workCityList | city | 逗号拼接 |
| projectName | job_type | 直接映射 |
| postId | external_id | 直接映射 |
| 完整响应 | raw_json | JSON 存储 |

- 具体表结构变更在 4-1.3 执行
