## 一、本阶段目标

## 二、MyResumesPage 原保存问题

| 问题 | 原行为 |
|------|------|
| 保存按钮 | `onClick={() => setSavedHint(true)}`（不调 API） |
| 成功提示 | `"已保存本次演示修改"` |
| add 模式 | 不调 `createResume` |
| edit 模式 | 不调 `updateResume` |
| 失败处理 | 无（save 永远"成功"） |

| 文件 | 操作 |
|------|:--:|
| `web/src/app/pages/MyResumesPage.tsx` | 修改 |

## 四、add 模式保存接入

- 调用 `createResume(payload)` → `POST /api/resumes`
- 成功提示：`"简历已创建成功"`

## 五、edit 模式保存接入

- 调用 `updateResume("", payload)` → `POST /api/resumes`（版本迭代模型）
- 成功提示：`"修改已保存，已生成新的简历版本"`

## 六、保存请求字段映射

| 表单 state | 请求字段 |
|------|------|
| `resumeName \|\| personalName` | `name` |
