## 一、本阶段目标

## 二、MyResumesPage 原问题

| 问题 | 原行为 | 本阶段处理后 |
|------|------|------|
| edit 模式数据源 | `loadCurrentResumeSummaryViewModel` → 仅回填 name | `loadResumeManagementPageViewModel` → 完整回填 |
| 个人姓名 | `useState("测试候选人 A")` | `personalName` from VM |
| 学校 | `useState("某大学")` | `school` from VM |
| 手机/邮箱 | 虚假数据 | VM 真实数据或空 |
| 教育经历 | 硬编码"某大学" | `education[]` from VM |
| 实习经历 | 硬编码"ExampleTech" | `experiences[]` from VM |
| 项目经历 | 硬编码 3 个项目 | `projects[]` from VM |
| 技能 | 硬编码 8 个技能 | `skills[]` from VM |
| 自我评价 | 硬编码文本 | `selfEvaluation` from VM |
| add 模式 | `"V3 新简历"` + 硬编码 | 空表单 |
| 保存按钮 | `setSavedHint(true)` | 不变（留到 9-3） |

## 四、字段映射结果

| 表单字段 | VM 来源 | 映射逻辑 |
|------|------|------|
| `personalName` | `vm.displayName` | 非"暂未填写"才回填 |
| `phone` | `vm.displayPhone` | 直接映射 |
| `email` | `vm.displayEmail` | 直接映射 |
| `school` | `vm.displaySchool` | 非"暂未填写"才回填 |
| `major` | `vm.displayMajor` | 直接映射 |
| `direction` | `vm.directionLabel` | 非"暂未填写"才回填 |
| `cities` | `vm.displayLocation` | 非"暂未填写"才回填 |
| `educations[]` | `vm.education[]` (ResumeEducation) | `{id, school, major, degree, startDate(end_date→startDate), ...}` |
| `internships[]` | `vm.experiences[]` (ResumeExperience) | `{id, company, position(role), startDate(end_date→startDate), content(description)}` |
| `projects[]` | `vm.projects[]` (ResumeProject) | `{id, name, stack(tech_stack.join), desc(description), role(responsibilities.join)}` |
| `skills[]` | `vm.skills[]` | Array.isArray 守卫 → 直接映射 |
| `summary` | `vm.selfEvaluation` | 直接映射 |
