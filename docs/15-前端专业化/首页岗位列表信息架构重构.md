# 首页岗位列表信息架构重构

## 背景

首页 `/jobs` 原有设计混合了"岗位列表"和"AI 决策"两套信息架构，导致用户困惑：首页标题和右侧模块暗示这是 AI 决策页，但实际只是一个岗位列表页。

## 修改目标

把 `/jobs` 改成标准岗位列表页：

- **左侧**：真实筛选
- **中间**：真实岗位列表
- **右侧**：简历状态 + 下一步引导

## 修改内容

### 1. 岗位卡片（JobCard.tsx）

- 移除 `selected` / `onSelect` 双按钮模式
- "选择岗位"→"查看详情"，点击卡片直接进入详情
- 不再维护"已选择"状态

### 2. 岗位列表（JobList.tsx）

- 移除 `selectedJobId` / `onSelectedJobIdChange` 传递
- 副标题改为："浏览当前开放岗位，按方向、城市和岗位类别筛选适合你的机会。"

### 3. 首页页面（JobListPage.tsx）

- 移除 `selectedJobId` 状态
- 不再向右侧传递选中岗位

### 4. 右侧区域（AIDecisionWorkspace.tsx）

- 移除"当前选择岗位"卡片（含 Target 图标、分析匹配度按钮）
- 移除 `SelectResumeModal`（推荐场景弹窗，与首页无关）
- 移除 `selectedJobId` prop 及关联的岗位详情加载
- 改为纯引导式三状态：

| 状态 | 展示 |
|------|------|
| 未登录 | 登录后使用 AI 求职决策 → 登录/注册按钮 |
| 已登录无简历 | 完善简历后开始智能推荐 → 去创建简历 |
| 已登录有简历 | 当前简历摘要 + "推荐适合的岗位"按钮 → `/recommend` |

## 未修改

- 匹配分析页（JobMatchAnalysisPage）
- 简历优化页（ResumeOptimizationPage）
- 后端代码
- API 层
