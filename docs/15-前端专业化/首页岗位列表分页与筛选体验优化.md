# 首页岗位列表分页与筛选体验优化

## 背景

首页 `/jobs` 之前没有分页，筛选面板视觉像静态 checkbox 列表，不像专业求职产品。

## 修改内容

### 后端（1 文件）

- `server/internal/http/job_handler.go`：新增 `page`/`page_size` 参数支持，`offset=(page-1)*page_size`，保留 `limit`/`offset` 向后兼容

### 前端（4 文件）

| 文件 | 修改 |
|------|------|
| `api/jobs.ts` | `JobListParams` 改为 `page`/`page_size`；`buildQuery` 对应更新 |
| `pages/JobListPage.tsx` | `useSearchParams` 实现 URL 同步（keyword/direction/city/recruit_type/category/page），筛选/搜索变更重置 page=1 |
| `components/JobList.tsx` | 新增分页组件（页码按钮/上一页/下一页/总岗位数/总页数）；loading 时禁用；只有 >1 页时显示 |
| `components/JobFilterSidebar.tsx` | 视觉重构：搜索框独立区域、选中项蓝色高亮+Check 图标、count 数字弱化、已选 chip 可点击清除、清空筛选按钮 |

## 关键设计

### 分页
- `page_size=10`
- 页码冲突/搜索/筛选变更 → 自动回到 `page=1`
- URL 同步所有筛选参数 + page
- 空数据不显示分页
- loading 时分页按钮 disabled

### 筛选
- count 全部来自 `/api/jobs/facets` 真实数据
- 无静态数字
- facets 失败显示"筛选条件加载失败"

## 验证

- `npm run build` ✅
- `curl /api/jobs?page=1&page_size=3` → total=8, items=3 ✅
- `curl /api/jobs?page=2&page_size=3` → total=8, items=3（不同岗位）✅
- `curl /api/jobs?keyword=Go&page=1&page_size=5` → total=5 ✅
- 无"选择岗位"/"Mock 演示"残留 ✅
- 无静态数字 ✅
