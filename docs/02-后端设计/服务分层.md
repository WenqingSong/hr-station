## 分层架构

```
Handler（控制器层）
  ↓
Service（业务逻辑层）
  ↓
Repository（数据访问层）
  ↓
Model（数据模型）
```

### Handler 层

- 接收 HTTP 请求，参数校验
- 调用 Service 层处理业务
- 返回统一格式的响应

### Service 层

- 业务逻辑处理
- 调用 Repository 层操作数据
- 调用 Agent 层获取 AI 结果
- 事务管理

### Repository 层

- 数据库 CRUD 操作
- 缓存读写
- 数据模型转换

### Agent 层

- AI 模型调用封装
- Prompt 管理
- Mock Agent 实现（前期）
