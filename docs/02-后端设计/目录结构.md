## 1. 当前后端目录

```
server/
├── go.mod                     # Go module 定义（offer-catcher/server）
├── README.md                  # 后端说明文档
├── cmd/
│   └── server/
│       └── main.go            # 程序入口
├── internal/
│   ├── config/
│   │   └── config.go          # 配置读取（阶段 1 已实现，2-2 增强）
│   ├── database/              # MySQL 连接管理（2-5 ✅ 已创建）
│   │   └── mysql.go
│   ├── response/              # 统一响应结构（2-3 ✅ 已创建）
│   │   └── response.go
│   ├── errors/                # 应用错误定义（2-3 ✅ 已创建，包名 apperror）
│   │   └── error.go
│   ├── http/
│   │   ├── router.go          # HTTP 路由与 Handler（阶段 1 已实现，2-3/2-4/2-6/3-3 修改）
│   │   └── auth_handler.go    # 认证 Handler（3-3 ✅ 已创建）
│   ├── middleware/             # 中间件（2-4 ✅ 已创建，3-3 新增 Auth）
│   │   ├── logger.go          # RequestLogger
│   │   ├── cors.go            # CORS
│   │   ├── recover.go         # Recover
│   │   └── auth.go            # JWT Auth（3-3 ✅ 已创建）
│   ├── health/                # 健康检查（2-6 ✅ 已创建）
│   │   └── service.go         # 健康检查服务，聚合 app/database 状态
│   ├── model/                 # 数据模型（阶段 3 实现）
│   ├── repository/            # 数据访问层（阶段 3 实现）
│   ├── service/               # 业务逻辑层（阶段 3 实现）
│   ├── agent/                 # AI Agent（阶段 3 Mock / 阶段 4 真实）
│   └── llm/                   # LLM 调用（阶段 4 实现）
└── sql/
    └── init.sql               # 数据库初始化脚本（阶段 3 填写）
```

## 文件命名规范

- Go 文件使用英文小写 + 下划线
- 示例：`user_handler.go`、`resume_service.go`、`match_mock.go`
- 不使用中文命名代码文件
- `internal/http/` 目录下包名使用 `httpserver`，避免与标准库 `net/http` 包名冲突
