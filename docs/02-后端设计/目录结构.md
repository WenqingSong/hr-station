# 目录结构

> 最后更新：2026-05-28（阶段 1-5 初始化 Go 后端工程目录）

## 1. 当前后端目录

```
server/
├── go.mod                     # Go module 定义（offer-catcher/server）
├── README.md                  # 后端说明文档
├── cmd/
│   └── server/
│       └── main.go            # 程序入口
├── internal/
│   ├── config/
│   │   └── config.go          # 配置读取（已实现）
│   ├── http/
│   │   └── router.go          # HTTP 路由与 Handler（已实现 /healthz）
│   ├── middleware/             # 中间件（阶段 2 实现）
│   ├── model/                 # 数据模型（阶段 3 实现）
│   ├── repository/            # 数据访问层（阶段 3 实现）
│   ├── service/               # 业务逻辑层（阶段 3 实现）
│   ├── agent/                 # AI Agent（阶段 3 实现）
│   └── llm/                   # LLM 调用（阶段 4 实现）
└── sql/
    └── init.sql               # 数据库初始化脚本（阶段 3 填写）
```

## 4. 当前阶段实现范围

阶段 1-5 只实现：

1. Go module（`offer-catcher/server`）
2. 基础 HTTP Server（使用 Go 标准库 `net/http`）
3. `/healthz` 健康检查接口
4. 基础配置读取（`APP_ENV`、`LOG_LEVEL`、`SERVER_PORT`）
5. 预留业务分层目录
6. 预留 SQL 初始化文件

## 文件命名规范

- Go 文件使用英文小写 + 下划线
- 示例：`user_handler.go`、`resume_service.go`、`job_match_agent.go`
- 不使用中文命名代码文件
- `internal/http/` 目录下包名使用 `httpserver`，避免与标准库 `net/http` 包名冲突
