## 规划目录结构

```
server/
├── cmd/
│   └── server/
│       └── main.go          # 入口文件
├── internal/
│   ├── handler/             # HTTP Handler（控制器层）
│   ├── service/             # 业务逻辑层
│   ├── repository/          # 数据访问层
│   ├── model/               # 数据模型
│   ├── middleware/           # 中间件
│   ├── agent/               # AI Agent 封装
│   └── config/              # 配置管理
├── pkg/                     # 可导出的公共包
├── migrations/              # 数据库迁移文件
├── seeders/                 # 种子数据
├── go.mod
├── go.sum
└── Makefile
```
