## 错误码规范

| 范围 | 说明 |
|------|------|
| 0 | 成功 |
| 10000-19999 | 通用错误（参数错误、未授权等） |
| 20000-29999 | 用户相关错误 |
| 30000-39999 | 简历相关错误 |
| 40000-49999 | 岗位相关错误 |
| 50000-59999 | AI/Agent 相关错误 |

## HTTP 状态码使用

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
