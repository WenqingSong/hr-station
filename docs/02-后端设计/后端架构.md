# 后端架构

## 当前状态

待初始化（server/ 目录为空）

## 技术选型

- **语言**：Go
- **框架**：Gin（轻量 Web 框架）
- **数据库**：MySQL 8.0
- **缓存**：Redis 7
- **ORM**：GORM

## 整体架构

```
客户端 → Nginx → Gin API Server → MySQL
                              ↓
                           Redis（缓存/Session）
                              ↓
                        Agent 服务（AI 调用）
```
