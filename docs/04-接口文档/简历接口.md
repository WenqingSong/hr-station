# 简历接口

> 最后更新：2026-05-29（阶段 3-4 实现简历版本接口）

## 1. 当前实现状态

✅ 已实现。5 个简历版本接口全部可用：
- POST /api/resumes — 新增简历版本
- GET /api/resumes/current — 获取当前（最新版本）简历
- GET /api/resumes/detail — 获取简历详情（同 current）
- GET /api/resumes/versions — 获取版本列表
- GET /api/resumes/versions/{versionNo} — 获取指定版本

所有简历接口需要 JWT 认证（Bearer Token）。

## 2. 产品规则

1. **单主简历**：用户只有一份主简历，不设计多简历
2. **版本管理**：每次 POST /api/resumes 都创建一个新版本（V1, V2, V3...）
3. **所有字段可选**：降低填写压力
4. **历史版本只读**：不能编辑或删除历史版本
5. **不做文件上传**：只支持结构化表单录入
6. **不自动生成优化版简历**：只给诊断和建议

## 4. POST /api/resumes

新增一个简历版本。系统自动分配版本号（当前最大版本号 + 1）。

### 请求头

```
Authorization: Bearer <token>
Content-Type: application/json
```

### 请求

所有字段均为可选：

```json
{
  "name": "string",
  "phone": "string",
  "email": "string",
  "location": "string",
  "target_city": "string",
  "target_role": "string",
  "education": [{ "school": "...", "major": "...", "degree": "...", "start_date": "...", "end_date": "..." }],
  "experience": [{ "company": "...", "position": "...", "start_date": "...", "end_date": "...", "description": "..." }],
  "project": [{ "name": "...", "role": "...", "start_date": "...", "end_date": "...", "description": "..." }],
  "skills": ["Go", "MySQL", "Redis"],
  "self_evaluation": "string",
  "raw_text": "string"
}
```

- `education`、`experience`、`project`：JSON 数组，为空时默认存储 `[]`
- `skills`：JSON 数组，为空时默认存储 `[]`
- 所有字段可选填

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 3,
    "version_no": 3,
    "name": "Arthur",
    "phone": "",
    "email": "",
    "location": "",
    "target_city": "深圳",
    "target_role": "Go 后端开发工程师",
    "education": [],
    "experience": [],
    "project": [],
    "skills": ["Go", "MySQL", "Docker"],
    "self_evaluation": "具备后端开发与云计算基础",
    "raw_text": "",
    "created_at": "2026-05-29T10:00:00+08:00"
  }
}
```

### 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 未认证 | 40100 | unauthorized | 401 |
| JSON 解析失败 | 40001 | invalid request body | 400 |
| 方法不允许 | 40500 | method not allowed | 405 |

## 5. GET /api/resumes/current

获取当前用户的最新版本简历。

### 请求头

```
Authorization: Bearer <token>
```

### 成功响应（有简历）

返回 version_no 最大的版本完整数据。

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 2,
    "version_no": 2,
    "name": "Arthur",
    "...": "完整简历数据"
  }
}
```

### 成功响应（无简历）

```json
{
  "code": 0,
  "message": "ok",
  "data": null
}
```

### 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 未认证 | 40100 | unauthorized | 401 |

## 6. GET /api/resumes/detail

获取简历详情（等同于 current，返回最新版本完整数据）。

### 请求头

```
Authorization: Bearer <token>
```

响应格式同 `/api/resumes/current`。

## 7. GET /api/resumes/versions

```json
  "message": "ok",
  "data": {

        "id": 2,
        "version_no": 2,
        "name": "Arthur",
        "target_city": "深圳",
        "target_role": "后端开发工程师",
        "created_at": "2026-05-29T14:00:00+08:00"
      },
      {
        "id": 1,
        "version_no": 1,
        "name": "Arthur",
        "target_city": "深圳",
        "target_role": "后端开发工程师",
        "created_at": "2026-05-29T10:00:00+08:00"

    "total": 2

```

## 8. GET /api/resumes/versions/{versionNo}

获取指定版本号的简历详情。

### 请求头

```
Authorization: Bearer <token>
```

### 路径参数

| 参数 | 类型 | 说明 |
|------|------|------|
| versionNo | int | 版本号（必须 ≥ 1） |

### 成功响应

返回该版本号的完整简历数据。

### 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 未认证 | 40100 | unauthorized | 401 |
| 版本号无效 | 40001 | invalid version number | 400 |
| 版本不存在 | 42001 | resume version not found | 404 |
| 缺少版本号 | 40001 | version number is required | 400 |

## 9. 错误响应

所有错误响应使用统一格式：

```json
{
  "code": 42001,
  "message": "resume version not found",
  "data": null
}
```

### 简历错误码

| 错误码 | 说明 |
|--------|------|
| 42001 | 简历版本不存在 |
