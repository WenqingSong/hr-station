# 简历接口

> 最后更新：2026-05-29（阶段 3-1 创建阶段 3 核心业务后端 Mock 方案）

## 当前状态

阶段 3 方案已创建，接口已规划。阶段 3-4 将实现简历版本接口。

## 接口列表

| 方法 | 路径 | 说明 | 认证 | 实现任务 |
|------|------|------|------|---------|
| POST | `/api/resumes` | 新增简历版本 | ✅ | 3-4 |
| GET | `/api/resumes/current` | 获取当前（最新版本）简历 | ✅ | 3-4 |
| GET | `/api/resumes/detail` | 获取简历详情 | ✅ | 3-4 |
| GET | `/api/resumes/versions` | 获取版本列表 | ✅ | 3-4 |
| GET | `/api/resumes/versions/:versionNo` | 获取指定版本 | ✅ | 3-4 |

## 核心设计

1. **单主简历**：用户只有一份主简历，不设计多简历
2. **版本管理**：每次添加简历就是新增一个版本（V1, V2, V3...）
3. **所有字段可选**：降低填写压力
4. **历史版本只读**：不能编辑或删除历史版本
5. **不做文件上传**：只支持结构化表单录入

## 1. POST /api/resumes

新增一个简历版本。系统自动分配版本号（当前最大版本号 + 1）。

### 请求头

```
Authorization: Bearer <token>
```

### 请求

```json
{
  "name": "string, 可选",
  "phone": "string, 可选",
  "email": "string, 可选",
  "location": "string, 可选",
  "target_city": "string, 可选",
  "target_role": "string, 可选",
  "education": [
    {
      "school": "string",
      "major": "string",
      "degree": "string",
      "start_date": "string",
      "end_date": "string"
    }
  ],
  "experience": [
    {
      "company": "string",
      "position": "string",
      "start_date": "string",
      "end_date": "string",
      "description": "string"
    }
  ],
  "project": [
    {
      "name": "string",
      "role": "string",
      "start_date": "string",
      "end_date": "string",
      "description": "string"
    }
  ],
  "skills": ["string"],
  "self_evaluation": "string, 可选"
}
```

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "version_no": 1,
    "name": "张三",
    "phone": "13800138000",
    "email": "zhangsan@example.com",
    "location": "北京",
    "target_city": "北京",
    "target_role": "后端开发工程师",
    "education": [...],
    "experience": [...],
    "project": [...],
    "skills": ["Go", "MySQL", "Redis"],
    "self_evaluation": "...",
    "created_at": "2026-05-29T10:00:00Z"
  }
}
```

## 2. GET /api/resumes/current

获取当前用户的最新版本简历。如果没有简历，返回 data 为 null。

### 请求头

```
Authorization: Bearer <token>
```

### 成功响应（有简历）

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 2,
    "version_no": 2,
    "name": "张三",
    "...": "..."
  }
}
```

### 成功响应（无简历）

```json
{
  "code": 0,
  "message": "ok",
  "data": null
}
```

## 3. GET /api/resumes/detail

获取简历详情（含最新版本完整数据）。

### 请求头

```
Authorization: Bearer <token>
```

### 成功响应

同 `/api/resumes/current`，返回最新版本完整数据。

## 4. GET /api/resumes/versions

获取简历版本列表。

### 请求头

```
Authorization: Bearer <token>
```

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "versions": [
      {
        "version_no": 1,
        "name": "张三",
        "target_role": "后端开发工程师",
        "created_at": "2026-05-29T10:00:00Z"
      },
      {
        "version_no": 2,
        "name": "张三",
        "target_role": "后端开发工程师",
        "created_at": "2026-05-29T14:00:00Z"
      }
    ],
    "total": 2
  }
}
```

## 5. GET /api/resumes/versions/:versionNo

获取指定版本号的简历详情。

### 请求头

```
Authorization: Bearer <token>
```

### 路径参数

| 参数 | 类型 | 说明 |
|------|------|------|
| versionNo | int | 版本号 |

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "version_no": 1,
    "name": "张三",
    "...": "完整简历数据"
  }
}
```

### 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 版本不存在 | 42001 | version not found | 404 |

## 阶段 3 不做

- 多简历管理
- 文件上传（PDF/DOC）
- PDF 解析
- 自动生成优化版简历
- 删除版本
- 编辑历史版本
