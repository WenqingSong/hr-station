# 认证接口

> 最后更新：2026-05-29（阶段 3-1 创建阶段 3 核心业务后端 Mock 方案）

## 当前状态

阶段 3 方案已创建，接口已规划。阶段 3-3 将实现认证接口。

## 接口列表

| 方法 | 路径 | 说明 | 认证 | 实现任务 |
|------|------|------|------|---------|
| POST | `/api/auth/register` | 用户注册 | ❌ | 3-3 |
| POST | `/api/auth/login` | 用户登录 | ❌ | 3-3 |
| GET | `/api/auth/me` | 获取当前用户 | ✅ | 3-3 |

## 1. POST /api/auth/register

### 请求

```json
{
  "email": "string, 必填",
  "password": "string, 必填, 最少6位",
  "name": "string, 可选"
}
```

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "email": "demo@offer-catcher.com",
    "name": "Demo用户"
  }
}
```

### 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 邮箱已注册 | 41001 | email already registered | 400 |
| 参数错误 | 40001 | invalid parameter | 400 |

## 2. POST /api/auth/login

### 请求

```json
{
  "email": "string, 必填",
  "password": "string, 必填"
}
```

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": {
      "id": 1,
      "email": "demo@offer-catcher.com",
      "name": "Demo用户"
    }
  }
}
```

### 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 邮箱或密码错误 | 41002 | invalid email or password | 401 |
| 参数错误 | 40001 | invalid parameter | 400 |

## 3. GET /api/auth/me

### 请求头

```
Authorization: Bearer <token>
```

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "email": "demo@offer-catcher.com",
    "name": "Demo用户"
  }
}
```

### 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 未认证 | 40100 | unauthorized | 401 |
| Token 过期 | 40100 | unauthorized | 401 |

## 阶段 3 不做

- 刷新 token
- 角色权限
- 邮箱验证码
- 找回密码
- 退出登录接口（前端删除本地 token 即可）
