## 接口列表

| 方法 | 路径 | 说明 | 认证 | 实现任务 |
|------|------|------|------|---------|
| GET | `/api/jobs` | 岗位列表 | ✅ | 3-5 |

## 1. GET /api/jobs

获取岗位列表，从 `jobs` 表读取种子数据。支持简单查询参数。

### 请求头

```
Authorization: Bearer <token>
```

### 查询参数

| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | string | 可选，搜索关键词（匹配标题/描述） |
| city | string | 可选，城市筛选 |
| category | string | 可选，方向分类筛选 |

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "jobs": [
      {
        "id": 1,
        "title": "Java 后端开发工程师",
        "department": "技术部",
        "city": "北京",
        "category": "后端开发",
        "job_type": "校招",
        "description": "...",
        "requirements": "...",
        "skill_keywords": ["Java", "Spring", "MySQL"],
        "created_at": "2026-05-29T00:00:00Z"
      }
    ],
    "total": 10
  }
}
```

## 2. GET /api/jobs/:id

获取单个岗位的完整详情。

### 请求头

```
Authorization: Bearer <token>
```

### 路径参数

| 参数 | 类型 | 说明 |
|------|------|------|
| id | int | 岗位 ID |

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "title": "Java 后端开发工程师",
    "department": "技术部",
    "city": "北京",
    "category": "后端开发",
    "job_type": "校招",
    "description": "负责公司核心业务系统的后端开发...",
    "requirements": "1. 计算机相关专业本科及以上学历...",
    "skill_keywords": ["Java", "Spring", "MySQL", "Redis"],
    "created_at": "2026-05-29T00:00:00Z",
    "updated_at": "2026-05-29T00:00:00Z"
  }
}
```

### 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 岗位不存在 | 43001 | job not found | 404 |

## 阶段 3 不做
