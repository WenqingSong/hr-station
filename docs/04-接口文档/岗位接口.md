# 岗位接口

> 最后更新：2026-05-29（阶段 4-1.2.1 腾讯招聘信息接入方案）

## 1. 当前实现状态

岗位列表与岗位详情接口已实现（3-5）。岗位数据来自 `jobs` 表种子数据，支持简单筛选（keyword / city / category）。

## 2. 产品规则

1. 岗位数据来自 `jobs` 表种子数据
2. 阶段 3 不做真实岗位爬取
3. 阶段 3 不做岗位收藏
4. 阶段 3 不做岗位投递
5. 阶段 3 不做岗位推荐（3-6 单独实现）
6. 阶段 3 不做岗位匹配分析（3-7 单独实现）
7. 所有岗位接口需要 JWT 认证

## 3. 接口列表

| 方法 | 路径 | 说明 | 认证 | 实现任务 |
|------|------|------|------|---------|
| GET | `/api/jobs` | 岗位列表 | ✅ | 3-5 ✅ |
| GET | `/api/jobs/:id` | 岗位详情 | ✅ | 3-5 ✅ |

## 4. GET /api/jobs

获取岗位列表，从 `jobs` 表读取种子数据。支持简单查询参数。

### 请求头

```
Authorization: Bearer <token>
```

### 查询参数

| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | string | 可选，搜索关键词（匹配 title / department / description / requirements） |
| city | string | 可选，城市筛选（精确匹配） |
| category | string | 可选，方向分类筛选（精确匹配） |
| limit | int | 可选，每页数量，默认 20，最大 50 |
| offset | int | 可选，偏移量，默认 0 |

### 示例请求

```
GET /api/jobs?keyword=Go&city=深圳&limit=10&offset=0
Authorization: Bearer <token>
```

## 6. 查询参数

### keyword

- 匹配字段：title、department、description、requirements
- 匹配方式：LIKE %keyword%（不区分大小写取决于数据库排序规则）
- 不提供时不过滤

### city

- 匹配方式：精确匹配
- 不提供时不过滤

### category

- 匹配方式：精确匹配
- 不提供时不过滤

### limit

- 默认值：20
- 最大值：50
- 非法值使用默认值

### offset

- 默认值：0
- 不能小于 0
- 非法值使用默认值

## 7. 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 未认证 | 40100 | unauthorized | 401 |
| 非法岗位 ID | 40001 | invalid job id | 400 |
| 岗位不存在 | 43001 | job not found | 404 |
| 服务内部错误 | 50000 | internal server error | 500 |

## 8. 当前不支持能力

- 岗位收藏
- 岗位投递
- 复杂筛选（多维度组合、范围筛选、排序配置）
- 真实岗位爬取
- 岗位推荐（3-6 实现）
- 岗位匹配分析（3-7 实现）
- 版本对比（3-8 实现）
