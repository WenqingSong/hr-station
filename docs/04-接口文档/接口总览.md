## API 基础信息

- **Base URL**：`/api`（阶段 3 简化，不带 /v1）
- **认证方式**：JWT Bearer Token（阶段 3-3 实现）
- **响应格式**：JSON
- **统一响应结构**：阶段 2-3 ✅ 已确立

## 统一响应格式（阶段 2-3 ✅ 已确立）

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

### 错误响应

```json
{
  "code": 40001,
  "message": "invalid parameter",
  "data": null
}
```

### 当前 /healthz 响应示例

数据库正常时：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "service": "offer-catcher",
    "env": "local",
    "app": "ok",
    "database": "ok"
  }
}
```

数据库不可用时：

```json
{
  "code": 0,
  "message": "degraded",
  "data": {
    "service": "offer-catcher",
    "env": "local",
    "app": "ok",
    "database": "unavailable"
  }
}
```
