## 1. POST /api/jobs/:id/match

**这是阶段 3 的核心亮点接口**。深度分析用户简历与目标岗位的匹配情况，返回 JD-简历证据链、初筛风险、P0/P1 优化建议。

### 请求头

```
Authorization: Bearer <token>
```

### 路径参数

| 参数 | 类型 | 说明 |
|------|------|------|
| id | int | 岗位 ID |

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "match_score": 72,
    "screening_result": "likely_pass",
    "evidence_chain": [
      {
        "jd_requirement": "熟练掌握 Java 核心技术",
        "resume_evidence": "项目中使用 Java 开发后端服务",
        "match_status": "matched",
        "detail": "简历中体现了 Java 开发经验"
      },
      {
        "jd_requirement": "熟悉分布式系统设计",
        "resume_evidence": null,
        "match_status": "missing",
        "detail": "简历中未体现分布式系统相关经验"
      }
    ],

  }
}
```

### 初筛判断说明

| 值 | 说明 |
|---|------|
| `likely_pass` | 匹配度较高，预计可通过初筛 |
| `borderline` | 匹配度一般，初筛有风险 |
| `unlikely_pass` | 匹配度较低，初筛可能不通过 |

### 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 岗位不存在 | 43001 | job not found | 404 |
| 无简历 | 42002 | resume not found | 400 |

## 2. GET /api/resumes/versions/compare

对比两个简历版本的差异，用于简历版本迭代页。

### 请求头

```
Authorization: Bearer <token>
```

### 查询参数

| 参数 | 类型 | 说明 |
|------|------|------|
| from | int | 必填，旧版本号 |
| to | int | 必填，新版本号 |

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "from_version": {
      "version_no": 1,
      "name": "张三"
    },
    "to_version": {
      "version_no": 2,
      "name": "张三"
    },
    "score_change": {
      "from_score": 60,
      "to_score": 72,
      "change": "+12"
    },
    "field_changes": [
      {
        "field": "experience",
        "change_type": "added",
        "description": "新增了一段实习经历"
      },
      {
        "field": "project",
        "change_type": "modified",
        "description": "项目描述增加了量化指标"
      }
    ],
    "risk_changes": [
      {
        "risk": "项目描述缺乏量化指标",
        "from_severity": "medium",
        "to_severity": "resolved",
        "description": "项目描述已补充量化指标"
      }
    ],
    "suggestion_completion": [
      {
        "suggestion": "补充分布式系统相关学习经验或项目实践",
        "priority": "P0",
        "status": "completed",
        "description": "已在实习经历中补充相关内容"
      }
    ],
    "summary": "V2 相比 V1 在项目描述和实习经历方面有明显改进，匹配度从 60 提升至 72。建议继续优化技能描述。"
  }
}
```

### 字段变化类型

| 值 | 说明 |
|---|------|
| `added` | 新增字段内容 |
| `modified` | 修改了字段内容 |
| `removed` | 删除了字段内容 |

### 建议完成状态

| 值 | 说明 |
|---|------|
| `completed` | 已完成该建议 |
| `partially_completed` | 部分完成 |
| `not_started` | 未开始 |

### 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 版本不存在 | 42001 | version not found | 404 |
| 参数错误 | 40001 | invalid parameter | 400 |
