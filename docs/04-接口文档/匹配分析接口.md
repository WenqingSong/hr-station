# 匹配分析接口

> 最后更新：2026-05-29（阶段 3-8 实现简历版本对比 Mock 接口）

## 1. 当前实现状态

阶段 3-7 已完成，岗位匹配分析 Mock 接口已实现。`POST /api/jobs/{id}/match` 可基于当前用户简历版本和目标岗位生成 Mock 匹配分析结果。匹配分析包含 JD-简历证据链、初筛判断、风险点、P0/P1 优化建议、下一步建议和真实性提示。

版本对比接口（3-8 已实现）与匹配分析接口的关系：
- 匹配分析负责单个岗位与简历版本的匹配分析
- 版本对比负责两个简历版本之间的变化分析

## 2. 产品规则

1. 匹配分析是阶段 3 的核心亮点功能
2. 当前是 Mock 实现，不调用真实 LLM
3. 不读取 LLM_API_KEY
4. 匹配结果基于简历版本和岗位种子数据
5. 推荐结果可保存到 match_analyses 表作为快照
6. 不做岗位匹配分析之外的任何功能
7. 不自动生成优化版简历
8. 不修改用户简历

## 4. POST /api/jobs/{id}/match

### 请求头

```
Authorization: Bearer <token>
Content-Type: application/json
```

### 路径参数

| 参数 | 类型 | 说明 |
|------|------|------|
| id | uint64 | 岗位 ID（必填） |

### 请求体

请求体可以为空：

```json
{}
```

也可以指定简历版本：

```json
{
  "resume_version_no": 2
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| resume_version_no | int | 否 | 简历版本号，不传则使用最新版本 |

## 5. Mock 匹配逻辑

当前匹配分析使用简单规则打分，不调用真实 LLM：

| 规则 | 加分 | 说明 |
|------|------|------|
| target_city = job.city | +15 | 城市匹配 |
| target_role 与 category/title 相关 | +25/+8 | 方向匹配 |
| 技能交集（每项） | +5 | 最大 35 |
| 高技能重叠奖励 | +5 | 交集 > 5 |
| 关键技术同时匹配 | +3/项 | Go/MySQL/Redis/Docker/K8s 等，最大 15 |
| 有实习/工作经历 | +5 | |
| 有项目经历 | +5 | |

初筛判断：

| 分数 | 判断 | 说明 |
|------|------|------|
| 85-100 | `highly_likely` | 匹配度高 |
| 70-84 | `likely` | 匹配度较高 |
| 55-69 | `possible` | 匹配度一般 |
| 0-54 | `risky` | 匹配度低 |

证据链判断：

| 判断 | 值 | 说明 |
|------|---|------|
| 强匹配 | `strong_match` | 简历中有明确对应内容 |
| 部分匹配 | `partial_match` | 简历中有部分对应内容 |
| 缺失 | `missing` | 简历中没有对应内容 |

优化建议优先级：

| 优先级 | 说明 |
|--------|------|
| P0 | 必须优化，否则初筛风险高 |
| P1 | 建议优化，可提升匹配度 |

## 6. 匹配结果快照

每次匹配分析调用后，结果自动保存到 `match_analyses` 表，包含 user_id、resume_version_id、job_id、score、result_json。保存失败不阻断响应。

## 7. 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 未认证 | 40100 | unauthorized | 401 |
| 非法岗位 ID | 40001 | invalid job id | 400 |
| 非法请求体 | 40001 | invalid request body | 400 |
| 非法 resume_version_no | 40001 | invalid resume_version_no | 400 |
| 简历不存在 | 42001 | resume not found | 404 |
| 简历版本不存在 | 42001 | resume version not found | 404 |
| 岗位不存在 | 43001 | job not found | 404 |
| 方法不允许 | 40500 | method not allowed | 405 |
| 内部错误 | 50000 | internal server error | 500 |

## 8. 当前不支持能力

1. 不调用真实 LLM
2. 不读取 LLM_API_KEY
3. 不自动生成优化版简历
4. 不修改用户简历
5. 不做简历版本对比
6. 不做岗位收藏
7. 不做岗位投递
8. 不做异步分析（当前同步返回）
