## 1. POST /api/jobs/recommend

基于用户当前简历，返回 Mock 推荐岗位列表。

### 请求头

```
Authorization: Bearer <token>
```

### 请求

无请求体（使用当前用户的最新简历版本进行推荐）。

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "recommended_jobs": [
      {
        "job_id": 1,
        "title": "Java 后端开发工程师",
        "city": "北京",
        "category": "后端开发",
        "recommendation_reason": "简历中的 Java 和 Spring 技能与岗位要求高度匹配",
        "match_highlights": [
          "掌握 Java 核心技术",
          "有 Spring Boot 项目经验",
          "熟悉 MySQL 数据库"
        ],
        "risk_points": [
          "缺乏分布式系统经验"
        ],
        "priority": "strong_recommend"
      }
    ],
    "total": 3
  }
}
```

### 推荐等级说明

| 等级 | 值 | 说明 |
|------|---|------|
| 强推荐 | `strong_recommend` | 匹配度高，建议优先投递 |
| 推荐 | `recommend` | 有一定匹配度，值得尝试 |
| 可尝试 | `try` | 部分匹配，可以作为备选 |

### 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 无简历 | 42002 | resume not found | 400 |
