# 推荐接口

> 最后更新：2026-05-29（阶段 4-1.2.6 阶段 4-1.2 汇总）

## 1. 当前实现状态

岗位推荐 Mock 接口已实现（3-6）。推荐数据基于当前用户简历版本 + jobs 表种子数据，使用 Mock Agent 生成。推荐结果保存为快照到 recommendation_results 表。阶段 3 不接真实模型。

## 2. 产品规则

1. 当前是 Mock 推荐，不调用真实 LLM
2. 不读取 LLM_API_KEY
3. 推荐结果基于简历版本和岗位种子数据
4. 推荐结果可保存到 recommendation_results
5. 不做岗位匹配分析（3-7 单独实现）
6. 不自动生成优化版简历
7. 不做岗位收藏
8. 不做岗位投递
9. 所有推荐接口需要 JWT 认证

## 3. 接口列表

| 方法 | 路径 | 说明 | 认证 | 实现任务 |
|------|------|------|------|---------|
| POST | `/api/jobs/recommend` | 获取推荐岗位 Mock | ✅ | 3-6 ✅ |

## 4. POST /api/jobs/recommend

基于用户当前简历版本（或指定版本），返回 Mock 推荐岗位列表。

### 请求头

```
Authorization: Bearer <token>
Content-Type: application/json
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| resume_version_no | int | 否 | 简历版本号，不传则使用当前最新版本 |
| limit | int | 否 | 返回数量，默认 5，最大 5 |

### 请求示例

空 body（使用默认参数）：

```json
{}
```

指定简历版本：

```json
{
  "resume_version_no": 2,
  "limit": 3
}
```

## 5. 推荐等级说明

| 等级 | 值 | 分数范围 | 说明 |
|------|---|---------|------|
| 强推荐 | `strong_recommend` | ≥50 | 匹配度高，建议优先投递 |
| 推荐 | `recommend` | 30-49 | 有一定匹配度，值得尝试 |
| 可尝试 | `try` | <30 | 部分匹配，可以作为备选 |

## 6. Mock 推荐逻辑

当前推荐使用简单规则打分：

| 规则 | 加分 | 说明 |
|------|------|------|
| target_city 与岗位 city 一致 | +25 | 城市匹配 |
| target_role 与岗位 category/title 相关 | +30/+10 | 方向匹配 |
| 技能交集（每项） | +5 | 技能重叠 |
| 关键技术匹配 | +3/项 | Go/MySQL/Redis/Docker/K8s/分布式等 |
| 高技能重叠奖励 | +5 | 交集 > 6 |

## 7. 推荐结果快照

每次推荐调用后，推荐结果会保存到 `recommendation_results` 表：

| 字段 | 说明 |
|------|------|
| user_id | 当前登录用户 |
| resume_version_id | 使用的简历版本 ID |
| result_json | 推荐结果 JSON（recommended_jobs 数组） |
| created_at | 创建时间 |

## 8. 错误响应

| 场景 | code | message | HTTP 状态码 |
|------|------|---------|------------|
| 未认证 | 40100 | unauthorized | 401 |
| 非法请求体 | 40001 | invalid request body | 400 |
| 非法 resume_version_no | 40001 | invalid resume_version_no | 400 |
| 简历不存在 | 42001 | resume not found | 404 |
| 简历版本不存在 | 42001 | resume version not found | 404 |
| 无岗位数据 | 43001 | no jobs available | 404 |
| 服务内部错误 | 50000 | internal server error | 500 |

## 9. 当前不支持能力

- 岗位匹配分析（3-7 实现）
- 版本对比（3-8 实现）
- 真实 LLM 推荐
- 个性化推荐
- 复杂推荐算法
- 岗位收藏
- 岗位投递
- 自动生成优化版简历
