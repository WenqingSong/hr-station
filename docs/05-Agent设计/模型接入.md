## 接入策略

按照 ADR-003 决策，采用"先 Mock 后接模型"策略：

1. **阶段 1**：Mock Agent — 硬编码/规则引擎，跑通产品闭环
2. **阶段 2**：接入 LLM — 替换为真实大模型调用
3. **阶段 3**：优化迭代 — Prompt 调优、缓存、批处理

## 候选模型

| 模型 | 适用场景 | 说明 |
|------|---------|------|
| OpenAI GPT-4 | 通用文本理解 | 匹配分析、优化建议 |
| Claude | 长文本分析 | 简历提取、版本对比 |
| 国内模型 | 合规要求 | 备选方案 |

## 统一接口设计

```go
type Agent interface {
    Name() string
    Execute(ctx context.Context, input AgentInput) (AgentOutput, error)
```
