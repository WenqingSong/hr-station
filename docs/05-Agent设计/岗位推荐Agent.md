# 岗位推荐 Agent

## 当前状态

待设计（Mock 阶段）

## 功能

基于用户简历内容，推荐匹配的岗位：

- 分析简历中的技能、方向、经验水平
- 从岗位库中筛选匹配岗位
- 计算推荐等级（强推荐/推荐/可尝试）
- 生成推荐依据说明

## 输入

- 用户简历的提取结果（技能标签、方向、经验水平）

## 输出

- 推荐岗位列表
- 每个岗位的推荐等级
- 推荐依据说明

## Mock 实现

- 基于关键词的简单匹配
- 预定义的推荐结果
- 固定的推荐等级
