# 简历提取 Agent

## 当前状态

待设计（Mock 阶段）

## 功能

从用户提交的结构化简历中提取关键信息：

- 核心技能标签
- 求职方向
- 经验水平
- 关键成就提取
- 表达风险检测（模糊描述、空洞经历）

## 输入

- 结构化简历数据（基本信息、教育经历、工作经历、项目经历、技能、自我评价）

## 输出

- 提取的关键信息标签
- 求职方向推断
- 表达风险列表（具体指出哪些描述存在风险及原因）

## Mock 实现

- 基于规则的关键词匹配
- 预定义的表达风险模式检测
- 固定的提取结果模板
