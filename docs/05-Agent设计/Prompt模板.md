# Prompt 模板

> 最后更新：2026-05-29（阶段 3-6 实现岗位推荐 Mock 接口）

## 当前状态

阶段 3-6 已完成，岗位推荐 Mock Agent 已实现。阶段 3 Prompt 仅作为结构化 Mock 输出参考，不调用真实 LLM。推荐输出结构可作为阶段 4 Prompt 输出格式基础。阶段 4 再完善真实 Prompt。

## 模板管理规范

所有 Prompt 模板统一管理，便于版本控制和调优。

### 文件结构

```
server/internal/agent/prompts/
├── resume_extract.md     # 简历提取 Prompt（阶段 4）
├── job_recommend.md      # 岗位推荐 Prompt（阶段 4）
├── job_match.md          # 岗位匹配 Prompt（阶段 4）
└── version_compare.md    # 版本对比 Prompt（阶段 4）
```

### 模板格式

使用 Go template 语法，变量用 `{{.Variable}}` 标记。

## 设计原则

1. **不虚构**：Prompt 中明确要求不编造不存在的经历
2. **有证据**：所有结论必须基于简历中的真实内容
3. **可追溯**：每条建议都要指出对应的简历原文
4. **有建设性**：不仅指出问题，还给出改进方向

## 阶段 3 Prompt 定位

阶段 3 不使用真实 Prompt。Prompt 模板仅作为：

1. **结构化输出参考**：定义 Mock Agent 应返回的 JSON 结构
2. **接口契约文档**：明确各 Agent 的输入输出规范
3. **阶段 4 准备**：为阶段 4 真实 Prompt 提供基础框架

阶段 3 Mock Agent 实现时：
- 不读取 Prompt 文件
- 不调用 LLM API
- 不使用 `{{.Variable}}` 模板渲染
- 直接在 Go 代码中生成固定 JSON 或简单规则结果

## 各 Agent Prompt 方向（阶段 4 完善）

### 简历提取 Prompt

- 输入：结构化简历数据
- 输出：关键技能标签、求职方向推断、表达风险列表
- 阶段 3 暂不实现

### 岗位推荐 Prompt

- 输入：简历提取结果 + 岗位列表
- 输出：推荐岗位列表 + 推荐理由 + 推荐等级
- 阶段 4 完善

### 岗位匹配 Prompt

- 输入：简历数据 + 目标岗位 JD
- 输出：匹配分数 + 证据链 + 风险点 + 优化建议
- **核心 Prompt**，阶段 4 重点调优

### 版本对比 Prompt

- 输入：旧版本 + 新版本简历
- 输出：差异分析 + 改进评价 + 仍需改进
- 阶段 4 完善
