```
Prompt Render → fake LLM 返回合法 JSON → JSON parse 成功 → Schema validate 成功 → AgentStatus=success
```

- ✅ 测试覆盖：TestPipeline_MatchAnalysis_FirstSuccess / TestPipeline_Recommendation_FirstSuccess / TestPipeline_ResumeOptimization_FirstSuccess

### 2. JSON parse 异常 + repair 成功

```
fake LLM 返回非法 JSON → JSON parse 失败 → JSONRepairAgent repair once → repair output parse 成功 → schema validate 成功 → AgentStatus=repaired
```

- ✅ 测试覆盖：TestPipeline_ParseFailed_RepairSuccess

### 3. Schema validate 异常 + repair 成功

```
fake LLM 返回合法 JSON，但不符合 Schema → schema validate 失败 → JSONRepairAgent repair once → repair output validate 成功 → AgentStatus=repaired
```

- ✅ 测试覆盖：TestPipeline_SchemaValidateFailed_RepairSuccess

### 4. repair 失败 + fallback_required

```
fake LLM 返回非法 JSON → repair output 仍非法或 schema 不合法 → AgentStatus=fallback_required → FallbackRequired=true
```

- ✅ 测试覆盖：TestPipeline_ParseFailed_RepairFailed

### 5. LLM 调用失败 + fallback_required

```
fake LLM 返回 error → AgentStatus=fallback_required → ErrorCode 可识别
```

- ✅ 测试覆盖：TestPipeline_LLMError_FallbackRequired / TestPipeline_LLMStructuredError_RateLimit / TestPipeline_LLMDisabled

### 6. Prompt / Schema 加载失败

```
unknown prompt 或 unknown schema → fallback_required 或明确错误
```

- ✅ 测试覆盖：TestPipeline_PromptLoadFailed / TestPipeline_SchemaLoadFailed
