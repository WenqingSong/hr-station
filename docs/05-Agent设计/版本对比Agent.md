# 版本对比 Agent

## 当前状态

待设计（Mock 阶段）

## 功能

对比两个简历版本的差异：

- 逐字段对比差异
- 分析变化原因
- 评估改进效果
- 指出仍需改进的地方

## 输入

- 版本 A 简历数据
- 版本 B 简历数据

## 输出

- 字段级差异列表
- 变化原因分析
- 改进效果评估
- 仍需改进的建议

## Mock 实现

- 基于字段值的简单对比
- 预定义的改进效果评价
- 固定的改进建议
