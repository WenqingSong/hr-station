# 岗位匹配 Agent

## 当前状态

待设计（Mock 阶段）

## 功能

深度分析用户简历与目标岗位的匹配情况：

- 生成匹配度评分
- 构建 JD-简历证据链（逐条对照岗位要求与简历经历）
- 检测真实性风险
- 给出优化建议

## 输入

- 用户简历数据
- 目标岗位 JD

## 输出

- 匹配度评分（0-100）
- 证据链列表（JD 要求 → 简历对应内容 → 匹配/缺失）
- 真实性保护提示
- 优化建议列表
- 下一步行动建议

## Mock 实现

- 基于关键词匹配的伪评分
- 预定义的证据链模板
- 固定的优化建议
