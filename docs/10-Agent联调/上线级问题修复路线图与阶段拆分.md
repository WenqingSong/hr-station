## 四、P1/P2 修复优先级

### 第一优先级 — 登录态闭环

```
P1-1: 登录态 / token / 用户态不完整
```

**原因**：没有用户态，就无法判断"我的简历""我的保存""我的 Agent 分析"是否真实属于当前用户。这是所有"真实用户数据"的前置条件。

### 第二优先级 — 简历数据真实化

```
P1-2: 简历页硬编码用户数据
P1-3: 简历保存仅是演示态
```

**原因**：简历是 Agent 分析的输入源；简历数据不真实，后续 Agent 上下文也不真实。

### 第三优先级 — Agent 上下文真实化

```
P1-4: Agent 页面上下文仍有 mock 风险
```

**原因**：Agent 主结果已接后端，但上下文如果仍是 mock，会造成用户看到的信息与真实请求不一致。

### 第四优先级 — 真实 LLM 验证

```
P1-5: 真实 LLM 有 Key 场景未验证
```

**原因**：当前 Agent 可 fallback，但真实 AI 产品必须验证真实 LLM 链路。

### 第五优先级 — 上线文案与测试页清理

```
P2-1: 演示标签/演示态文案
P2-2: StyleGuide/Test 页面确认
P2-3: 简历比较页对比详情硬编码
P2-4: meta/trace/latency 观测信息
P2-5: 错误场景真实环境补验
```

**原因**：前面真实链路完成后，再统一清理上线文案更稳。

## 五、问题依赖关系矩阵

| 问题 | 依赖什么 | 为什么 | 是否必须先做 |
|------|------|------|:--:|
| P1-1 登录态 | 无前置依赖 | 登录态是整个系统的认证基础 | **是** |
| P1-2 简历硬编码 | P1-1 登录态 | 用户态实现后才能区分"我的数据" | **是**（需等P1-1完成） |
| P1-3 简历保存 | P1-1 登录态 + P1-2 数据源 | 保存需要用户ID归属 + 真实数据源 | **是**（需等P1-1/P1-2完成） |
| P1-4 Agent上下文mock | P1-2 简历真实数据 + P1-3 真实保存 | Agent 上下文依赖真实简历数据 | **是**（需等P1-2/P1-3完成） |
| P1-5 真实LLM验证 | 无强依赖（独立验证） | LLM Key 是独立配置 | 否（但建议Agent上下文真实化后一起回归） |
| P2-1 演示标签 | P1-1~P1-5 全部完成 | 真实链路完成后统一清理更稳 | 否 |
| P2-2 测试页确认 | P2-1 同步 | 同类工程清理 | 否 |
| P2-3 比较详情硬编码 | P1-2/P1-3 简历数据 | 需要后端比较数据 | 否 |
| P2-4 meta/trace | 无强依赖 | 可独立增强 | 否 |
| P2-5 错误场景补验 | P1-5 真实LLM | 真实LLM验证后才能做真实环境错误验证 | 否 |

### 依赖链摘要

```
P1-1(登录态) → P1-2(简历硬编码清理) → P1-3(简历真实保存) → P1-4(Agent上下文真实化)
                                                                   ↓
                                               P1-5(真LLM验证) ← 可与P1-4并行
                                                                   ↓
                                               P2-1/P2-2/P2-3(文案/清理) → P2-4/P2-5(补验)
```

### 关键判断

| 判断 | 结论 |
|------|------|
| 登录态是否是简历真实保存的前置 | **是** — 后端 /api/resumes/* 均需 JWT Bearer token |
| 登录态是否是用户数据隔离的前置 | **是** — 后端 AuthMiddleware 提取 userID 后查询数据 |
| 简历真实保存是否是清理硬编码简历数据的前置 | **是** — 没有真实保存链路，无法区分"现在是演示态还是真实态" |
| 简历真实数据是否是 Agent 页面上下文真实化的前置 | **是** — Agent 上下文的简历数据必须来自真实 API |
| 真实 LLM Key 是否必须在 Agent 回归前完成 | **是** — 但可与 Agent 上下文真实化后的回归阶段合并 |
| 演示标签清理是否应该等真实链路完成后再做 | **是** — 避免过早清理后真实链路变更再次引入 |

| 用户态 | 数据隔离依赖用户态，无用户态 = 无数据安全 |
| 简历保存真实持久化 | 用户核心操作，不能永远演示态 |
| 核心用户数据硬编码 | 用户看到的如果不是自己的数据，产品无意义 |
| 核心 Agent 上下文 mock | 上下文与请求不一致 = 展示欺诈 |
| 真实 LLM 验证（如果产品定位是 AI 求职助手） | 如果只有 mock fallback，就不是 AI 产品 |
