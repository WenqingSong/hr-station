# Demo验收清单

## 1. 验收目标

验证「Offer 捕手」Demo 可完整演示主链路，包括：

- 用户注册登录
- 添加简历
- 岗位列表与推荐
- 岗位匹配分析
- 简历版本迭代

## 7. 主链路验收

### 主链路流程

```
登录 → 添加简历 → 岗位列表 → 岗位推荐 → 岗位匹配分析 → 添加新版本 → 简历版本迭代
```

| 编号 | 步骤 | 验收标准 | 状态 |
|------|------|---------|------|
| FL-01 | 用户注册登录 | 注册后可登录，登录后跳转工作台 | ⬜ |
| FL-02 | 添加简历 | 填写简历后保存成功，可在详情页查看 | ⬜ |
| FL-03 | 岗位列表 | 可浏览岗位列表，查看岗位详情 | ⬜ |

| FL-06 | 添加新版本 | 根据建议修改后添加新版本，版本号递增 | ⬜ |
| FL-07 | 简历版本迭代 | 可查看版本列表，可对比版本差异和匹配度变化 | ⬜ |

## 10. 不通过条件

出现以下任一情况，验收不通过：

1. 主链路无法走通（登录 → 匹配分析 → 版本迭代）
2. 前端白屏或 JS 报错导致页面不可用
3. 后端 API 返回 500 错误
4. 数据库连接失败
5. Docker 无法启动
6. Mock 数据结构与前端类型不匹配导致渲染异常
7. 核心文档缺失（说明书、项目状态、下一步任务）
