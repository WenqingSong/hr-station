## 6. 样式规范冻结

* 页面最大宽度：核心业务页 `max-w-[1440px]`（JobList、JobDetail、Recommend、Match、Optimize），简历对比 `max-w-[1360px]`，简历管理 `max-w-[960px]`
* 页面 padding：`px-6 md:px-8 py-6`（主流模式）
* PageHeader 结构：标题 h1/h2 + 描述 p + 操作按钮区（各页自行实现，差异可接受）
* 主按钮：`<Button>` default variant（`bg-[#0052D9] text-white`）
* 次按钮：`<Button variant="outline">`（`border-gray-200`）
* Card 语义：页面内联 `bg-white border rounded-lg`，未使用 ui/Card
* Badge 语义：`variant="secondary"` 用于次要标签，`variant="blue"` 用于筛选标签，`variant="green"` 用于成功状态
* Loading 语义：`<PageLoading message="正在加载…" />`（图标 + 文案）
* Empty 语义：`<PageEmpty title="…" description="…" />`（图标 + title + description + 可选 action）
* Error 语义：`<PageError title="…" description="…" />`（图标 + title + description + 可选 action）
