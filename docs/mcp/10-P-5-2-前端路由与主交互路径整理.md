## 4. Navbar / 用户态整理

| 项 | 修改前 | 修改后 | 说明 |
| - | --- | --- | -- |
| 登录入口 | Navbar 始终显示"登录"（`<Link to="/login">`） | 根据 `getAuthToken()` 动态判断：无 token 显示"登录"，有 token 显示"退出" | 通过 `authStorage.getAuthToken()` + `clearAuthToken()` 实现 |
| 退出入口 | 不存在 | 登录后显示"退出"按钮，点击清除 token 并导航到首页 | 引入 `useNavigate` + `clearAuthToken()` |
| 推荐岗位入口 | Navbar 无"推荐岗位"链接 | 新增 `<Link to="/recommend">` "推荐岗位"入口，使用 `Sparkles` 图标 | 补齐产品闭环主入口 |
| 用户状态监听 | 不存在 | `useEffect` + `storage` event 监听跨 tab 同步 | 最小实现，不依赖后端 me 接口 |
| 登录前显示 | "登录" + "我的简历" | "登录" + "推荐岗位" + "我的简历" | — |
| 登录后显示 | "登录" + "我的简历" | "推荐岗位" + "我的简历" + "退出" | — |
| 是否依赖后端 me 接口 | 否 | 否 | 仅依赖 localStorage token 存在性判断 |
| 是否新增接口 | 否 | 否 | 不新增后端接口 |
