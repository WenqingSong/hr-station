## 7. 空态 / 错误态说明

| 场景 | 当前展示 | 是否会显示 mock |
| -- | ---- | ---------- |
| 版本列表加载中 | "正在加载简历版本…" | 否 |
| 版本列表加载失败 | "简历版本数据加载失败，请稍后重试。" + "返回我的简历"链接 | 否 |
| 版本列表为空 | "暂无可比较的简历版本" + 返回链接 | 否 |
| 仅一个版本 | "仅有一个简历版本，无法进行比较。请先创建更多版本。" + 返回链接 | 否 |
| 未选择两个不同版本 | 不触发对比（useEffect 判断 version_no 相同则 return） | 否 |
| 对比生成中 | "正在生成版本对比…" | 否 |
| 对比接口失败 | "版本对比接口暂时不可用，请稍后重试。" + 返回链接 | 否 |
| 对比结果为空 | "暂无可展示的对比数据" | 否 |
| 字段变化为空 | "两个版本之间未检测到显著差异。" | 否 |
| 未登录或 token 失效 | 接口需 JWT 鉴权，401 由 API client 统一处理 | 否（不会 fallback） |
