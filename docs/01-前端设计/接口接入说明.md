# 接口接入说明

## 当前状态

待实施（当前全部使用 Mock 数据）

## 现状

- 所有页面使用硬编码 Mock 数据
- Mock 数据直接写在各页面组件文件中（如 `JOBS`、`RECOMMENDATIONS`、`VERSIONS` 等数组）
- 无 API Client、无 axios/fetch 封装、无环境变量配置

## 接入方案

### 1. 创建 API 基础层

```
web/src/api/
├── client.ts      # axios 实例，baseURL 从环境变量读取
├── types.ts       # 通用响应类型
└── modules/
    ├── auth.ts    # 认证相关
    ├── resume.ts  # 简历相关
    ├── job.ts     # 岗位相关
    ├── recommend.ts  # 推荐相关
    └── match.ts   # 匹配分析相关
```

### 2. 环境变量

```env
VITE_API_BASE_URL=http://localhost:8080/api
```

### 3. 接入步骤

1. 安装 axios（如未安装）
2. 创建 `web/src/api/client.ts`
3. 创建各模块 API 函数
4. 在页面中替换 Mock 数据为 API 调用
5. 添加加载状态和错误处理

### 4. 各页面需接入的接口

| 页面 | 需要的接口 |
|------|-----------|
| 登录页 | 登录、注册 |
| 工作台 | 最近分析记录 |
| 简历页 | 获取简历列表 |
| 添加简历页 | 创建/更新简历 |
| 简历详情页 | 获取简历详情、AI 提取结果 |
| 版本迭代页 | 获取版本列表、版本对比 |
| 岗位列表页 | 搜索岗位、获取岗位详情 |
| 岗位推荐页 | 获取推荐列表 |
| 匹配分析页 | 获取匹配分析结果 |
