## 页面清单

### /login - 登录页

- **文件**：`web/src/app/pages/LoginPage.tsx`
- **功能**：登录/注册表单，示例账号入口
- **状态**：有登录/注册两种模式

### /dashboard - 工作台

- **文件**：`web/src/app/components/HomeContent.tsx`
- **功能**：3 个功能入口卡片（简历管理、岗位探索、匹配分析）+ 最近分析记录状态栏
- **状态**：有/无分析记录两种状态

### /resume - 我的简历

- **文件**：`web/src/app/pages/ResumePage.tsx`
- **功能**：简历状态总览 + 操作入口 + 最近分析摘要
- **状态**：有/无简历两种状态

### /resume/add - 添加简历

- **文件**：`web/src/app/pages/AddResumePage.tsx`
- **功能**：结构化表单录入简历
- **字段**：基本信息、求职意向、教育经历、工作经历、项目经历、技能、自我评价
- **状态**：首次/非首次两种状态

### /resume/detail - 简历详情

- **文件**：`web/src/app/pages/ResumeDetailPage.tsx`
- **功能**：简历内容展示 + AI 信息提取 + 表达风险
- **状态**：有/无简历两种状态

### /resume/versions - 版本迭代

- **文件**：`web/src/app/pages/VersionsPage.tsx`
- **功能**：版本列表 + 版本对比 + 变化原因 + 仍需改进
- **状态**：有/无版本两种状态

### /jobs - 岗位列表

- **文件**：`web/src/app/pages/JobsPage.tsx`
- **功能**：岗位搜索 + 列表 + 侧栏操作面板 + 详情抽屉

### /jobs/recommend - 岗位推荐

- **文件**：`web/src/app/pages/RecommendPage.tsx`
- **功能**：推荐依据 + 推荐等级说明 + 推荐卡片 + 详情抽屉
- **状态**：有/无简历两种状态

### /jobs/match/:jobId - 匹配分析

- **文件**：`web/src/app/pages/MatchPage.tsx`
- **功能**：匹配总览 + JD-简历证据链表格 + 真实性保护 + 优化建议 + 下一步
- **状态**：无简历/无岗位/正常三种状态
