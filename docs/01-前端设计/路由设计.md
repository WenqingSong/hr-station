# 路由设计

## 1. 路由设计目标

- 将 useState 页面切换改造为真实 URL 路由
- 支持浏览器刷新、前进后退、链接分享
- 为每个页面提供独立的 URL 入口
- 支持登录态保护和空状态处理

## 2. 页面路由表

| 路由路径 | 页面组件 | 说明 |
|---------|---------|------|
| `/` | HomeContent | 首页 / 工作台 |
| `/login` | LoginPage | 登录页 |
| `/resume` | ResumePage | 我的简历页 |
| `/resume/add` | AddResumePage | 添加简历页 |
| `/resume/detail` | ResumeDetailPage | 简历详情页 |
| `/resume/versions` | VersionsPage | 简历版本迭代页 |
| `/jobs` | JobsPage | 岗位列表页 |
| `/jobs/recommend` | RecommendPage | 岗位推荐页 |
| `/jobs/match/:jobId` | MatchPage | 岗位匹配分析页 |

## 3. 路由与页面组件映射

```
src/
├── app/
│   ├── App.tsx              # RouterProvider + 路由配置
│   ├── layouts/
│   │   └── AppLayout.tsx    # 统一布局（顶部导航 + 内容区）
│   └── pages/
│       ├── LoginPage.tsx
│       ├── HomePage.tsx     # HomeContent 包装
│       ├── ResumePage.tsx
│       ├── AddResumePage.tsx
│       ├── ResumeDetailPage.tsx
│       ├── VersionsPage.tsx
│       ├── JobsPage.tsx
│       ├── RecommendPage.tsx
│       └── MatchPage.tsx
```

路由配置示意：

```tsx
const router = createBrowserRouter([
  { path: "/login", element: <LoginPage /> },
  {
    path: "/",
    element: <AppLayout />,   // 需登录
    children: [
      { index: true, element: <HomePage /> },
      { path: "resume", element: <ResumePage /> },
      { path: "resume/add", element: <AddResumePage /> },
      { path: "resume/detail", element: <ResumeDetailPage /> },
      { path: "resume/versions", element: <VersionsPage /> },
      { path: "jobs", element: <JobsPage /> },
      { path: "jobs/recommend", element: <RecommendPage /> },
      { path: "jobs/match/:jobId", element: <MatchPage /> },
    ]
  }
]);
```

## 4. 页面跳转关系

```
/login → /（登录成功后跳转）

/（首页）
  ├→ /resume/add（添加简历）
  ├→ /resume/detail（查看简历详情）
  ├→ /jobs（浏览岗位）
  └→ /jobs/recommend（查看推荐）

/resume
  ├→ /resume/add（添加/修改简历）
  ├→ /resume/detail（查看详情）
  └→ /resume/versions（查看版本）

/jobs
  └→ /jobs/match/:jobId（进入匹配分析）

/jobs/recommend
  └→ /jobs/match/:jobId（进入匹配分析）

/jobs/match/:jobId
  ├→ /resume/add（根据建议修改简历）
  └→ /resume/versions（查看版本迭代）
```

## 5. 需要登录保护的页面

| 路由 | 需要登录 | 说明 |
|------|---------|------|
| `/login` | ❌ 不需要 | 登录页本身不需要保护 |
| `/` | ✅ 需要 | 工作台 |
| `/resume` | ✅ 需要 | 简历相关 |
| `/resume/add` | ✅ 需要 | 简历相关 |
| `/resume/detail` | ✅ 需要 | 简历相关 |
| `/resume/versions` | ✅ 需要 | 简历相关 |
| `/jobs` | ✅ 需要 | 岗位相关 |
| `/jobs/recommend` | ✅ 需要 | 岗位相关 |
| `/jobs/match/:jobId` | ✅ 需要 | 岗位相关 |

**登录保护规则**：
- 未登录用户访问受保护页面 → 重定向到 `/login`
- 已登录用户访问 `/login` → 重定向到 `/`
- Demo 阶段可使用示例账号或本地 token 兜底

## 6. 当前缺口

| 缺口 | 说明 |
|------|------|
| react-router 未配置 | 已安装 v7.13.0 但未使用 |
| 无 AppLayout | 当前无统一布局组件与路由绑定 |
| 无路由守卫 | 无登录态判断逻辑 |
| jobId 参数缺失 | MatchPage 当前不接收 jobId 参数 |
| 无 404 页面 | 未处理未匹配路由 |
| 底部浮动预览按钮 | Demo 预览用，路由化后需移除 |

## 7. 后续实现建议

1. 创建 `AppLayout` 组件，包含顶部导航和内容区
2. 使用 `createBrowserRouter` + `RouterProvider` 配置路由
3. 创建 `AuthGuard` 组件，包裹需要登录的路由
4. MatchPage 从 URL 参数获取 `jobId`
5. 添加 404 兜底路由
6. 移除 App.tsx 中的 useState 页面切换和底部浮动按钮
7. 各页面使用 `useNavigate` / `Link` 替代手动切换
