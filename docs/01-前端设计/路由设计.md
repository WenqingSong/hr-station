# 路由设计

## 当前状态

待实施（前端当前无真实路由）

## 规划路由表

| 路由路径 | 页面组件 | 说明 |
|---------|---------|------|
| `/login` | LoginPage | 登录/注册 |
| `/` 或 `/dashboard` | HomeContent | 工作台/首页 |
| `/resume` | ResumePage | 简历总览 |
| `/resume/add` | AddResumePage | 添加简历 |
| `/resume/detail` | ResumeDetailPage | 简历详情 |
| `/resume/versions` | VersionsPage | 版本迭代 |
| `/jobs` | JobsPage | 岗位列表 |
| `/jobs/recommend` | RecommendPage | 岗位推荐 |
| `/jobs/match/:jobId` | MatchPage | 匹配分析 |

## 路由守卫

- 未登录用户访问除 `/login` 外的页面 → 重定向到 `/login`
- 已登录用户访问 `/login` → 重定向到 `/`
- `/jobs/match/:jobId` 需要有效 jobId，否则重定向到 `/jobs`

## 实施方案

- 使用已安装的 react-router v7
- 采用 `createBrowserRouter` + `RouterProvider` 模式
- 页面组件复用现有组件，仅移除底部浮动预览按钮
