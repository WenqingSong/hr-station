## 6. 当前前端风险

| 风险 | 严重度 |
|------|--------|
| 无真实路由，URL 不变，无法刷新/分享/前进后退 | 🔴 高 |
| 无 API 对接层，所有数据硬编码 | 🔴 高 |
| inline style 比重极大，不利于迭代 | 🔴 高 |
| 无 tsconfig.json | 🟡 中 |
| 无 lock 文件，依赖版本不确定 | 🟡 中 |
| react/react-dom 为 peerDependencies (optional) | 🟡 中 |
| MUI 冗余依赖 | 🟡 中 |
| shadcn CSS 变量与 tokens.ts 并存 | 🟡 中 |

## 7. 后续工程化建议

按优先级排序：

1. **接入 react-router**：实现真实 URL 路由，替换 useState 页面切换
2. **添加 tsconfig.json**：完善 TypeScript 编译配置
3. **创建 API 对接层**：axios 封装 + 环境变量 + API Client 模块
4. **添加 ESLint + Prettier**：代码风格统一
5. **清理冗余依赖**：移除 MUI、整理 shadcn 组件
6. **收敛 inline style**：迁移到 TailwindCSS 类或 tokens 系统
7. **生成 lock 文件**：锁定依赖版本
