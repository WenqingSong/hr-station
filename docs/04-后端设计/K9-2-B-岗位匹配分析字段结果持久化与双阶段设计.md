## 2. 核心输入

| 参数 | 来源 | 说明 |
|------|------|------|
| `resume_id` | URL query + profile | 必须属于当前用户 |
| `job_id` | URL path + DB | 目标岗位 |
| `generation_tier` | POST body | fast / quality |

## 3. Fast / Deep 阶段设计

| 阶段 | 定位 | 输出 |
|------|------|------|
| **Fast** | 快速判断是否值得投递 | score + level + summary + 2 fit + 1 gap + 1 suggestion |
| **Deep** | 深度分析匹配关系与投递策略 | score + level + fit + evidence + requirements + gaps + risks + improvements + talking_points + strategy |

## 5. match_score 规则

| 分数段 | match_level | priority |
|--------|-------------|-----|
| 90-95 | 强匹配，优先投递 | strong |
| 80-89 | 高匹配，建议重点投递 | high |
| 70-79 | 可尝试，需要补强 | try |
| 60-69 | 备选参考，不建议优先 | backup |
| <60 | 不建议投递 | not_recommended |

评分基于：ResumeProfile dominant + CandidateTags + JobDirection + SkillOverlap + EvidenceStrength - GapPenalty - ConflictCap。

## 6. match_analyses 表结构

```sql
ALTER TABLE match_analyses
  ADD COLUMN generation_tier VARCHAR(20) NOT NULL DEFAULT 'fast',
  ADD COLUMN generated_by VARCHAR(50) NOT NULL DEFAULT 'mock_agent',
  ADD COLUMN status VARCHAR(20) NOT NULL DEFAULT 'ready',
  ADD COLUMN profile_type VARCHAR(20) NULL,
  ADD COLUMN profile_dominant_profile VARCHAR(50) NULL,
  ADD COLUMN updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  ADD INDEX idx_match_resume_job_created (resume_id, job_id, created_at),
  ADD INDEX idx_match_user_resume_job_created (user_id, resume_id, job_id, created_at);
```
