# K9-3-B: Resume Optimization New Architecture Design

## 1. Break from Old Design

| Old | New Decision |
|-----|-------------|
| POST/GET /api/resumes/optimize | POST /api/resumes/{resume_id}/optimization |
| latest by user_id only | latest by user_id+resume_id+mode |
| target_job required | Three modes: general/target_direction/target_job |
| No generation_tier in DB | DB metadata: tier/gen_by/status/profile |
| No ResumeProfile | Must consume ResumeProfile |
| No match_analyses reuse | target_job mode reuses match_analyses |
| AIThinkingLoading | AgentStepLoadingOverlay |

## 2. Three Optimization Modes

| Mode | Required Input | Optional | Use Case |
|------|---------------|----------|----------|
| **general** | resume_id | — | Generic resume improvement |
| **target_direction** | resume_id, target_direction | — | Optimize for a career direction |
| **target_job** | resume_id, job_id | — | Optimize for a specific job application |

## 3. New API

### POST /api/resumes/{resume_id}/optimization

Request: `{optimization_mode, generation_tier, target_direction?, job_id?}`

### GET /api/resumes/{resume_id}/optimization/latest

Query: `?optimization_mode=X&target_direction=Y&job_id=Z`

Response: `{has_result, optimization_id, generation_tier, ...metadata, result}`

## 4. DB Schema Extension

```sql
ALTER TABLE resume_optimization_results ADD
  optimization_mode VARCHAR(30) NOT NULL DEFAULT 'general',
  generation_tier VARCHAR(20) NOT NULL DEFAULT 'fast',
  generated_by VARCHAR(50) NOT NULL DEFAULT 'mock_agent',
  status VARCHAR(20) NOT NULL DEFAULT 'ready',
  profile_type VARCHAR(20) NULL,
  profile_dominant_profile VARCHAR(50) NULL,
  target_direction VARCHAR(50) NULL,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP;

-- Indexes
CREATE INDEX idx_opt_user_resume_mode ON resume_optimization_results (user_id, resume_id, optimization_mode, created_at);
CREATE INDEX idx_opt_resume_job ON resume_optimization_results (resume_id, job_id, created_at);
CREATE INDEX idx_opt_resume_direction ON resume_optimization_results (resume_id, target_direction, created_at);
```

Latest query: `WHERE user_id=? AND resume_id=? AND optimization_mode=? AND status='ready' ... ORDER BY created_at DESC LIMIT 1`
