## 3. Confidence（0-3）

- 单关键词命中 +1，多同类 +2，项目/实习中有描述 +2，研究方向/论文/实验室/实习岗位强相关 +3
- 技能列表短 token（go/redis/docker）最多 +1，除非有项目证据
- 长中文研究术语（推荐系统/CTR/用户行为建模）可 +3

## 7. 冲突规则

- algorithm_research 主画像下 backend_service 岗位不得标记 >=high
- dominant_profile 与岗位主方向不同 → label 降级
- 短工程 token 不能覆盖研究/算法主标签

## 8. 评分公式

```
final = 50 + tag_matrix(≤35) + evidence(≤20) + education(≤8) + project/intern(≤12) - risk_penalty(≤20) - conflict_penalty(≤15)
```

Top1-5 分差 ≥ 8。同分用 evidence_strength 打破。

## 9. Label 升级

Label = f(score, direction_fit, tag_fit, risk_level)  
≥90 + strong+strong+low → 强匹配  
≥80 + ≥medium+medium → 高匹配  
≥70 → 可尝试  
≥60 → 备选

## 10. Judge 升级

检查 dominant_profile × top1_direction, top3 algorithm count, label←→risk conflict, 短 token 误导
